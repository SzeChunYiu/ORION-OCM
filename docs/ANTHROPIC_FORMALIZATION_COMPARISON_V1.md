# OCM and the September 2026 FLT formalization

Read on 2026-09-05 in response to the operator's linked post. This is a design
comparison, not a novelty receipt or an independent replay of the external proof.

Anthropic reports a shared dependency graph, searchable theorem descriptions,
statement/proof separation and kernel verification. Its released artifact builds
on Mathlib and earlier formalization projects. A pre-existing mathematical library
therefore is not, by itself, an OCM distinction. See the
[research account](https://www.anthropic.com/research/formalizing-fermats-last-theorem)
and [released proof](https://github.com/anthropics/fermats-last-theorem).

The relevant OCM hypothesis is that a persistent space can retain not only
propositions but also procedures, learning methods, support dependencies,
counterexamples and organization decisions. Success on a new task should add
reusable structure, while withdrawn assumptions should reopen exactly the
dependent capabilities. That is a testable architecture proposal. Neither
``having a graph`` nor ``using a pre-existing space`` establishes its novelty.

| Requirement | OCM state in runtime V4 | Remaining demonstration |
|---|---|---|
| Durable reusable knowledge | User reports, checked arithmetic methods and generators survive restart | Broad mathematical library ingestion with exact statement identity |
| Independent correctness | Polynomial coefficient checker; existing formal-proof channels | Live proof generation and kernel replay over substantially harder targets |
| Dependency revision | Warrant support and revocation disable dependent reuse | Large proof-library revision and recovery under matched budgets |
| Learning to search | Repeated checked fragments yield bounded search generators | Improvement on prospectively fixed unseen problem families |
| Organization evolves | Existing organization and governed self-change mechanisms | Learned organization that beats the strongest matched parent |
| Unsolved mathematics | No such solution established | New proof of an independently identified open target, externally checked |

“Pre-existing space” should mean an initialized, reusable substrate, not that all
future answers are already stored. New statements, methods and relations can be
admitted; a representation change needs its own preservation and reopening
contract. The checker and adoption authority are outside the learner's power to
redefine as a shortcut to success.

The concrete comparison to develop is a shared theorem library and identical
search/checking budget across (1) a strong theorem-search parent, (2) that parent
with durable verified-result reuse, and (3) the OCM space plus learned method
selection/organization. Freeze task identities, available lemmas, checker and
axioms, data exposure, total search/verification cost and refusal semantics before
outcomes. Count failures, all attempted tasks and repeated-run dependence.

First test known proof reconstruction; then unseen compositions; then learning
and reuse across problem families with revocation; only then a prospective open
target. Mathematical correctness, generalization, efficiency and scientific
novelty are different outcomes and must be reported separately. This comparison
has not been run. The current 32-case spelling assessment and arithmetic demo do
not supply evidence for frontier theorem proving.
