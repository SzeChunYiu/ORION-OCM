# Failure continuation and scientific deadline

No scientific arm, process, phase, row or seed is retried. Predeclared generator draws
after a syntactic/identity rejection are the generator algorithm, not outcome retries.
Authored engineering controls before the scientific seal may diagnose and repair defects.
After a scientific outcome, a separately registered successor may investigate a failure;
it never overwrites, completes by substitution, or relabels the original run.

Global abort takes precedence over this table: actual invalid accepted answer,
forged accepted use, violated semantic/restart/revision control, source/binary/input
custody drift, containment failure, memory termination, or scientific deadline.
Stop further scientific dispatch and retain all reached/unreached rows. A violated
semantic/control obligation is SEMANTIC_CONTROL_FAILED; an environmental failure
without an observed semantic/control violation is CANNOT_CHECK. Preserve both if both occur.
Algorithmic refusal/exception is unavailable execution, not a false semantic answer.

| Phase | Operational failure while global controls and time remain |
| --- | --- |
| Generation | At the split's draw limit, retain every missing slot. Skip remaining partitions/solve phases of that episode as dependency unavailable; proceed to the next episode. |
| A training/mining/development/admission | Stop the failed A at its first refused/missing/unverifiable operation, retain prior work and unreached rows. Execute the other adaptive A once. If either A is incomplete, skip all B/C/role phases of this episode and proceed to the next episode. |
| A identity comparison | Candidate/ranking/library mismatch is an integrity/control violation: global abort, never substitute one arm's output. |
| B | Stop the failed arm at the first operationally unavailable row/presentation; retain remaining original slots as unavailable. Continue other arms in fixed order. If any B arm is incomplete, skip C/roles for that episode and proceed to the next episode. |
| C | Stop the failed arm at its first operationally unavailable operation; retain remaining C slots. Continue other C arms. If any C arm is incomplete, skip roles for that episode and proceed to the next episode. |
| Role mutation/solve | A failed role chain stops that chain, retaining dependent withdrawal/reinstatement/solve slots as unavailable. Continue other roles/arms from their independent A copies. No substitute reference row or record. |

Semantic UNKNOWN/INCONSISTENT with accepted certificates is successful execution.
NO_METHOD_ACQUIRED and NO_DEVELOPMENT_BENEFIT still create a sealed empty selected
library and run B/C exact fallbacks; no-use role references are structural N/A.
Schema/utility withdrawal returning a checked fallback is the intended control outcome.
An expected role NOT_APPLICABLE is not an exception that stops its chain.

The coordinator checks the monotonic dispatch deadline before every phase/row and
while waiting for any child. The process-group controller enforces it independently
so a single stuck call cannot extend scientific work. No child is launched after expiry.
Termination escalation uses the already qualified fixed launcher policy; bind its
exact durations in the final launch seal, never select them after observing a run.
Observe actual stop, reap, group absence and mandatory record fsync. Cleanup may
overrun dispatch time; include it in physical wall/CPU/storage totals and report the
overrun. Cleanup not observed complete means CLEANUP_CANNOT_CHECK, not clean exit.

If output retention fails, the external controller preserves its independently observed
minimal failure/exit/stage record in its prequalified output location. It cannot recreate
missing child counters or task artifacts. Missing closure keeps the relevant result unavailable.
No waiting period or implementation fix pauses or resets a started scientific clock.
