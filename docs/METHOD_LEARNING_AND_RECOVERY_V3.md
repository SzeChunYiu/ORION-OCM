## Runnable method-learning example

Run `ocm methods` from an installed wheel, or
`python -m ocm.evaluation.method_learning_eval` with the package available.
The example requires no repository tests, external model, network service or
external experiment. `--out NEW_PATH` saves a new engineering receipt.

Two checked training problems generate the reusable fragment
`increment -> square`. The held-out mathematical specifications are different
from both training specifications; renaming a duplicate task does not make it
held out.

| Held-out specification | Primitive search slots | Learned-generator slots |
| --- | ---: | ---: |
| `x² + 2x` | 35 | 15 |
| `(x+1)⁴` | 37 | 19 |

The generator is stored in the runtime, recovered after restart and refused
after an essential training proof is revoked. Every returned mathematical
solution is rechecked against exact coefficients before admission.

These selected examples establish finite measured improvement only. Training,
verification and storage costs are additional costs, so this is not a claim of
whole-lifetime speedup or superiority over stronger synthesis systems.

## What convergence means

With `p` total primitives and maximum program length `L`, primitive enumeration
has `sum(p**i, i=0..L)` candidates. Alternating guided and primitive slots reaches
a solution of primitive rank `r` in at most `2r` slots, if the budget permits.
The implementation counts duplicate and over-length guided expansions as slots.
This is a search-slot bound, not a CPU or memory bound for arbitrary arithmetic.

A finite grammar can be exhausted. A finite budget can be exhausted. Neither
terminal says that every larger method space lacks a solution. Unrestricted
mathematics does not inherit a universal convergence guarantee.

For science, if a finite deterministic model class contains the truth, observations
are accurate and allowed experiments distinguish every surviving pair, a
separating-query policy identifies the model within `|H|-1` observations.
Noise, missing models, measurement error or insufficient experiments can prevent
identification. The executable science example uses **simulated** observations;
it has not established a claim about nature.

The written proofs and independent finite checker live in ORION-V2 at
`research/machine-epistemics-theory/method_learning_v1/`. The construction reduces
to synthesis, fragment abstraction, fair enumeration, generalized binary search,
exact polynomial checking and dependency-based evidence maintenance. No new
mathematics or architecture residual is claimed.
