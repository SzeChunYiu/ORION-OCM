# Current chat, learning and concurrent-main integration

Runtime revision V4, 2026-09-05. Current engineering evidence; no independent
ChatGPT comparison or frontier-mathematics solution is claimed.

## What now works through chat

* Unknown spellings receive bounded edit hypotheses. Unique world-question
  corrections are answered with an explicit assumption. Ambiguous alternatives
  and statements request confirmation. Known words, numerical arguments,
  negation and lesson/revocation commands are not silently rewritten.
* `remember: mira is a botanist` persists a source-attributed user report.
  A later answer identifies it as unverified. Revocation withdraws its support.
* `learn method next-square: inc square` creates a reusable named total arithmetic
  method. `run next-square on 3` computes 16; after restart, input 4 computes 25.
  Exact rational polynomial normalization checks method meaning; lookup verifies
  data identity and live support again. Names cannot silently replace live methods.
* `find method: 1,2,1` searches for a program with the specified coefficients,
  constant first. Every accepted answer has a checked polynomial identity.
  Exhausting the fixed search budget does not establish impossibility.
* Greetings, capability explanations and common explanation requests are supported.
  Existing vocabulary/construction learning and the `ocm methods` generator
  demonstration remain available.

These are bounded command and grammar interfaces. A learned method changes the
durable knowledge space; it does not grant authority to change its checker. This
revision does not make grammar arbitrary or add voice/audio output. Spelling
clarification choices are session-local; learned reports and methods are durable.

## What remains open

The fetched GitHub inventory still contains the OCM grand-plan issue and 47 V2
issues. Several foundation child issues concern completed scoped packages awaiting
integration/disposition, while parent programmes require additional experiments or
independent review. An open issue is not automatically a runtime defect, and this
revision does not mark the research programme finished.

ChatGPT-level conversation needs a prospectively specified comparison, broader
language coverage, unseen human conversations, spelling ambiguity and context
tests, blinded scoring and matched resources. No such comparison has run here.
General scientific-method invention, learning large mathematical representations,
and solving an independently identified unsolved theorem remain research goals.
The [Anthropic comparison](ANTHROPIC_FORMALIZATION_COMPARISON_V1.md) identifies the
relevant shared dependency/reuse design and the further experiments needed.
