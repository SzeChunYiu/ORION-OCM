# GMI Recursive Evolvability V0

**Status:** PROVISIONAL FORMAL/OPERATIONAL EXTENSION.  No empirical ORION RSI claim.

This specification links Machine Epistemics developmental evolvability to recursive self-improvement (RSI) without promoting any currently incomplete G6/G7 empirical result.

## Core extension

Starting from

\[
M_t=(F_t,O_t,\Pi_t,C),
\]

define the improvement-generating process `D_t` and registered lineage/archive `A_t`:

\[
X_t=(M_t,D_t,A_t;C).
\]

Ordinary self-improvement can change `M` while leaving `D` fixed.  **Recursive evolvability** begins only when a verified, machine-originated intervention changes `D`, descendants actually execute that changed mechanism, and a matched frozen-`D` counterfactual shows better held-out descendant production under the same registered resource budget.

This is the formal bridge:

```text
G6 developmental evolvability
    ↓
D becomes an addressable self-change target
    ↓
meta-evolvability (κ_D, Ω_D, χ_D)
    ↓
resource-matched descendant metaproductivity
    ↓
R3 recursive evolvability
    ↓
G7 persistence / inherited D change
    ↓
R4 heritable recursive development
```

## Evidence levels

`R0` refinement → `R1` persistent adaptation → `R2` self-modification → `R3` recursive evolvability → `R4` heritable recursive development → `R5` general/open-ended RSI.

R5 is deliberately not awarded by finite experiments in this specification.

## Governance invariant

The external constitution `C`, protected evaluation channel, resource meter and lineage receipts remain outside the candidate's self-authorized mutation surface.  Internal proxies may evolve, but they cannot alone certify their own improvement.

## Resource / morphology compatibility

Current task performance is not assumed to identify future self-improvement potential.  Descendant outcomes are compared at matched budgets.  When no justified utility scalar exists, the full resource/performance profile is primary.

This also preserves Grand GMI's static/developmental distinction: a mutable development kernel can introduce search priors, so recursive developmental claims must respect the declared operational quotient and cannot infer universal morphology optimality from one authored search trajectory.

## Nonclaims

This spec does not claim:

- current ORION G6 positive closure;
- measured real-world `(κ_D,Ω_D,χ_D)`;
- an earned ORION governed-self-evolution lineage transition;
- domain-general/open-ended RSI;
- recursive acceleration or intelligence explosion.

The executable research capsule and complete recursive gap ledger are in `research/gmi-rsi-bridge-v1/`.
