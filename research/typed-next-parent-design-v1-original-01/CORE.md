# Next native learning experiment: ordinary theorem acquisition

**Decision, 2026-09-08:** extract one useful typed subproof from exposed training
proofs and install it as an ordinary proved theorem. Compare against a conventional
parent that already stores all whole training theorems. Build no new recipe
representation for this experiment.

The completed typed lifecycle qualified an ordinary `jccir` alias, six typed
renamings and class reconstruction, with empty serving-eligible method IDs.
That coordinator-supplied result is an interface control, not useful discovery.

The smallest decisive question is:

> Does machine-selected subproof structure, acquired without later target hints,
> causally improve solving in different source families beyond ordinary
> accumulation of the demonstrated theorems, after paying its lifetime costs?

Use one selected lemma, one sealed training/development allocation, and two
independent held-out source families. No corpus population or suitable nonalias
candidate has been inspected or established by this design review.

[MECHANISMS.md](MECHANISMS.md) compares three established choices and pins
their assumptions. [EXPERIMENT.md](EXPERIMENT.md) fixes the engineering sequence,
leakage controls, causal comparisons, costs and failure-directed next decisions.
[READ-SCOPE.md](READ-SCOPE.md) records what was read and what remains unqualified.
[SOURCE-READS.json](SOURCE-READS.json) binds the local design inputs.

Success would establish a bounded conventional symbolic-learning mechanism.
It would not establish an OCM-specific advantage, general scientific autonomy,
natural-language meaning, or a new theorem of learning. The same acquired theorem
must remain available to the strongest matched conventional host.
