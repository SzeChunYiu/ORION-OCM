# R9 — update laws as information-conditioned process transforms

An update law is an admissible process U:(M,D)->M'. No named learning method is foundational.

## Regime principle
Different information channels and resource prices select different update processes. Evaluative-only probing, directional information, reverse derivative accumulation, Bayesian conditioning, hypothesis elimination, memory writes, reusable-library formation, population variation/selection, meta-search and code self-modification are specializations.

## Registered exact microscopes
- Evaluative vs directional: an evaluative search fixture needs four probes; a directional+verification route costs 1+rho, so directional wins for rho<3, ties at 3 and loses above.
- Credit accumulation: a four-input/one-output graph costs 40 for four forward sweeps. Reverse accumulation costs 10+3*sigma; it wins for sigma<10, ties at 10, loses above. This is a resource-conditioned specialization, not a universal backprop claim.
- Binary Bayes: prior 1/2 and 3/4-accurate observation gives posterior 3/4 for the matching hidden state.
- Rule induction: all four unary Boolean hypotheses are retained until evidence eliminates them; two examples identify ID uniquely, one example leaves non-identifiability.
- Memory update: storing one key-value changes only the addressed query in the registered map.
- Library formation: D+nc<nL gives the exact reuse crossover.
- Population update: a local single-start search is trapped by a registered landscape while a multi-candidate population containing the global basin preserves the superior candidate.
- Meta-update: a cue-conditioned change to search order improves expected search cost below its cue-processing price threshold.
- Self-modification: when code is data, an update process can rewrite executable code; the same type covers update-law modification.
- Abstention: if multiple hypotheses remain observationally equivalent under current evidence, the required terminal is UNKNOWN rather than an arbitrary winner.
