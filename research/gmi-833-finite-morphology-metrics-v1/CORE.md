# Exact finite collapse and morphology metrics v1

This package depends on merged PR #966 and closes only three Section-F tasks at
registered finite scope: exact semantic-collapse rates, a novelty score that is
not source-syntax distance, and an exact semantic/resource/developmental
morphology metric.

The receipt is generated by:

```bash
python research/gmi-833-finite-morphology-metrics-v1/finite_morphology_metrics_v1.py
```

Tests run in ordinary and optimized modes:

```bash
python -m unittest research/gmi-833-finite-morphology-metrics-v1/test_finite_morphology_metrics_v1.py
python -O -m unittest research/gmi-833-finite-morphology-metrics-v1/test_finite_morphology_metrics_v1.py
```

The clustering-stability task remains unchecked because this package validates
the metric and novelty score, not any clustering algorithm or recovered cluster
partition.
