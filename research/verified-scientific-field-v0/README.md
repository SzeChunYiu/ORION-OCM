## Canonical architecture

```text
M_t = (F_t, O_t, Π_t, C)
```

with the **research hypothesis**:

```text
F_t = one authoritative typed persistent General Epistemic Field
O_t = learned/composed/donor operators
Π_t = small domain-general executive
C   = external non-self-certifying constitutional boundary
```

No fifth subsystem is introduced.

Important implementation boundary:

```text
one authoritative persistent field
!=
all transient representations physically flattened into one graph
```

Current language/dialogue are semantically aligned with KSO, but complete physical unification is **not established**. `MeaningGraph` and `DialogueWorkspace` remain specialized/materialized structures. Test explicit representation bindings/materialized KSO subspaces before deciding whether further physical unification is useful.

## Domain rule

Language, science, mathematics, coding and planning are initially treated as:

```text
typed views + representations + operators + checker/authority interfaces
```

over one field.

A domain-specific core fork is allowed only after a registered falsifier demonstrates that the shared substrate cannot faithfully represent the required behavior.

## Language rule

OCM should aim for strong LLM-like communication, but language remains a bidirectional field interface:

```text
utterance -> candidate field proposals -> cognition -> intended field obligations -> utterance
```

Surface fluency does not grant semantic correctness or authority. A large parametric realizer is a valid reference and possible negative boundary.

Do not assume a perfect universal interlingua. Language representations may remain specialized payloads/views with explicit bindings into authoritative field identities.

## Quantum rule

Quantum research contributes only mechanisms that survive domain-neutral mapping and strongest classical-parent subtraction. Physical QPU use is strictly downstream and requires full end-to-end access/resource accounting.
