## Immediate contraction

The following are **not candidate novelty claims**:

```text
one shared cognitive store
one typed graph/metagraph for multiple domains
language and reasoning sharing knowledge
procedures and data represented together
working/long-term memory separation
production/operator control
grammar as form↔meaning structures
active clarification/experiment selection
semantic graph parsing
```

## What remains worth testing

The strongest plausible residual is a **coupled Machine-Epistemics lifecycle**, not the existence of a unified architecture:

```text
explicit warrant/authority/scope distinctions
+ exact support alternatives and local revocation
+ context-certified representation/refinement
+ unresolved-alternative preservation
+ resource-responsibility routing
+ sparse lifetime active state after full maintenance accounting
+ learned bidirectional language over the same state
+ mutable field/operators under an external non-self-certifying constitution
```
