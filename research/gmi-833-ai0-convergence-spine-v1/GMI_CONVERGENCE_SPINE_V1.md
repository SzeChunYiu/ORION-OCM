## Classification rule

Every registered material theory/result receives one primary class:

`FOUNDATIONAL | SPECIALIZATION | PARENT_OWNED | EMPIRICAL_LAW | SUPERSEDED_REDUNDANT`

A result may feed multiple canonical interfaces but has exactly one authoritative owner. Imported modules never re-own the theorem.

## Duplicate and disagreement rule

1. If one result strictly generalizes another, the stronger result is authoritative and the weaker becomes a corollary/historical witness.
2. If parent literature already owns the mathematics, GMI cites/imports it and moves novelty to the integration/generalization/experiment layer.
3. If two results genuinely disagree, require a discriminating theorem/counterexample/experiment.
4. If no discriminator exists at the registered scope, mark them observationally/equationally indistinguishable there.

The registered example is G0 structural neutrality: the stronger universal-neutrality reading is rejected by #896's same-semantics/non-isometric grammar counterexample. The surviving statement is only label blindness / invariance under certified isometries.
