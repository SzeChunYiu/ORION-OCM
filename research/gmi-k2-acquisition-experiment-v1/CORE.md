# K2 acquisition experiment: read first

Ledger item 10, run rather than argued.

- **K2 is positive at a registered scope.** With the `squares` library, K2 holds
  on **148 of 148** held-out reuse targets.
- **Semantic reuse is necessary.** Across four libraries and two disjoint
  populations — **1,707** no-reuse targets — there are **zero** K2 successes.
- **It is not sufficient.** Rates run 45%–100% by library, so the condition is
  one-sided and an iff would be false.
- **Absent reuse, retention hurts**: `H` is strictly worse on 100% of held-out
  no-reuse targets, because macros inflate the search alphabet with nothing to
  shorten.
