# Cognitive-function re-audit core v1

This package closes only three Section-M audit rows at a registered finite
interface. It does not infer physical cognitive anatomy or a universal
architecture.

- `MEMORY-1`: a memory role is an operational response/trace profile over the
  registered probes. Distinct profiles are functionally distinguishable. The
  same protected profile implemented by separated stores or one tagged store
  proves that functional evidence does not identify a physical partition.
- `ATTENTION-1`: let `T` be required items, `S` processed items, per-item cost
  `c>0`, and discovery costs `d_F,d_S>=0`. Selective processing is admissible
  only when `T subseteq S`; then it strictly beats full processing exactly when
  `d_S-d_F < (n-|S|)c`.
- `CONCEPT-1`: on a complete finite response table, equality of complete
  response rows is the coarsest equivalence relation through which every
  registered response factors. Observation-equivalent partial completions with
  different full quotients require abstention.
- `ADOPT-1`: for `r` reuses, fresh cost `f`, installation cost `i`, and lookup
  cost `l`, an already verified abstraction strictly saves cost exactly when
  `(r-1)(f-l)>i`. This is an adoption rule, not a formation or semantic-
  correctness algorithm.

All decisions use integers or exact rational numbers. `RESULT_V1.json` is the
canonical replay receipt.
