# G-SURF on band 3–4: the entry gate does not false-fire outside the band it was calibrated on

Instrument calibration, not a scored run and not an authored package. The worlds here
were built by this lane acting as a fake author — exactly as `VAL-A`..`VAL-H` were in
[M2P2_GSURF_CALIBRATION.md](../m2p2/M2P2_GSURF_CALIBRATION.md) — and no arm was scored
on any of them. Run on laptop billy, never the Mac.

## Why this had to be done first

[BAND_FEASIBILITY.md](BAND_FEASIBILITY.md) identifies the one registrable second-grammar
route: **chunk band 3–4 with chunk count 10–16**. Before any such spec can be registered,
its blocking entry gate has to be shown not to misbehave on the new band. G-SURF's
recalibrated rule is parameter-free —

```text
fire SURFACE_DERIVABLE iff (FREE − CHANCE) >= 0.5 · (ORACLE − CHANCE)
```

— but its **no-false-fire property was proven only on band-2–3 worlds**. A gate that
fired on band 3–4 would void the authoring rather than measure it.

i.e. no feature family beats chance at all.

## What this does and does not establish

- **Does:** the blocking entry gate is safe to use on a band-3–4 authoring; it does not
  void those worlds spuriously. The feasibility prediction from `f + k² ≥ 90` is also
  confirmed against the real compiler — every sampled k ≥ 13 world compiled viable.
- **Does not:** say anything about whether the OCM benefit replicates on band 3–4. No arm
  was scored. That requires a registered spec, a fresh author session and the frozen
  gates — none of which this file authorises.
- **Scope limit worth stating:** six worlds, one lane-author, one part-fraction setting
  (0.50/0.25/0.25). The band-2–3 calibration used seven synthetic worlds plus two recorded
  positives; this is comparable but not larger.

## The compiler variant, and why it is not a modification

The frozen `m2p2_compile.py` is untouched. `m2p2_compile_b34.py` is generated by
[make_compile_variant.py](make_compile_variant.py), which **proves** the relationship
rather than asserting it: the variant with its banner removed must be byte-identical to
the frozen source with exactly three substitutions applied — chunk-count bound `4..8` →
`4..16`, per-chunk length bound `2..3` → `2..4`, and the schema string relabelled to
`OCM_M2P4_B34_COMPILED_WORLD_V1` so a variant-compiled world can never be mistaken for a
frozen one. The generator aborts on any other drift.
