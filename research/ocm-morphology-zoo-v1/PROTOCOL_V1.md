## Invariants (all enforced in code, tested)

1. Evaluation is deterministic; every record chains into a sha256 receipt
   (`evaluation/receipts.py`), and `verify_receipt` must pass before any write.
2. Hard gates are EXECUTED, not logged: capability floor 0.5, no-warrant-leak,
   budget non-negative, fail-closed compile (`evaluation/invariants.py`).
   Infeasible genomes never enter archives.
3. Denominators are frozen prospectively (`FREEZE_V1.json`) before scored
   outcomes; wider arrays / extra seeds / changed budgets are numbered
   amendments reported separately.
4. >= 3 independent seeds per stochastic arm; same-evaluation-count AND
   same-CPU-hour comparisons both reported.
5. Census truth is BOUND-RELATIVE: arms may exceed the census optimum from
   outside CENSUS_BOUND_V1 (observed: 0.700384 > 0.649325); this is reported,
   never treated as a defect.
6. Zoo elites never self-adopt; any adoption into OCM flows through the #217
   protocol with external governance sign-off.
7. Terminals only from the #221 sec-15 vocabulary; forbidden AGI-class terms
   are never used.

## Scoring

Objective vector (10 objectives; capability maximized) in
`evaluation/objectives.py`; frozen scalar dev_score = capability -
0.5*normalized_cost (W_REF 500, B_REF 150) reported alongside raw vectors,
never as the sole conclusion. Diversity metrics and their frozen denominators:
pareto_recovery (/387), S_cell_recovery (/4), B_cell_recovery (/2) — the
near-degenerate cell denominators are themselves a reported finding.

## Slurm discipline (MZ-D6)

Job arrays for independent runs, `--array=0-N%K` concurrency cap, candidate
manifest frozen before submission, `$SNIC_TMP` for scratch, per-task
stdout/stderr retained with crashes kept (never overwritten), aggregation only
when all array indices have a disposition, no login-node heavy work, `--qos=test`
smokes only, CPU partitions by default.
