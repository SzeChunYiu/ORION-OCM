# Interface and remaining authority

The four current modules are [goal_library](source/goal_library.py),
[goal_solve](source/goal_solve.py), [goal_native](source/goal_native.py) and
[cohort_suffix](source/cohort_suffix.py). The [original source freeze](records/ORIGINAL-SOURCE-FREEZE.json)
pins all 31 copied production, donor, control and qualification source files.

The solver accepts only an issued goal, ordered premises, three homogeneous
class/wff parameters with empty DV, and finite positive limits. There is no
official target proof, trace, label, route or expected proof-stream input.
The shared finite bank contains goal syntax closure, issued premises and
resident cohort conclusions. Indexed floating order normalizes resident hints
without changing retained contracts, proof bodies or grounding substitutions.

All arms retain the same bank, resident grounding and syntax materialization.
Only cohort logical actions are disabled. Actual cohort consumption is
recomputed from generated proof labels and later the current native USED set.
The emitter preserves ordered floating and essential occurrences, including
composite substitutions and repeated argument use.

The [source origins](records/SOURCE-ORIGINS.json) bind 18 donors: 14 exact copies.
Existing finite search/matching gains an explicit syntax callback and private
floating-label classification; the bank and native-result helper functions
retain their donor ASTs. Accepted syntax/cache and native verification machinery
are reused. The [verifier license](source/vendor/mmverify.LICENSE) is preserved.

A bounded supported failure means no proof in the registered finite bank and
tree-decision bound. Unsupported actions, syntax and resource failures remain
UNKNOWN. The soft wall uses checkpoints; it is not inner-operation preemption.
Syntax/proof bounds and the native 256-node/current-frame boundary can still
refuse a generated proof.

The suffix constructor changes only each member's scoped essential labels and
their normal-proof occurrences. It retains original/new identities, exact
statements/types/floating order, theorem names and empty DV. Repeated local
names across members receive distinct labels; collisions refuse. Its current
scope accepts base-only proof dependencies. Indexing is not native admission.

Actual integration remains pending: bind one exact cohort/transport map;
freshly verify every ordered P1+C proof under the current unchanged 100-axiom
authority; register goal-only allocation and dependency/exposure exclusions;
then bind the isolated caller, mode, resources, runtime and output custody.
Old 96-axiom or selected-claim receipts do not qualify that joined authority.
The [original prospective request](records/ORIGINAL-PROSPECTIVE-REQUEST.json)
explicitly lacks those inputs and grants no execution permission.
