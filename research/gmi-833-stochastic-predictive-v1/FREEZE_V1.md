## 1. Registered finite controlled process

Fix:

- a finite nonempty action alphabet `A`;
- a finite nonempty observation alphabet `O`;
- a finite process horizon `N >= 1`;
- exact rational observation kernels

`K_h(o | a) in Q_[0,1]`

for every registered history `h` of length `< N` and action `a in A`, with

`sum_(o in O) K_h(o | a) = 1`.

A history is an alternating action-observation word

`h = (a_1,o_1,...,a_d,o_d)`.

Actions are interventions/controls, not random variables generated by a behavior policy. The observation likelihood of `h` is

`L(h) = product_(i=1..d) K_{h_<i}(o_i | a_i)`.

A **positive-probability history** is a registered history with `L(h) > 0`. Zero-likelihood histories are excluded from conditional predictive-state claims; no conditional law is fabricated on them.

For a fixed history depth `d` and residual test horizon `ell` satisfying

`0 <= d < N`, `0 <= ell <= N-d`,

let `H_d^+` be all positive-probability histories of exactly depth `d`.

A controlled test of length `m <= ell` is

`t = (a'_1,o'_1,...,a'_m,o'_m)`.

The empty test `epsilon` is included. Its success probability is `1`. For nonempty `t`, define the exact conditional test probability by the registered continuation kernels:

`P_h(t) = product_(j=1..m) K_{h t_<j}(o'_j | a'_j)`.

The **complete registered finite test family** is

`T_ell = union_(m=0..ell) (A x O)^m`.

The finite system-dynamics block is

`D_(d,ell)[h,t] = P_h(t)`, for `h in H_d^+`, `t in T_ell`.

All executable certificates in this tranche use exact `Fraction` arithmetic. No Monte Carlo or floating-point tolerance may substitute for an exact theorem control.

## 2. PQ-1 — predictive-row equivalence and exact sufficiency

Define

`h ~_P h'  iff  D_(d,ell)[h,:] = D_(d,ell)[h',:]`.

The quotient statistic is the complete row / its equivalence class.

### Target PQ-1A — exact sufficiency

For every registered finite test `t in T_ell`, `P_h(t)` is a function of the predictive class `[h]_P` alone.

### Target PQ-1B — cardinality minimality

Let `S : H_d^+ -> Z` be any exact predictive statistic satisfying:

for every `t in T_ell`, there exists `f_t` such that

`P_h(t) = f_t(S(h))` for every `h in H_d^+`.

Then

`S(h)=S(h') => h ~_P h'`.

Hence every exact predictive statistic refines the predictive-row quotient and

`|im S| >= |H_d^+ / ~_P|`.

If equality holds, the induced partitions agree up to relabeling.

### Strongest-parent subtraction

This quotient/minimality mathematics is already owned at the declared finite-test level by merged #846 PS-1. #836 may instantiate/revalidate it for an explicitly generated system-dynamics block, but may not advertise PQ-1 as a new theorem.

Frozen hostile: deliberately assign one statistic label to two distinct rows; the checker must return an explicit separating controlled test rather than accepting the merge.

## 3. LR-1 — exact linear predictive rank lower bound

An exact `q`-dimensional linear predictive representation of a finite block `D` means there exist exact rational vectors

`s(h) in Q^q`, `w(t) in Q^q`

such that

`D[h,t] = s(h)^T w(t)`

for every registered history and test.

### Target LR-1

For every such representation,

`rank_Q(D) <= q`.

Analytic proof target: stack the state vectors as rows of `S` and the test vectors as columns of `W`; then `D = S W`, so `rank(D) <= min(rank(S),rank(W)) <= q`.

Because `D` is rational, its rank over `Q` equals its rank over `R`; the executable certificate works entirely over `Q`.

## 4. LR-2 — rank-attaining core-test factorization

Let

`r = rank(D)`.

Choose `r` linearly independent columns of `D`; let their controlled tests be the core-test set `C`, and write

`Q = D[:,C]`.

### Target LR-2

Every column of `D` lies in `colspan(Q)`, so there is an exact coefficient matrix `W` with

`D = Q W`.

Thus assigning each history the vector of its `r` core-test predictions,

`s_C(h) = D[h,C] in Q^r`,

gives an exact `r`-dimensional linear predictive representation. Combined with LR-1, the minimum exact linear predictive dimension of the registered finite block is exactly

`rank(D)`.

The machine checker must independently:

1. compute exact row-reduction rank;
2. select independent core columns;
3. select an invertible `r x r` row minor of `Q`;
4. solve exact rational coefficient systems for every test column;
5. reconstruct every entry of `D` exactly.

### Boundary

This is a finite fixed-block factorization. It does **not** by itself prove a closed recursive PSR update law, a stationary infinite-horizon model, learnability from samples, or numerical stability.

### Strongest-parent subtraction

The rank/core-test theorem is established PSR/system-dynamics-matrix mathematics, especially Singh, James & Rudary (UAI 2004). #836's residual is exact repository formalization, hostile boundary checking, and explicit separation from quotient cardinality—not novelty in the rank theorem.

## 5. SEP-1 — predictive class count is not linear predictive dimension

These are different invariants:

- `c(D)` = number of distinct complete rows / predictive equivalence classes;
- `r(D)` = exact matrix rank / minimum linear predictive dimension.

Always `r(D) <= c(D)` for a finite block after duplicate rows are removed, but equality need not hold.

### Frozen valid-process witness

Use one action `a`, observation alphabet

`O = {A,B,C,X,Y}`,

and horizon `N=2`.

At the empty history:

`P(A|a)=P(B|a)=P(C|a)=1/3`, `P(X|a)=P(Y|a)=0`.

At depth-one histories:

- after `A`: next observation is `X` with probability `1`;
- after `B`: `X` and `Y` each have probability `1/2`;
- after `C`: next observation is `Y` with probability `1`.

At registered depth `d=1`, residual horizon `ell=1`, the positive histories are exactly `A,B,C` (with their control action), and the complete one-step predictive rows, including `epsilon`, are distinct. The `B` row is exactly the arithmetic mean of the `A` and `C` rows, and `epsilon = P(X)+P(Y)` on every row. Therefore the frozen target is

`c(D_(1,1)) = 3`, `rank(D_(1,1)) = 2`.

The executor must reconstruct this from the process kernels, not from a hand-entered matrix.

This counterexample blocks any inference that a cardinality-minimal arbitrary statistic and a minimum linear coordinate dimension are the same optimization problem.

## 6. LAT-1 — observable predictive state does not identify latent realization

### Target collision

Construct two non-isomorphic latent realizations with identical observable controlled-test laws at the registered finite horizon:

1. **one-latent-state model:** a single hidden state emits a fair bit at every step;
2. **two-latent-state model:** a hidden bit is independently resampled fair at every step and the observation equals that hidden bit deterministically.

For every finite observable bit string of length `m`, both models assign probability `2^-m`. Hence their complete predictive rows agree at every registered finite test horizon although their latent state cardinalities and latent mechanisms differ.

### Target LAT-1

No function of the observable predictive row alone can identify the unique latent realization on a model class containing both witnesses.

Proof target: collision/non-injectivity. The input predictive row is identical but the requested latent-model identity differs.

This does not prove causal latent identification impossible under every richer intervention/assumption regime; it proves only the stated observational non-identifiability boundary.
