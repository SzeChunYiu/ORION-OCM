This file is the pre-implementation scientific authority. It freezes the shared low-level grammar,

## 1. Finite universe

The registered input tuple is

```text
(w, x, y, r) ∈ {-1,0,1}^4
```

with all 81 tuples present. Arithmetic is exact over `Q`; no floating point is part of the theorem.

The scorer receives three targets only as opaque IDs and complete 81-row exact-rational truth tables.
It must not branch on target names or formulas.

## 2. One shared family-blind grammar

Leaves, each cost 1:

```text
w, x, y, r, -1, 0, 1
```

Operators add one node of cost:

```text
add(a,b)  = a+b
sub(a,b)  = a-b
mul(a,b)  = a*b
half(a)   = a/2
```

Total expression cost is syntax-tree node count. The exhaustive cap is

```text
C = 6.
```

The same grammar, cost, cap, universe, scorer and tie rule apply to every opaque target. No target may
receive a task-specific primitive, macro, cost discount, search order, or post-activation rule change.

## 3. Frozen target semantics

These formulas define the independent oracle that creates the frozen opaque truth tables. They are not
available to the search routine as formulas.

```text
OPAQUE_A: w' = (w + y)/2
OPAQUE_B: w' = w + (x*y)/2
OPAQUE_C: w' = w + (r*x)/2
```

The intended qualitative reading is deliberately secondary to the extensional target:

- A: interpolation / prediction-error-like update;
- B: correlation / associative update;
- C: reward-gated / reinforcement-like update.

Architecture/law-family labels are not search features and are assigned only after scoring.

## 4. Semantic quotient and exhaustive search

For an expression `e`, let

```text
T(e) = ( e(p_1), ..., e(p_81) ) ∈ Q^81
```

be its complete registered truth table.

Two expressions are equivalent at this scope iff

```text
T(e1) = T(e2).
```

The dynamic program must enumerate every expression of cost `<= 6` compositionally and retain exactly
one deterministic canonical minimum-cost representative for each distinct semantic table. Search
success for a target means exact equality of all 81 outputs.

The reported target representative must have globally minimum frozen cost among exact matches in the
bounded grammar.

## 5. Frozen theorem obligations

### C1-1 bounded search completeness

For every expression generated by the grammar with cost `c <= 6`, the DP semantic quotient contains
`T(e)` by the end of cost layer `c`. Proof route: structural induction on the expression root.

### C1-2 quotient soundness

For all expressions `e1,e2` in the registered bounded grammar,

```text
T(e1)=T(e2)
```

iff they are extensionally equal on every registered input tuple. Canonicalization may change syntax but
not registered semantics.

### C1-3 neutral minimum-cost recovery

All three opaque target tables must occur in the one shared quotient. For each target, the returned
representative cost must equal the first DP cost layer containing the target table.

Frozen expected minimum costs, derived algebraically but still to be independently checked by exhaustive
DP:

```text
OPAQUE_A: 4
OPAQUE_B: 6
OPAQUE_C: 6
```

### C1-4 dependency necessity

If two registered rows differ only in input coordinate `z` and their target outputs differ, every exact
deterministic realization of that target on this universe must depend semantically on `z`.

### C1-5 qualitative distinctness

The frozen irreducible dependency signatures are:

```text
OPAQUE_A: {w, y}
OPAQUE_B: {w, x, y}
OPAQUE_C: {w, x, r}
```

For each included coordinate the receipt must exhibit an explicit single-coordinate counterfactual pair.
For each excluded coordinate it must exhaustively verify invariance over all matched row pairs.
The three signatures are pairwise distinct.

## 6. Hostiles / ablations frozen before implementation

The lane fails if any of the following is not detected.

1. **Required-variable removal.** For every target/signature variable, delete access to that variable. The
   explicit counterfactual witness proves exact recovery is impossible independent of search algorithm.
2. **Remove `half`.** With integer-valued leaves and only `+,-,*`, every expression is integer-valued on
   this integer universe, while every frozen target has at least one half-integer output. Exact recovery is
   therefore impossible.
3. **Perturb one target row after freeze.** The previously recovered expression must cease to be an exact
   match; the scorer may not adapt grammar/pricing to rescue it.
4. **Equivalent syntax.** Syntactically distinct expressions such as `add(w,y)` and `add(y,w)` must collapse
   when their complete truth tables agree; the quotient is semantic rather than string-based.
5. **Task-specific mutation.** Any attempt to change grammar, costs, cap, universe or tie rule after
   activation must fail closed as `FROZEN_PROTOCOL_MUTATION`.

## 7. Strongest parents / subtraction

The formal ingredients are parent-owned: finite program enumeration, dynamic programming over expression
size, exact truth-table semantic hashing, version-space/program-synthesis minimality, and elementary
counterfactual dependence arguments.

The repository contribution is the single frozen family-blind grammar/protocol, exact multi-law neutral
rediscovery, bounded completeness/minimality certificate, hostile ablations, and explicit claim ceiling.

## 8. Acceptance / falsifier

Success requires all of:

- one unchanged grammar/cost/search protocol recovers all 3 opaque tables exactly;
- the recovered costs are global bounded minima `4,6,6`;
- dependency signatures are exactly the three frozen sets above;
- required-variable and no-half ablations fail as predicted;
- normal Python and `python -O` reproduce a byte-identical deterministic receipt;
- dedicated CI verifies this freeze predates implementation/result artifacts.

Any failure is a negative result and the #602 Section-C checkbox remains open.
