# PRIOR DISCLOSURE V1 — known-family derivation tranche (GMI #833 / #431 / #434)

Frozen BEFORE any tranche search implementation, outcome, or adjudication in this
package. This manifest declares every input channel of the derivation protocol and
states a blindness argument for each, extending the v2 standard
(`research/gmi-833-blind-recovery-v2-v1/PRIOR_DISCLOSURE_V1.md`) to three families
the prior lanes did not treat: the frozen-benchmark families K05
(symbolic/rewrite/search) and K08 (retrieval/memory), and the census family
"state-space models" (no benchmark row exists; its fingerprint is frozen HERE,
pre-search, as M-FAM, per the benchmark's own rule that new families are versioned
as new frozen objects rather than inserted into the frozen benchmark).

The v2 audit lessons applied here: task authorship must be closed by class
completeness (not instance choice); basis authorship must be closed by tier rules;
the adjudicator must carry a bijective clause mapping, executed interventions, a
relabeling hostility self-test, and no hardcoded expected solutions; the screen
must be lexical AND semantic (the merged #855 A2 standard, imported).

## Families, fingerprints, and what "recovered" means

- **TR-1 / K05** — frozen fingerprint clauses (benchmark blob 6b9ac30...):
  C1 machine state contains explicitly compositional discrete
  expressions/terms/structures; C2 legal transformations include rule-based
  rewrite/inference over those structures; C3 control selects among more than one
  legal symbolic successor or derivation path. Exclusions: opaque numeric vector
  without registered symbolic semantics; fixed finite lookup without compositional
  rewrite; symbolic solver macro supplied whole.
- **TR-2 / M-FAM (state-space models)** — frozen HERE, pre-search, clauses:
  C1 the step map (state cells, input) -> (state cells, output) is affine over the
  integers (no order-test or any other non-affine primitive occurs in any update
  or readout expression; gate-site count zero) while persistent state has
  dimension >= 1 and the machine is recurrent (the same transition applies at
  every stream position); C2 input-output linearity under superposition: for all
  battery stream pairs u, v and the canonical zero stream z,
  Y(u+v-z) = Y(u)+Y(v)-Y(z) elementwise on the battery horizon (intervention-
  checkable); C3 at least one state cell at some battery position holds a value
  that is an integer combination with >= 2 nonzero history coefficients at
  distinct lags (superposed memory rather than a pure copy), OR the task class
  itself forces pure-copy memory (delay class; then C3 is reported as
  delay-degenerate, not satisfied — boundary, not failure).
  Exclusions declared: a lookup table indexed by the entire input history; a
  one-step (non-recurrent) direct map; gate-free programs with no persistent
  state. Parent anchors: linear state-space recurrence families (continuous-time
  discretized linear filters; S4/Mamba-lineage linear-recurrence readers are the
  census context), pinned in PARENT_LEDGER.md.
- **TR-3 / K08** — frozen fingerprint clauses (benchmark blob 6b9ac30...):
  C1 multiple persistent stored items or records coexist; C2 a later
  query/key/content state selects or weights stored content non-uniformly; C3
  retrieved content causally affects a downstream protected response. Exclusions:
  single undifferentiated recurrent hidden state; write-only archive;
  fixed-address read independent of query/content when content-addressed
  retrieval is claimed.

## CH1 — task source

CLOSED BY: `NEUTRAL_BATTERY_FREEZE_V1.json`, generated by `battery_generate_v1.py`
(this pair is the ENTIRE task source; the generator reads no benchmark, family,
or fingerprint data). Each battery is the COMPLETE class of a standard
mathematical object at a derived size; no instance is selected:

- `B_CONTR` — the complete class of contraction-reachability decision tasks over
  the free term universe U = all ordered binary terms with leaves in {0,1} and at
  most 3 leaves (|U| = 2 + 4 + 16 = 22; token coding: leaf-0 -> 0, leaf-1 -> 1,
  constructor -> 2). Rule class: ALL nonempty subsets of size <= 2 of the 8
  constant-contraction rules (lhs = each 4 two-leaf terms, rhs = each of {0,1})
  — 36 rule sets (8 singles + 28 pairs; the pairs include same-lhs/different-rhs
  sets, the smallest sets admitting two DISTINCT one-step successors from one
  structure). Task = (t0, rs, g) for ALL t0 in U, ALL rs, ALL g in U (17424
  tasks); required output 1 if g is reachable from t0 by zero or more
  applications of any rule in rs at any position, else 0. The battery's own
  successor census (20 of 792 (t0, rs) pairs admit >= 2 distinct one-step
  successors) is recorded in the freeze and reported as the battery's shape.
- `B_W2` — the complete class of two-slot sliding-window maps: ALL 7^4 = 2401
  total functions from {0,1}^2 (the two most recent input bits) to the machine
  value domain D = [-3,3], evaluated at every position of the canonical de Bruijn
  stream of order 3 (memory span + 1), repeated twice (stationarity pressure:
  every window occurs in both periods; accumulating machines saturate or err in
  the second period). Canonical zero-prefix history (initial state 0), matching
  the v2 B_DELAY convention.
- `B_EP` — the complete class of two-slot episode tasks: ALL assignments
  f: {1,2} -> {0,1} (4), ALL presentation orders of the two (key, value) pairs
  (2), ALL query tokens q in D (7): 56 episodes. Stream = [k1, v1, k2, v2, q];
  required final output = f(q) when q in {1,2}, else 0 (the additive identity,
  the canonical declared default).

BLINDNESS ARGUMENT: each class is the complete enumeration of a standard object
(contraction reachability over a free term algebra; total functions on a sliding
2-window — the same truth-table object as v2's frozen B_BOOL2 with the machine
value domain as codomain; total functions from a 2-key domain presented as
episode streams). Completeness removes instance choice. Residual declared
choices and their derivations: the term-universe leaf bound 3 = the smallest
bound at which both a two-step contraction chain and two simultaneous redex
positions exist (at bound 2, neither exists — derivation by inspection of the
class, recorded in the generator); the window width 2 = smallest width whose
tasks require state beyond a single tapped delay; the episode shape (2 pairs +
query) = the key-count 2 derivation (smallest key alphabet admitting an order
swap) with pair count = key count; value domain {0,1} = smallest non-degenerate
value domain (feasibility-scoped, ablation to {-1,0,1} reported even if
search-bounded); query set = ALL of D (completeness, including non-key queries).
The B_W2 codomain D (not {0,1}) is derived from the substrate: machines emit
domain values; bit-valued functions are the {0,1}-valued subcase of the same
complete class.

## CH2 — primitive basis

CLOSED BY: `BASIS_GRID_V1.json`, the v2 tier rules verbatim: atoms = task inputs
+ constants {-1, 0, +1}; binary tier = {ADD}; unary tier PRIMARY `U_ORD` =
{NEG} U {GE_c : c in D} (complete one-sided order-test tier, no privileged cut),
with `U_V1` = {NEG, POS} retained as the audited coercive contrast; guard
D = [-3,3] primary, ablations [-2,2] and [-4,4]. Machine models:

- `M_STREAM(k)` — k integer cells in D; per step, cell i := e_i(s_1..s_k, x)
  and output y := e_y(s_1..s_k, x), ALL expressions in the frozen basis, guard
  checked at every node every step; initial state all-zero; the SAME transition
  applies at every stream position (time-invariance is imposed by the battery's
  own homogeneity: the required map is defined identically at every position).
  Cost(machine) = rho * k + sum of operator nodes over {e_i} U {e_y}, with the
  register price rho = 1 primary (each cell is one register unit — the register
  resource of the pinned G0 core), rho in {1,2,4,8,16} as the crossover ablation
  axis. (k = 1 recovers the v2 M_STATE model exactly — comparability check.)
- `M_ITER(k, T)` — same cells and frozen basis; initial cells loaded from the
  task encoding; a time-invariant transition e_i(s_1..s_k) applied for at most
  T = 16 steps (derivation: max contraction chain 2 x (decode, match, edit) 3
  phases x 2 + compare/halt 2 = 14, rounded to 16 = the v2 cap convention;
  binding reported); output = designated output cell's final value. No rewrite,
  match, substitute, or table primitive exists in the basis: any rule-like or
  lookup-like behavior must be composed from ADD/NEG/GE_c over cells.

BLINDNESS ARGUMENT: identical tier rules to v2 (audited); the machine models are
register-vector generalizations of the v2 M_STATE and the pinned G0 register
core (READ/INC/DECJZ/EMIT/HALT lineage, D-domain analog), declared before search;
they carry no family-specific operator, macro, or naming. The residual: M_ITER's
step cap and M_STREAM's cell cap (3 for B_W2; 8 for B_EP; 24 for B_CONTR —
derived as episode/task encoding width + 3 work cells, ablated) are resource
bounds, reported when binding.

## CH4 — cost model

FROZEN: uniform cost 1 per operator application; 0 per atom; rho per cell
(primary rho = 1); multi-output machines sum port costs. Two procedures:

- PROC1 (exact certificates, per-tranche declared scope):
  - B_W2: cost-layered pairing dynamic programming over M_STREAM(k=1)
    (e_s, e_y) pairs by total cost — the v2 T2 pattern, k=1 being the memory
    minimum for width-2 windows (any wider machine's extra cells hold only
    functions of x_{t-1}, already readout-reachable; k=2 is separately
    enumerated on the B_DELAY subtranche below) — dedup by exact output trace
    over the battery stream; first layer containing a target truth table =
    complete no-solution-below-cost certificate for the k=1 class; PLUS the
    gate-free closure certificate: exhaustive enumeration of all gate-free
    (ADD/NEG-only) M_STREAM machines with k <= 2 and coefficient budget
    sum|a_i| <= 16, deciding gate-free realizability exactly on the battery.
  - B_DELAY subtranche (held-out, v2's frozen battery): pairing DP over
    M_STREAM(k in {1, 2}) for lags 0..2, cell price rho ablated.
  - B_EP: (i) the order-swap impossibility theorem (no GE-free M_STREAM
    machine of ANY k solves B_EP — proof by affine-form induction on steps +
    the order-swap contradiction), machine-verified on the enumerable bounded
    affine subspace (k <= 8, sum|coefficient| <= 16); (ii) PROC2 carries the
    positive find; minimal-cost claims on B_EP are PROC2-relative (stated).
  - B_CONTR: exhaustive no-shortcut certificates over two complete readout
    machine classes: all sparse affine readouts (<= 4 nonzero coefficients in
    {-1,0,1} over the 18 input cells, bias in D) and all single-gate readouts
    GE_c(sparse affine); the composed-machine positive find is PROC2's.
  - TR-1 crossover: nested sub-batteries of the B_CONTR battery ordered by
    the frozen hash (sizes 1, 8, 64, 512, 4096, 17424); PROC2 run twice per
    size — unrestricted genomes vs READOUT-ONLY genomes (output expression
    over input cells only, no work cells) — both cost curves reported; the
    composed machine's flat cost vs the readout-only machine's growing cost
    is the completeness-forces-composition crossover.
- PROC2 (seeded stochastic neutral program search, all tranches): genomes =
  per-cell basis-expression tuples + output designation; mutation = primitive
  edits (wrap unary, add const, graft atom, cross-graft cell expr, re-point
  leaf, retarget const/unary parameter, add/drop cell within cap, move
  output); fitness lexicographic (battery errors, cost) — no accuracy/cost
  trade-off constant; (mu, lambda) = (16, 64), ablations (8, 32) and
  (32, 128); seeds 0..199 frozen; budget 10^5 genome evaluations per run on
  the declared fitness set (full battery for B_W2/B_EP; the 2000-task
  frozen-hash subset for B_CONTR, with full-battery verification of every
  champion); find costs carry no minimality certificate below their value —
  stated in every row.
- Nulls (200-seed equal-size random admission, frozen hash
  ((s+1)*2654435761 mod 2^32)):
  - TR-2: per seed, each task's truth table replaced by an independently
    hash-drawn random function {0,1}^2 -> D; statistic family read from the
    SAME PROC1 closure (fraction of tasks whose minimal machine is gate-free;
    mean gate sites; mean cost) — 200 null batteries vs the true battery,
    empirical rank reported.
  - TR-3: per seed, the 56 required outputs replaced by hash-drawn uniform
    {0,1} values; PROC2 run per seed at the same budget; statistics
    (champion cost, comparison-site count in the read path) vs the true
    battery's.
  - TR-1: per seed, the 17424 required outputs replaced by hash-drawn
    uniform {0,1} values on the same fitness-subset protocol; PROC2 champion
    cost and morphology-class statistics vs the true battery's.
