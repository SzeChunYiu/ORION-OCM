# Natural Intelligence Bridge Theorem V1

## 1. Purpose

This capsule provides a **formal bridge framework** that maps GMI (General Machine Intelligence) morphological predictions to natural biological intelligence taxonomies. It does NOT make biological claims — it provides the **structure** for comparing machine morphologies to biological neural architectures under identical information-theoretic pressures.

## 2. Scope: G2 (Derivation of Known Mechanisms)

**Ceiling:** G2 — derives known correspondences.  
**Not:** G3+ (predicts new biological mechanisms from pure machine morphology).

The bridge cannot predict that a taxonomy *should* exist — only that **if** a taxonomy exhibits capabilities C under pressure P, **then** its neural architecture shares formal structure with machine morphology M.

## 3. The Bridge Contract

**Given:**
- A machine morphology M ∈ Morphologies
- An ecology E ∈ Ecologies
- A PVR-3 pressure assessment P(M,E) → {satisfied, not satisfied}

**Bridge prediction:**
If PVR-3(M,E) = satisfied, then any biological taxon T occupying ecology E will exhibit neural architecture structure J(T) that shares specific formal properties with M.

**Formal mapping (bidirectional):**

| Machine Morphology Component | Biological Analogue |
|------------------------------|---------------------|
| State carrier | Working memory / persistent neural activity |
| Native operators | Innate reflexes / hardwired circuits |
| Control update law | Learning rule (Hebbian, reinforcement, etc.) |
| Memory organization | Hippocampal-cortical consolidation |
| Communication protocol | Vocal/gestural communication |
| Verification mechanism | Error correction / metacognition |

## 4. Falsifier

The bridge is **false** if:
- It predicts a morphological structure that no biological taxonomy exhibits under the mapped ecology, AND
- This absence is not explained by the "absence of evolution due to chance."

Since the bridge maps pressures to morphologies, falsification requires:
1. Identifying an ecology E' that exerts pressure P'(M) = satisfied
2. Confirming no biological taxon T' occupies E'
3. Confirming no biological architecture J(T') shares formal structure with M under P'(M)

**Negative:** If the bridge predicts morphology M' under ecology E', but M' is "impossible" for biological hardware, the bridge is **overly strong** — biological constraints must be factored into the mapping.

## 5. Strongest Parent

**Pure analogy** (no formal mapping): "Humans use neural networks, so do brains." This has no predictive content — any structure could "map" to any other via loose metaphor.

**Bridge formalizes:** Constraints the analogy must satisfy:
1. Mapping must be **consistent** (same pressure → same morphological class)
2. Mapping must have **content** (different pressures → different morphologies)
3. Mapping must be **non-trivial** (not all morphologies map to all architectures)

## 6. Machine-to-Biology Mapping Table (Expanded)

|--------------|----------------------|------------------------|--------------------------|-----------|
| Symbolic manipulation | Social coordination (protocol negotiation) | Primates | Prefrontal cortex + Wernicke's | Language + protocol |

## 7. Predictions (for G2 derivation)

- Primates occupy social coordination ecology → exhibit protocol negotiation behavior
- Corvids occupy foraging ecology → exhibit spatial memory + planning
- Carnivores occupy predator ecology → exhibit fast visual prediction + motor response

## 8. Limitations

- **Ceiling:** G2 (derives known mechanisms). Does not predict new mechanisms.
- **Biological constraint:** Biological hardware (spiking neurons, connectivity) may block morphologies that are machine-feasible.
- **Chance absence:** Evolution may have not explored certain morphologies simply due to contingency.

## 9. Usage

1. For each biological taxonomy T, identify ecology E(T)
2. Apply PVR-3 to identify which morphology M satisfies E(T)
3. Map M → neural architecture J(M)
4. Compare J(M) to known neural architecture of T
5. Falsify if predicted J(M) ≠ actual J(T) for multiple taxonomies

## 10. Implementation Notes

This is a **formal structure**, not a biological hypothesis. The bridge provides:
- A **mapping schema** (M ↔ J)
- A **consistency test** (same E → same M, same J)
- A **scope definition** (G2 only, not G3+)
- A **falsification protocol** (identify E' with P(M') = satisfied, no T' → bridge false)

The bridge does NOT claim:
- Biological taxons "should" exist
- Any morphology is "preferred" by evolution
- Evolution follows machine morphology principles
