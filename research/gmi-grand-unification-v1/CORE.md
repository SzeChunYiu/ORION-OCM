# GMI scientific theory: read first

The [master declaration](GRAND_GMI_MASTER_THEORY_V1.md) fixes the causal-process
scope. The theory is a set of conditional results and constructions. A named
sector or successful finite replay does not establish universal completion.

The [all-partition separation](FULL_PARTITION_WIDTH_COMPUTATION_SEPARATION_V1.md)
matches every indexed input-partition width while separating expected query
work, and supplies the reverse control. This concerns the declared width/query
summaries; richer semantic and physical spectra need their own proof.

Parent results are cited and distinguished from the GMI applications in each
module. Exact finite checks challenge those applications; the analytic proofs
state the domain beyond the enumerated cases.

The stopping criterion for a registered claim is a valid proof/construction
with its assumptions discharged, or an explicit mathematical impossibility
with the requested feasible alternative investigated. A finite review cannot
certify that no further scientific question or counterexample exists.
