# 2. Common formal objects

## 2.1 Registered GMI scope

Write a registered scope as

\[
\Omega=(\mathcal W,\mathcal O,\mathcal E,\mathcal R,\mathcal V,\mathcal H,\Gamma,\mathcal C,\varepsilon),
\]

where:

- `W` is the admitted world/task family;
- `O` is the protected obligation / admissible-output relation;
- `E` is the ecology contract;
- `R` is the vector of resource prices and hard budgets, kept separate;
- `V` is the verifier / evaluator;
- `H` is developmental history;
- `Γ` is the legal neutral construction/search grammar;
- `C` is the external constitutional/protected-evaluation boundary;
- `ε` is the declared error tolerance.

This is a closure notation over the already-defined objects in `GRAND_GMI_MASTER_THEORY_V1.md`, `DEFINITIONS_V2_EXACT.md`, the A2 ecology contract, and #233. It adds no architecture label.

## 2.2 Morphology and lifecycle vector

For closure bookkeeping, a morphology is represented only by architecture-independent fields

\[
M=(F,O,\Pi,U,\Lambda,\Theta,J),
\]

with carrier/representation `F`, operators `O`, controller/schedule `Pi`, update law `U`, composition/topology `Lambda`, mutable state `Theta`, and external interfaces `J`.

Its complete registered lifecycle vector is

\[
c_\Omega(M)=(c_{desc},c_{state},c_{exec},c_{upd},c_{ver},c_{rev},c_{comm},c_{search},c_{acq},c_{lat},c_{fail}).
\]

No scalar `C(M)` exists unless a price vector was frozen before the protected result. Hard budgets and latency constraints are feasibility constraints, not prices that may be silently scalarized.

## 2.3 Obligation equivalence and target quotient

For histories/states `h,h'`, define

\[
h\sim_{\mathcal O}h'
\iff
\text{every registered continuation/probe gives the same protected obligation response.}
\]

At exact continuation-closed scope this is a right congruence; its quotient is the minimal obligation-sufficient semantic state. At approximate scope a tolerance relation need not be transitive; use a metric covering/packing object or an explicitly proved coarse-graining instead.

## 2.4 Five distinct questions that must never be collapsed

For a candidate property/family `K`:

```text
EXPRESSIBLE:  some Γ-composite has K.
ADMISSIBLE:   some K-composite satisfies the registered obligation/budgets.
REACHABLE:    the declared development/search process can reach K.
SELECTED:     K is on the frozen resource/Pareto optimum under the declared selector.
REPLICATED:   the prediction survives a disjoint encoding/search/scale/substrate test as required.
```

`EXPRESSIBLE => REACHABLE` is false in general. `ADMISSIBLE => SELECTED` is false in general. No rung of #602 may infer the next.

# 4. Formal residual theorem suite

## T602-01 — obligation-quotient necessity [P1]

Let `q(h)` be a machine state computed from history. If there exist `h1,h2` such that `q(h1)=q(h2)` but the protected obligation requires disjoint correct continuation behavior on the two histories, then no policy depending only on `q` can satisfy both.

**Proof.** The policy receives the same `q` in both cases and therefore induces the same action/output distribution. Disjoint required correct sets cannot both receive probability one (or exact correctness in the deterministic case). Contradiction. ∎

If the exact continuation-closed obligation quotient has finite index `K`, every exact deterministic realization therefore needs at least `K` distinguishable internal states, and the quotient transition system supplies a `K`-state constructive upper bound. In sequential language-recognition scope this is Myhill–Nerode, not GMI novelty.

**Residual:** one obligation-quotient object can be reused across families, resource channels and developmental states.

## T602-02 — residual-quotient lower bound [P1]

Let `S_P` be an already-available predictive state and `S_O` the protected target state. For each predictive class `p`, let

\[
m(p)=|\{s_O: P(S_O=s_O,S_P=p)>0\}|.
\]

Any exact residual symbol `R` from which `(S_P,R)` reconstructs `S_O` needs

\[
|R|\ge \max_p m(p),\qquad
B_{fixed}\ge \lceil\log_2\max_p m(p)\rceil.
\]

**Proof.** Fix a class `p` attaining the maximum. If fewer than `m(p)` residual symbols exist, two target states inside that class share the same `(p,r)` by pigeonhole, so exact reconstruction fails. ∎

Under ordinary probabilistic coding assumptions, expected residual information is lower bounded by `H(S_O|S_P)`. This is the formal core already exercised by #422; ordinary RAG/adapters/caches/databases remain parent-owned implementations.

## T602-03 — universal computation is insufficient for predictive GMI [P1/P5]

Computational universality implies representability, not a morphology/resource/development law.

**Construction.** Let universal interpreter `U` simulate target `M`. For every integer `d>0`, form a semantics-preserving interpreter `U_d` that performs `d` charged no-op steps before each simulated target step. All `U_d` compute the same target behavior, while lifecycle cost differs arbitrarily with `d`. Likewise multiple syntactic encodings/programs implement the same behavior with different acquisition/search burden.

Therefore universality alone does not identify:

```text
which morphology is Pareto-optimal;
which learning law is reachable;
where a phase boundary lies;
how much state/update/search/verification is required;
or which developmental path will be selected.
```

This formally witnesses the `UNIVERSAL_COMPUTATION_ONLY` null and agrees with `DEFINITIONS_V2_EXACT.md` §5.

## T602-04 — compensation-aware basis equivalence and minimality [P1]

For a registered cost-bound class `K` closed under composition, define `B1 ≡_K B2` iff every primitive of either basis has a semantics/development-preserving `K`-bounded compiler into the other.

Then `≡_K` is an equivalence relation. A primitive `p in B` is **K-resource-irreducible** only if no compensating composite over `B\{p}` implements `p` within `K` on the protected scope. A basis is K-minimal iff every primitive is K-resource-irreducible.

**Proof.** Reflexivity uses identity compilers; symmetry is definition; transitivity composes compilers and uses closure of `K`. The necessity criterion follows directly: if a bounded compensating compiler exists, removal does not change the generated equivalence class at K-resolution. ∎

**Consequence for #602 A1:** a unique syntactic primitive basis is not required and generally is the wrong target. The earned conclusion may be several K-equivalent minimal bases. `DEFINITIONS_V2_EXACT.md` already supplies typed primitives/combinators/no-smuggling machinery; #602 still needs a registered compensation census before its stricter A1 removal boxes can close.

## T602-05 — lifecycle reuse / compilation threshold [P1]

Suppose retained mechanism `m` replaces baseline `b` for `H` useful uses before invalidation. Under a prospectively frozen scalar price vector `w`, define per-use saving

\[
\Delta = w\cdot(c_b-c_m),
\]

and one-time/expected overhead

\[
K=w\cdot(c_{build}+c_{acq}+c_{maint}+E[c_{revision}]).
\]

Then retaining/compiling `m` is cheaper over that horizon iff

\[
H\Delta>K.
\]

For vector accounting, do not scalarize: compare the two attainable lifecycle vectors under hard budgets and report Pareto dominance/tradeoff.

This arithmetic is parent-owned by amortized analysis/indexing/library learning. The GMI residual is the repeated appearance of the same accounting across memory, skills, teaching, culture, compilation and routing.

## T602-06 — information-conditioned morphology value [P1]

Let `W` be world/ecology, `m` a morphology choice, `L(m,W)` frozen loss/cost, and `Z` side information observed before choosing `m`. Define

\[
R_Z=E_Z\min_m E[L(m,W)|Z],\qquad
R_0=\min_mE[L(m,W)].
\]

Then

\[
R_Z\le R_0.
\]

Equality holds iff there exists at least one morphology that is a conditional minimizer for every positive-mass value of `Z`; otherwise inequality is strict.

**Proof.** For any fixed `m0`, conditional minimization is no worse than choosing `m0`; take expectations and then choose the best fixed `m0`. Equality requires a common conditional minimizer, and such a minimizer is sufficient for equality. ∎

This is standard decision theory. #674's finite theorem/certificate is an exact instantiated pressure test, not a new decision-theory theorem.

## T602-07 — expressibility/reachability separation and hitting law [P1]

Let a development/search process propose at step `t` from a conditional distribution with target-set mass

\[
p_t=P(X_t\in A\mid\mathcal F_{t-1}).
\]

The conditional probability of avoiding the target through `T` steps is

\[
P(\tau_A>T)=E\left[\prod_{t=1}^T(1-p_t)\right]
\]

when `p_t` is the conditional hit probability induced by the registered process. In the iid constant-mass case, `P(τ>T)=(1-p)^T` and `E[τ]=1/p`.

If `p_t=0` on every reachable history, the target is unreachable even when the grammar can express it abstractly. If a grammar omits the necessary operator entirely, target mass is identically zero.

**Residual:** every neutral-recovery claim must establish both grammar support and nonzero search mass; a derivation theorem only establishes admissibility.

## T602-08 — no universal learning/update law [P5 + conditional P1]

NFL blocks a universally superior optimizer on unrestricted appropriately closed function classes. Therefore no GMI theorem may derive `gradient`, `Bayes`, `rule induction`, `evolution`, or any fixed update law as universally optimal.

The lawful target is conditional selection:

\[
U^*(E,R,V,H)\in\arg\min_{U\in\mathcal U_{adm}} E[L(U,W)|E,R,V,H].
\]

Examples of parent-owned sufficient conditions:

- for an `L`-smooth objective, gradient step `x'=x-η∇f(x)` satisfies
  `f(x') <= f(x)-η(1-Lη/2)||∇f(x)||²` for `0<η<2/L`;
- with a specified probabilistic model/prior/likelihood, Bayesian conditioning supplies the posterior; under proper scoring/Bayesian decision assumptions the corresponding Bayes action is parent-optimal;
- exact counterexamples/rule structure can make symbolic induction/synthesis preferable to smooth local updates;
- black-box rugged/no-derivative regimes may favor evolutionary/search proposals.

**GMI residual:** freeze an architecture-name-free descriptor that predicts which parent law enters the resource frontier, then recover it neutrally. Mechanism rediscovery alone is parent sufficient.

## T602-09 — deterministic and probabilistic capability information floor [P1]

If a capability contract has `K` world classes requiring pairwise incompatible exact actions, any exact deterministic sufficient state needs at least `K` distinguishable values, hence at least `ceil(log2 K)` bits in a fixed code.

For a uniform `K`-class target decoded from state `S` with error probability at most `ε`, Fano's inequality gives

\[
I(W;S)\ge \log_2K-h_2(\varepsilon)-\varepsilon\log_2(K-1).
\]

This parent information lower bound converts a capability contract into a resource floor; it does not say which architecture realizes the floor.

## T602-10 — interaction sign is not universal [P1/P5]

For baseline cost `C0`, mechanisms `A,B` and joint cost `CAB`, define synergy in saved cost

\[
Syn(A,B)=C_A+C_B-C_{AB}-C_0.
\]

All three signs are possible under valid nonnegative costs, e.g. with `C0=10`, `CA=CB=8`:

```text
CAB=3 -> Syn=+3  (joint complementarity)
CAB=6 -> Syn= 0  (additive)
CAB=7 -> Syn=-1  (interference)
```

Therefore F3/F4 cannot inherit a universal superadditivity claim. Interaction laws must be derived from shared state, shared search, communication, verification, or frozen-budget competition in the registered ecology. The bounded F3 pairwise rows in #670/#671/#672 are P2 instances of this general fact.

## T602-11 — developmental-history switching threshold [P1]

Suppose installed morphology `A` can be migrated to `B` at future charged cost `K>0`, and `B` thereafter saves `Δ>0` per future block. With `h` blocks remaining, switching is strictly cheaper iff

\[
h\Delta>K.
\]

The first integer horizon favoring migration is

\[
h^*=\lfloor K/\Delta\rfloor+1.
\]

Direction-dependent switching costs yield ordinary hysteresis/path dependence; zero migration cost erases that source of history dependence. #680 is a prospective finite instantiation. Switching-cost, warm-start and indexing parents own the mechanism.

## T602-12 — evolvability/search-burden law [P1 + P3 boundary]

For proposal kernel `Q(.|x)` and registered useful-successor set `U`, define

\[
Ev(x;U)=Q(U|x).
\]

Under iid proposals with exact verifier and constant proposal/verification cost `c`, expected first-success burden is `c/Ev` for `Ev>0`. If an inherited transformation changes mass from `p` to `p'`, it reduces expected proposal count iff `p'>p`; full lifecycle benefit additionally requires the saved future burden to exceed acquisition, maintenance and revision cost.

For prefix-coded Levin-style allocation, shortening a target code by `Δ` bits multiplies nominal search share by `2^Δ`, but wall-time improvement is conditional on execution/verification/scheduler costs.

This belongs to Levin/OOPS/evolvability parents. The GMI/HST residual is prospective prediction of the transformation under a registered future-task ecology.

## T602-13 — capability species is an equivalence/preorder, not a label list [P1]

At scope `Ω` and bound class `K`, define `M1 <=_K M2` when there exists a K-bounded compiler/simulator from `M1` into `M2` preserving protected capability/development profiles. Mutual simulation induces `M1 ≡_K M2` when `K` is composition-closed.

A distinct GMI species at scope therefore requires more than a different architecture name: it needs a nonempty capability/resource region plus failure of every registered bounded reduction in at least one direction, or a proved lower-bound separation.

**Consequence:** F/G species work must quotient implementation variants before counting species.

## T602-14 — finite domain closure is decidable; universal semantic domain closure is not [P2/P5]

For a finite grammar, finite input/world set, finite resource cap and decidable protected equivalence, candidate generation and pairwise reduction are finite and exhaustive. Domain closure is therefore decidable at that registered finite scope.

For unrestricted programs, any nontrivial extensional property of the partial function computed is undecidable by Rice's theorem. Semantic equivalence is likewise undecidable in general. Therefore there is no general algorithm that certifies universal absence of every semantically distinct computational domain over arbitrary programs.

**Required #602 wording:** `DOMAIN_BASIS_COMPLETE_AT_REGISTERED_FINITE_SCOPE`, never universal ontological completeness.

## T602-17 — causal observational alias iff the causal target fails to factor through observation [P1]

Let `Θ` be the registered causal-model state class. Let

\[
O(\theta)=\text{registered observational predictive object},\qquad
I(\theta)=\text{registered interventional/counterfactual target}.
\]

Then observational prediction is sufficient for target `I` **iff** there exists a function `g` such that

\[
I=g\circ O.
\]

Equivalently,

\[
O(\theta_1)=O(\theta_2)\Longrightarrow I(\theta_1)=I(\theta_2)
\]

for all admitted `θ1,θ2`.

**Proof.** If `I=g∘O`, equal `O` gives equal `I`. Conversely, if `I` is constant on every fiber of `O`, define `g(o)` as that common `I` value for any `θ` with `O(θ)=o`; this is well defined. ∎

Thus observational prediction **aliases causal states** exactly when there exist `θ1,θ2` with equal observational object but different causal target. No learner using only `O` can identify which target holds for both models.

This closes the missing converse condition in #602 I5 at the formal level. SCM/do-calculus/causal-identifiability parents own the causal semantics.

### T602-17b — active-causal parent subtraction

Let experiment/intervention `e` induce observation `Z_e`. Choosing interventions to achieve that at minimal cost is active causal learning/Bayesian experimental design/value-of-information territory. GMI owns no separate intervention algorithm unless a residual survives those parents; its possible residual is only the shared lifecycle/morphology phase law.

## T602-18 — cross-substrate/natural-intelligence identifiability boundary [P1/P4]

Let biological/physical measurement map `ψ` send substrate states to registered observations. If `ψ(s1)=ψ(s2)` but the GMI capability prediction/obligation requires different outputs for `s1,s2`, no predictor using only `ψ` can be correct on both. This is T602-01 on a cross-substrate measurement channel.

Therefore G10 cannot be earned by analogy (`"brain has memory"`, `"attention resembles routing"`). ## T602-19 — fixed-sample concentration is not adaptive validity [P1/P3]

For iid `X_i in [0,1]` with mean `μ`, Hoeffding gives

\[
P(|\bar X-\mu|\ge\epsilon)\le2e^{-2N\epsilon^2}.
\]

This justifies a registered fixed-sample interval under its sampling assumptions. It does **not** justify repeatedly inspecting the same protected set, selecting hypotheses from its outcomes, then reporting the original fixed-test guarantee. Adaptive reuse requires fresh protected data or a theorem designed for adaptive analysis/sequential validity.

Remint/invariance testing is an anti-leakage/implementation check; it is not statistical independence and does not count as an independent real-world replication.

#681's Hoeffding experiment is therefore correctly scoped as controlled synthetic P3 evidence, not real-world phase-boundary uncertainty.

## T602-20 — finite-data extrapolation non-identifiability [P5]

Let distinct training inputs be `x_1,...,x_n` and let fitted law `f` match all observed values. For any nonzero scalar `a`, define

\[
g_a(x)=f(x)+a\prod_{i=1}^n(x-x_i).
\]

Then `g_a(x_i)=f(x_i)` for every observed point, while outside the training set `g_a` can diverge arbitrarily as `a` varies.

Therefore no finite set of exact fitted points identifies an unrestricted out-of-range scaling law. Extrapolation requires a prospectively restricted function/model class or structural assumption plus protected out-of-range tests.

#681 does exactly the right finite thing: restrict to an affine law, require zero residual on extra training sizes, freeze larger-size predictions, then test `n=17,31`. Passing would validate that registered extrapolation only; it would not prove universal scaling.

## T602-21 — complete lifecycle accounting invariants [P1]

For a fixed system boundary, each physical/computational event is charged exactly once to an identified lifecycle stage. Let stage event sets `E_j` be disjoint and exhaustive over the registered run. Then total coordinate cost is

\[
c_k=\sum_j\sum_{e\in E_j}c_k(e).
\]

If event sets overlap, summing stage reports double-counts. If their union omits proposal failures, compilation, acquisition, migration, verification or maintenance, the report undercounts. A scalar total is meaningful only after a prospectively frozen price vector; hard latency/capacity constraints remain separate feasibility predicates.

This turns #602 N from a prose desideratum into an auditable accounting condition.

A P2 certificate can refute a universal claim and can verify a finite theorem instance, but cannot promote an unproved universal statement to P1.
