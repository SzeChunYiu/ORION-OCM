# Epistemic Acquisition Integration V1

This tranche adds no primitive to the Grand-GMI master tuple.

For the explicit complete-response identification obligation, the derived acquisition object is

\[
\eta_\Omega(\mathcal E,\Theta,\rho)
=
\inf\{\text{experiment resource}:\text{the obligation-relevant ecology quotient is identified}\}.
\]

It lives between semantic definition and developmental action:

\[
(\mathbf P,\mathcal B,\mathcal E,\Omega,\Theta,\rho,\mathcal D)
\to S^*
\to \underbrace{\eta_\Omega}_{\text{learn which semantic ecology class obtains}}
\to (\kappa,\tau)
\to Reach_{\mathcal D}
\to (\mathcal F,\mathcal F^{reach}).
\]

Equivalently, `eta_Omega` is a named derived specialization of `tau` and `D` for transformations whose purpose is to acquire obligation-relevant distinctions through interventions in `Theta`.

Consequences:

1. **Exploration** is experiment selection whose outcome changes future reachable semantic state.
2. **Active learning** can optimize `eta_Omega` for response identification; adequate-action acquisition instead uses the compatible-leaf value `V` of TDA-1.
3. **Causal discovery** requires complete graph identity when the declared scientific target demands it. A successful-action target may need less information even than the complete response quotient.
4. **Scientific discovery** is recovered by choosing an obligation that explicitly values the richer explanatory/model distinction; GMI does not force instrumental coarsening when the scientific goal requires full identification.
5. **Embodied sensing/action** can trade experiment cost against downstream `kappa/tau/rho`, making information acquisition part of the morphology frontier rather than a preprocessing step.

The master ontology therefore remains unchanged; the quantitative law becomes sharper.

For an erased acquisition transcript and an `m`-symbol terminal carrier,
TDA-3 makes the connection constructive: minimize `V_D` over output action
sets of size at most `m`. This jointly selects the experiment tree and its
retained information. The exact frontier `{(1,3),(2,2)}` proves that separately
minimal experiment and memory coordinates need not be jointly attainable.
