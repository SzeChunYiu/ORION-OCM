# Grand GMI novelty priority protocol V1

Status: **REQUIRED BEFORE PRIORITY LANGUAGE**  
Date: 2026-09-13

This protocol separates theorem validity from scholarly priority. Passing a finite checker, having no known counterexample, or failing to find a paper in one search does not establish novelty.

## N1 — freeze the residual

Write the candidate result as a theorem with exact hypotheses, conclusion, scope and explicit parent-subtraction target. Freeze the statement before the priority search. A later weakening/strengthening is a new candidate and restarts the audit.

## N2 — search by at least three vocabularies

Search primary literature under:

1. GMI vocabulary;
2. the nearest classical parent vocabulary;
3. a deliberately foreign vocabulary from another field likely to contain an isomorphic result.

Examples: `semantic cut` / `zero-error functional compression` / `communication complexity of relations`; `morphology frontier` / `vector optimization realization set` / `resource theory`; `architecture-neutral development` / `quotient-compatible search` / `invariant optimization on equivalence classes`.

Record search date, databases/engines, exact queries and strongest hits.

## N3 — strongest-parent test

For every candidate, write the strongest parent theorem in the same notation where possible. Then establish one of:

- `EQUIVALENT_TO_PARENT`: parent implies GMI claim and vice versa at the relevant scope;
- `PARENT_STRICTLY_STRONGER`: no GMI novelty;
- `GMI_STRICTLY_STRENGTHENS`: exhibit a model satisfying GMI hypotheses/conclusion outside parent scope or prove a formal strict implication;
- `INCOMPARABLE`: exhibit witnesses in both directions;
- `NO_MAPPING_FOUND`: novelty remains unresolved, not supported.

A naming change is never a strengthening.

## N4 — parallel-framework subtraction

For broad framework claims, explicitly compare against the contemporary Answerability programme as well as older parent disciplines. Similarity of terminology is not enough; compare primitives, derived objects, theorem statements, resource semantics, composition and empirical/prospective obligations.

## N5 — independent review

A second reviewer who did not author the theorem must repeat the search and strongest-parent mapping. Disagreement leaves the status `TECHNICAL_NOVELTY_CANDIDATE`.

## N6 — empirical priority

For an empirical/prospective novelty claim, freeze before outcome access:

- ecology/task/substrate;
- predicted operational region or law;
- falsifier;
- parent baselines and their optimization budget;
- selection/adjudication rule;
- resource accounting and measurement instrument.

A result is `PROGRAMME_EMPIRICAL_NOVELTY` if it adds new evidence to this programme. It is `HUMANITY_WIDE_NOVEL_FORM_CANDIDATE` only if a dated literature census found no prior occupant of the operational signature before search, and an independently produced realization later occupies it.

## N7 — allowed language

| Status | Allowed public wording |
|---|---|
| `PARENT_OWNED_SPECIALIZATION` | “GMI specializes / applies / rederives …” |
| `NEW_SYNTHESIS_CANDIDATE` | “GMI proposes a unified synthesis of …” |
| `TECHNICAL_NOVELTY_CANDIDATE` | “candidate new result; priority not established” |
| `PRIORITY_SUPPORTED` | “we found no prior theorem after the committed priority protocol; independent review agrees” |
| `PROGRAMME_EMPIRICAL_NOVELTY` | “new prospective/empirical evidence in the GMI programme” |
| `PROSPECTIVE_INTERNAL_NOT_HUMANITY_WIDE` | “predicted before execution in the frozen GMI registry” |

Never convert `NO_MAPPING_FOUND` into `PRIORITY_SUPPORTED`.

## N8 — reopening

Reopen a novelty classification immediately if a stronger parent, earlier theorem, equivalent framework, prior implementation or pre-existing empirical result is found. Priority corrections are additive; historical claims are not silently edited away.
