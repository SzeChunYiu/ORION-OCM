## 1. Phenomenology sufficiency criterion

A named mechanism `Z` has an operational machine-intelligence effect at the declared resolution only if introducing/removing/intervening on `Z` changes at least one protected object:

1. a protected response profile / semantic state distinction;
2. a semantic cut requirement or available cut channel;
3. a required/available local transformation and its complexity;
4. a physical feasibility/resource coordinate;
5. a developmental transition/reachable morphology;
6. a declared symmetry/factorization/boundary;
7. the ecology, obligation or probe family itself.

If none changes, the two systems have the same complete protected behavior/resource/developmental disposition at the declared resolution and Grand GMI intentionally identifies them.

**GG53 — Phenomenon Invisibility Theorem.** A mechanism that changes none of the master primitive/derived operational objects has no distinguishable intelligence effect at the declared GMI resolution.

This theorem is not vacuous architecture renaming: the master objects carry independent lower bounds, composition laws, no-go theorems and physical constraints already proved in layers 1–9.

## 3. Exact microscopes for characteristic phenomena

### 3.1 Memory is a temporal cut

A hidden symbol `x in {0,...,m-1}` appears before a delay and must be reproduced after it. No later observation contains `x`. Exact success requires the persistent machine state after the observation to distinguish all `m` values; otherwise two values collide and the downstream decoder cannot output both correctly.

Therefore

\[
|S_{memory}|\ge m.
\]

The checker exhausts encodings for `m=1..6` and confirms that no smaller state alphabet admits an injective code while `m` states do.

**GG54 — Temporal Memory Cut Theorem.** Exact delayed reproduction of `m` obligation-distinct possibilities through an otherwise uninformative interval requires at least `m` persistent semantic memory states.

### 3.2 Attention/dynamic routing is conditional cut allocation

World `(x0,x1,q)` is uniform binary and the obligation is `x_q`.

A fixed one-source route that always exposes only `x0` (plus `q`) has best exact average accuracy `6/8=3/4`; the same holds for fixed `x1`. A selector-aware route that exposes `x_q` achieves `8/8=1`.

This proves a precise, architecture-free condition under which dynamic routing has value: **which source carries the needed semantic distinction depends on context**.

**GG55 — Conditional Routing Advantage.** Under a finite access constraint, context-dependent routing can strictly dominate every fixed source choice when the obligation-relevant source varies with context.

This is a theorem about channel allocation, not about softmax attention or Transformers.

### 3.3 In-context adaptation is deployment-time side information

A hidden task bit `t` selects the rule `y=x XOR t`. Weights/program are frozen before `t` is selected.

Without a prompt revealing `t`, a machine seeing only `x` is correct on at most `2/4=1/2` uniformly over `(t,x)`. With a one-bit prompt carrying `t`, a fixed downstream transducer achieves `4/4=1`.

**GG56 — Context Side-Information Theorem.** Capability can change at deployment with fixed long-term parameters solely because query-time context changes the semantic cut information and transient state.

No parameter update is required for the phenomenon to be real.

### 3.4 Continual retention is a multi-time temporal cut

Two independent binary facts `(x,y)` must both be output exactly after sequential learning episodes. Any final persistent state with fewer than four distinguishable values merges two obligation-distinct pairs and cannot decode both exactly. Four states are sufficient.

The checker exhausts all encodings to state alphabets of sizes 1..4: injective encodings exist only at size four (24 bijections).

**GG57 — Retention Capacity Theorem.** Exact retention of `m` independently obligation-distinct joint histories requires enough final semantic state to distinguish their joint response classes; later adaptation cannot erase them without violating the retained obligation.

Catastrophic forgetting is therefore a developmental violation of a temporal semantic-cut requirement.

### 3.5 Tool/oracle use moves transformation complexity across a boundary

For parity of `n` independent input bits in a deterministic bit-query model, every input bit is relevant: for each bit there are paired inputs differing only in that bit with opposite outputs. Any exact decision tree must therefore query all `n` bits in the worst case.

If the boundary instead includes one declared exact parity oracle with direct access to those bits, one tool call returns the protected answer. The task semantics have not changed; the process theory/boundary and transformation resource have.

**GG58 — Tool Boundary Theorem.** External tools affect intelligence capability by adding a process/channel/transformation to the declared system boundary; their apparent computational gain must be charged to tool access, communication and tool resources rather than attributed to a new semantic primitive.

## 4. No-new-primitive result for the registered atlas

Every phenomenon in §2 admits a typed reduction to the existing master tuple/objects. None requires adding a primitive such as `attention`, `neuron`, `symbol`, `language model`, `planner`, `agent society`, `tool`, `memory module` or `evolution` to the foundational declaration.

**GG59 — Registered Phenomenology Reduction Closure.** For the phenomena listed in this frozen atlas, every claimed operational role factors through existing Grand-GMI primitives/derived objects; no additional architecture-specific foundational primitive is required.

This is a **coverage/reduction theorem about the registered atlas**, not a proof that no future physical phenomenon can ever require extension.

### Falsifier for GG59 / master-ontology saturation

A genuine ontology counterexample must exhibit a causal machine-intelligence phenomenon for which two systems agree on all currently declared master primitives and derived response/resource/development objects yet differ on a protected operational capability. If such a reproducible case exists, the master tuple is incomplete and must be extended.

Merely introducing a new architecture name or implementation trick is not a counterexample.

## 5. What remains explanatory rather than merely taxonomic

A reduction becomes a strong explanation only when Grand GMI derives a necessity, upper/lower capability law, phase boundary or constructive frontier for the relevant ecology/resources. Current strength varies:

- **exact/tight sectors:** finite semantic cuts, several channel laws, finite operational frontiers, selected verifier/retrieval/noise/memory compositions, recursion/product laws, selected physical/quantum capacity constraints;
- **structurally explained but quantitatively open at modern scale:** attention routing geometry, large-model feature learning, optimization dynamics, continual learning, broad OOD generalization, tool ecosystems, modern multi-agent systems, empirical scaling exponents;
- **empirical application programme:** measured `rho`, realistic `tau`, prospective architecture-neutral phase predictions and independent replications.

This distinction is preserved deliberately. Grand unification should compress phenomena into a small law set; it should not convert unmeasured constants into theorems.
