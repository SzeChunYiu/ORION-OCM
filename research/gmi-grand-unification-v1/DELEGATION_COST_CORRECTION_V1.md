## Failure and constructive repair

The old pair counted visible Python opcodes and opaque call boundaries.
A transparent partial wrapping the written shared-sum parent receives (32,8);
an object with Python-coded subscription receives (32,0). Both are below the
parent's (312,32) while still executing its work. The count of an opaque
boundary cannot substitute for the work behind it. The original positive
controls remain reproducible; they did not cover these counterexamples.

DCR uses a finite immutable typed source register and explicit transparent
partial bindings. Exact primitive types prevent hidden Python method dispatch;
unsupported objects, instructions or calls are refused. Every admitted
descendant Python opcode is retained in order, together with separate native
and adapter obligations. Its independent native oracle compares complete
instruction sequences and outputs on 304 executions.

The direct and partial wrappers now each have 344 Python opcodes per sweep
and retain all 32 native-int obligations of the 312-opcode parent. The partial
adds eight adapter obligations. An exact tuple lookup is a positive control;
the implicit Python object is refused before invoking its method.

If a complete child trace preserves the parent's ordered events and merely
inserts events, every declared nonnegative additive event-cost assignment is
monotone. Strictness additionally needs a positive inserted charge. This
conditional statement does not cover arbitrary refactoring or context-sensitive
hardware costs. Unknown native-resource contracts yield an unknown upper bound,
not zero. No native weights were fitted to restore an ordering.

## Structural and physical limits

The [STR analytic correction](STRUCTURAL_THRESHOLD_ANALYTIC_CORRECTION_V1.md)
still proves 39 opcodes per input and 312 per full domain for its two flat
written shapes. DCR's larger source class inherits no such minimum or complete
frontier. Setup, source descriptions, monitoring, acquisition, native work and
lifetime costs require their own accounting before any physical comparison.
