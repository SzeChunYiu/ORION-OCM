# 2. Common formal objects

Use a registered scope

\[
\Omega=(\mathcal W,\mathcal O,\mathcal E,\mathcal R,\mathcal V,\mathcal H,\Gamma,\mathcal C,\varepsilon),
\]

where `W` is the world/task family, `O` protected obligation, `E` ecology, `R` resource prices/hard budgets, `V` verifier, `H` developmental history, `Γ` legal neutral construction/search grammar, `C` protected constitutional boundary and `ε` declared error tolerance.

A morphology is bookkeeping-only architecture-independent structure

\[
M=(F,O,\Pi,U,\Lambda,\Theta,J)
\]

with representation/carrier, operators, controller, update law, composition/topology, mutable state and external interfaces.

The lifecycle vector is

\[
c_\Omega(M)=(desc,state,exec,upd,ver,rev,comm,search,acq,lat,fail).
\]

No scalar total exists unless a price vector was frozen before protected outcomes. Hard capacity and latency remain feasibility constraints.

For histories `h,h'`, exact obligation equivalence is

\[
h\sim_{\mathcal O}h'
\iff
\text{all registered continuations/probes have identical protected obligation response.}
\]

At continuation-closed sequential scope this is a right congruence. Approximate `distance <= ε` is not automatically transitive and must not be called a quotient unless transitivity is separately established.

Finally keep five questions distinct:

```text
EXPRESSIBLE: Γ contains a composite with the property.
ADMISSIBLE:  such a composite can satisfy obligation/budgets.
REACHABLE:   the declared development/search process can reach it.
SELECTED:    it is on the frozen optimum/Pareto frontier.
REPLICATED:  it survives the required disjoint encoding/search/scale/substrate test.
```

No implication to the next rung is automatic.

# 4. Formal residual theorem suite

## T602-01 — obligation-quotient necessity [P1]

If a machine encoding `q` maps two histories to the same state while the protected obligation requires pairwise incompatible correct continuation behavior, no policy using only `q` can be exact on both.

**Proof.** The policy receives the same state and therefore cannot produce two incompatible exact responses. ∎

For a continuation-closed sequential obligation with finite quotient index `K`, every exact deterministic realization needs at least `K` distinguishable states; the quotient transition system gives a matching `K`-state realization. In regular-language scope this is Myhill–Nerode, not GMI novelty.

## T602-02 — residual-quotient lower bound [P1]

Let predictive state be `S_P` and protected target state `S_O`. For predictive class `p`, define

\[
m(p)=|\{s_O:P(S_O=s_O,S_P=p)>0\}|.
\]

Any exact residual symbol `R` from which `(S_P,R)` reconstructs `S_O` needs

\[
|R|\ge\max_p m(p),\qquad B_{fixed}\ge\lceil\log_2\max_p m(p)\rceil.
\]

**Proof.** In a class attaining the maximum, fewer residual symbols force two target states onto the same `(p,r)` by pigeonhole. ∎

Under ordinary probabilistic coding assumptions expected residual information is lower-bounded by `H(S_O|S_P)`. This is already the core of #422; RAG/adapters/caches/databases remain parent-owned realizations.

## T602-03 — universality does not imply predictive GMI [P1/P5]

Take universal interpreter `U` for target `M`. For every `d>0`, construct semantics-preserving `U_d` that executes `d` charged no-ops before each simulated target step. All compute the same behavior while cost differs arbitrarily.

Hence universality alone determines neither morphology frontier, learning law, phase boundary, state/update/search/verification burden nor developmental trajectory. This is an explicit `UNIVERSAL_COMPUTATION_ONLY` witness and matches `DEFINITIONS_V2_EXACT.md` §5.

## T602-04 — compensation-aware basis equivalence/minimality [P1]

For bound class `K` closed under compiler composition, define `B1 ≡_K B2` iff each primitive of either basis has a semantics/development-preserving `K`-bounded compilation into the other. Then `≡_K` is an equivalence relation.

Primitive `p in B` is K-resource-irreducible only if no compensating composite over `B\{p}` implements it within `K`. A K-minimal basis has every primitive irreducible.

**Proof.** Identity gives reflexivity, mutual compilation symmetry, and compiler composition plus closure of `K` transitivity. A compensating bounded compiler defeats necessity at that resolution. ∎

Thus #602 A1 may validly terminate `MULTIPLE_EQUIVALENT_MINIMAL_BASES`.

## T602-05 — lifecycle reuse/amortization threshold [P1]

If retained mechanism `m` replaces baseline `b` for `H` useful uses before invalidation, under prospectively frozen price vector `w` let

\[
\Delta=w\cdot(c_b-c_m),\qquad
K=w\cdot(c_{build}+c_{acq}+c_{maint}+E[c_{revision}]).
\]

Retention is cheaper over that horizon iff `HΔ>K`. Without a frozen scalar price vector compare full lifecycle vectors/Pareto feasibility. The arithmetic is parent-owned by amortized analysis/indexing/library learning; the possible GMI residual is the shared cross-morphology accounting object.

## T602-06 — information-conditioned morphology value [P1]

Assume a finite morphology set, or attainment of the minima. Let `W` be world, `m` choice, `L(m,W)` frozen loss and `Z` information observed before choice. Define

\[
R_Z=E_Z\min_mE[L(m,W)|Z],\qquad R_0=\min_mE[L(m,W)].
\]

Then `R_Z <= R_0`. Equality holds iff at least one morphology is a conditional minimizer for every positive-mass `Z`; otherwise inequality is strict.

**Proof.** Conditional minimization is no worse than any fixed `m0`; take expectations and then minimize over `m0`. A common conditional minimizer is exactly the attained equality case. ∎

This is decision-theory parent material; #674 is a finite instantiation.

## T602-07 — expressibility/reachability separation and hitting bounds [P1]

Let target set be `A` with first hit `τ_A`. If, on every not-yet-hit history,

\[
p_t=P(X_t\in A\mid\mathcal F_{t-1},\tau_A\ge t)\ge p_{min}>0,
\]

then iterated conditioning gives

\[
P(\tau_A>T)\le(1-p_{min})^T.
\]

For iid proposals with target mass `p`, `P(τ_A>T)=(1-p)^T` and `E[τ_A]=1/p`.

If target mass is zero on every reachable not-yet-hit history, the target is unreachable even if another abstract grammar can express it. If a necessary operator is absent from the registered grammar, it is likewise unreachable there. Neutral recovery therefore needs both grammar support and nonzero search support.

## T602-08 — no universal learning/update law [P5 + conditional P1]

NFL blocks a universally superior optimizer on unrestricted appropriately closed problem classes. GMI therefore cannot universally derive gradient descent, Bayes, rule induction, evolutionary search or another fixed law as *the* law.

The correct target is conditional:

\[
U^*(E,R,V,H)\in\arg\min_{U\in\mathcal U_{adm}}E[L(U,W)|E,R,V,H].
\]

Parent-owned sufficient examples include the smooth-descent inequality

`f(x-η∇f(x)) <= f(x)-η(1-Lη/2)||∇f(x)||²` for L-smooth `f` and `0<η<2/L`, Bayesian conditioning under a declared model, rule/program induction under discrete counterexample structure, and derivative-free/evolutionary search in matched black-box regimes.

The possible residual is an architecture-name-free ecology/resource descriptor predicting which parent law enters the frontier and surviving neutral recovery/negative twins.

## T602-09 — capability information floor [P1]

If a capability contract has `K` world classes requiring pairwise incompatible exact actions, exact deterministic sufficient state needs at least `K` values and a fixed code at least `ceil(log2 K)` bits.

For uniform K-class target `W` decoded from state `S` with error at most `ε`, Fano gives

\[
I(W;S)\ge\log_2K-h_2(\varepsilon)-\varepsilon\log_2(K-1).
\]

This is an information-theory parent floor, not an architecture-selection theorem.

## T602-10 — interaction sign is not universal [P1/P5]

For lower-is-better baseline cost `C0`, mechanisms `A,B` and joint cost `CAB`, define synergy of saved cost

\[
Syn(A,B)=C_A+C_B-C_{AB}-C_0.
\]

With `C0=10`, `CA=CB=8`: `CAB=3` gives +3, `CAB=6` gives 0, `CAB=7` gives -1. Hence no universal complementarity sign exists. F3/F4 interactions must derive from shared state/search/communication/verification or budget competition. #670/#671/#672 are bounded P2 instances.

## T602-11 — developmental-history switching threshold [P1]

If installed morphology `A` can migrate to `B` at cost `K>0` and `B` saves `Δ>0` per future block, with `h` blocks left switching is strictly cheaper iff `hΔ>K`; first integer crossover is

\[
h^*=\lfloor K/\Delta\rfloor+1.
\]

Directional migration costs yield ordinary hysteresis/path dependence; zero migration cost removes this source. #680 is a finite prospective instance; switching/indexing/warm-start parents own the mechanism.

## T602-12 — evolvability/useful-descendant burden [P1 with P3/P4 boundary]

For proposal kernel `Q(.|x)` and useful-successor set `U`, define `Ev(x;U)=Q(U|x)`. Under iid proposals, exact verifier and constant charged attempt cost `c`, expected first-useful-success burden is `c/Ev` for `Ev>0`. An inherited transformation is beneficial only after charging acquisition, maintenance and revision.

Under prefix-coded Levin-style allocation, shortening a target code by `Δ` bits multiplies nominal search share by `2^Δ`; wall-time benefit still depends on scheduler/execution/verification. These are Levin/OOPS/evolvability parents; HST's residual is prospective future-ecology prediction.

## T602-13 — species equivalence/preorder [P1]

At scope `Ω` and compiler class `K`, define `M1 <=_K M2` when a K-bounded compiler/simulator preserves protected capability/development profiles. Mutual simulation gives equivalence when `K` is composition-closed.

A distinct species needs more than an architecture name: a nonempty capability/resource region plus failure of registered bounded reductions in at least one direction, or a proved lower-bound separation. Implementation variants are quotiented first.

## T602-14 — finite domain closure vs universal undecidability [P2/P5]

With finite grammar, finite world/input set, finite resource cap and decidable protected equivalence, candidate generation and registered reductions are finite; domain closure is decidable at that scope.

For unrestricted programs, nontrivial extensional properties are undecidable by Rice's theorem and general semantic equivalence is undecidable. Thus no universal algorithm can certify absence of every semantically distinct computational domain. Correct terminal: `DOMAIN_BASIS_COMPLETE_AT_REGISTERED_FINITE_SCOPE`.

## T602-17 — causal observational alias iff target fails to factor through observation [P1]

Let admitted causal state be `θ`, observational object `O(θ)` and protected interventional/counterfactual target `I(θ)`. Observational prediction is sufficient for `I` iff a function `g` exists with `I=g∘O`, equivalently

\[
O(\theta_1)=O(\theta_2)\Rightarrow I(\theta_1)=I(\theta_2)
\]

for every admitted pair.

**Proof.** Factorization gives the implication. Conversely, if `I` is constant on each fiber of `O`, define `g(o)` as that common value; it is well-defined. ∎

Therefore observational prediction aliases causal states exactly when equal observational objects permit different causal targets. This closes the missing #602 I5 converse; SCM/identifiability theory owns the causal semantics.

## T602-18 — cross-substrate identifiability boundary [P1/P4]

Let measurement map `ψ` send biological/physical states to registered observations. If `ψ(s1)=ψ(s2)` while the protected GMI target differs, no predictor using only `ψ` can be correct on both. Thus G10 cannot be earned by analogy; it needs held-out operational measurement/intervention preserving needed distinctions and strongest cognitive/neuroscience comparators. ## T602-19 — fixed-sample concentration is not adaptive validity [P1/P3]

For iid `X_i in [0,1]` with mean `μ`, Hoeffding gives

\[
P(|\bar X-\mu|\ge\epsilon)\le2e^{-2N\epsilon^2}.
\]

This licenses a fixed-sample statement under its assumptions, not repeated outcome-adaptive reuse of the same protected sample with the original guarantee. Adaptive reuse needs fresh protected data or an adaptive/sequential-validity theorem. Remint is an anti-leakage/invariance check, not statistical independence. #681's Hoeffding experiment is controlled synthetic P3 evidence only.

## T602-20 — finite-data extrapolation non-identifiability [P5]

For distinct observed `x_1,...,x_n`, any fitted law `f`, and nonzero `a`, let

\[
g_a(x)=f(x)+a\prod_{i=1}^n(x-x_i).
\]

Then `g_a(x_i)=f(x_i)` for every observed input while the functions can diverge arbitrarily outside the set. Therefore finite exact fit does not identify an unrestricted out-of-range law. Extrapolation needs a preregistered function/regularity class plus protected out-of-range testing. #681's affine restriction and frozen `n=17,31` predictions test that finite class only.

## T602-21 — complete lifecycle accounting invariant [P1]

Fix the system boundary. Partition run events into disjoint lifecycle stages `E_j`, whose union covers every charged event. For resource coordinate `k`,

\[
c_k=\sum_j\sum_{e\in E_j}c_k(e).
\]

Overlapping stage event sets double-count; omissions undercount. A single event may contribute to several *resource coordinates* via its cost vector, but belongs to one lifecycle stage for stage aggregation. Scalarization still needs a frozen price vector.

## T602-22 — theorem / certificate / empirical separation [P1 governance]

A theorem contains definitions, assumptions, statement and derivation independent of witness code. P2 exhaustive certificates verify finite instances or refute universals; they do not promote unproved universal statements to P1. P4 positives do not become P1–P3 by wording. Each theorem-shaped #602 row therefore needs proof, checker/proof assistant where feasible, hostile countermodel and claim ceiling.

## T602-23 — #602 closure is a dependency conjunction [P1]

Let target maps be architecture/domain derivation `A`, capability prediction `B`, development prediction `C`, and domain discovery `D`. For claim rung `r` with required gates `Gates(r)`,

\[
Closure_r(\Omega)=A_r\land B_r\land C_r\land D_r\land\bigwedge_{g\in Gates(r)}g.
\]

A single open required antecedent blocks the higher-rung claim. Issue state or checkbox percentage is not scientific closure.
