specification/ecology (`R01`); `P3`/`P4` grammar (`R02`); no family macros

lower bound where possible (`R06`); resource crossover (`R07`); held-out frozen
prediction (`R08`); independent regeneration (`R09`); independent search
(`R10`); real-scale test (`R11`).

Two packages already certify ten of eleven for these three rows, each at its
own scope: `gmi-833-h-neutral-four-family-v1` at `SIGMA_4F` (a finite `Z3`
grammar over an eight-point state representation), and
`gmi-833-h-real-scale-classical-v1` at `SIGMA_H02`/`SIGMA_H03`/`SIGMA_H04`

It is **invalid** to add the missing certificate at a different scope and
declare the conjunction. That is `CROSS_SCOPE_GATE_COMPOSITION`, forbidden by
`gmi-833-h-family-requirement-ledger-v1` `HRL-1` and proved invalid by PR #997
`FGS-2`. A scope is the tuple `(family row, grammar, ecology, budget, freeze,
protected interface)`; every one of those coordinates moves here.

**Therefore this package imports no gate certificate from any parent. It earns
all eleven coordinates at its own three scopes, self-contained.** The parents
supply form — one lower grammar shape, the eleven-coordinate ledger shape, the
post-hoc structural classifier idea, the charged-cost model idea — and are
cited as the strongest parents in `PARENT_LEDGER.md`. They supply no evidence
that is counted here. Reading a parent's *slice rule* to prove this package's
held-out rows are not a parent's held-out rows is custody hygiene and is done;
reading a parent's *number* as evidence is forbidden and is not done.

A test asserts that no gate certificate emitted here carries a `sigma` that is
not one of this package's own three, and that no parent result file is read by
the checker.

- `D3` = the CPython 3.8 standard-library sources

### The three ecologies, registered before any of them is built

`F02` (`SIGMA_R02`). Concatenate `D2` in filename order into one PCM sequence
`x_0 .. x_{N-1}`. Row `t` for `t = 0 .. N-34` has design
`(x_t, x_{t+1}, ..., x_{t+31})` — thirty-two consecutive frames — and response
`x_{t+33}`. The frame `x_{t+32}` is deliberately withheld: this is a **gap-1**
forecast, strictly harder than the adjacent-lag forecast a parent used, and a
different response column from every parent row.

`F03` (`SIGMA_R03`). Tokenise every file of `D3` with the registered pattern
`[A-Za-z_][A-Za-z0-9_]*`. A row is a `(token, file)` pair that occurs at least
once; rows are ordered by file path then by first-occurrence offset within the
file. The response is the exact occurrence count of that token in that file, an
integer `>= 1` by construction. The design is twelve target-independent columns
read from the token's spelling and the file's size alone — token length,
leading-underscore indicator, trailing-underscore indicator, uppercase-letter
count, lowercase-letter count, digit count, underscore count, vowel count,
first-character-is-underscore indicator, file byte length, file line count,
file distinct-token count — none of which reads the response.

`F04` (`SIGMA_R04`). The same PCM sequence. Row `t` for `t = 0 .. N-34` has
design `(x_{t+1}, ..., x_{t+32})` and response
`#{ i in [t, t+31] : x_i >= 0 }`. Thirty-one of the thirty-two summands are
visible in the design and one, `[x_t >= 0]`, is not, while the design carries
one frame, `x_{t+32}`, that the response does not count. The response is
therefore an additive functional of a per-input non-affine transform, with an
irreducible one-bit residual. It is not exactly attainable and it is not a
functional of any affine score of the design.

### Why the ecologies moved, stated before the outcome

`gmi-833-h-real-scale-classical-v1` left these three rows open with three
single-stage attributions, published in its `RESULT_V1.json`. Each is answered
here by the matching lever, and by no other change:

- Row 2, stage `null`. Its registered control refitted least squares on a
  **permuted design** and compared it with the best constant arm. That control
  **nests** the constant arm — at zero slopes it *is* the constant arm — so the
  comparison is a coin flip by construction and carries no information either
  way. Lever: a control that cannot nest the arm it is compared with, plus an
  applicability certificate that fails the run when the control fails to
  degrade. Section 8, `P2d`. The informative diagnostic that package published
  is **not** imported, **not** re-used, and **not** substituted for the
  falsifier.
- Row 3, stage `ecology`. Its response was the per-line count of digit
  characters in Python source, which is zero on most lines. Zero-inflation is a
  legitimate source of over-dispersion, so the ecology met its own registered
  description; what it does not meet is the registered *comparison*, because a
  per-row strict-closeness test rewards an arm that can predict exactly zero and
  a log link cannot reach zero. Lever: an ecology whose response is `>= 1` by
  construction, so the criterion is informative, with the admissibility
  condition asserted before any arm is fitted (Section 8, `P3e`). The criterion
  itself is **unchanged** from the one that failed.
- Row 4, stage `ecology`. Its response was the energy of the *next* window,
  which is not additive in any per-input non-affine transform and which a
  squared affine score approximates well; the family-blind search accordingly
  returned a non-affine head, not a lifted per-input basis. That is a real
  boundary and it is recorded as one in `REAL_SCALE_REVIVAL_THEOREMS_V1.md`
  `RSR-5`. Lever: an ecology whose response **is** additive in a per-input
  non-affine transform, which is the defining ecology of the family the row
  names. The classifier is **not** re-read, **not** re-ordered, and **not**
  re-tuned; it is re-implemented here from its registered priority list and a
  test asserts the priority order.

Marginal properties of the `F03` response — its minimum, its median, and its
exact variance-to-mean ratio — were inspected on the full corpus before this
freeze, to choose a response that is not zero-inflated. That inspection is
disclosed here as `ECOLOGY_MARGINAL_INSPECTION_DISCLOSED`. No relation between
any design column and any response was inspected, no arm was fitted, no slice
was split, and no search was run before this file was committed.

### Slice rule, frozen here

For each ecology the row index runs `0..n-1` in the source order defined above.
Rows with `index mod 7 == 5` form the **search** slice (family-blind structural
search only). Rows with `index mod 7 == 6` form the **held-out** slice, never
touched before the selected structure is fixed. The remaining rows form the
**fit** slice. The `R09` regeneration slices are `index mod 7 in {0,1,2}` for
fitting and `index mod 7 == 3` for scoring; both are disjoint from the search
slice and from the held-out slice, and the `R09` claim is the identity of the
recovered structural class, not a fresh held-out number.

The modulus is 7, where both parent packages used 5. No held-out slice of this
package is a held-out slice of either parent under either rule.

## 5. The lower grammar `G_S`, frozen before any data is read

Leaves: `ARG` (the input value at the current fold index), `PARAM` (the
parameter at the current fold index), `ACC` (the accumulator), `S` (the
completed fold value), `BIAS` (a scalar parameter), `STATE` (the delay-cell
read), `C0` = 0, `C1` = 1.

Operations, all generic and of arity at most two: `ADD(a,b)`, `MUL(a,b)`,
`NEG(a)`, `ABS(a)`, `STEP(a)` = 1 if `a > 0` else 0, `RECIP(a)` = `1/a` if
`a != 0` else 0.

Control constructs, both generic: one indexed accumulate
`ACC <- ADD(ACC, BODY(ARG_i, PARAM_i))` over a registered index set, and one
delay cell `STATE_{t+1} <- OUT_t`.

A candidate program is a pair `(BODY, HEAD)`:

```
ACC_0 = 0 ;  ACC_{i+1} = ADD(ACC_i, BODY(ARG_i, PARAM_i))  for i in the index set
S     = ACC_N
OUT_t = HEAD(S, BIAS, STATE_t) ;  STATE_{t+1} = OUT_t
```

`BODY` ranges over every `G_S` expression of at most 3 nodes over leaves
`{ARG, PARAM, C0, C1}`. `HEAD` ranges over every `G_S` expression of at most 4
nodes over leaves `{S, BIAS, STATE, C0, C1}`. Both are enumerated exhaustively
and target-independently, once, before any ecology is loaded, and semantically
quotiented on the fixed exact rational probe grid
`(-2, -1, -1/2, 0, 1/2, 1, 2)`.

The delay cell is kept in the grammar although none of the three rows of this
tranche is a stateful family. Removing it would tailor the grammar to the
answer; keeping it means the `PERSISTENT_STATE` class stays reachable and every
`R05` control at every scope can fail by reaching it.

The generator receives **no family name, no family identifier, no
family-specific candidate menu, and no response values**. Structural names
(`PERSISTENT_STATE`, `LIFTED_BASIS`, `NONLINEAR_LINK`, `AFFINE_SCORE`) are
attached only after a candidate is chosen, by an external classifier that reads
the chosen expression trees and never the family label.

The classifier priority, fixed here before any outcome exists:

```
head depends on STATE            -> PERSISTENT_STATE
else BODY not affine in ARG      -> LIFTED_BASIS
else HEAD not affine in S        -> NONLINEAR_LINK
else                             -> AFFINE_SCORE
```

A no-smuggling audit checks the grammar digest before and after every search,
provenance closure over the registered operations, totality of denotations on
the probe grid, and target-independence of the enumeration. A token scan alone
is not sufficient and is not relied on.

## 6. Arithmetic rule

Every reported quantity is an integer or a `fractions.Fraction`. Floats appear
only inside parameter-fitting routines. A fitting routine's output is
rationalised at the registered precision `limit_denominator(10**9)`, applied
identically to every arm, **before** it is used, and from that point on it is
data. No float enters any comparison, any count, any loss, or any claim.

## 7. What `real-scale` means here — the registered definition

Adopted unchanged in substance from `gmi-833-h-real-scale-classical-v1`
Section 7, because a definition that moves with the package it certifies
certifies nothing. A test at scope `sigma` is **real-scale** exactly when all
five hold:

1. **Real provenance.** Every input value is read from a source of Section 4,
   verified by sha256 at run time. Data derived by counting, windowing, or
   indexing those bytes is real; data produced by a sampler, simulator, or
   generator is not, and none is used.
2. **Scale coordinate and threshold.** The scale coordinate is the number of
   fitted rows `n_fit` and the held-out row count `n_held`, both after the
   Section-4 slice rule. Real-scale requires `n_fit >= 100,000` and
   `n_held >= 20,000` at every scope.
3. **Fitted systems.** At each scope at least two arms are fitted at that scale
   — the structure the family-blind search chose and its registered comparison
   arm — with the same slices, the same rationalisation, and the same charged
   cost model.
4. **Protected evaluation.** Every claimed number is computed on the held-out
   slice only, after the structure is fixed, in exact arithmetic.
5. **Resource accounting at scale.** The charged cost model is evaluated at the
   real `n`, `d` and index-set size, not at a reduced search budget.

**Falsifier of the definition itself.** If any claimed number at a scope can be
reproduced from fewer than 100,000 real fitted rows, or from bytes not covered
by a Section-4 digest, the real-scale certificate at that scope is void.

**What this definition does not license.** It does not license: frontier-model
or deep-network real-scale claims; any statement about data outside `D2`–`D3`;
any statement about ecologies other than `F02`–`F04`; transport of these
certificates to another scope; independent-team replication; maturity `M5`;
`EV4`/`EV5`; the aggregate Section-H rows; or any of the other 40 named-family
rows. Reproducing on a second host or a second Python version licenses none of
those either — intra-package agreement is not independent replication.

## 9. `R09`, `R10`, hostiles, controls

- **`R09` independent regeneration**: the whole derivation is re-run on the
  disjoint regeneration slices of Section 4; the chosen structural class at each
  scope must be identical. A different class fails the gate.
- **`R10` independent search**: a source-separated oracle re-derives every
  choice and every held-out claim without importing the primary executor.
  Non-import is enforced structurally by an `ast` scan of the oracle's imports
  and by a `sys.modules` assertion, not by a comment.
- **Hostiles**: every hostile carries an `applicable` flag. The run **fails** if
  a hostile is vacuous — that is, if the quantity the hostile perturbs is not
  moved by the perturbation. A hostile that cannot fire tests nothing. Ten are
  registered: source-digest perturbation, artifact-path perturbation, grammar
  extension, slice leakage, foreign `sigma` stamping, float leakage into a
  claimed quantity, an out-of-band control, a family label offered to the
  classifier, a parent gate certificate offered to a row ledger, and a tampered
  committed replay partial.
- **Controls**: the 200 response-permutation controls of `P2d` with their
  applicability band, and the no-alarm assertion that the true run raises no
  hostile.
- **Non-degeneracy**: every scope reports its non-degenerate row count
  explicitly — held-out rows with non-constant response, designs with non-zero
  variance in every used column, and decision arms that emit both classes. A
  scope whose held-out predictions are degenerate closes no row, however good
  its aggregate number looks.
