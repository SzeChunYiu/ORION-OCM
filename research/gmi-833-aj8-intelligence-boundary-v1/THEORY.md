# AJ8 — where intelligence first appears: negative-control boundary

## Status

AJ8 does **not** freeze a universal metaphysical definition of intelligence. It asks which candidate conditions survive finite same-substrate controls after AJ1–AJ7.

Candidate principle under test:

> A resource-bounded organization exhibits scoped machine capability when its control can exploit operationally accessible distinctions whose collapse would materially reduce verified attainable value under a registered requirement family. Developmental capability is an additional property of how history/information/resources change the organization's future capability/search response.

This is a scoped operational classification, not `THE_DEFINITION_OF_INTELLIGENCE`.

## 1. Same-substrate negative controls

All controls use the same frozen unary-Boolean organization substrate.

### Fixed lookup

`FIXED_LOOKUP_ID` is a two-entry table implementing identity. It has perfect current identity-task capability, exploits the relevant input distinction, and has **no developmental update**. Therefore development cannot be a necessary condition for every scoped notion of machine capability.

But this also shows why one-task success cannot establish general intelligence: an arbitrarily supplied table can buy perfect finite-task behaviour with prior information.

### Fixed calculator

`FIXED_CALCULATOR_NOT` implements one fixed Boolean transformation. It is capable at its registered task but does not acquire skills or expand its future response surface.

### Passive memory

`PASSIVE_MEMORY` stores the input distinction but always emits zero. On the identity task it scores exactly the best collapsed constant baseline `1/2`. Thus

`preserving a distinction != exploiting it for capability`.

### Random dynamics

A fair random bit has one bit of output entropy, but when independent of a fair target its joint law factors exactly, mutual information with the target is zero and expected accuracy is `1/2`. Thus

`entropy / novelty != target information != target-aligned capability`.

### Universal finite interpreter

At this finite scope an interpreter supplied the correct one of four unary Boolean programs can solve all four tasks exactly. With a fixed default program and no task/program information, mean accuracy across the four tasks is `1/2`.

Therefore

`expressive universality != autonomous selection/discovery/accessibility of the useful program`.

The provenance and cost of the program/task information must be charged.

## 2. Current capability and developmental capability are different axes

A frozen identity table has current identity score `1` and score `0` after the requirement switches to NOT if no adaptation is allowed.

A table learner starts at `1/2` on identity but, after receiving the complete labelled task table under the registered developmental contract, reaches score `1`.

So neither direction holds:

`high current capability -> high developmental response` is false;

`low current capability -> low developmental potential` is false.

This is consistent with AJ6's stronger same-current/different-future counterexamples.

## 3. Information acquisition versus computational unfolding

A dormant organization may already contain the correct identity table but lack enough computation budget to use it. Increasing compute from the disabled state to one admitted access step raises its task score from `1/2` to `1` while the registered new external target information is exactly zero.

Hence:

`new external information acquired != information/capability made computationally accessible`.

This does not create target information from nothing; the relevant structure was already present in the initial organization.

## 4. Development is an optional extra axis, not a prerequisite for all capability

AJ8 therefore registers at least two classes:

`SCOPED_CONTROL_CAPABILITY(Q,R,V)`
: a fixed or changing organization can exploit accessible Q-relevant distinctions under resources to improve verified attainable value over an explicit collapsed/no-distinction baseline.

`DEVELOPMENTAL_CAPABILITY(Q,R,H,V)`
: history/information/resource interaction changes the future mapping from available information/resources to reachable capability, search or organization.

A system may have the first without the second. A developing system may temporarily have weak first-axis performance while having strong future response.

Whether the paper-facing word **intelligence** should cover both classes, only the developmental class, or a family of graded/general measures is not derived by the operational substrate itself; it is a theory-definition choice constrained by parent literature and validation goals.

## 5. Why the universal definition remains open

The lookup-table hostile proves that single-task behavior cannot distinguish memorized prior knowledge from adaptive/general problem-solving. The universal-interpreter hostile proves that expressibility alone is not enough. The random hostile proves novelty alone is not enough. Passive memory proves representation/preservation alone is not enough.

Any stronger flagship criterion must therefore state at least:

- requirement/task family and its provenance;
- allowed priors/training/task information;
- resource budget;
- capability versus acquisition/development axis;
- generalization/transfer or breadth claim if one is made;
- verifier/uncertainty semantics.

AJ8 deliberately stops short of a universal scalar or binary definition.

## Strongest parents

- **Legg & Hutter**: agent performance aggregated over environments as a formal machine-intelligence proposal.
- **Russell & Subramanian bounded optimality**: program performance relative to architecture, environment and computational constraints.
- **Chollet, On the Measure of Intelligence**: separates task skill from skill-acquisition efficiency and emphasizes priors/experience/generalization difficulty.
- **Hernandez-Orallo / universal psychometrics and generality work**: broad performance, task difficulty and resource-sensitive generality across artificial/biological systems.
- #233 HST/HSG: developmental response/evolvability rather than current fitness alone.

AJ8 does not claim to supersede or uniquely reconcile these definitions; it supplies exact negative controls that any stronger GMI definition must survive.
