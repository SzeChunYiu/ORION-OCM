# AJ8 strongest-parent / ownership ledger

AJ8 does not claim to have invented or settled a universal definition of intelligence.

Strong parent programmes include:

- **Legg & Hutter (2007), Universal Intelligence: A Definition of Machine Intelligence** — formal aggregation of agent performance across environments; parent for broad environment-relative performance measures.
- **Russell & Subramanian (1995), Provably Bounded-Optimal Agents** — intelligence/rationality as constrained program performance relative to machine architecture and task environment; parent for resource-relative capability.
- **Chollet (2019), On the Measure of Intelligence** — distinction between task skill and skill-acquisition efficiency, with explicit attention to priors, experience, scope and generalization difficulty.
- **Hernandez-Orallo and universal psychometrics / generality work** — evaluation across biological/artificial systems, task difficulty and resource-sensitive generality.
- **#233 HST/HSG** — developmental response, transfer/evolvability and future search geometry rather than current fitness alone.

AJ8 residual contribution is a same-substrate finite hostile suite establishing that preservation, entropy/novelty, universality/expressibility, single-task current performance and development are mutually non-equivalent properties. This supports a fixed-control versus developmental-capability separation and explicitly leaves the universal paper-facing intelligence definition open.
