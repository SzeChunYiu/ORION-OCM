# Once-only screening observer

The prepared request is final bytes despite its DRAFT filename. No gate exists.
The root gate binds this request, observer, output contract and accepted source/observer
reviews. The request names the observer without its digest, avoiding a circular binding.

Popen, poll, 180-second containment, process-group termination and wait4 cleanup are
byte-identical to the reviewed opportunity observer. No inherited process tests are rerun.
New authored controls cover only SCREEN output populations and changed custody checks.

The output contract independently derives expected occurrence identities from the saved
root/cut sequence. It preserves all 76 occurrences, including duplicate canonical bodies.
It checks exact full P1 identity and count, prior cost records, actual child cwd and imported
project/Lark module paths. This is JSON/custody inspection, not syntax or proof evaluation.

A complete result requires all 76 matching SCREEN files and RESULT. Failure may retain a
shorter emitted prefix and a final recorded row whose SCREEN write failed. Missing RESULT
retains every available file hash and reports incomplete evidence. No missing row is
invented and no partial attempt is called completed.

The observer measures its run entry through input/output custody; interpreter startup and
final PROCESS serialization are excluded. Child Popen-to-reap wall and wait4 CPU/RSS are
nested within that interval. Root's separate caller captures its own enclosing interval.
Partial logs/files, nonzero exits and containment are retained without automatic retry.

Standard-library imported paths are recorded under the pinned interpreter prefix; the
request explicitly pins project and Lark files. This does not claim a complete OS open
audit. Source/publication preparation is separate from measured screening cost.

Paths: ROOT-SCREENING-GATE.json, screening-01, observation-01 and root-owned caller-01
are siblings in this directory. Current scope is source and authored controls only.
