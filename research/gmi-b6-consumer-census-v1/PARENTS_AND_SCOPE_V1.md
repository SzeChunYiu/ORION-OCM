# Native parents, reuse and scientific contribution

This is a correction of one instrument and its interpretation. No new general
learning law, graph invariant, program-equivalence theorem or empirical
performance result is claimed.

The direct specification is the frozen
[morphology alphabet](https://github.com/SzeChunYiu/ORION-OCM/blob/cf1c0f8e11f2f548f8a5010826b88f1823c2b7de/research/machine-intelligence-morphogenesis-v1/gmi_microscope/morph.py#L28)
and [VM evaluator](https://github.com/SzeChunYiu/ORION-OCM/blob/cf1c0f8e11f2f548f8a5010826b88f1823c2b7de/research/machine-intelligence-morphogenesis-v1/gmi_microscope/vm.py#L139).
LINEAR reads a parameter-name list and data vector. AFFINE partitions that
list into output blocks and may emit zero for missing blocks or incompatible
runtime values. GRAD updates named cells by reference; it need not write an
edge into the zero-input DENSE node. INSERT updates memory without GRAD.

The existing [consumer proof](https://github.com/SzeChunYiu/ORION-OCM/blob/bbbc9dec44cc5a25bb2e1995aa2647bde4701e98/research/gmi-witness-mechanism-v1/CONSUMER_SEMANTICS_V1.md)
is the strongest matched parent for S1. It already proves query/abstention
and ordered common-store preservation for every finite event sequence in its
model. The proof uses exact INSERT keys, EVIDENCE semantics and update order,
not just absence of one primitive name. Its registered 33-call mechanism
experiment supplies separate finite regression evidence; this unit reruns none.

The census reuses the original cohort definitions and corrects their primitive
mapping. Ordinary finite directed reachability supplies the adjacency and
ancestry algorithms. The independent backward port oracle is a validation
method, not a stronger semantic classifier. Exact original Python bytes and
claims are preserved rather than rewritten.

The static replay/custody pattern adapts the existing
[retained V6 audit](../gmi-parity-v6-evidence-v1/CORE.md): strict JSON, exact input
hashes, whole-payload comparison, real-data no-alarm controls and explicit
unknown evidence. Here there are no interpreter-specific opcodes or timing
measurements. Tests use CPython 3.12; the archived historical runtime is not
impersonated. All relevant source and raw members are inside this unit.

Scientific repair: correct LINEAR/AFFINE roles, keep exact cohorts and duplicate
instances, expose the eight retained source GRAD graphs, and distinguish
structural observations from universal and causal claims. Missing full search
telemetry, operative-gradient verification, current-bar adequacy and lifetime
costs remain concrete separate obligations.
