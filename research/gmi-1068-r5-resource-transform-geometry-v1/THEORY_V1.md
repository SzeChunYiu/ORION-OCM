# R5 — resource and transformation geometry is derived structure

Attach an ordered resource value c(f) to an admissible process/transform f. For vector resources use the coordinatewise preorder and vector addition under sequential composition when the resource accounting warrants additivity (or an explicit subadditive upper bound when it does not).

For objects M,N define the vector transformation burden

D(M,N) = ParetoMin { c(f) | f : M -> N }.

If Hom(M,N) is empty, the burden is UNREACHABLE / +infinity rather than a fabricated finite value.

For a frozen nonnegative scalarization w, define at finite scope
d_w(M,N)=min_f w·c(f).

When identities have zero cost and composition is subadditive,
d_w(M,M)=0 and
d_w(M,P) <= d_w(M,N)+d_w(N,P).

Symmetry is neither required nor expected. One-way compilation/physical conversion yields finite d(M,N) and infinite d(N,M).

## Frontier transport
A bijection/remint that preserves contextual values and cost vectors preserves domination and therefore transports the finite Pareto frontier exactly. A lexical rename that changes costs, reachability or observations does not earn this theorem.

General resource convertibility, ordered commutative monoids and categorical resource theories are parent mathematics.
