## Channel manifest and blindness arguments

### CH1 — task source

CLOSED BY: `NEUTRAL_BATTERY_FREEZE_V1.json`, generated by
`battery_generate_v1.py` (this pair is the ENTIRE task source; the generator
reads no benchmark/family data). Generation rules are coverage-complete
classes; no per-family selection exists anywhere in the generator:

- `B_BOOL2` — ALL 16 two-input boolean functions (lexicographic truth-table
  order) as per-task battery, PLUS one class-universal task: a single machine
  computes all 16 functions, selected by task bits that encode the same
  lexicographic rank. The class-universal task is the primary K01 tranche:
  no author chose XOR; every function is present.
- `B_BOOL3` — ALL 256 three-input boolean functions, same construction
  (secondary tranche, K04 counterfactual-bearing).
- `B_DELAY` — ALL delayed-copy lags L=0..L_MAX on a de Bruijn stream of
  order L_MAX+1 (every binary (L_MAX+1)-gram occurs exactly once; full
  input-history coverage). L_MAX is DERIVED, not chosen: the machine's state
  domain D can distinguish at most |D| histories, so the complete feasible
  lag class is L <= floor(log2(|D|)); the battery takes exactly that class.
- `B_LOCAL` — ALL 256 elementary local rules (complete radius-1 binary
  local-rule class) on a ring of width W over ALL 2^W ring states, per-rule,
  PLUS the class-universal task (rule bits + ring bits).

BLINDNESS ARGUMENT: each battery is the complete class of a standard
mathematical object (two/three-input boolean functions; lagged identities;
radius-1 local rules). Completeness removes the author's choice: nothing is
selected, everything is enumerated. Residual declared choices and their
neutrality: (i) WHICH classes appear at all is declared here, pre-search, and
is justified by class-completeness + definability without family vocabulary;
(ii) encodings (lexicographic rank digits, Wolfram-canonical rule bits, ring
site order) are fixed canonical orders, not tuned; (iii) the delayed-copy
class is the lag-parameterized identity — the unique task family that is
complete in its parameter, computable at the information-theoretic minimum
state, and definable without state-machine vocabulary.

### CH2 — primitive basis

CLOSED BY: `BASIS_GRID_V1.json` (frozen). The basis is chosen by TIER RULES,
declared before search, symmetric within each tier:

- Atoms tier: the task inputs themselves + constants {-1, 0, +1} (the
  minimal sign-symmetric constant set).
- Binary tier: `{ADD}` — the single group law of the integer value domain;
  the weakest structural assumption permitting signal mixing. No second
  binary primitive, no multiplication, no comparison-of-two-signals macro.
- Unary tier (PRIMARY, `U_ORD`): `{NEG} U {GE_c : c in D}` — the COMPLETE set
  of one-sided order tests over the value domain at every cut point, plus
  sign negation. Tier-complete within order-statistics: every cut level and
  the sign flip are present; no single threshold is privileged (v1 had
  exactly one: `POSITIVE_TEST` = `GE_1`). Under `U_ORD` a single gate can
  realize any one-sided test, so multi-site constructions are NOT forced by
  the basis — if they appear, they are demanded by the battery class.
- Unary tier ablation `U_ALL3`: ALL total unary maps D->D, feasible where
  |D|=3 (guard [-1,1]); the fully complete tier. Where verdicts agree with
  `U_ORD`, order-tier completeness was not load-bearing.
- Unary tier ablation `U_V1`: v1's `{NEG, POS}` — retained ONLY as the
  audited coercive baseline for contrast; recovery claims may NOT rest on it.
- Guard: value domain D = [-3,3] primary (contains all signed sums of the
  atom constants and two input bits, matching v1's guard for comparability);
  ablations [-2,2] and [-4,4].

BLINDNESS ARGUMENT: each tier is closed under a stated symmetry (sign pair;
group law; all-cut-points completeness). The characteristic gate of K01
(threshold) is present but UNPRIVILEGED — one of |D| cuts — and single-gate
solutions are always available, so any multi-site/reused morphology in the
recovered constructions is attributable to the battery class (coverage
pressure), not the basis. The residual bound, stated honestly: `U_ORD` is
complete within order-tests, not within all unaries; the `U_ALL3` ablation
bounds that gap where feasible.

### CH4 — cost model

FROZEN: uniform cost 1 per operator application (any tier), 0 per atom;
total cost of a multi-output machine = sum of output-port costs (v2 tree
model: no cross-port sharing credit — sharing is measured, not rewarded;
this is the CONSERVATIVE choice for reuse claims). Search = cost-layered
dynamic programming over semantic quotient (exhaustive per layer, dedup by
exact I/O semantics), so "first layer containing the target" is a complete
no-solution-below-cost certificate; termination = target found or layer
adds no new semantics (closure saturation). Safety cap 16 layers = 2x the
largest minimal cost (7) observed across all v1 tranches, expected never to
bind before saturation; the outcome must REPORT whether it ever bound.

### CH5 — adjudicator thresholds

FROZEN IN `posthoc_adjudicate_v2.py` SPEC (below) BEFORE outcomes: every
threshold is a clause-form restatement of a frozen benchmark clause or a

tests executed as real interventions (input/state clamping) on the
recovered construction.

## Machine models (frozen)

- M_EXPR (B_BOOL2/B_BOOL3/B_LOCAL per-task and class-universal): a machine is
  one expression tree per output port over the frozen basis; semantics =
  tuple of port values over the battery's canonical input rows; guard checked
  at every node.
- M_STATE (B_DELAY): one integer state cell s in D; update
  s' = e_s(s, x), output y = e_y(s, x); both expressions in the frozen basis;
  initial state 0 (canonical, matches the battery's zero padding); the
  machine must reproduce the required stream on the de Bruijn input.
- M_RING (B_LOCAL): per-rule, one expression per output site over ring-atom
  inputs (site-symmetry NOT assumed: each site's expression is searched
  independently over all atoms; locality and sharing are adjudicated
  posthoc, never enforced by the model).

## DERIVATIONS (no arbitrary defaults)

- constants {-1,0,+1}: minimal sign-symmetric set containing the additive
  identity and both signs.
- guard [-3,3] primary: smallest symmetric interval containing all signed
  sums of the atom constants and any two input bits (v1's own guard;
  ablations [-2,2], [-4,4]).
- L_MAX = floor(log2(|D|)) (counting bound above): 2 for D=[-3,3] primary;
  ablation D=[-8,8] gives 4.
- ring width W = 4 primary: smallest width strictly greater than the 3-site
  neighborhood span (battery class definition); ablation W=8.
- de Bruijn order L_MAX+1: full (L_MAX+1)-gram coverage per definition.
- layer safety cap 16: 2x max v1 minimal cost (7); must report if it binds.
- canonical orders: lexicographic truth-table; rank-digit select bits
  (big-endian); Wolfram canonical rule bits; left-to-right ring sites.
