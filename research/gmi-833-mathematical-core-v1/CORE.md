# Core claim

At the registered finite scope, the compact typed GMI objects have a concrete
two-state model, so the registered axiom set is consistent relative to ordinary
finite set/arithmetic semantics. Capability, morphology, uncertainty, and
abstention are defined without architecture names. The parent-equivalence
boundary is imported from merged PR #847 and is not reclaimed here.

All local mathematics remains attributed to its strongest parent. This package
does not establish universal grammar completeness, empirical validity, or
ontological completeness.
