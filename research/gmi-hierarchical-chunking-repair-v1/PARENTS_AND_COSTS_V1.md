# Mechanism ancestry and cost boundary

- Nevill-Manning and Witten, [SEQUITUR (JAIR1997), §§2–2.2](https://arxiv.org/pdf/cs/9709102):
  earlier nonterminal rules are reused in later bodies; replacements do not
  overlap, and multiple valid grammars can exist. This is actual hierarchical
  grammar construction. We borrow its structural meaning, not its compression
  objective, linear-time claim or empirical scores.
- Charikar et al., [smallest grammar problem (2005), §I](https://shelat.khoury.northeastern.edu/dl/GrammarIEEE.pdf):
  minimize total production-body symbols of a grammar generating exactly one
  string. This differs from lifecycle execution work; their hardness result
  warns against calling a restricted dictionary census a global optimizer.
  No new grammar-search implementation or matched performance win is claimed.
- Dijkstra, [1959, problem2](https://www.cs.cornell.edu/courses/JavaAndDS/shortestPath/1959dijkstra.pdf):
  shortest paths retain the cheapest prefix to the same state. HCR-1 uses the
  simpler acyclic position graph, and HCR-2 uses finite configuration minima.
- Archived PVR-3 supplies the exact first-derivation reuse law. PVR-4 expressly
  restricts independent items; nested shared acquisition does not satisfy it.
- Archived SMR-1–2 is a stronger existing configuration/lifecycle parent,
  handling capacity, shared prerequisites, release and invalidation. HCR-2 is
  a smaller acyclic calibration with no new dynamic-programming mechanism.
- The developmental quotient and MSC distinguish state equivalence from
  construction, full feasible-class coverage, attainment and program costs.

## Meter and comparisons

Every execution event records its category, token and exact charge: primitive
construction, rule expansion/control, admitted compiled invocation or final
construction/check/index/storage. Native timing and energy are unmeasured.
The artifact contract includes all implementation work attributed to that
operation. Additionally every emitted primitive action pays its declared
delivery price, identical across routes (30 total in every principal arm).
Each admission1 explicitly splits into positive compiler/check/index-storage
charges1/3 each. Primitive output strings have no hidden semantics or side channels.

The finite model is intentionally not an instruction-level compiler. A
compiled call emits a verified expansion using a supplied invocation charge;
it need not recursively invoke its original children. If the real mechanism
is a recursive interpreter, charge all executed child calls and dispatch:
no such costs may be absorbed into a falsely claimed constant100 upper fee.
The counterexample is conditional on its actual advertised compiled primitive.
It refutes a theorem of universal shallow benefit under arbitrary admitted
PVR prices, not a physical lower bound or an implemented hardware speedup.

Rule and workload descriptions, expanded validation traces, retained artifact
count/expanded sizes, synthesis-state and transition counts are separately
reported. Actual compiler-search, table construction, verification, controller
memory, setup, holding and termination must be added if not included in an
admitted event contract. No all-physical-cost optimum follows from this meter.
Existing SMR handles a richer declared arena and BCR handles bounded control;
this unit leaves those frozen results untouched.

The comparison includes all deterministic admitted admission/expansion/use
policies for the fixed register and each named allowed-rule class. It is not
restricted to eager admission. Independent complete execution-tree enumeration
on small registers checks the recurrence. A flat dictionary parsing oracle
enumerates complete tokenizations independently. These synthetic checks do
not evaluate experience acquisition or transfer to fresh obligations.
