## 1. Why #323 matters to Track B

Track B defines a morphology's developmental geometry partly through its pre-solution proposal/search bias.

#323 already measures exactly such a quantity on fresh targets:

```text
rank_0(t) = history-free enumeration rank of the eventual verified solution
rank_H(t) = continued/history-conditioned charged proposal rank
```

and guarantees the target solution itself is absent from developmental history.

Therefore

\[
\Delta I(t)=\log_2\frac{rank_0(t)}{rank_H(t)}
\]

is a directly observable proposal-geometry shift on that registered search process.

## 2. Existing result — imported without promotion

The current main receipt reports:

This is #323's C2 evidence:

```text
history-induced search / cognition-generation capital
```

not Track-B proof of a general morphology law.

## 3. Mapping to the Track-B geometry object

For this OCM-like morphology at the registered scope:

```text
H_M     = search states / partial constructions / library-conditioned solver state
pi_M    = history-conditioned proposal ordering / effective proposal mass
K_M     = history/library/controller update process
c_M     = charged search / probe / validation resource accounting
V_M     = external checker / registered success contract
```

The empirical observation is:

```text
history changed pi_M before target success
AND target solution was not in history
AND the change usually lowered first-hit proposal burden.
```

This is a concrete instance of the abstract condition

\[
d_{M,t+1}(h,h^*) < d_{M,t}(h,h^*)
\]

or, more directly here, lower rank/surprisal for `h*`.

## 4. What this does NOT establish

It does not show:

- one fundamental cognitive basis;
- cross-paradigm geometry invariance;
- that the geometry signature can be predicted from structure before running the target;
- C3/K2 developmental capital;
- a neural/symbolic/probabilistic phase law;
- independent-domain generality.

The lane's own claim ladder says C3 remains partial because the procedure making the next acquisition cheap is designed rather than itself learned.

## 5. Immediate Track-B use
