Every run must satisfy:


# 4. Search encodings

At least three independent encodings are required before a recovered unknown form can support a strong claim.

```text
S-EVO   typed evolutionary mutation/recombination
S-QD    quality-diversity / MAP-Elites-style archive
S-GRAM  grammar/program synthesis search
S-SUR   optional surrogate/Bayesian multiobjective search
S-DIFF  optional differentiable relaxation for compatible primitives
S-COEV  optional paired ecology-machine open-ended search
```

Search budget is fixed and charged separately for each encoding.

---

# 5. Protected split

For each experiment family:

```text
D: adaptive search, architecture tuning, law fitting
V: limited model selection / stopping
P: generated or frozen only after grammar, baselines, metrics and primary hypotheses freeze
```

Recommended structure:

- development uses broad reusable generators;
- validation contains unseen seeds/combinations but may be queried a bounded number of times;
- protected ecologies include unseen seeds **and** withheld mechanism combinations / substrate prices / surface remints.

Protected failure followed by adaptation requires a fresh P set.

---

# 6. Replication and statistics

Primary independent unit is the ecology seed or real task instance family, not token/query count.

For each confirmatory comparison, use:

```text
multiple ecology seeds
multiple training/development seeds
multiple search seeds
multiple substrate contexts where the claim crosses P
```

Use hierarchical/mixed-effects or hierarchical bootstrap analysis.

Primary confirmatory hypotheses are preregistered. Exploratory biosphere discoveries are labeled exploratory until replicated on fresh P worlds.

For many discovered species, control false discovery with a preregistered FDR procedure or require independent replication rather than treating every archive cell as a hypothesis test.

Report uncertainty on Pareto membership; do not deterministically rank overlapping confidence regions.

# 21. Claim boundary

A successful biosphere run does not “prove GMI universal.”

The strongest legitimate progression is:

```text
microfeature laws survive matched interventions
-> known forms are recovered in predicted niches
-> F1-F6 property vectors are neutrally recovered
-> unknown frontier-distinct species appear
-> candidates survive remint/search-encoding replication
-> candidates survive parent reduction
-> candidates transfer to real protected regimes
-> learned morphogenesis improves future morphology discovery
```

That sequence would be strong evidence that GMI is becoming a predictive theory of machine-intelligence form rather than a descriptive taxonomy.
