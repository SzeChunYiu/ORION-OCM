# GMI theory-discrimination identifiability no-go v1

Status: **FORMAL META-THEORY NO-GO / B1 CLARIFICATION**

Date: 2026-09-12.

Purpose: prevent the programme from demanding empirical discrimination between GMI and a parent theory that is allowed to make exactly the same predictions on the registered evidence space.

## 1. Prediction maps

Let registered pre-outcome cell descriptors be `x in X` and protected outcome/morphology targets be `y in Y`.

A theory induces a frozen prediction rule

\[
f_T:X\to\mathcal P(Y)
\]

or a deterministic special case.

## 2. Theorem TD-1 — extensional equivalence is observationally unidentifiable

If two theories `T_1,T_2` satisfy

\[
f_{T_1}(x)=f_{T_2}(x)
\]

for every registered cell `x` that the experiment may sample, then every experiment whose likelihood depends on the theories only through those predictions has the same data distribution under both theories.

Therefore no amount of such protected outcome data can distinguish `T_1` from `T_2`.

This is immediate: equal predictive distributions induce equal likelihood for every possible observation sequence.

## 3. Corollary — unrestricted lifecycle oracle cannot be a discriminating parent

Suppose an “ordinary resource/lifecycle parent” receives exactly the same sufficient descriptors, searches exactly the same admissible realization set, prices exactly the same burdens and is allowed an unrestricted response law containing the GMI mapping.

Then the parent class contains a member extensionally identical to GMI on every registered cell. A claim that GMI must empirically outperform that unrestricted oracle is ill-posed.

A lifecycle optimizer may be a valid **reduction/home** for part of GMI rather than a competing falsifiable theory.

## 4. What a valid B1 discrimination test requires

At least one of the following must be prospectively frozen:

1. **Different numeric predictions** on the same protected cells.
2. **Different admissible descriptors**: one theory predicts a collision where the other includes a necessary variable.
3. **Different complexity/sample burden**: both can fit development data, but one uses a materially smaller/frozen law and generalizes better to held families.
4. **Different intervention predictions** under a causal manipulation.
5. **Different unknown-form prediction** before the realization is searched/constructed.

If none applies, report `PREDICTIVELY_EQUIVALENT_AT_REGISTERED_SCOPE`, not a win/loss.

## 5. Theory-compression comparison

When two theories induce the same protected predictions, scientific preference can still depend on a separately registered meta-criterion such as description length, number of free fitted parameters, transfer to new obligation coordinates, or derivation of multiple laws from fewer assumptions. That is a theory-selection criterion, not evidence of different outcome predictions.

## 6. GMI consequence

B1 should target constrained strong parents, for example:

```text
current-state MDL/compression model
static resource optimizer
present-signature-only response law
history-free morphology predictor
one-family fitted scaling law
```

or require GMI to make a novel quantitative/causal prediction not already contained in the parent.

The current-state compression collision theorem is a valid discriminator against a current-only parent. It is not a discriminator against a parent already endowed with identical update/lineage variables and lifecycle law.

## Claim ceiling

This closes a meta-theory identifiability gap. It does not demonstrate empirical superiority of GMI over any specific constrained parent; such tests still require prospectively different predictions and protected evidence.
