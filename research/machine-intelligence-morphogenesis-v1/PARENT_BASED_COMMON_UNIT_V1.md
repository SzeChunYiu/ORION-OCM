# Parent-based common adaptive unit candidate v1

Status: **strongest current lower-level candidate; parent-owned in substantial part; not ORION novelty.**

## 1. Why this replaces the urge to invent an OCM-specific atom

The current Track-B evidence does not support `u2` as a fundamental cognitive atom. Mature parent mathematics already contains a much smaller compositional adaptive object.

A useful parent-derived candidate is the learner/lens/open-cybernetic pattern:

\[
\mu = (P,I,U,r;\rho)
\]

with:

```text
P    mutable parameter/state space
I    forward implementation / behavior
U    update of P from experience/feedback
r    backward request / credit / desired-input signal for composition
rho  resource semantics added by Track B for bounded comparisons
```

The `(P,I,U,r)` core is directly threatened/parented by the category of learners and lens/optic formalisms. Track B does **not** claim to have invented it.

The additional resource semantics `rho` are measurement structure, not by themselves a new cognitive primitive.

For interactive/agentic systems this object may need the more general categorical-cybernetics/open-system form, where the process interacts with both an environment and a controller. That is a parent formalism to absorb, not a reason to rename it OCM.

# 2. Important interpretation

The primitive/unit does **not** need to be intelligent by itself.

Analogy:

```text
transistor != computer
cell != organism
instruction != algorithm
learner/open process != intelligent machine
```

The intelligence form emerges from:

```text
many units / composed processes
+ topology / representation
+ mutable state
+ control
+ credit/request structure
+ update law
+ memory
+ ecology/resource pressure
```

This prevents us from forcing high-level warrant/provenance/goal semantics into the lowest-level atom merely to make it sound cognitive.

# 3. Neural specialization

A conventional supervised neural component can be viewed as:

```text
P = weights / biases / optimizer state
I = parameterized differentiable forward map
r = reverse-mode/backpropagated request / adjoint signal
U = SGD / Adam / other update
```

Composition of components yields layered/recurrent neural morphologies.

The important Track-B statement is therefore not:

```text
neural networks are outside the general unit
```

but:

```text
neural learning is a specialization of a broader compositional adaptive-process pattern
```

This is strongly parent-owned by Backprop-as-Functor and categorical gradient-learning work.

---

# 4. Symbolic / production specialization

A symbolic adaptive component can be represented schematically as:

```text
P = rule / production / constraint state
I = rule matching + execution / rewrite
r = failed obligation, counterexample, requested antecedent/subgoal or change signal
U = rule addition/removal/refinement, chunking, constraint revision
```

Unlike the neural case, there is no requirement that `r` be a derivative or numeric vector.

The exact compositional semantics depend on the parent formalism—production systems, rewrite systems, delta lenses, CEGIS/CEGAR, TMS, etc. Track B must not pretend one schematic mapping proves a universal symbolic learner category.

---

# 5. Probabilistic specialization

A probabilistic adaptive component can be represented schematically as:

```text
P = prior / belief / distributional parameters
I = forward generative/stochastic process
r = likelihood / Bayesian inversion / backward message
U = posterior conditioning / parameter update / inference step
```

Bayesian-lens / Markov-category parents show that important parts of this composition are already formalized.

Therefore:

```text
common bidirectional adaptive structure spanning neural + Bayesian updates
```

is itself not sufficient novelty.

---

# 6. Programmatic / synthesis specialization

A programmatic adaptive component can be represented as:

```text
P = program / grammar / library / search bias
I = execute program
r = desired output, failing test, specification residual, requested intermediate behavior
U = program synthesis / mutation / rewrite / library induction / search-bias update
```

OOPS, PowerPlay, GP, DreamCoder, Stitch, CEGIS and related systems own major parts of this territory.

---

# 7. OCM-like specialization

An OCM-like higher-level component can be mapped schematically as:

```text
P = explicit field/assets/operators/applicability/lifecycle state
I = retrieve / compose / execute cognitive asset(s)
r = typed failure receipt, unmet obligation, verification request, causal diagnostic signal
U = externally governed admit/revise/revoke/consolidate/change-representation process
```

Important:

- warrant/provenance/authority may live at morphology/governance level, not in every fundamental primitive;
- external constitution `C` remains outside self-certifying mutable state;
- this mapping does not make OCM the parent class; it makes OCM one specialization.

# 8. What varies between intelligence morphologies if the unit is shared?

The morphology is determined by constraints on at least:

```text
state representation P
forward map family I
credit/request form r
update family U
composition/topology
memory/persistence
control/scheduling
resource costs
feedback/verifier channel
```

Thus neural versus symbolic versus probabilistic is not one binary architectural choice. It is a **structured specialization of an adaptive-process space**.

Candidate phase-law coordinates therefore include:

```text
feedback/credit density
credit decomposability
noise/stochasticity
representation smoothness
algorithmic/compositional structure
exactness/verification requirement
reuse horizon
revision rate
drift
compute/memory/communication prices
parallelism/hardware
```

# 9. Does this answer the “fundamental unit” question?

Not yet.

There are three competing possibilities:

### U-A — parent unit sufficient

A learner/lens/open-cybernetic process is already a sufficient lower-level basis for Track-B purposes.

Terminal:

```text
PARENT_ADAPTIVE_PROCESS_BASIS_SUFFICIENT
```

This would be a scientifically valuable answer. ORION novelty moves entirely upward to morphology/phase/development laws.

### U-B — several equivalent bases

Learners/lenses, coalgebraic adaptive transducers and programmatic adaptive processes compile into one another within bounded overhead on the target scope.

Terminal:

```text
MULTIPLE_EQUIVALENT_ADAPTIVE_BASES
```

This is currently more plausible than one metaphysically unique atom.

### U-C — real residual

Some registered developmental/resource semantics cannot be represented/composed by the strongest parent bases without material overhead or loss.

Only then is a new primitive formalism justified.

Terminal:

```text
PARENT_BASES_MISS_REGISTERED_RESIDUAL_<which>
```

# 10. Decisive experiments/formal work

1. map the Stage C-v1 structured unit exactly into `(P,I,U,r)` where possible;
2. identify which fields have no parent counterpart rather than naming them differently;
3. compile a tiny neural learner through the same parent object;
4. compile a Boolean/discrete learner (reverse-derivative/delta-lens parent first);
5. compile a Bayesian update through a lens/optic parent;
6. compile a tiny rule/program update;
7. compare bounded description/update/execution overhead;
8. if all map cleanly, accept parent basis sufficiency and move Track B upward.

The Track-B field-level question then becomes:

> Given a common adaptive-process substrate, what ecology/resource/verification law determines which organized intelligence morphology develops?
