# 1. Exploration is necessary under action-conditioned ambiguity

Consider two actions `a,b` and two deterministic environments:

```text
W0: reward(a)=1/2, reward(b)=0
W1: reward(a)=1/2, reward(b)=1
```

## Theorem EM-1 — no-exploration collision

Any agent that only ever selects action `a` receives exactly the same observation/reward history in `W0` and `W1`.

Therefore it cannot distinguish the worlds, yet the optimal action differs: `a` is optimal in `W0`, `b` in `W1`.

Hence no policy that permanently refuses to sample `b` can be uniformly optimal over the registered world family.

### GMI interpretation

Exploration is not an architecture preference. It is forced whenever:

1. legal worlds remain observationally aliased under the current action policy;
2. those worlds require different optimal future actions.

This is the same collision logic as the semantic-quotient no-go theorems, now applied to intervention/action choice.

# 2. Information value of an intervention

Let current evidence state be `E` and let `W` denote the unresolved world/hypothesis. For candidate intervention/action `a`, define expected posterior uncertainty reduction

\[
IG(a)=H(W|E)-\mathbb E[H(W|E,O_a)].
\]

This is the mutual information

\[
I(W;O_a|E,a).
\]

## Theorem EM-2 — zero information gain cannot resolve a decision-relevant alias

If `IG(a)=0`, then the observation generated by `a` is conditionally independent of `W` given current evidence; that intervention cannot reduce uncertainty about which aliased world is true.

If optimal action differs across those worlds, some other informative intervention or risk-bearing decision rule is required.

### Claim boundary

High information gain is not automatically high decision value: information about irrelevant distinctions can be useless. The relevant quantity is information about the target semantic/decision quotient.

# 3. Simple finite-sample exploration burden

Suppose two stochastic arms have bounded rewards in `[0,1]` and means differing by gap `Delta>0`. Estimate each mean from `n` IID samples.

Hoeffding's inequality gives, for one arm,

\[
P(|\hat\mu-\mu|\ge\Delta/2)
\le2e^{-n\Delta^2/2}.
\]

A union bound over both arms implies correct ordering with probability at least `1-delta` when, for example,

\[
n\ge\frac{2}{\Delta^2}\ln\frac{4}{\delta}.
\]

### GMI consequence

Small decision gaps require more exploratory evidence; the developmental data burden diverges as `Delta -> 0` under this simple estimator.

This is a base law, not an optimal bandit regret theorem.

# 4. Shared base state across related tasks

Consider `T` tasks. Each task target is specified by:

```text
one shared base law z chosen from M possibilities
one task-specific residual r_t chosen from R possibilities
```

Assume `(z,r_t)` uniquely determines task `t`'s target and all combinations are legal/distinguishable.

## Theorem EM-3 — cross-task shared-state information saving

Encoding every task independently requires

\[
T\log_2(MR)
=
T\log_2M+T\log_2R
\]

bits of target identity information.

Encoding the shared base once and one residual per task requires

\[
\log_2M+T\log_2R.
\]

The exact information saving is

\[
(T-1)\log_2M.
\]

### Derivation consequence

Repeated related tasks create pressure for a persistent meta-state/base representation rather than relearning every task from scratch.

The benefit grows linearly in the number of tasks that genuinely share the base.

---

# 5. Negative twin: unrelated tasks

If each task has an independent base `z_t` chosen separately from `M` possibilities, the task family contains

\[
(MR)^T
\]

target combinations and requires

\[
T\log_2(MR)
\]

bits. There is no exact shared-base information saving.

Thus meta-learning pressure should disappear when cross-task reusable structure disappears.

---

# 6. Fast adaptation as residual identification

Once shared base `z` is known, adapting to a new task only needs to identify residual `r` among `R` possibilities rather than the full pair among `MR` possibilities.

Thus target-identity burden drops from

\[
\log_2M+\log_2R
\]

to

\[
\log_2R
\]

for subsequent tasks, before considering observation noise and optimization.

This gives a zero-prior structural derivation of **fast adaptation from shared developmental state**.

It does not uniquely derive MAML, hypernetworks, in-context learning or any other implementation; those are competing realizations of the same reusable-task structure.

---

# 7. Developmental potential connection

If acquiring shared meta-state costs `C_meta` and it reduces per-task adaptation burden by `Delta C>0`, then over `T` future tasks it is beneficial iff

\[
T\Delta C>C_{meta}
\]

(up to the registered off-by-one convention for the first task).

This is the same amortization logic that appears throughout GMI at a higher developmental timescale.
