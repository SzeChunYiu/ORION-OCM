# 2. N3 — Relational-Constraint / Sheaf Intelligence

## Carrier

A family of local semantic states over overlapping regions together with restriction/compatibility maps:

\[
Z=\{s_U\in\mathcal F(U)\}_{U\in\mathcal U}.
\]

The machine need not possess one explicit global state. Cognition can consist of mutually compatible local sections plus unresolved global obstructions.

## Native operators

```text
restrict local state
propagate compatibility
extend a local section
glue compatible local sections
detect/localize obstruction
refine the cover where inconsistency remains
```

## Natural complexity coordinate

Not total state dimension, but approximately:

```text
cover size
overlap width
constraint locality
obstruction rank/number
minimal inconsistent subcover size
```

## Predicted niche

Large systems with enormous global combinatorics but mostly local compatibility and sparse global obstruction.

Examples of synthetic obligations:

```text
many locally valid pieces with one rare global inconsistency
multi-view world models with local coordinate systems
large distributed constraint systems
scientific models whose local laws agree except on sparse interfaces
```

## Capability hypothesis

If obstruction complexity remains bounded while total global state count grows exponentially, a native local/gluing realization can retain high capability with burden controlled by overlap/obstruction size rather than global state count.

## Weak regime

Dense all-to-all consistency, no locality, or obligations requiring explicit enumeration of global assignments.

## Parent attacks

```text
D4 CSP/SAT/program representations
D3 factor graphs/probabilistic inference
D7 distributed consensus/message passing
D1 GNN/message-passing neural systems
```

## Domain discriminator

Construct families where parent state-space or communication burden grows with global assignment space while the candidate grows with local cover/obstruction complexity.

Kill:

`N3_REDUCES_TO_LOCAL_CONSTRAINT_PARENT_WITH_BOUNDED_BURDEN`

# 3. N8 — Constructive / Autocatalytic Intelligence

## Carrier

A set/population of constructors plus their reachable constructive closure:

\[
Z=(C,\operatorname{Cl}(C)),
\]

where a constructor is an object that can build, modify, activate or replicate another computational component.

The future cognitive capacity of the system can differ even when present input-output behavior is identical because constructor closures differ.

## Native operators

```text
construct component
compose constructors
replicate constructor
modify constructor
activate/deactivate component
expand or prune constructive closure
```

## Natural complexity coordinate

```text
minimal constructor basis size
reachable closure size/depth
construction graph depth
reuse of constructed components
autocatalytic closure gain
```

## Predicted niche

Long-lived nonstationary ecologies where future useful machinery cannot be anticipated cheaply but reusable constructors can create it when needed.

## Capability hypothesis

Capability after `T` regime changes should correlate more strongly with reachable useful constructor closure than with current architecture size.

A constructive machine can therefore begin weaker than a fixed neural/program machine yet overtake it after enough novel regime shifts.

## Weak regime

Short horizon, stationary task distribution, expensive construction, or no reusable structure between future modules.

## Parent attacks

```text
D8 self-rewriting/morphogenetic systems
D5 architecture/program search
D4 metaprograms/program synthesis
DC6 chemical reaction networks
DC7 population-hereditary systems
```

## Domain discriminator

Create pairs with identical present computation and morphology but different constructor closure. If future protected capability differs predictably under novel demands while ordinary D8 state descriptors collide, constructor closure is missing sufficient state.

Kill:

`N8_CONSTRUCTOR_CLOSURE_ADDS_NO_PREDICTIVE_POWER_BEYOND_D8_STATE`

# 4. N10 — Event-Causal / Partial-Order Intelligence

## Carrier

An event structure rather than a sequence of global snapshots:

\[
Z=(E,\preceq,\#,\lambda),
\]

with events `E`, causal order `preceq`, conflict relation `#`, and labels/resources `lambda`.

Concurrent events need not be forced into an arbitrary total order.

## Native operators

```text
extend causal frontier
compose concurrent processes
synchronize events
branch on conflict
splice/rollback a causal cone
answer provenance queries over partial order
```

## Natural complexity coordinate

```text
causal width
frontier width
conflict degree
critical-path depth
minimal synchronization cut
```

rather than Cartesian global-state size.

## Predicted niche

Highly concurrent obligations with sparse causal interaction, strong provenance/history requirements and expensive global synchronization.

## Capability hypothesis

When independent event streams multiply, snapshot/state-product parents can grow combinatorially while an event-native representation grows near linearly in realized events plus causal edges.

## Weak regime

Dense synchronization where almost every event depends on almost every other event; then the partial order approaches a total/global state process and the advantage disappears.

## Parent attacks

```text
D4 process calculi/Petri nets/program representations
D6 state machines/dynamical systems
D7 distributed logs/collective systems
```

This candidate is likely to reduce to D4 unless a genuine lifecycle separation is found.

Kill:

`N10_EVENT_STRUCTURE_IS_BOUNDED_SYMBOLIC_COMPILATION`

# 5. N11 — Invariant / Obstruction Intelligence

## Carrier

Equivalence classes and obstruction/invariant objects rather than detailed configurations.

Examples of carrier shapes include:

```text
quotient classes
cycles/boundaries
homology/cohomology classes
persistent invariants
conserved quantities
obstruction certificates
```

## Native operators

```text
quotient away nuisance deformation
compute/update invariant
compose invariants
detect obstruction
track birth/death of invariant under scale/time
```

## Natural complexity coordinate

```text
invariant rank
obstruction dimension
persistence complexity
number of equivalence classes relevant to obligation
```

## Predicted niche

Obligations where the protected answer is invariant under huge families of microscopic transformations and where impossibility/obstruction information is more useful than reconstructing the full state.

## Capability hypothesis

A native invariant machine should show extreme robustness and sample/resource efficiency under semantic-preserving deformation, but poor reconstruction of fine metric detail.

## Weak regime

Tasks whose answer depends on exact coordinates, fine metric values, or nuisance variables intentionally quotiented away.

## Parent attacks

```text
D4 symbolic algebra/theorem proving
D1 engineered invariant features/neural equivariance
D6 dynamical conserved-state summaries
```

Kill:

`N11_INVARIANTS_ARE_ONLY_FEATURE_COMPILATION`

# 6. N12 — Morphism / Interface-First Intelligence

## Carrier

A typed network/category of transformations and interfaces rather than a single global value state:

\[
Z=(Obj,Hom,\circ,\otimes,\mathcal C),
\]

where cognition is encoded in which transformations are available, how they compose and what contracts they preserve.

## Native operators

```text
compose typed transformations
parallel/tensor composition
factor a transformation
substitute implementation behind an interface
trace/feedback a process
verify interface contract
```

## Natural complexity coordinate

```text
interface width
composition depth
minimal factorization size
reuse multiplicity
contract complexity
```

## Predicted niche

Large compositional obligations assembled repeatedly from reusable transformations with stable interfaces and highly variable internal realizations.

## Capability hypothesis

The candidate should transfer to unseen compositions with burden predicted by interface/composition complexity rather than by total retraining examples.

## Weak regime

Monolithic entangled tasks with no reusable factorization or stable interfaces.

## Parent attacks

```text
D4 programs/type systems/category-theoretic computation
D8 modular morphogenesis
D7 service/agent composition
```

This candidate is expected to reduce unless composition itself gives a protected burden separation unavailable to ordinary symbolic programs.

Kill:

`N12_MORPHISM_STATE_REDUCES_TO_TYPED_PROGRAM_WITH_BOUNDED_BURDEN`
