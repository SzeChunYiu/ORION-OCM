# Description invariance and speedup limits v1

Status: **parent-theory subtraction / implications for Track B**, not a new theorem claim.

Refs #377, #233, #373.

## 1. Why description length alone cannot identify one metaphysically unique cognitive basis

For universal description languages / universal machines, the invariance theorem of Kolmogorov complexity says that description complexity is machine-dependent only up to an additive compiler constant. Informally, for suitable universal machines `U` and `V`,

\[
K_U(x) \le K_V(x) + c_{UV}
\]

and symmetrically in the other direction.

Scientific consequence:

```text
"basis B gives the shortest universal descriptions"
```

cannot by itself establish that `B` is the uniquely fundamental cognitive basis. Another universal basis may describe the same computable objects with only a fixed translation constant, and which one wins at small practical scales can depend on encoding choices.

Track B therefore treats:

```text
ONE_UNIQUE_MINIMAL_BASIS
```

as a hypothesis, not an expected result. A more plausible formal outcome is an equivalence class of bases under registered bounded compilers.

## 2. Resource cost does not collapse to description length

Even when two universal formalisms are close in description length, execution/update/communication/storage costs can differ dramatically.

Therefore the Track-B comparison object remains a resource vector rather than one scalar:

```text
description
execution
update / learning
communication
verification
maintenance / revision
search / acquisition
```

A price vector may be frozen for a particular engineering/ecology question, but it is not a universal intelligence definition.

## 3. Speedup theorems attack the idea of one universally optimal executable morphology

Classical Blum-style speedup results show that, for admissible complexity measures, there are computable problems for which no single program is asymptotically optimal in the strongest naive sense: another program can provide a prescribed improvement, and the phenomenon can repeat.

This does not mean practical problems have no good algorithms. It means Track B must not seek a theorem of the form:

```text
one fixed morphology M* is asymptotically best for all computable cognition
```

without very strong restrictions.

Together with No-Free-Lunch boundaries, this pushes the scientific target toward:

```text
conditional morphology optimality / Pareto efficiency
under a declared structured ecology and resource model.
```

## 4. Universal-program parent kills weak cross-paradigm derivation claims

Any computable neural, symbolic, probabilistic-sampling or programmatic morphology can, in principle, be encoded as a program for a suitable universal machine.

Therefore:

```text
same basis can REPRESENT all known morphologies
```

is weak and normally parent-owned.

Track B requires more:

1. bounded developmental compilation;
2. no architecture-labelled hidden macro;
3. useful resource bounds;
4. developmental acquisition from experience/search;
5. prospective ecology -> morphology frontier prediction.

Without these, return:

```text
UNIVERSAL_COMPUTATION_ONLY
```

## 5. Consequence for the user's original "fundamental unit" hypothesis

The strong version

> there is one unique minimum irreducible cognitive unit, and every intelligence form is generated from it

is **not currently supported** and is threatened by mature computability/description-invariance results.

A more defensible object is:

> a resource-bounded equivalence class of adaptive generating bases, together with composition, developmental-update and morphogenesis laws.

Compactly:

\[
\mathfrak B=[B]_{\text{bounded developmental compilation}}
\]

and

\[
\Gamma(\mathfrak B,E,R,V,H) \to \mathcal F_{\text{morphology}}.
\]

The theory can still discover small irreducible primitives **relative to a frozen ecology/resource/compiler class**. It should not promote such relative minimality into metaphysical uniqueness.
