## 2. Obvious hybrid holes are also occupied

Combining two pressures does not by itself create a new form. Many obvious pairings already have parent products:

```text
neural + symbolic                 -> neuro-symbolic
neural + probabilistic            -> variational/Bayesian neural systems
neural + programmatic             -> differentiable/neural program induction and tool/program agents
symbolic + probabilistic          -> probabilistic logic / graphical-model hybrids
programmatic + probabilistic      -> probabilistic programming
neural + memory/retrieval         -> memory-augmented nets / RAG / kNN hybrids
continual + modular               -> dynamic/modular continual learning
architecture search + learning    -> NAS/meta-learning/evolution
```

Therefore a new combination of familiar components is not a new morphology by default.

## 3. The current ORION/OCM region

ORION's strongest distinctive emphasis is not an empty computational morphology region. It combines:

```text
explicit persistent developmental capital
pre-solution proposal/search change
external verification/warrant
provenance/scope/lifecycle
complete acquisition + serving + revision accounting
governed self-change
```

Each component has parents. The candidate residual is the **causally measured, governed developmental interaction** among them and eventual cross-domain evidence—not a presently unoccupied primitive architecture class.

## 4. What would count as a real hole

A phase hole must be specified before morphology search by a conjunction of required properties `R*`:

\[
R^*=(r_1,\ldots,r_k)
\]

such that:

1. each property is operational/measurable;
2. the strongest parent frontier is evaluated under the same information/tools/resources;
3. no parent or ordinary parent product satisfies all `R*` within registered cost bounds;
4. a lower bound or strong empirical obstruction explains why;
5. theory predicts that a feasible region nevertheless exists;
6. the search grammar does not contain a named solution macro.

Only then should #221/#220 morphology search be authorized.

## 5. Candidate hole templates worth testing later

These are **templates, not currently established holes**.

### H1 — local revision + high amortization + exact warrant

Require simultaneously:

```text
statistical/high-throughput inference
exact local evidence withdrawal/revision
bounded collateral competence change
explicit warrant/provenance
low serving cost
```

Neural, symbolic and hybrid parents must be tested first. Current evidence does not establish that ordinary hybrid systems fail.

### H2 — open vocabulary of new operators + bounded verification

Require a machine to invent new reusable transformations, verify them externally, integrate them without global retraining, and retain old competence under a complete lifetime ledger.

Program synthesis/library learning + theorem-proving/tool-agent + continual-learning parent products are mandatory controls. No hole established yet.

### H3 — cross-validation-regime developmental transfer

Require the same learned developmental structure to improve future learning across formal-proof, execution-test and empirical-evidence regimes without a domain-core fork.

This is closer to Track A / #369 and may reveal a missing morphology or simply a strong integration result. No hole established.

### H4 — self-improving morphology generator under external constitution

Require generation/search of better morphology itself to improve across fresh ecology families while evaluator, authority and resource accounting stay external/frozen.

MetaBBO/AutoML/PowerPlay/AI4AI/RSI parents are very strong. No hole established.

## 7. What can unlock Question 4

Only one of these should unlock unknown-form search:

1. **formal obstruction:** prove/derive that all registered known parent families pay an unavoidable cost in a target regime, while a lower bound leaves headroom;
2. **prospective empirical gap:** on a frozen regime, every strong parent fails a registered property vector and the gap is stable across independent instances;
3. **cross-paradigm phase law:** a validated structure-to-developmental-geometry theory predicts a morphology property combination absent from the atlas.

Until then, the correct upward move is to improve the theory/measurement of known morphology frontiers rather than generate novelty for its own sake.
