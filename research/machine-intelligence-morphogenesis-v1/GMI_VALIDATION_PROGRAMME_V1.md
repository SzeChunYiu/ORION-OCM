# GMI Validation Programme v1 — how the theory becomes established

Status: **execution plan for establishing the synthesis**, not a promise that every rung will be positive.

Refs: #233, #377, #373, #369, #323, #144.

The programme now distinguishes two goals that were previously conflated:

1. **Establish a coherent general theory/framework** by showing that one set of definitions and imported theorem modules consistently contains known machine-intelligence forms.
2. **Establish a new general empirical law** only if the theory predicts something across forms that the parent product does not already predict.

Goal 1 does **not** require ORION to invent new mathematics at every layer.

# Level GMI-E1 — within-family prospective developmental prediction

This asks whether pre-outcome structure/history predicts later developmental burden in a real nontrivial system.

## OCM programme-search family

`S2G_OCM_PROSPECTIVE_V1` is already frozen. It requires fresh eligible worlds after freeze and predicts proposal-rank information shift from validation geometry.

No pre-freeze world may be backfilled.

## Neural family

Design a small controlled neural learning family where pre-training geometry is measurable before protected target outcomes, e.g.:

```text
representation/task alignment
gradient covariance / Fisher or NTK proxy
condition number / curvature
plasticity/interference statistic
```

Predict held-out sample/update burden. Compare to strongest family-native predictor.

## Probabilistic family

Use model/prior structure to predict posterior concentration / evidence requirement on held-out task families.

Again the family-native Bayesian bound is the parent.

This stage does not require one cross-family formula yet.

# Level GMI-E2 — cross-paradigm invariant test

Register two or more materially different families and ask whether one compact pre-outcome signature or theorem predicts a normalized developmental property across both.

A valid target must be stronger than generic expected cost or generic hitting time, which are parent-owned.

Candidate normalized quantities to investigate:

```text
history-induced reduction in target surprisal / search rank
verified acquisition burden relative to matched reset
fraction of developmental state changed per useful gain
retention/plasticity cost of update
amortization horizon to repay acquired structure
useful-descendant mass under a registered proposal kernel
```

Requirements:

- same definition, no family-specific rewording;
- family-native parent predictors included;
- predictor frozen before protected outcomes;
- at least one disjoint confirmatory batch;
- negative transfer retained.

Positive terminal:

`CROSS_PARADIGM_DEVELOPMENTAL_LAW_SUPPORTED__SCOPE_<s>`.

Negative terminal:

`NO_USEFUL_CROSS_PARADIGM_INVARIANT_AT_REGISTERED_SCOPE`.

A negative leaves GMI as a synthesis/metrology theory rather than killing its coherence.

# Level GMI-E3 — real capability regimes

This is where #369 becomes a direct test of the theory.

## Mathematics

Use strongest available autoformalization / retrieval / proof-search donors and Lean kernel verification.

Compare:

```text
strong lifelong theorem parent
same donors + RESET developmental state
same donors + CONTINUED developmental state
```

Measure:

```text
formalization faithfulness
verified proof success
premise/tactic/proposal rank
search nodes / checker calls
new-method acquisition burden
retention/plasticity
full lifetime cost
```

## Code/tools

Use execution/tests/compilers as external verification.

Same GMI definitions; do not invent code-specific “intelligence.”

## Language-mediated tasks

Use a frozen strong language model as interface/donor initially. The same model must be supplied to parent/reset/continued arms. Measure development in reasoning/tool/clarification/verification behavior, not surface fluency.

## Science

Use evidence/reproducibility rather than binary formal proof. `V` changes, GMI definitions do not.

### Key generality test

If `B`, K1/K2 and developmental-frontier definitions must be changed to make each domain look positive, the theory fails its own generality criterion.

# Level GMI-E4 — heterogeneous lifelong machine

One persistent machine experiences a chronological mixture such as:

```text
formal math -> code -> tool use -> data/science -> mixed tasks
```

with no core reset between domains.

Required readouts:

- within-domain positive transfer;
- cross-domain positive/negative transfer;
- retention;
- plasticity;
- whether earlier experience changes later cognition generation;
- complete maintenance/acquisition cost;
- same developmental-state definitions throughout.

This is the first strong empirical test that GMI's abstraction is actually useful across validation regimes.

# Level GMI-E5 — endogenous morphology phase prediction

Only after known-family mappings and prediction work.

Protocol:

```text
1. define a neutral candidate/generative space;
2. derive a morphology/frontier phase prediction before search;
3. keep architecture labels out of the search objective;
4. search blindly;
5. classify/reduce the discovered solutions after search;
6. compare against graph-partitioning, AutoML/NAS, bounded-rational and family-specific parents;
7. repeat on disjoint ecologies.
```

Positive terminal:

`ENDOGENOUS_MORPHOLOGY_PHASE_RECOVERED_PROSPECTIVELY`.

This can be scientifically important even if every ingredient is parent mathematics.

# Level GMI-E7 — meta-morphogenesis / RSI

The machine must improve not merely itself but the process that discovers/improves future cognition.

For generation `g`, define complete burden to first verified frontier improvement on fresh ecology family:

\[
B^{improve}_g.
\]

A minimal RSI-style target is a prospectively supported decline such as

\[
E[B^{improve}_{g+1}]<E[B^{improve}_g]
\]

with evaluator/constitution fixed and strong learned-optimizer/MetaBBO/AutoML/AI4AI parents.

One self-edit is not RSI.

# What counts as 'the theory is established'?

## Established synthesis theory

We may use

`GMI_SYNTHESIS_THEORY_ESTABLISHED_AT_SCOPE_V1`

when F0-F3 are complete and the framework demonstrably contains the major known forms/parents with consistent definitions.

This claim means:

> there exists a coherent unified formal language for the studied machine-intelligence forms and developmental comparisons.

It does **not** mean a novel universal law has been discovered.

## Empirically supported general developmental theory

Requires at least E1-E4 with the same definitions and a disjoint replication.

## New general law

Requires E2 and/or E5 beyond parent products.

## New form of intelligence

Requires E6.

## Recursive general machine intelligence / RSI

Requires E7 plus real capability breadth.

This ladder lets ORION move upward even when parent theory supplies most of the mathematics.
