No single experiment can verify a general theory of machine intelligence. The intended standard is convergent survival across theorem microscopes, controlled interventions, held-out families, neutral search, real transfer and parent-reduction attacks.

# 1. Evidence ladder

Every major claim should progress through as many applicable tiers as possible.

```text
X0  EXACT / FORMAL MICROSCOPE
    finite enumeration, constructive proof check, symbolic calculation, exact simulator

X1  CONTROLLED LEARNING INTERVENTION
    train actual learners while independently varying the hypothesized cause

X2  HELD-OUT PREDICTION
    freeze response law on development families and predict untouched family/ecology cells

X3  NEUTRAL MORPHOLOGY RECOVERY
    low-level search grammar with no named target architecture macro

X4  REAL-REGIME TRANSFER
    code, formal mathematics, changing factual/scientific tasks, multimodal/control regimes

X5  PARENT REDUCTION / NOVELTY ATTACK
    strongest parent families receive first refusal; compile/reduce the recovered form

X6  LONGITUDINAL / META-MORPHOGENESIS
    repeated developmental generations, changing regimes, learned Gamma
```

A theory statement must carry the highest tier actually passed, not the tier intended.

# 2. Global experimental constitution

All protected experiments inherit these rules.

## 2.1 Development / validation / protected separation

Use:

```text
D  development/search/tuning worlds
V  limited validation worlds
P  one-shot protected worlds generated/frozen after model, metric and analysis freeze
```

If `P` is reused adaptively after a failure, it becomes development information and a fresh protected split is required.

## 2.2 Hierarchy-aware replication

Do not pseudo-replicate thousands of queries from one generated ecology as thousands of independent theory tests.

Primary replication units should include, as appropriate:

```text
ecology seed
latent law seed
data-generation seed
training seed
architecture family
hardware/substrate context
search encoding
```

## 2.3 Resource accounting

Charge at least:

```text
training/development compute
labels/demonstrations/interventions
search/NAS cost
failed candidates
verification calls
memory/storage
communication
serving compute/latency
update/maintenance burden
human intervention
compiler/materialization cost
```

## 2.4 Parent first refusal

Every experiment proposing a new mechanism/form includes strong tuned parent arms with the same legal information.

## 2.5 Semantic remint

Surface names, IDs, ordering, token conventions and irrelevant encodings must be reminted between development and protected worlds where possible.

## 2.6 Continuous + threshold metrics

For scaling/emergence studies report continuous underlying scores as well as discrete success thresholds.

# 23. Theory-level success criterion

Do **not** define “GMI verified” as a binary terminal.

Instead maintain a claim matrix:

\[
C_{ij}
=
\text{highest evidence tier survived by theory atom }i\text{ in family/regime }j.
\]

A mature theory should show:

```text
formal atoms surviving X0;
mechanism directions surviving matched X1 interventions;
response laws predicting X2 held families;
new property vectors recovered at X3;
important claims transferring at X4;
novelty candidates surviving X5;
meta-development claims surviving X6.
```

The theory is weakened locally when an atom fails. It should be rewritten only at that causal layer unless the failure logically propagates upward.
