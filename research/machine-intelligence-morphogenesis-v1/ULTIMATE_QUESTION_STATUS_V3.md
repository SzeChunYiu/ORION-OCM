# Q1 — Is there one minimum irreducible cognitive unit?

## Current answer: probably not in the strong representation-independent sense

Track B now has several independent attacks:

1. **split/merge granularity:** computational units can often be refactored into smaller composed units, while finite networks can be merged into one global transducer;
2. **finite flattening:** finite deterministic adaptive networks with finite topology/configuration state flatten exactly to finite-state transducers;
3. **universal representation:** general program formalisms encode all computable morphology families;
4. **description invariance:** universal description length is reference-language dependent up to compiler constants;
5. **multiple minimal bases:** even tiny exact algebraic systems can have several distinct minimal generating bases;
6. **speedup/NFL boundaries:** unrestricted claims of one universally optimal implementation/morphology are not available.

Therefore the live mathematical object is not one sacred atom but something like

\[
\mathfrak B=[B]_{E,R,V,\mathcal K},
\]

an equivalence class of generating factorizations relative to an ecology, resource model, verification contract and compiler/update class.

A stronger physical/locality theorem could still identify irreducible primitives under added constraints, but that would be a **relative physical/resource result**, not a representation-free computational atom.

### Current terminal

`NO_REPRESENTATION_INDEPENDENT_UNIQUE_COGNITIVE_ATOM_ESTABLISHED`.

# Q3 — What limits a form of intelligence, and why does one dominate?

## Current answer: ecology–bias alignment + lifecycle resources is the generic parent-level law

For an idealized proposal/search morphology `M` with target distribution `P`, induced proposal prior `Q_M`, build cost `B_M` and horizon `N`, Track B derives the calibrated form

\[
C_M=B_M+N[H(P)+D_{KL}(P\Vert Q_M)].
\]

This cleanly captures:

```text
match the morphology's inductive/proposal bias to the ecology
+ amortize build/training cost over the lifetime
```

but this is information theory + decision/resource economics, not GMI novelty.

For generic stochastic development, if a useful potential and local drift are already supplied, drift/SSP/metareasoning parents bound first-hitting burden.

Known paradigms expose different useful structural quantities:

```text
programmatic      code length / grammar prior / branching / library compression
Bayesian           prior odds / KL information / Fisher / factor graph structure
neural             curvature / condition / Fisher / contraction / initialization
symbolic           branching / proof depth / rule selectivity / constraint propagation
evolutionary       neighborhood / fitness landscape / drift / evolvability
OCM                library size, probe depth, guided rank, tiling/validation, liveness
```

No morphology-neutral sufficient statistic has been established.

### Current residual

A pre-outcome, low-information-cost signature `G(M,H,E)` that predicts the developmental burden/frontier across more than one paradigm and supports causal intervention.

# What Track B has actually established so far

- finite local adaptive decomposition does not create a new expressivity class;
- current behavior equivalence does not imply developmental equivalence;
- finite burden vectors do not identify internal morphology;
- finite toy cross-paradigm derivation is scientifically weak because generic program/state parents can flatten/encode it;
- target-specific compilers can hide architecture information and must be charged;
- an exact universal burden predictor for unrestricted Turing-complete systems is unavailable in general;

# Current ultimate answer

The evidence presently supports the following—not more:

> **Machine intelligence is not presently best described by one uniquely identifiable cognitive atom. Known machine-intelligence forms are better viewed as alternative adaptive factorizations/inductive biases whose developmental dynamics induce different cost geometries. Which form is useful is conditional on task structure, information, feedback, verification, hardware and lifetime resources. The broad framework is mostly parent-owned; the unresolved scientific opportunity is to discover predictive cross-paradigm invariants linking machine structure to developmental geometry and endogenous morphology transitions.**

This is a provisional scientific answer, not a final metaphysical definition of intelligence.
