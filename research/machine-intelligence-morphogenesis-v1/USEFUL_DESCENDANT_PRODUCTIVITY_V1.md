# Useful-descendant productivity v1

Status: **candidate measurable invariant, mostly parent-owned mathematics; linked to HST evolvability.**

## 1. Local developmental productivity

Given morphology developmental state `h`, update/proposal kernel

\[
K_M(h'\mid h,e),
\]

and a prospectively registered usefulness/admissibility predicate `U(h')`, define useful-descendant mass

\[
Ev_M(h;U,e)
=
P_{h'\sim K_M(\cdot\mid h,e)}[U(h')].
\]

This is closely aligned with the evolvability quantity already proposed in HST.

If one proposal costs scalar `c` under a frozen price model and independent identically distributed proposals have stationary useful probability `p=Ev`, then the number of proposals to the first useful candidate is geometric:

\[
E[N]=1/p
\]

and expected proposal cost is

\[
E[C_{first}]=c/p.
\]

With a resource vector, retain the vector distribution rather than forcing a scalar.

## 2. Candidate normalized quantity

Where scalarization is justified, define

\[
\rho_M(h)=\frac{Ev_M(h)}{c_M(h)}
\]

as local useful-descendant productivity.

Higher `rho` means useful changes are denser/cheaper in the morphology's local developmental neighborhood.

This is not a universal intelligence score.

## 3. Cross-paradigm interpretation

### Gradient/neural

When the task loss is locally informative and gradients align with useful directions, optimizer-induced `K` concentrates probability/mass on locally improving parameter changes. Smooth parameterization can therefore create high local useful-descendant productivity.

Failure regimes include flat/noisy/misaligned gradients, catastrophic interference, or useful changes requiring nonlocal architecture/representation moves.

### Programmatic/synthesis

`K` is induced by grammar, prefix prior, mutation/edit operators, library abstractions and search order. Reusable libraries can move future useful programs to shorter/higher-prior descriptions, increasing `Ev` or lowering proposal cost.

### Symbolic/production

Rule induction/chunking and unification define a structured local neighborhood over explicit transformations. Strong typing/scoping may reduce invalid proposal mass but can also exclude required representational moves.

### Probabilistic

Posterior/inference updates redistribute mass toward models/hypotheses supported by evidence. Useful-descendant mass depends on prior adequacy, likelihood informativeness and inference quality/cost.

### OCM/history-induced search capital

A measured history-induced change in candidate rank/proposal ordering is naturally a change in `K` / useful mass. A true developmental result should show this change **before** target success and charge the cost required to acquire the new geometry.

## 4. Why this helps morphology phase prediction

Suppose two morphology families have similar current capability but different developmental geometries.

A first-order phase prediction can compare:

```text
cost to obtain useful next competence
≈ proposal/check cost / useful-descendant mass
+ persistent build/maintenance cost
```

An ecology with smooth reusable structure may favor a morphology whose local geometry places high mass near improvements. A sparse compositional ecology may favor a grammar/library morphology. Frequent representation breaks may favor a form with cheaper nonlocal moves even if its local `rho` is lower.

This gives a quantitative bridge from ecology structure to developmental burden.

## 5. Required corrections beyond the geometric toy law

The simple `c/p` equation fails when:

- proposal probabilities change after failures;
- proposals are correlated;
- candidate quality is continuous, not binary;
- the verifier is noisy/expensive;
- failures teach the search policy;
- useful changes have different downstream value;
- search can branch/backtrack;
- a proposal changes the morphology generator itself.

Therefore serious experiments must log the complete sequential process.

## 6. Strong parents

No novelty is claimed for geometric first-hit cost or evolvability probability. Parent families include:

- evolutionary evolvability / mutation-neighborhood analysis;
- stochastic local search;
- Bayesian/search priors;
- algorithmic probability / Levin-style search;
- meta-learning / learned optimizers;
- rational metareasoning/value of computation;
- HST-T10 useful-descendant mass.

Track B's residual would be a **prospectively predictive cross-paradigm use** of these quantities, not the definition itself.

## 7. Proposed measurable morphology signature

For registered states/ecologies measure:

```text
useful proposal mass or rank
cost per proposal/update
verification cost
first-useful-change burden
quality distribution of useful descendants
retention/regression probability
nonlocal escape cost
```

Call the vector

\[
\Xi_M(E)
\]

the developmental-neighborhood signature.

A phase-law hypothesis should state which coordinates of `Xi` are expected to differ between morphology families and how that predicts whole-lifetime frontier membership.
