Status: **authority convergence**. GMI-v1 does not replace #233 Heritable Search Transformation (HST).

HST remains the programme's sole live formal-theory authority for developmental search transformation.

GMI-v1 is a specialization/refinement that answers four questions HST deliberately leaves abstract:

1. What is the least representation-dependent notion of machine/developmental state?
2. What is a machine-intelligence morphology relative to that state?
3. How should intelligence/generality be compared under complete resources?
4. How do known neural/symbolic/probabilistic/programmatic/OCM forms instantiate the theory?

# 2. GMI refinement inside HST

## 2.1 Developmental sufficient state

GMI forms a **developmental situation** from the current machine configuration, registered history and relevant current ecology/authority context:

\[
d_t=(\chi_t,h_t,\xi_t).
\]

It then defines the task-relative semantic quotient

\[
z_t=[d_t]_{\sim_{\mathcal O}}.
\]

This is not an additional persistent store. It is an abstract semantic state used to reason about when two complete machine situations are future-equivalent under the registered obligation.

Mapping into HST:

```text
HST L_t/Q_t/H_t + current runtime/configuration + relevant E_t/R_t/C context
          ↓ future-obligation equivalence quotient
GMI z_t
```

The exact quotient may be impossible/intractable to construct; it is a theory object. Practical systems may use beliefs, predictive states or other approximations.

## 2.2 Morphology

GMI morphology

\[
M=(F,\Theta,K,U,\Gamma,\kappa,\rho_M)
\]

is a computational realization/factorization of the HST search-generating state.

Approximate mapping:

```text
GMI F, kappa        <- structure/realization of HST L_t and H_t
GMI Theta           <- mutable realization state inside HST H_t / runtime
GMI K               <- realization of HST Q_t + executive/action dynamics
GMI U               <- within-form component of HST update U_HST
GMI Gamma           <- HST changes to L_t/Q_t/organization / morphology
GMI rho_M           <- implementation contribution to HST resource semantics R_t
GMI verifier/const.  = HST V_t, C (external, not inside the morphology's authority)
```

GMI therefore does not introduce a second developmental loop.

## 2.3 Intelligence profile

HST's Verified Search Burden becomes a coordinate of the GMI developmental feasible set/frontier.

For task `tau`:

\[
\mathbf B_t(\tau)
\]

from HST is the raw resource burden until first admissible verified solution.

GMI aggregates this with capability over an ecology from a developmental situation `d`:

\[
\mathcal F_M(E\mid d)=Pareto\{(Q,\mathbf B)\}.
\]

Thus:

```text
HST measures how development transforms future search burden.
GMI embeds that burden in an intelligence/generality profile across ecologies and situations.
```
