# Structure → developmental geometry programme v1

Status: **next decisive Track-B theory/empirical bridge after the execution-basis no-go.**

## 1. Why this is now central

The latest subtraction establishes three things:

1. finite adaptive machines can be flattened into ordinary state machines;
2. generic programs can compactly realize many useful factorizations;
3. costed finite developmental state graphs reduce to mature stochastic-shortest-path / metareasoning parents.

So neither

```text
common execution language
```

nor

```text
costed state-transition graph
```

is enough for a new general theory of machine intelligence.

The remaining difficult map is:

\[
\boxed{
\text{morphology structure + learning law + history}
\longrightarrow
\text{predictive developmental geometry}
}
\]

before the full target-development outcome is observed.

## 2. Target object

For morphology `M` at developmental time `t`, estimate a compact signature

\[
\Phi(M_t)=
(\hat\pi,\hat K,\hat c,\hat r,\hat p,\hat v),
\]

where candidate coordinates include:

- `pi`: proposal/search/inductive mass over useful future constructions;
- `K`: update transition kernel or local response model;
- `c`: raw resource vector per proposal/update;
- `r`: retention / interference response;
- `p`: plasticity / remaining useful-change capacity;
- `v`: verification/evidence access and cost.

The signature is useful only if it can be estimated **without solving the protected future target**.

## 4. Required prediction task

For fresh task/ecology unit `tau`, freeze a prediction before target solution access:

\[
\hat B(M,\tau)=f(\Phi(M),\psi(\tau,E)),
\]

where `psi` contains only legal pre-outcome ecology/task descriptors.

Predict one or more of:

```text
first-verified-solution burden
successful-candidate rank
proposal surprisal
update count
data/examples needed
verification calls
revision/retention burden
probability of useful adaptation within budget
```

Then compare prediction with actual outcome.

## 5. Strongest parents

The prediction must beat or clarify the residual beyond:

```text
ordinary algorithm selection
portfolio models
learning-curve extrapolation
Bayesian optimization/surrogates
PAC/PAC-Bayes bounds where applicable
meta-learning performance predictors
AutoML/NAS performance prediction
resource-rational metareasoning
```

A generic supervised model that identifies the winning algorithm from task IDs is not a general morphology theory.

## 6. Cross-paradigm requirement

A field-level positive requires at least two materially different morphology families and ultimately four.

The important question is whether the **same invariant family** retains predictive meaning after moving between, for example:

```text
program search
↔ neural adaptation
↔ probabilistic inference
↔ explicit symbolic learning
```

It is acceptable if some coordinates are morphology-specific, but the theory must state the mapping rather than calling unrelated features the same thing.

## 7. Prospective phase prediction

For ecology coordinate `z`, freeze a predicted crossing:

\[
\hat B(M_i,E_z)=\hat B(M_j,E_z)
\]

before executing the protected sweep.

Then test whether the observed developmental Pareto/frontier membership changes near the predicted region.

This is stronger than fitting a phase boundary after observing the sweep.

## 8. Causal geometry intervention

Prediction alone can be correlational.

Where possible intervene on the predicted geometry while leaving task information fixed:

- change proposal prior/search order;
- change library representation;
- change optimizer/update locality;
- alter factorization without altering represented function;
- disable/re-enable a learned asset;
- change verification cost/access while preserving target.

Require the burden/frontier to move in the registered direction.

## 10. Immediate sequence

1. **S2G-0 exact calibration:** derive `pi/K/c` analytically in a finite family and verify predicted burden exactly.
2. **S2G-1 programmatic:** code-length/library/search geometry on a small synthesis family.
3. **S2G-2 OCM:** use #323 pre-solution search-prior receipts as explicit geometry-change data.
4. **S2G-3 probabilistic:** factor/prior/inference family with exact finite inference.
5. **S2G-4 neural:** small controlled network family with frozen optimizer/data and exact/fully recorded training trajectories.
6. **S2G-5 cross-paradigm:** fit/derive common invariant candidates on development families, freeze a phase prediction, test on held-out ecologies.

Do not skip directly to LUNARC morphology search.

## 11. Ultimate relevance

If this programme succeeds, the general theory is no longer “all forms run on the same computer.”

It becomes a predictive account of how machine structure shapes the **cost and direction of future learning**, and how ecology selects among those developmental geometries.

If it fails, the most likely scientifically honest conclusion is that morphology selection remains an algorithm-portfolio/AutoML problem without a useful cross-paradigm invariant at the registered resolution.
