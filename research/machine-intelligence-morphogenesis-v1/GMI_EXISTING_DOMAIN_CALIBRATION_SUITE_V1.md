# GMI Existing-Domain Calibration Suite v1

Status: **PROSPECTIVE PREREGISTRATION — EXISTING DOMAINS AS CALIBRATION FOSSILS**

Status date: 2026-09-12.

Purpose:

> Test whether GMI can derive, regenerate and quantitatively predict the capabilities and limitations of already-known machine-intelligence domains before trusting it on undiscovered ones.

---

# 1. Calibration principle

Known domains are not merely baselines. They are held-out scientific calibration targets.

For each domain:

```text
A derive its carrier/operator signature from GMI coordinates
B predict favorable and unfavorable ecologies
C predict capability/resource response
D neutrally regenerate the domain from lower-level primitives
E reduce implementations back to the registered domain
F test negative twins and failure modes
```

Failure at any step weakens new-domain claims.

---

# 2. Calibration ladder

```text
CD0  TYPE RECOVERY
     classify state carrier and native operators without architecture-name leakage

CD1  NECESSITY/FAVORABILITY
     derive why the domain should enter the frontier in specific ecology coordinates

CD2  FAILURE PREDICTION
     predict negative twins and weak regimes

CD3  CAPABILITY ENVELOPE
     freeze scaling/ceiling/crossover predictions

CD4  NEUTRAL REGENERATION
     low-level carrier/operator grammar rediscovers domain

CD5  HELD-FAMILY TRANSFER
     predictions survive unseen task/ecology families

CD6  CROSS-SUBSTRATE REMINT
     domain-level response survives implementation changes
```

# 11. Cross-domain tournament matrix

Every ecology cell includes strongest relevant representatives from all domains that can legally act.

Report:

```text
protected capability
full lifecycle burden
frontier membership probability
calibration error of GMI prediction
winner and runner-up
predicted/observed crossover
reason for loss
```

No domain receives a protected handicap based on historical popularity.

---

# 12. Leave-one-domain-out derivation test

For each `D_i`:

1. hide its label and named implementation macros;
2. train/freeze GMI response laws on the remaining domains;
3. expose the carrier/operator primitives and ecologies;
4. require GMI to predict the missing structural signature;
5. run neutral search;
6. score recovery.

This is a direct test of whether GMI **derives domains** or merely memorizes the taxonomy.

---

# 13. Leave-one-domain-out capability prediction

Fit capability-envelope predictor on domains except `D_i` using structural descriptors.

Predict for held-out `D_i`:

```text
niche location
scaling elasticity
capability ceiling/floor
resource bottleneck
negative twin
crossover with closest parent
```

Then compare with executed measurements.

This is the strongest calibration precursor to predicting a truly unseen domain.

# 15. Advancement gate

Unknown-domain search may make strong predictive claims only after:

```text
>=7/8 baseline domains recovered neutrally at registered scope
all 8 have at least one correct favorable-niche and one correct unfavorable-niche prediction
capability-envelope predictor passes held-domain calibration threshold
false-new-domain rate under implementation remints is below frozen bound
```

If this gate fails, improve GMI theory rather than scaling open-world search.
