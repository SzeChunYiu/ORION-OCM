## Scientific question

Can a small resource-bounded adaptive generating basis, or an equivalence class of bases, generate qualitatively different machine-intelligence morphologies and predict which morphology should be favored by a task ecology, resource regime and verification contract?

The target is not another OCM core and not an LLM replacement. Current OCM is treated as one candidate morphology, not as the assumed universal form.

## Four foundational questions

Track B is now explicitly organized around:

1. **Basis:** what is the minimal/equivalent generating basis of machine intelligence?
2. **Morphogenesis:** what law maps basis + ecology + resources + verification + history into different intelligence morphologies?
3. **Developmental frontier:** what limits each morphology and why does one dominate a regime?
4. **Unknown forms:** can theory predict a non-parent-equivalent morphology before search?

Higher rung: can the morphology generator/update law themselves develop?

Canonical details: `FOUNDATIONAL_QUESTIONS_V2.md` and `ROADMAP_V2.md`.

- continual-learning research includes direct evidence for long-horizon plasticity loss and mitigation;

Therefore the surviving candidate residual is deliberately higher:

No novelty is claimed for any individual line above until parent subtraction is completed.

## Hard null

`UNIVERSAL_COMPUTATION_ONLY` is the central hostile. If the proposed basis reduces to arbitrary mutable state + arbitrary program + universal interpreter, and yields no nontrivial learnability/resource/morphology prediction, Track B has rediscovered generic computation rather than a theory of intelligence.

A second strong null is `PARENT_FORMALISM_SUFFICIENT`: if a candidate basis is simply a coalgebra/state machine, compositional learner, program interpreter or stochastic kernel with no new developmental/resource law, absorb the parent and move upward.

## Four levels of derivation

1. `D0 REPRESENTABILITY`: basis can simulate a morphology. Weak; universal computation can trivialize it.
2. `D1 BOUNDED_COMPILATION`: semantics and developmental update behavior are preserved within registered resource inflation.
3. `D2 DEVELOPMENTAL_ACQUISITION`: architecture-specific structure is not supplied; experience/search acquires it.
4. `D3 PROSPECTIVE_MORPHOGENESIS`: before search, theory predicts which morphology family should occupy the frontier under a new ecology/resource/verifier regime.

Only D3 is close to the intended field-level claim.
