# Generative Machine Intelligence — core hypothesis v2

Status: **converged candidate after finite no-go, family-scale compilation and parent subtraction; still unestablished as a new law.**

Refs #377, #233, #373, #165.

## 1. What changed from v1

Track B no longer treats discovery of one privileged execution primitive as the likely route to a general theory.

Current evidence/theory says:

```text
finite adaptive local systems flatten to state machines;
universal program formalisms compactly realize many morphology families;
target-specific compilers can hide the architecture being "derived";
costed finite development is already a stochastic-control/metareasoning object;
fixed-portfolio phase prediction is already algorithm selection;
experience-conditioned future priors/learning rules are already meta-learning.
```

So the remaining candidate theory must live above execution universality, portfolio selection and generic meta-learning.

## 2. Current general object

Use a **resource-bounded developmental equivalence class of bases**

\[
\mathfrak B=[B]_{E,R,V,\mathcal K}
\]

rather than one assumed atom.

A morphology `M` is a factorized machine organization with execution structure, mutable state/configuration, control and update law.

A morphology induces a **developmental geometry**

\[
\mathcal G_M=(\mathcal H_M,\pi_M,K_M,c_M,V_M),
\]

where:

- `H_M` is the useful/legal configuration space;
- `pi_M` is inherited proposal/search/inductive bias;
- `K_M` is the experience-conditioned update/proposal kernel;
- `c_M` is the complete transition/resource vector;
- `V_M` is the evidence/verification interface.

These ingredients are parent-owned individually. The tuple is not claimed novel.

## 3. Morphogenesis is decomposed

The user's original generator `theta(...)` is best decomposed into:

### Generative closure

\[
\mathcal M_{\mathfrak B}
\]

What organizations can the basis/grammar realize under the registered bounds?

### Developmental/ecology frontier

\[
\mathcal F_{\mathfrak B}(E)
\]

Which developmental-equivalence classes are Pareto-admissible in ecology `E` after full lifecycle costs?

### Search / morphogenesis dynamics

\[
\Gamma
\]

Which parts of that reachable/frontier space are actually discovered at finite search/development budget?

### Within-form development

\[
M_{t+1}=U(M_t,e_t).
\]

This is learning after a morphology exists.

Thus:

```text
basis/grammar      -> what can exist
ecology/resources  -> what is worth existing
search/morphogenesis -> what is found
within-form U       -> how the found form develops from experience
```

## 4. Exact baseline phase law

In the idealized finite target/proposal model with ecology `P`, morphology proposal distribution `Q_M`, build cost `B_M` and horizon `N`,

\[
C_M=B_M+N[H(P)+D_{KL}(P\Vert Q_M)].
\]

So morphology `M_1` beats `M_2` iff

\[
D_{KL}(P\Vert Q_1)-D_{KL}(P\Vert Q_2)
<\frac{B_2-B_1}{N}.
\]

This is information theory + amortization, not GMI novelty.

It gives a useful baseline interpretation:

> a morphology dominates when its inherited/developed bias aligns with the ecology strongly enough to repay acquisition/build/maintenance cost.

## 5. The genuinely hard map

The theory becomes nontrivial only if it predicts developmental geometry from actual machine structure:

\[
\boxed{
(M,U,H,\text{resource realization})
\longrightarrow
(\pi_M,K_M,c_M,\text{plasticity/retention})
}
\]

using only pre-target information.

This map must predict future acquisition/search/update burden and eventually frontier crossings.

If it cannot, Track B reduces to generic algorithm selection / AutoML / metareasoning.

## 7. Why neural morphology can dominate without being fundamental

Candidate parent-grounded reasons include:

```text
powerful differentiable credit assignment
shared/distributed representation
training-to-inference amortization
large-data scaling
massive parallel hardware/software co-design
pretraining-induced useful priors / transfer
```

These can make neural developmental geometry highly aligned with broad real data ecologies.

That does not imply neural morphology is universally optimal; revision, drift, exact verification, interaction cost, plasticity and reuse horizon can move the frontier.

## 8. OCM's relationship to the general theory

OCM is no longer the assumed substrate.

It is one morphology hypothesis characterized by:

```text
explicit persistent cognitive assets
history-conditioned search
external verification/governance
local revision/dependency structure
heterogeneous donor operators
lifetime accounting
```

#323 supplies a real measured geometry change: history moved eventual fresh solutions earlier in proposal order on most registered targets. The general theory must explain when that sort of explicit geometry is favored relative to parametric/probabilistic/programmatic alternatives.

## 9. Highest surviving novelty candidate

After current parent subtraction, the possible field-level residual is:

> A cross-paradigm, resource-bounded theory that derives predictive developmental geometry from machine factorization and learning law, prospectively predicts ecology-conditioned morphology-frontier transitions, and supports endogenous recovery/discovery of those morphologies from a shared low-level generative space without architecture labels.

This is **not established**.
