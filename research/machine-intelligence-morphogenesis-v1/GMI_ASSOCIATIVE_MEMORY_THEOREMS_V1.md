# 1. Stored pattern family

Let memory contain `M` binary patterns

\[
\mathcal C=\{c_1,\ldots,c_M\}
\subseteq\{0,1\}^n.
\]

Define minimum Hamming distance

\[
d_{min}
=
\min_{i\ne j}d_H(c_i,c_j).
\]

A cue `y` is generated by corrupting one stored pattern `c_i`.

Content-addressable retrieval chooses a nearest stored pattern under Hamming distance.

---

# 2. Exact error-correction radius

## Theorem AM-1 — nearest-pattern retrieval is exact below half the minimum distance

If cue `y` satisfies

\[
d_H(y,c_i)=t
\]

and

\[
2t<d_{min},
\]

then `c_i` is the unique nearest stored pattern.

### Proof

For any other pattern `c_j`, triangle inequality gives

\[
d_H(y,c_j)
\ge
d_H(c_i,c_j)-d_H(y,c_i)
\ge d_{min}-t>t.
\]

Therefore `c_i` is uniquely nearest. QED.

### GMI consequence

Associative retrieval is justified when target identities are redundantly separated in content space so that corrupted cues remain inside disjoint semantic basins.

The relevant coordinate is not only memory count; it is **pattern separation relative to cue corruption**.

---

# 3. Collision/no-go when corruption balls overlap

Let allowed corruption radius be `t`.

## Theorem AM-2 — exact cue-only retrieval is impossible when two allowed balls intersect

If two stored patterns satisfy

\[
d_H(c_i,c_j)\le2t,
\]

then there exists at least one cue `y` within Hamming distance at most `t` of both patterns.

If both source patterns are legal and no side information is supplied, `y` is semantically ambiguous; no deterministic cue-only decoder can be exact for both worlds.

### Interpretation

The half-distance condition is not merely sufficient. Once corruption neighborhoods overlap, additional authority/context or abstention is required for exact retrieval.

---

# 4. Packing/capacity bound

If the memory must correct every corruption of radius `t`, the Hamming balls of radius `t` around stored patterns must be disjoint.

Let

\[
V(n,t)=\sum_{j=0}^{t}{n\choose j}
\]

be the binary Hamming-ball volume.

## Theorem AM-3 — Hamming packing upper bound

\[
M\,V(n,t)
\le
2^n.
\]

Therefore

\[
M
\le
\frac{2^n}{V(n,t)}.
\]

### GMI interpretation

Robust associative capacity trades directly against corruption radius. More robust basins consume more of the finite content space.

This is a real capability ceiling for exact content-addressable storage at fixed state dimension.

---

# 5. Memory-state information lower bound

Independently of retrieval geometry, identifying one of `M` stored target identities requires at least

\[
\log_2M
\]

bits of semantic identity information in the memory system when all are equally legal/distinguishable.

The Hamming representation spends `n` cue/content bits per pattern but gains corruption tolerance through redundancy/separation.

Thus GMI distinguishes:

```text
identity information
representation redundancy
retrieval computation
robustness radius
```

rather than calling all stored bits equally semantic.

---

# 6. Key-value versus associative memory

## Exact key-value memory

Input carries an external key identifying the record. Arbitrary values require the lookup/table information lower bound.

## Associative memory

Input cue is itself a noisy/partial version of the content. Retrieval succeeds from geometry/redundancy when basins are sufficiently separated.

### Phase intuition

```text
stable external identifiers + exact updates:
    indexed/key-value memory

corrupted content cues + redundant separated patterns:
    associative/content-addressable retrieval

continuous metric local smoothness:
    nearest-neighbor/case memory
```

These are different semantic interfaces even if one implementation can simulate another.

---

# 7. Negative twins

## Dense overlapping patterns

If stored patterns have small pairwise distance relative to corruption, cue-only retrieval becomes ambiguous.

## Exact key supplied

If every query includes a perfect external identifier, associative search can add burden without semantic benefit.

## Novel pattern outside stored basins

Nearest retrieval will still return some memory unless the system has a rejection/novelty threshold. Protected systems therefore need an abstention criterion when out-of-memory cues are legal.

---

# 8. Development/update implications

Adding a new pattern can shrink minimum distance and break previous robustness guarantees even if no old stored bits are directly overwritten.

Thus associative-memory development must verify:

```text
new pattern separation
basin overlap
capacity/packing margin
retrieval threshold
```

This is a retention constraint distinct from parameter interference.

---

# 9. Relationship to Hopfield/energy memories

Hopfield-like systems implement content-addressable basins through an energy/dynamical realization. AM-1--AM-3 describe an architecture-neutral semantic geometry; they do not require Hopfield dynamics.

Energy/attractor implementations are candidate realizations whose basin size, spurious attractors and lifecycle burden must be compared separately.
