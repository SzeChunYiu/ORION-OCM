The legacy V4/V5 modules, measured resource panel, all existing freezes, execution
scripts and historical results are unchanged. A `THEORY_RED` is not deleted or
retrospectively rewritten. The new interpretation and bounded class comparison
are separate outputs. No protected beacon is acquired, and no protected execution
or result is claimed. The old V3 schema patch is excluded as superseded by PR #447.

The source-pinned class optimizer includes V5 nulls ON BOTH SIDES of a comparison:
a null may be a target-class member as well as a rival. Candidate-mode identity
and the null pricing rule are explicit. A caller cannot forge a null discount by
supplying a boolean, nor certify a whole class by supplying a number and claiming
it is a lower bound. Null admissibility still uses the source surrogate, not
actual unseen recall, learning or planning episodes.

unit/exhaustive checks and actual imported legacy modules. The generated CI
receipts, rather than this document, determine whether those commands passed on
a particular commit. Local validation and upstream execution are separate records.
