# 1. Scientific rule

Do not ask whether a candidate looks novel.

Ask:

```text
What object carries sufficient cognition?
What are its native operators?
What information can it preserve cheaply?
How does it develop/update?
What burden law follows?
Can D1-D8 compile it with bounded semantic/resource overhead?
In what ecology should it enter/leave the frontier?
```

If these questions collapse to an existing domain, demote the candidate to kingdom/phylum/substrate status.

# 2. Evidence ladder for domains

```text
DX0 TYPE
    state carrier and native operator law precisely specified

DX1 PARENT MAP
    strongest reductions to D1-D8 implemented or formally analyzed

DX2 NECESSITY
    exact lower bound / separation family or controlled collision

DX3 PHASE LAW
    frozen ecology coordinates predict appearance/disappearance

DX4 NEUTRAL RECOVERY
    low-level grammar recovers the carrier/operator complex without its name

DX5 CROSS-ENCODING REPLICATION
    independent search encodings recover equivalent complex

DX6 REAL TRANSFER
    protected real task family preserves the law

DX7 DOMAIN ADMISSION
    bounded reductions fail at registered burden class and recurrence survives
```

Only DX7 supports a serious new-domain claim.

# 4. Tier B — GMI-generated under-covered domain hypotheses

These candidates are not asserted as literature-novel. They are frozen as **theory-generated hypotheses** before exhaustive parent reduction.

## ND1 — Relational-Constraint / Sheaf Intelligence

Carrier:

A family of local states `{s_i}` defined on overlapping contexts, with restriction/compatibility maps rather than one global state vector.

Schematic object:

\[
Z=(\{s_i\},\{r_{ij}\},\mathcal C),
\]

where `C` specifies which local states can be globally glued.

Native operations:

```text
local inference
restriction
compatibility checking
constraint propagation
gluing
detection/localization of global obstruction
```

Hypothesized niche:

```text
large systems with highly local information and sparse cross-region consistency constraints
frequent local updates
need to identify exactly where global inconsistency originates
```

Why this could differ from ordinary symbolic CSP:

The primary state is the *cover of compatible local semantic sections and their obstruction structure*, not a monolithic formula or assignment search frontier.

Hostile parents:

```text
SAT/CSP/SMT
factor graphs/belief propagation
GNN/message passing
D7 distributed consensus
D2 versioned local memory
```

Key exact target:

Construct families where local updates affect only a bounded overlap cone but any flat global encoding must rewrite/communicate across growing system size. Determine whether this yields a genuine asymptotic/lifecycle separation or simply an implementation choice.

Kill:

`SHEAF_STATE_REDUCES_TO_EXISTING_LOCAL_CONSTRAINT_PARENT_WITH_BOUNDED_BURDEN`

## ND2 — Constructive / Autocatalytic Intelligence

Carrier:

```text
set/population of constructors plus the closure of components they can construct
```

Let `C_t` be constructors and `Reach(C_t)` the computational structures reachable by legal construction sequences.

Native operations:

```text
construct
replicate
assemble
modify constructor
activate/deactivate
recycle
```

Hypothesis:

For some long-lived ecologies, the sufficient developmental state is not one current architecture but the **constructive closure**: what cognitive machinery the system can rapidly manufacture next.

This differs from ordinary morphogenesis if two machines with identical current morphology but different constructor closure have different future protected competence under the same legal continuation.

Hostile parents:

```text
D8 self-rewriting
program synthesis
D5 search
evolutionary populations
chemical reaction networks
compiler systems
```

Exact collision experiment:

Create two systems with identical current input-output/update traces but different constructor sets. Present an unseen regime requiring a component constructible by only one system. If current GMI developmental state does not distinguish them, refine the quotient. Then test whether an ordinary D8 description can encode constructor closure with bounded burden.

Kill:

`CONSTRUCTIVE_CLOSURE_ADDS_NO_NECESSARY_STATE_BEYOND_BOUNDED_D8_DESCRIPTION`

# 5. Domain derivation experiments

## DX-A — reduction matrix

For every candidate `C`, fill an explicit matrix against D1-D8:

```text
state compiler
operator compiler
semantic preservation
precision inflation
memory inflation
execution inflation
update inflation
communication inflation
verification inflation
morphogenesis inflation
```

Blank cells are blocking gaps.

## DX-B — collision construction

For every proposed carrier, construct pairs with:

```text
same present outputs
same ordinary task score
but different legal future response because the candidate carrier preserves a distinction parents discard
```

If no collision can be constructed, domain necessity is weak.

## DX-C — negative twins

Remove the ecological feature predicted to favor the domain:

```text
remove compositional binding -> HDC advantage should shrink
remove lesions/topology change -> self-organizing-field regeneration premium should shrink
remove quantum-native data/oracle structure -> quantum advantage should shrink
remove local-overlap structure -> sheaf candidate should shrink
remove constructor-demand regime changes -> constructive closure should shrink
```
