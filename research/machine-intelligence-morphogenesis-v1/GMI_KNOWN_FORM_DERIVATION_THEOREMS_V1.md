# 1. Linear coefficient state

Consider data `X in R^{n x d}`, targets `y in R^n`, and squared error

\[
L(\theta)=\|y-X\theta\|_2^2.
\]

## Theorem KF-1 — finite sufficient statistics for linear regression

For every `theta`,

\[
L(\theta)
=
y^Ty-2\theta^TX^Ty+\theta^TX^TX\theta.
\]

Therefore the full dataset is unnecessary for evaluating every candidate linear predictor once the statistics

\[
T=(X^TX,X^Ty,y^Ty)
\]

are known. The minimizer, when unique, depends only on `(X^TX,X^Ty)`.

### Derivation consequence

When the obligation is well described by a stable `d`-dimensional linear conditional law and many future queries reuse it, GMI should prefer a coefficient state whose retained developmental burden is `O(d^2)` or lower rather than an `O(nd)` raw exemplar store.

### Negative twin

If labels on `N` distinct keys are arbitrary and independent, no fixed `d << N` linear sufficient state can represent every possible labeling exactly. See KF-2.

### Zero-prior prediction

The property vector is:

```text
compact global coefficient state
shared evaluation across queries
batch/stream sufficient-statistic update
no explicit exemplar retention required for exact in-family prediction
```

This is the property-level derivation of linear regression. Choosing linear rather than nonlinear coefficient families still requires a pre-outcome model-class adequacy test.

# 2. Exemplar / lookup memory

Let there be `N` distinguishable keys and an output alphabet of size `q`.

## Theorem KF-2 — arbitrary volatile lookup requires `N log2(q)` bits

There are

\[
q^N
\]

possible exact key-value maps. Any state representation that can answer every such map exactly must therefore have at least `q^N` distinguishable states, requiring at least

\[
N\log_2 q
\]

bits in the worst case.

A direct table achieves this order exactly up to indexing overhead.

### Derivation consequence

If measured structure gives no compressive relation among keys, exact local update and exact retrieval are required, and values change independently, GMI should derive explicit memory rather than a compact coefficient field.

### Negative twin

If values are generated by a low-dimensional stable law such as `y=theta^T x`, the memory lower bound no longer applies to that restricted obligation family; KF-1 yields compression independent of `N`.

### Core crossover variable

The unresolved empirical quantity is the **compressibility gap** between the minimum shared-law description and explicit record burden.

# 3. Explicit probabilistic belief state

Let the latent hypothesis set be finite, `H={h_1,...,h_m}`. After evidence `e`, write the posterior vector as

\[
p(e)=(P(h_1|e),...,P(h_m|e)).
\]

## Theorem KF-3 — posterior sufficiency for all expected-utility decisions

For any action `a` with utility vector `u_a in R^m`, the posterior expected utility is

\[
EU(a|e)=p(e)^T u_a.
\]

Hence the posterior vector is sufficient for every downstream decision whose consequence depends only on the latent hypothesis and action.

## Theorem KF-4 — distinct posteriors are necessary for the class of all utility decisions

Let `p != q` be two posterior vectors. There exists a binary decision problem for which the Bayes-optimal action under `p` differs from that under `q`.

### Proof

Set `v=p-q` and

\[
c=\frac{p^Tv+q^Tv}{2}.
\]

Define the utility difference between actions `a_1,a_0` by

\[
u_{a_1}-u_{a_0}=v-c\mathbf 1.
\]

Because probability vectors sum to one,

\[
p^T(v-c\mathbf 1)>0,
\qquad
q^T(v-c\mathbf 1)<0,
\]

with difference equal to `||p-q||_2^2`. Thus the preferred action flips. QED.

### Derivation consequence

When multiple latent alternatives remain live and future protected actions depend on calibrated uncertainty, GMI must preserve an uncertainty-bearing belief state rather than only a point estimate.

### Negative twin

If the latent state is fully observed and deterministic, the posterior collapses to a point mass; explicit probabilistic state provides no semantic advantage.

# 4. Minimal recurrent state from history equivalence

Let `h` denote an interaction history. Define

\[
h \sim_F h'
\]

iff every legal future input continuation produces the same protected future output trace/distribution from `h` and `h'`.

## Theorem KF-5 — minimal exact recurrent state is the future-response quotient

Any exact recurrent realization must assign different internal states to histories in different `~_F` classes. Conversely, the equivalence class `[h]_{~_F}` is itself a sufficient exact recurrent state.

### Proof

If two future-distinguishable histories map to the same internal state, identical future execution from that state cannot produce two different required traces. Conversely, transitioning equivalence classes under the next legal input is well defined by right congruence of future response. QED.

### Derivation consequence

Whenever history matters but the number/description complexity of future-response classes is much smaller than raw history, GMI derives a recurrent/state-machine carrier.

This subsumes finite-state machines and gives the abstract target that RNN/LSTM/SSM implementations approximate.

### Negative twin

For memoryless obligations all histories with the same current observation are equivalent, so persistent recurrent state is unnecessary.

### Remaining gap

Estimating the quotient dimension from finite real data remains open.

# 5. Translation symmetry and convolution-like sharing

Consider a cyclic one-dimensional signal of length `n` and linear maps `A:R^n -> R^n`. Let `P` be the cyclic shift operator.

## Theorem KF-6 — linear translation equivariance implies a circulant operator

`A` is translation equivariant,

\[
AP=PA,
\]

iff `A` is circulant. Therefore an arbitrary equivariant linear map is determined by `n` coefficients rather than `n^2` unconstrained coefficients.

If the obligation additionally has locality width `k`, only `k` kernel coefficients are required.

### Derivation consequence

Exact repeated local symmetry plus locality forces the efficient parameterization toward shared local filters. This is the zero-prior structural derivation of convolution-like computation, not a claim that one specific CNN architecture is unique.

### Negative twin

Break translation symmetry independently across locations. The parameter tying constraint is no longer semantically valid; an exact realization can require independent local coefficients.

### Predictive variable

The missing empirical response law is the amount of burden saved as symmetry degrades continuously rather than exactly.

# 6. Variable dependency and dynamic routing

For each input `x`, let `E(x)` be the set of dependency edges required for exact processing.

## Theorem KF-7 — fixed safe routing must contain the dependency union

Any fixed routing graph valid for all registered inputs must contain

\[
E_* \supseteq \bigcup_x E(x).
\]

An ideal dynamic router needs only `E(x)` on input `x`.

Hence the structural routing opportunity is lower-bounded by the gap

\[
\Delta_{route}
=
\left|\bigcup_x E(x)\right|
-
\mathbb E_x|E(x)|.
\]

### Derivation consequence

When `Delta_route` is large and routing overhead is lower than avoided edge-computation burden, GMI predicts content-dependent routing. Attention is one realization.

### Negative twin

If `E(x)=E_0` for every input, `Delta_route=0`; dynamic routing has no structural edge-count advantage over the optimal fixed graph.

### Remaining gap

Real attention selection requires a pre-outcome estimator of dependency variability plus optimization/routing-error costs.

# 7. Conditional specialization and expert routing

Let inputs have a latent mode `j in {1,...,m}` with probability `p_j`. Suppose a set of mode-specialized exact computations exists with serve costs `c_j` and an accurate router costs `c_r`.

## Proposition KF-8 — routed specialization beats execute-all portfolio when

\[
c_r+\sum_j p_j c_j < \sum_j c_j.
\]

The inequality is exact for the registered execute-all parent.

### Derivation consequence

Heterogeneous sparse demand creates a direct conditional-computation incentive.

### Important limitation

This does **not** prove MoE superiority over an optimally compressed dense shared model. The strong zero-prior MoE derivation therefore still requires a lower bound showing that incompatible mode functions cannot be represented/executed at comparable cost in the best shared parent.

### Negative twin

Homogeneous modes or dominant routing/communication cost erase the conditional-computation advantage.

# 8. Low-rank residual adaptation

Let a reusable linear map be `W` and a target adaptation require exact update `Delta W`.

An adapter of width/rank `r` represents

\[
\Delta W=BA,
\]

with `B in R^{d_out x r}`, `A in R^{r x d_in}`.

## Theorem KF-9 — exact adapter rank threshold

An exact factorization exists iff

\[
r \ge \operatorname{rank}(\Delta W).
\]

### Proof

Every product `BA` has rank at most `r`, giving necessity. The rank factorization/SVD of `Delta W` gives sufficiency at `r=rank(Delta W)`. QED.

### Derivation consequence

If the target-specific residual is low rank relative to the reusable core, GMI predicts localized low-rank adaptation rather than full replacement.

### Negative twin

A full-rank target update with slowly decaying singular spectrum removes the exact low-rank advantage.

### Remaining gap

For nonlinear networks the relevant residual rank is representation- and layer-dependent; predicting it pre-outcome is open.

# 9. Residual external memory / retrieval augmentation

Let `S_P` be a reusable predictive quotient and `S_O` a target quotient.

## Theorem KF-10 — exact residual state requirement

For predictive class `p`, let

\[
m(p)=|\{S_O(h):S_P(h)=p\}|.
\]

Any exact residual augmentation reconstructing target state from `(S_P,R)` requires

\[
|R|\ge \max_p m(p),
\]

and expected residual coding burden is lower-bounded by `H(S_O|S_P)` under ordinary coding assumptions.

This is the existing predictive residual quotient theorem reused as a zero-prior derivation law.

### Derivation consequence

A stable broad predictor plus small, volatile/provenance-sensitive residual implies an explicit residual state/memory is potentially cheaper than rewriting the broad predictor.

### Negative twin

When `H(S_O|S_P)=0`, no target residual is information-theoretically required.

### Remaining gap

Estimating the real predictive-target residual before choosing RAG/adapters/external authority storage remains blocking.

# 10. Ensemble aggregation

Let `m` unbiased estimators have identical error variance `sigma^2` and common pairwise correlation `rho`.

For their arithmetic mean,

## Theorem KF-11 — ensemble variance law

\[
\operatorname{Var}(\bar e)
=
\sigma^2\left(\rho+\frac{1-\rho}{m}\right).
\]

### Derivation consequence

When errors are sufficiently decorrelated and added serving/development cost is acceptable, multiple realizations plus aggregation reduce protected variance.

### Negative twin

If `rho=1`, averaging gives no variance reduction. If serve cost dominates, the lower risk may not justify the portfolio.

# 11. Search versus compilation/amortization

Suppose a repeated query family can be solved online at cost `c_search` per query. Alternatively, one may pay one-time compilation/development cost `C_compile` and then serve at `c_compiled<c_search`.

## Theorem KF-12 — compilation crossover

For expected reuse count `R`, compilation is cheaper iff

\[
R>
\frac{C_{compile}}{c_{search}-c_{compiled}}.
\]

### Derivation consequence

Low reuse or rapidly changing obligations favor online search/frontier state. High reuse and stable semantics favor compiled coefficient/program/cache/policy state.

### Negative twin

If the target changes before reuse amortizes the compiler, search remains favored.

This theorem is a general bridge between search, planning, policy compilation, caching and self-compiling species.

# 12. Autoregressive factorization

For any finite sequence distribution with positive-probability prefixes,

## Theorem KF-13 — chain-rule factorization

\[
P(x_1,...,x_T)
=
\prod_{t=1}^T P(x_t|x_{<t}).
\]

Thus next-step conditional prediction is an exact universal factorization of a sequence law.

### Derivation consequence

When sequential conditional serving/training is legal, autoregressive prediction is always representationally sufficient.

### Important limitation

The chain rule does **not** establish that autoregressive realization is resource-optimal relative to diffusion, flow, latent-variable or bidirectional factorizations. The generative-family selection law remains open.

# 13. Bayesian/linear/recurrent/symmetry derivations are not architecture uniqueness theorems

The theorems above predict implementation-invariant properties, not historical source code.

Examples:

```text
KF-1 predicts compact coefficient state, not specifically a software package called linear regression.
KF-5 predicts recursively updateable sufficient state, not specifically LSTM gates.
KF-6 predicts symmetry sharing/local equivariance, not one canonical CNN stack.
KF-7 predicts dynamic dependency routing, not uniquely softmax attention.
KF-9 predicts low-rank residual adaptation, not uniquely LoRA syntax.
```

This is deliberate. Zero-prior GMI succeeds when neutral search recovers the predicted property vector and known historical families lie in that equivalence neighborhood.
