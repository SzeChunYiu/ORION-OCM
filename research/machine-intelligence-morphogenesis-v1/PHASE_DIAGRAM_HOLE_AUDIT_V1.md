# Phase-diagram hole audit v1

Status: **negative parent-subtraction result / Q4 steering.** No new morphology is claimed.

Refs #377, #233, #373.

## Question

Before launching neutral morphology search, is there a defensible region of desired developmental properties that is not already occupied, at least conceptually, by known morphology families or their strong hybrids?

A "hole" must be more than a benchmark where one system is weak. It should be a prospectively specified combination of structural/developmental properties for which the registered known-parent frontier lacks a faithful representative.

## Candidate hole A — statistical generalization + explicit exact reasoning + continual retention

Tempting story:

```text
neural statistical learner
+ exact symbolic reasoning
+ stable continual learning
```

Parent collision:

- neuro-symbolic continual-learning systems explicitly target sequential neural-symbolic tasks and catastrophic forgetting;
- broad neuro-symbolic architectures already combine neural perception and symbolic reasoning;
- probabilistic neuro-symbolic systems add uncertainty and exact/structured constraints;
- meta-learned neural systems can display systematic compositional generalization without hand-supplied internal symbols.

Disposition:

```text
NOT_A_CLEAN_HOLE__STRONG_NEUROSYMBOLIC_CONTINUAL_PARENTS
```

Residual may remain in verification/revision economics, but not as a qualitatively undiscovered form.

## Candidate hole B — self-growing / self-reconfiguring architecture during learning

Tempting story:

```text
machine grows/prunes/reconfigures its own topology online
```

Parent collision:

- NEAT/HyperNEAT and developmental encodings evolve structure;
- neural cellular automata provide local-rule developmental morphogenesis;
- modern growing neural architectures add/prune capacity during learning;
- evolutionary developmental AI explicitly studies coupled evolution, learning and development.

Disposition:

```text
NOT_A_CLEAN_HOLE__DEVELOPMENTAL_NEURAL_EVOLUTION_PARENTS
```

## Candidate hole C — learner invents its own discrete symbolic/program language

Tempting story:

```text
continuous learner -> invents symbolic primitives/language -> composes programs
```

Parent collision:

- program induction/library learning already invent abstractions;
- ICLR-2026 Neural Language Interpreter learns a discrete symbolic-like programming vocabulary end-to-end with a differentiable executor;
- DreamCoder/Stitch/program-synthesis parents already grow explicit abstraction libraries.

Disposition:

```text
NOT_A_CLEAN_HOLE__PROGRAM_INDUCTION_AND_NEURAL_LANGUAGE_PARENTS
```

## Candidate hole D — explicit skills that evolve/refactor while preserving mature competence

Tempting story:

```text
executable skill network
+ fault localization
+ maturity-dependent plasticity
+ rollback/refactoring
```

Parent collision:

- Programmatic Skill Networks (COLM 2026) explicitly evolve executable symbolic skill networks with fault localization, maturity-aware update gating and structural refactoring;
- continual program/library learning and agent skill-library systems cover nearby territory.

Disposition:

```text
NOT_A_CLEAN_HOLE__PROGRAMMATIC_SKILL_PARENT
```

## Candidate hole E — hybrid distributed/vector/neural/event-driven cognition

Tempting stories:

```text
HDC/VSA + spiking
neural + symbolic + probabilistic
reservoir/liquid + explicit reasoning
```

Parent collision:

- HDC/VSA already supplies distributed algebraic symbolic representations;
- SNN/HDC hybrid training exists;
- reservoir/liquid systems cover dynamic continuous-time/fixed-dynamics regimes;
- probabilistic neuro-symbolic and broad neuro-symbolic systems already mix several of these mechanisms.

Disposition:

```text
NOT_A_CLEAN_HOLE__HYBRID_PARENTS_EXIST
```

## Candidate hole F — dynamically replace the learning-model family itself

Tempting story:

```text
system decides during life to move from one learner/morphology family to another
```

Parent collision:

- lifelong self-adaptive systems explicitly distinguish parametric from structural changes and can replace one learning model type with another;
- AutoML/hyper-heuristic/algorithm-selection systems can adapt portfolios/configurations;
- self-improvement/program-evolution systems can replace components/algorithms.

Disposition:

```text
CONCEPT_PARENT_OWNED__GENERAL_PHASE_LAW_RESIDUAL_OPEN
```

What remains open is not the existence of dynamic model replacement; it is whether a cross-paradigm law can *predict* when such a transition is beneficial and induce it from a common developmental substrate without a human-supplied model portfolio.

## Candidate hole G — OCM-style verified developmental reconfiguration

Candidate property bundle:

```text
statistical/approximate proposal power
+ explicit verified commitments
+ local causal revision/provenance
+ continual plasticity
+ morphology/factorization change
+ full lifetime resource governance
```

No single parent in this audit is known to satisfy this entire bundle under one matched experimental contract.

However, this is **not enough to call it an unknown morphology**:

1. a composition of neural/probabilistic/programmatic/verification/database parents may supply every function;
2. OCM itself is a human-designed candidate bundle, not a theory-predicted missing form;
3. integration novelty is weaker than a new developmental-equivalence class;
4. the strongest parent product has not been exhaustively reconstructed at this level.

Disposition:

```text
POSSIBLE_INTEGRATION_RESIDUAL__NOT_NEW_MORPHOLOGY
```

## Current Q4 conclusion

The first serious hole audit finds **no cleanly defensible unknown morphology target** from the obvious property combinations.

This is useful negative evidence.

```text
NO_CLEAN_PHASE_DIAGRAM_HOLE_IDENTIFIED_V1
UNKNOWN_MORPHOLOGY_SEARCH_NOT_AUTHORIZED
```

## What could create a real hole

A hole should emerge from quantitative theory, not brainstorming.

Required sequence:

```text
1. establish structure -> developmental-geometry predictors for known families;
2. map observed/predicted known-family Pareto frontier across ecology coordinates;
3. identify a region where every registered known parent is predicted to be dominated or infeasible;
4. derive the missing morphology properties without naming an architecture;
5. freeze those properties and the hole before morphology search;
6. only then search a neutral low-level space.
```

Until steps 1–3 exist, "invent a new form of intelligence" is premature.
