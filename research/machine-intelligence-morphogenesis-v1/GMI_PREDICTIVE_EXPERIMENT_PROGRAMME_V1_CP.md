# GMI predictive experiment programme v1

Status date: 2026-09-11.

Status: **PROSPECTIVE PROGRAMME FOR TURNING GMI FROM FORMAL SYNTHESIS INTO A PREDICTIVE EMPIRICAL THEORY.**

Primary target: test `COGNITIVE_POLYPHENISM_PREDICTION_V1.md` and, more generally, the GMI map

\[
\text{pre-outcome obligation + realization structure/resources}
\rightarrow
\text{future developmental geometry/frontier}.
\]

No protected outcome may be used to rewrite the primary prediction or thresholds below. Failed experiments remain evidence.

---

# 0. Cross-disciplinary hostile panel

Every stage is reviewed through five roles.

## A. Formal / learning-theory reviewer

Checks equivalence, asymptotics, identifiability, theorem assumptions and whether the measured quantity really follows from the registered GMI object.

## B. Continual-learning / unlearning reviewer

Checks retention, plasticity, negative transfer, update locality, exact/approximate forgetting and whether a claimed local revision is simply adapter isolation or retrieval.

## C. Systems / incremental-computation reviewer

Checks materialized-view, self-adjusting-computation, provenance, cache invalidation, compilation and hardware parents. This reviewer has authority to terminate novelty as `SYSTEMS_PARENT_SUFFICIENT`.

## D. Morphogenesis / search reviewer

Checks neutral grammar, search bias, NAS/evolution/AutoML parents, rejected-candidate accounting and whether the search space smuggles the predicted answer into its primitives.

## E. Scientific-method / novelty reviewer

Checks prospective freeze, comparator completeness, disjoint validation, family-held-out tests, independent replication and claim ceilings.

A positive result needs all five reviews to remain nonterminal.

# 1. E0 — exact CP phase calibration

Goal: verify the mathematical pressure that motivates Cognitive Polyphenism before touching learned systems.

## Registered toy process

- `k` recurrent regimes;
- regime queries iid uniform;
- authoritative semantic update before each query with probability `q`;
- a derived phenotype becomes stale after a semantic update;
- lazy CP recompiles a stale phenotype only when that regime is next queried;
- eager hybrid updates/synchronizes all maintained phenotypes after every semantic update;
- fixed specialist pays a registered cross-regime mismatch cost.

Expected stale probability for one phenotype:

\[
\sigma(k,q)=\frac{q}{1/k+q-q/k}.
\]

Registered costs:

\[
C_{CP}=s_P+qu_0+c\sigma(k,q),
\]

\[
C_{eager}=s_H+qke,
\]

and fixed-specialist cost from the prospectively declared mismatch matrix.

## E0 acceptance

The exact calculator and Monte-Carlo simulation must agree within numerical tolerance on every registered cell, including positive and negative twins.

E0 can establish only:

```text
CP_ECONOMIC_PHASE_PRESSURE_EXACT_AT_TOY_SCOPE
```

not a new intelligence morphology.

# 2. E1 — frozen parent-frontier hole assay

Goal: determine whether the predicted property vector is actually missing from strong known parent products.

No morphology search occurs in E1.

## 2.1 Shared semantic world

Construct finite generative worlds whose underlying semantic objects are reused across heterogeneous obligations. Each world contains entities, relations, uncertain observations and executable transformations. The same latent object can be queried under four validation/resource regimes:

1. **STAT** — noisy statistical prediction; approximation allowed; dense throughput rewarded;
2. **EXACT** — exact compositional query/constraint solving; any false positive fails;
3. **PROB** — calibrated uncertainty / selective action under observation cost;
4. **EXEC** — construct an executable transformation that must pass hidden tests.

Development episodes add, revise and revoke latent relations/operators shared across these regimes.

The world generator, train/development split, protected seeds and meters are frozen before parent execution.

## 2.2 Mandatory parent implementations

At minimum:

```text
dense neural / differentiable specialist
symbolic or programmatic exact specialist
probabilistic specialist
retrieval/memory-based adaptation parent
modular/adaptor continual-learning parent
fixed MoE or router-based modular parent
fixed neuro-symbolic / MRKL-style hybrid
algorithm-selection/model-switching portfolio
eager multi-phenotype hybrid
self-adjusting/materialized-view inspired parent where faithful
```

A parent may be stronger than these and must be admitted if identified before protected outcomes.

## 2.3 CP prototype

The CP prototype is allowed only the frozen abstract organization:

```text
shared authoritative developmental state
regime-conditioned phenotype materialization
version/dependency tracking
lazy invalidation/rebuild
```

The prototype may not receive protected regime labels unavailable to parent controls, extra supervision or a hand-written solution to a protected world.

## 2.4 Primary requirements

A candidate parent-frontier hole is supported only if, on disjoint protected worlds, one registered CP implementation simultaneously achieves:

```text
R1 semantic/verifier success threshold in all four regimes
R2 no more than 1 percentage point loss versus the best STAT specialist on statistical quality
R3 exact verifier pass = 100% on admitted EXACT/EXEC outputs; abstentions retained in denominator
R4 lower total lifecycle resource vector than every parent that satisfies R1-R3 on at least one registered nondominated coordinate without being worse on all others
R5 after a local semantic revision/revocation, collateral change outside the registered dependency closure remains below the frozen tolerance
R6 cross-regime history produces pre-solution K1 benefit on fresh targets in at least two regime pairs
```

Do not scalarize these into one score for the primary decision.

## 2.5 Negative twins

At least these twins are mandatory:

```text
TWIN-A low regime diversity: only STAT + one exact regime
TWIN-B low semantic overlap: regimes generated from independent latent worlds
TWIN-C high phenotype compile cost / short reuse horizon
```

The CP advantage must shrink or reverse in at least two twins. Otherwise the phase prediction is too flexible.

## E1 terminal

Positive:

```text
PARENT_FRONTIER_HOLE_SUPPORTED_FOR_CP_PROPERTY_VECTOR_AT_SYNTHETIC_SCOPE
```

Negative examples:

```text
FIXED_HYBRID_PARENT_SUFFICIENT
MODULAR_MEMORY_PARENT_SUFFICIENT
SELF_ADJUSTING_COMPUTATION_PARENT_SUFFICIENT
CP_PROPERTY_VECTOR_NOT_PARETO_DISTINCT
CP_PHASE_REVERSAL_NOT_OBSERVED
```

Only a positive E1 unlocks countable neutral search.

# 3. E2 — prospective structure -> developmental-geometry law

Goal: test whether GMI predicts **how much** developmental advantage will occur before protected target outcomes.

For every parent and CP candidate, compute only pre-target quantities such as:

```text
semantic overlap / reuse estimate
effective regime count / entropy
update/revocation rate
active-phenotype fraction
compile/build cost estimates
validation proposal surprisal / first-hit burden
dependency closure size
verification cost
measured family response curves from development worlds only
```

Freeze a compact predictor on development worlds.

Primary protected targets:

```text
future K1 proposal-geometry gain
verified acquisition burden
revision burden
frontier membership
```

## Required tests

1. world-held-out within-family prediction;
2. family-held-out prediction: fit without one realization family, predict it;
3. regime-held-out prediction;
4. negative-twin direction prediction;
5. comparison against the product of family-native predictors.

E2 is the key test for GMI as a **predictive theory**, rather than only a morphology proposal.

Positive terminal requires one frozen predictor whose errors are materially below the strongest parent-product baseline on at least two materially different realization families.

# 4. E3 — neutral morphology recovery

Goal: test whether the theory-predicted CP properties are recovered without architecture labels.

E3 is allowed only after positive E1.

## 4.1 Search grammar

Allowed primitive concepts must remain below known architecture labels. Candidate primitives may include:

```text
typed state cells
local transformations
composition edges
conditional activation
copy/create/delete of generic subgraphs
mutable vs persistent state
bounded local memory
message passing
generic update operations
```

Forbidden named macros include:

```text
NEURON
ATTENTION
PRODUCTION_RULE
BAYES_UPDATE
PROGRAM_INTERPRETER
RETRIEVER
SEMANTIC_CORE
COMPILER
PHENOTYPE_CACHE
OCM_ASSET
```

If caching/invalidation is an explicit primitive, the search encoding is considered biased toward CP and cannot count as the primary neutral recovery.

## 4.2 Frozen CP signature

Before search, score discovered systems using architecture-label-free observables:

```text
S1 concentration of cross-regime retained information in persistent shared substructure
S2 regime-conditioned turnover of derived execution substructure
S3 update work on inactive-regime state grows sublinearly with registered regime count
S4 fresh use after semantic change triggers selective new construction/work
S5 information acquired through one regime measurably changes pre-solution behavior in another
S6 at least two regimes have materially different execution graphs after simplification
S7 stale derived state cannot pass the registered verifier/authority boundary
```

Primary recovery bar:

```text
>= 6 / 8 independent search seeds produce a Pareto survivor satisfying S1-S7
AND
>= 5 / 8 do so under a second materially different search encoding
AND
negative-twin searches show a lower CP-signature rate
```

These numbers are frozen before protected search.

## 4.3 Strong search parents

```text
random search
ordinary multi-objective evolution
QD / novelty search
NAS-style graph search
program evolution
Bayesian optimization where feasible
```

All attempted candidates count in search-resource accounting.

E3 positive terminal:

```text
THEORY_PREDICTED_CP_SIGNATURE_RECOVERED_FROM_NEUTRAL_SEARCH_AT_SYNTHETIC_SCOPE
```

This reaches `U4` in `UNKNOWN_MORPHOLOGY_PROGRAMME_V1.md`, not `NEW_FORM_OF_INTELLIGENCE`.

# 5. E4 — real heterogeneous verifier benchmark

Goal: leave synthetic worlds without changing GMI definitions.

## 5.1 Shared concept cohort

Build a cohort of concepts with three or more independently checkable views of the **same underlying semantic object**, for example algorithms/discrete structures that admit:

```text
natural-language specification / evidence-grounded explanation
execution-verified implementation
formal theorem / Lean property
probabilistic or statistical observation variant where meaningful
```

Concept identity and cross-view mapping are frozen before system development.

## 5.2 No hidden core forks

One persistent developmental machine must be used. Domain-specific executors/verifiers are legal tools, but separate independently trained task cores cannot be silently counted as one intelligence.

## 5.3 Measurements

For every concept episode retain:

```text
pre-solution proposal distributions/ranks
which persistent state changed
phenotype construction/compile receipts
verifier calls and failures
serving cost
revision/revocation cost
retention on old concepts
cross-view transfer
abstention/refusal
human intervention
```

## E4 primary prediction

A CP-like system should use more distinct execution phenotypes as validation regimes become more heterogeneous **while preserving a smaller shared developmental state than an eager independent-specialist portfolio**.

Its advantage should correlate prospectively with measured semantic overlap and regime heterogeneity, not with architecture labels alone.

# 9. Programme-level GMI success criteria

GMI becomes meaningfully predictive only if the evidence stack reaches all of the following:

```text
G1 one pre-outcome architecture-neutral predictor forecasts future developmental geometry within family
G2 the same predictor transfers to a materially different realization family
G3 it predicts at least one frontier/ranking reversal under a negative twin
G4 a morphology property vector is frozen before search
G5 neutral search recovers the predicted property vector more often in the positive region than negative twins
G6 the recovered candidate survives strongest parent-product reduction at the registered resource/developmental scope
```

If G1-G3 fail, GMI remains a formal metrology/synthesis theory.

If G1-G5 pass but G6 fails, GMI is predictive but the predicted morphology was already parent-owned.

If G1-G6 pass and replicate, Track B has the first serious basis for claiming a theory-predicted machine-intelligence form at registered scope.
