# 3. SXP-01 — Residual Quotient scaling

Targets: RQM, CRWM.

Construct finite latent worlds where predictive quotient `S_P` and target quotient `S_O` are exactly known.

Independently vary:

```text
predictive state count
maximum target multiplicity inside predictive fibers
conditional entropy H(S_O|S_P)
residual volatility
target reuse horizon
```

Arms:

```text
full retraining neural
frozen predictor + dense adapter
frozen predictor + retrieval
frozen predictor + explicit minimal residual code
neuro-symbolic residual
oracle quotient realization
```

Primary predictions:

1. minimum exact residual cardinality tracks `max_p m(p)`;
2. average residual coding burden tracks conditional residual information;
3. when residual volatility rises but predictive core remains stable, residual augmentation gains lifecycle frontier share relative to full retraining;
4. when residual -> 0, residual machinery becomes dominated.

Kill:

```text
RESIDUAL_BURDEN_DOES_NOT_PREDICT_AUGMENTATION_REQUIREMENT
```

# 21. Species law benchmark

The strongest biosphere test asks whether GMI can predict **which species appears** from ecology coordinates before search.

For each protected ecology `e`, freeze a distribution

\[
\hat p(\Sigma\mid \Xi_{obl}(e),P(e),H_{dev}).
\]

Then run neutral search and compare predicted vs recovered phenotype/mechanism distribution.

Baselines:

```text
constant most-common species
architecture-label prior
nearest-neighbor ecology
black-box flexible predictor using same D information
parent-domain hand rules
```

Report:

```text
proper scoring rule / log score
calibration
mechanism-wise precision/recall
frontier membership prediction
held-family generalization
substrate repricing accuracy
```

A morphology theory that only explains the recovered species after the run fails the predictive target.
