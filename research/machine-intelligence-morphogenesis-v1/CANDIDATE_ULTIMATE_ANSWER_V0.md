# Candidate ultimate answer v0 — what Track B can defend now

Status: **working scientific synthesis, not a final theorem.** Replace rather than defend when stronger parent reconstruction or evidence contradicts it.

## The question

Is there a general form of machine intelligence built from a minimal cognitive unit/basis, from which neural, symbolic and other intelligence forms can arise, and can that theory predict forms not yet discovered?

## Current best answer

### 1. A unique metaphysical “cognitive atom” is not currently supported

The evidence and parent mathematics favor a weaker but more defensible object:

```text
an equivalence class of small adaptive generating bases
```

rather than one privileged atom.

A useful basis must expose, at minimum in some equivalent form:

```text
state / memory
interaction interface
state transformation
composition
experience-dependent update
resource semantics
```

but these fields are provisional. Generic state-machine, coalgebra, learner/lens and program formalisms already own much of this structure. A Track-B basis earns significance only if it supplies nontrivial resource/developmental predictions beyond universal computation.

Current OCM `u2` is therefore **not** the fundamental unit. It is better interpreted as a higher-level Cognitive Asset Contract whose fields are useful for explicit governed cognition.

### 2. Known forms of machine intelligence are better viewed as morphologies of adaptive computation

A morphology can be represented provisionally as:

```text
M = (representation/state organization,
     topology/composition,
     mutable configuration,
     control/execution,
     learning/update law,
     interface)
```

Different known forms emphasize different regions of this design space:

- **neural / differentiable:** distributed parametric state, dense differentiable transforms, gradient/evolution/plasticity updates;
- **symbolic / production:** explicit discrete state, condition-action/rewrite structure, agenda/control and rule/chunk updates;
- **probabilistic / generative-program:** distributions/generative structure, conditioning/inference and belief/posterior update;
- **programmatic / synthesis:** executable compositional programs, search/synthesis/library growth;
- **reservoir/dynamical:** rich fixed or slowly adapted dynamics plus cheaper trained/readout structure;
- **vector-symbolic / HDC:** high-dimensional distributed representations plus algebraic binding/superposition;
- **developmental/cellular:** repeated local rules generate global structure and can adapt morphology;
- **hybrid:** coupled non-equivalent forms behind explicit interfaces.

These are not assumed to be the only forms.

### 3. Morphogenesis and learning are different levels

Use two maps:

```text
Gamma(B, E, R, V, H) -> morphology/frontier distribution
U(M, experience)      -> updated morphology
```

`Gamma` answers why a form of intelligence should arise under an ecology/resource/verifier regime.

`U` answers how an already-existing form learns/develops.

This distinction is necessary because a neural network, symbolic system or probabilistic program can all be developmental.

### 4. The likely general law is not “one architecture wins”; it is a phase law over developmental frontiers

For morphology `M`, ecology `E`, horizon `H`, define the raw developmental frontier:

```text
F_M(E,H) = Pareto{ capability Q, lifetime resource vector B }
```

A morphology is favored only relative to an ecology and resource regime. No-Free-Lunch and speedup results rule against unrestricted universal dominance claims.

The desired theory is therefore a prospective map:

```text
(E, resources, verification, horizon)
    -> nondominated morphology family / families
```

not a scalar ranking of “intelligence”.

### 5. Why neural morphology often dominates current AI is plausibly a phase-region explanation

The strongest current explanatory factors include:

```text
differentiable credit assignment
distributed/shared representation
massive train-once / reuse-many amortization
empirical scaling with model/data/compute
hardware/software co-design for dense linear algebra
```

These make neural systems extremely favorable when data are abundant, objectives are sufficiently smooth/informative, reuse horizons are large, and accelerator economics dominate.

Known counter-pressures include:

```text
plasticity loss / forgetting over long streams
retraining or adaptation cost under regime change
exact verification / local revision requirements
strong provenance / authority requirements
sparse algorithmic/compositional structure
expensive interactions or observations
```

These do **not** imply symbolic/OCM victory. They are candidate coordinates of morphology phase boundaries.

### 6. The first exact Track-B results support developmental morphology as a meaningful distinction, but not a unique basis

Executed finite calibrations show:

```text
current behavior equivalence != developmental equivalence
```

and the one-bit adaptive census yields thousands of distinct developmental classes despite only four current-behavior classes.

However, its primitive-basis structure collapses to mature Boolean functional-completeness mathematics. Therefore the Boolean route is calibration, not a new intelligence theory.

A second bounded result shows one small generic microbasis can compile tiny neural-like, symbolic-rule, evidence-accumulator and programmatic behavior+update targets without architecture-labelled primitives. This is a D1 common-representation result only; a generic program algebra is the strongest mundane explanation.

### 7. A genuinely new form of machine intelligence should be predicted from a phase-diagram hole, not declared from structural novelty

The preferred discovery route is:

```text
known parent frontier
-> theoretically predicted unmet combination of properties
-> freeze required phenotype before search
-> search neutral low-level basis/grammar
-> reduce candidate against all applicable parent morphologies
-> disjoint ecology replication
-> independent search/implementation where feasible
```

A strange graph or new name is not a new intelligence form.

### 8. The deepest later question is meta-morphogenesis

If `Gamma` itself can improve from experience over fresh ecology families:

```text
Gamma_g -> Gamma_(g+1)
```

then development has moved from improving one machine to improving the process that generates/selects machine-intelligence forms.

This is a plausible higher-order interpretation of open-ended machine development / RSI, but it is far beyond current evidence.

# What would make this an actual answer rather than a framework?

The following obligations remain mandatory.

## A. Fundamental-basis obligation

Find either:

```text
ONE_MINIMAL_BASIS_AT_SCOPE
```

or more plausibly:

```text
MULTIPLE_EQUIVALENT_MINIMAL_BASES
```

under compensation-aware, resource-bounded tests that survive state-machine/program/learner parent reduction.

## B. Same-basis derivation obligation

From the **same frozen basis**, derive nontrivial tiny representatives of at least:

```text
neural/differentiable
symbolic/production
probabilistic/generative
programmatic/library-learning
```

including their update laws, with bounded cost and no architecture-labelled primitive.

Then scale beyond toy analogues.

## C. Developmental-acquisition obligation

Do not hand-compile the architecture. Starting from the same neutral basis, let experience/search acquire the target morphology without receiving its class label.

This is D2 and is substantially stronger than current results.

## D. Phase-law obligation

Before architecture search, predict at least one ecology/resource transition where the nondominated morphology frontier should change.

Then verify prospectively on a disjoint ecology.

## E. Unknown-form obligation

Predict a phase-diagram hole not occupied by strongest known parents, freeze its required developmental phenotype, and recover a candidate that remains non-equivalent to every applicable registered parent.

## F. External/independent obligation

Repeat the key phase/morphology result using a disjoint implementation/operator/ecology where feasible.
