# 1. Correction target

V0 was intentionally provisional and already listed signature collision, architecture leakage and post-outcome measurement as falsifiers.

The first predictive-morphology cycle exposed a deeper requirement:

> obligation demand, physical/resource context and morphology response must be different scientific types.

V1 therefore makes four corrections.

```text
1. pi leaves the obligation signature and becomes realization context P.
2. delta is split into query/composition and update/invalidation geometry.
3. gamma and lambda are restricted to obligation-side contracts; morphology utilization/interference moves to R_M.
4. lineage/coexistence demand beta_lin is added so version need is not inferred from drift nu alone.
```

V1 also treats effective reuse `eta` as a potentially derived statistic rather than assuming it is independent of drift and use intensity.

# 2. Typed objects

For registered obligation

\[
\Omega=(\mathcal E,D,J,V,C,H,\mathcal R),
\]

define an obligation-side measurement object

\[
\boxed{
\Xi_{obl}^{(1)}(\Omega)
=
(\sigma,\Delta_Q,\Delta_U,\gamma_F,\nu,\chi_V,\rho_{use},\lambda_R,\beta_{lin})
}
\]

where several entries are structured objects, not assumed scalars.

Define separately the exogenous realization context

\[
\boxed{
P=(\pi,\mathcal H,B_{build},B_{serve},B_{update},B_{search},\ldots)
}
\]

where:

- `pi` is the raw resource valuation/price vector when scalarization is legal;
- `H`/substrate terms describe hardware/physical constraints;
- `B_*` are relevant resource ceilings.

For morphology `M`, the realization response remains morphology-side:

\[
\mathcal R_M[\Xi_{obl,0:t}^{(1)},P_{0:t},Z_{M,0}].
\]

The same `Xi_obl` may yield different outcomes under different `P` or different morphology responses.

# 3. Coordinate admission rule

A quantity may enter `Xi_obl` only if all of the following hold at the registered scope.

```text
X1  It is definable from Omega/ecology/protocol/verifier/constitution before protected target outcomes.
X2  Its definition does not refer to architecture family identity.
X3  Its definition does not refer to morphology-internal parameters, modules or learned representations unless those are themselves fixed parts of the external obligation.
X4  Its measurement procedure and uncertainty can be frozen prospectively.
X5  The same semantic meaning can be used in every claimed morphology family.
```

Failure of X1-X5 is not repaired by renaming a response feature as “demand.”

Terminal:

```text
DEMAND_RESPONSE_TYPE_LEAKAGE
```

# 4. `sigma` — semantic developmental distinction burden

Question:

> How much future-relevant semantic state must an admissible realization preserve under the registered legal intervention/development class?

Preferred exact definitions continue to use the semantic developmental quotient where available.

Examples:

```text
log2 exact quotient-state count
minimal exact automaton state count
minimal sufficient predictive/developmental state dimension under a registered parent model
```

Approximate forms require a frozen distortion/admissibility contract.

## Measurement status

`DIRECT/EXACT` when the quotient is exhaustively computable.

`MODEL-IDENTIFIED` when a parent model provides an identifiable sufficient-state representation under explicit assumptions.

`UNIDENTIFIED` when only a latent “complexity” intuition exists.

## Forbidden proxy

```text
parameter count of candidate M
```

Parameter count is realization-side, not semantic demand.

# 5. `Delta_Q` — query/composition geometry

Question:

> Which semantic distinctions must be jointly accessed/composed by the serving workload?

This is not the same as update locality.

Represent prospectively by a query hypergraph/distribution or another registered structured object.

Candidate exact summaries:

```text
distribution of semantic query-scope size
expected number/fraction of factors jointly required
separator/cut profile under query weights
query hypergraph treewidth-like summaries
cross-boundary composition frequency
conditional-independence structure relevant to serving
```

No single scalar is presumed sufficient.

## Key hostile

Hold update cones fixed while changing queries from local to global.

If factor granularity changes, `Delta_Q` was necessary information.

# 6. `Delta_U` — intervention/update consequence geometry

Question:

> When legal evidence/source/semantic state changes, which future semantic consequences truly become invalid or require recomputation?

Candidate exact summaries:

```text
descendant-closure distribution
intervention support size
affected semantic-state fraction
separator profile under update weights
true dependency cone size
```

`Delta_U` is obligation-side only when measured from the semantic/ecological dependency contract, not from the update blast radius of a chosen implementation.

Morphology update blast radius is an outcome/response and is compared against `Delta_U`.

# 8. `nu` — invalidation/drift process

Question:

> How does the registered semantic/ecological state become invalid, revised or distributionally obsolete over development time?

Prefer a process/hazard description over a single average when nonstationarity matters.

Candidate components:

```text
hazard of semantic invalidation
```

A scalar `nu` may be used in controlled worlds if the process is truly summarized by one rate.

\[

\text{historical version persistence required}.
\]

That pressure belongs to `beta_lin`.

# 10. `rho_use` and derived `eta` — reuse process

Question:

> How intensively is a valid semantic capability used before invalidation/retirement?

Use a prospectively defined use process

\[
N_{use}(t)
\]

or intensity `rho_use(t)` where appropriate.

Let `T_inv` be the relevant invalidation/retirement time.

Then a derived effective reuse horizon may be

\[
\boxed{
\eta
=E[N_{use}(T_{inv})]
}
\]

under the registered process model.

This makes clear why high use intensity can coexist with high drift and why `eta` need not be treated as an independent primitive.

Synthetic experiments may manipulate `eta` directly, but must state that this is a controlled aggregate rather than a universal primitive coordinate.

# 12. `beta_lin` — lineage/coexistence demand

Question:

> Must multiple semantically distinct historical, branched or concurrent states remain addressable, distinguishable or auditable?

Candidate components:

```text
maximum/expected simultaneously live revisions
historical query depth
rollback window after successful admission
branch coexistence duration
provenance/lineage fidelity requirement
concurrent snapshot requirement
conflicting-update concurrency
whether readers may legally require different semantic snapshots at the same wall-clock time
```

Examples:

```text
high nu, low beta_lin:
fast overwrite stream where only the latest admitted state matters.

low nu, high beta_lin:
slowly changing formal/scientific/legal corpus where old branches and provenance remain queryable.
```

Therefore `beta_lin` is the primary obligation-side candidate for historical persistence pressure, while `nu`, `chi_V` and `lambda_R` may separately create speculative-staging pressure.

# 17. Primitive/derived distinction

Do not force every useful predictor into the same epistemic category.

Example dependency graph:

```text

                            |
rho_use process ------------+--> eta

chi_V + semantic scopes ---------> Delta_V

Omega semantic quotient ----------> sigma
```

A derived statistic can be convenient and predictive while still being redundant with its parents.

The theory should test whether adding both a primitive and its deterministic/near-deterministic derivative creates artificial apparent dimensionality or unstable regression coefficients.

# 18. Coordinate identifiability classes

Use four classes.

## I0 — exact operational

Measured exactly from the registered finite obligation.

## I1 — statistically operational

Estimator is frozen and consistent/calibrated under explicit sampling assumptions.

## I2 — structurally identified

Latent quantity is identifiable only under named model/auxiliary/interventional assumptions.

## I3 — not identified

Multiple incompatible latent values explain the same legal observations under the current assumptions.

I3 quantities cannot drive confirmatory GMI predictions.

This prevents a latent architecture-neutral vocabulary from becoming unfalsifiable.
