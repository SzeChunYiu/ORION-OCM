## CR-5 — finite relational/sheaf systems reduce to CSP/message passing

Let a finite cover contain local states `s_i`, finite restriction maps on overlaps, and finite compatibility predicates.

Construct a CSP/factor graph with:

- one variable for each local state;
- one factor for each local admissibility/compatibility relation;
- edges matching overlaps.

Then:

```text
local restriction      -> factor projection/message
compatibility check    -> factor evaluation
propagation             -> ordinary message passing/constraint propagation
global gluing           -> satisfying global assignment
obstruction witness     -> unsatisfied constraint / inconsistent cycle certificate
```

The translation is linear in the explicit local-state/overlap description up to fixed encoding constants.

Therefore finite relational/sheaf cognition is a **relational constraint kingdom/mechanism**, not a new H2/H3 classical domain unless a stronger resource lower bound survives the CSP/graph parent.

This retires ND1 as a domain candidate at the registered finite-classical scope while preserving it as a useful morphology.

## CR-6 — finite counterfactual-family state reduces to symbolic/probabilistic state

A finite set of possible worlds plus intervention maps is directly representable as a finite symbolic transition structure. If weights/probabilities are present, it is a probabilistic symbolic model.

The fact that probabilities are not primitive does not itself establish a new domain: an ordinary program can store worlds and intervention morphisms explicitly.

ND3 therefore remains a kingdom/representation choice unless an unbounded resource separation is shown.

## CR-7 — finite externalized ecological state is enlarged machine state

If the writable environment is finite/effectively encodable and its update/read operations are available to the comparison parent, define
\[
Z' = Z_{\text{agent}}\times Z_{\text{environment}}.
\]

The coupled machine-environment evolution is an ordinary state transition system on `Z'`.

Externalized memory/niche construction can change lifecycle burden dramatically, but ND4 is not a new domain under matched storage/actuation primitives.

## CR-8 — finite energy landscapes reduce to weighted-state search/dynamics

A finite energy landscape `(Z,E)` with a computable local transition/relaxation rule is a finite weighted transition system. An ordinary program with matched parallel transition primitives can simulate each transition and energy comparison.

New-domain status therefore requires a physical relaxation law whose measured time/energy/precision frontier is unavailable to the parent substrate.

## CR-9 — bounded-precision reaction networks reduce to numerical stochastic/dynamical programs

For a finite reaction network with bounded molecule counts or bounded-precision concentrations, computable rates and a registered finite time horizon, exact CTMC state enumeration (finite counts) or numerical ODE/SDE integration (bounded precision) gives an ordinary computational parent. The burden may be terrible, but novelty requires a proved asymptotic/physical separation after matched sensing, parallelism and precision.
