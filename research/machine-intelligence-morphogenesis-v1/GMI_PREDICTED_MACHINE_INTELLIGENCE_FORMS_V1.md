# 1. Novel-form admission rule

For a candidate `C`, distinguish four claims:

```text
C0 PROPERTY PREDICTION
   GMI predicts a behavior/mechanism vector in a registered regime.

C1 NEUTRAL RECOVERY
   a search grammar not containing the named architecture recovers the vector.

C2 PARENT NON-REDUCTION
   strong parent realizations cannot reproduce the frontier result under matched burden
   or require materially larger bounded compilation/search/resource inflation.

C3 REPLICATED FORM
   the property vector recurs across disjoint ecologies, search encodings and substrates.
```

Only C3 supports language such as “new machine-intelligence form,” and even then only at the registered scope.

Current status of every candidate below: **C0 only** unless a later receipt says otherwise.

# 2. Candidate F1 — Residual Quotient Machine (RQM)

## 2.1 Derivation

Let `S_P` be a broad predictive quotient and `S_O` the target semantic/developmental quotient.

When

\[
0 < H(S_O\mid S_P) \ll H(S_O),
\]

most target structure is already reusable through prediction, but a smaller set of target distinctions is observationally aliased.

`GMI_PREDICTIVE_RESIDUAL_QUOTIENT_THEORY_V1.md` proves that exact target realization then requires residual identities inside predictive fibers.

## 2.2 Frozen property vector

```text
F1.1 broad reusable predictive substrate
F1.2 separately mutable target-residual state
F1.3 composition rule that reconstructs target-semantic state/behavior from both
F1.4 residual capacity grows with within-predictive target multiplicity
F1.5 residual state disappears/dominates less as conditional residual burden -> 0
F1.6 full predictor replacement is avoided when residual updates are sparse and reuse is long
```

## 2.3 Predicted regime

```text
high predictive reuse
moderate/high broad semantic complexity
small but nonzero causal/provenance/lineage/task residual
residual changes faster than broad predictor
query volume high enough to amortize predictive core
```

## 2.4 Parent first refusal

```text
RAG / retrieval-augmented models
memory-augmented neural networks
neuro-symbolic systems
adapter/LoRA systems
causal representation systems
knowledge-base augmented models
```

RQM is not novel merely because it combines a neural model and memory.

## 2.5 Novel discriminator

The property-level prediction is supported only if the *size/necessity/location* of the augmentation tracks measured residual quotient burden under matched interventions.

Kill:

```text
RQM_BEHAVIOR_REDUCES_TO_PARENT_WITHOUT_RESIDUAL_LAW
```

# 3. Candidate F2 — Versioned Residual Quotient Mesh (VRQM)

## 3.1 Derivation

Combine F1 residual necessity with the independently derived A2–A6 lifecycle mechanisms.

When the broad predictor is reusable but residual state is:

```text
locally dependent
frequently revised
strictly verified/rejectable
retention-sensitive
possibly historical/branch-queryable,
```

GMI predicts that versioning/locality should concentrate around residual factors rather than forcing the entire predictive substrate through every revision.

## 3.2 Frozen property vector

```text
F2.1 stable broad predictive core
F2.2 sparse dependency-aligned residual factors
F2.3 authoritative residual state separated from compiled serving state
F2.4 dependency-tracked local residual rebuild
F2.5 verify-before-adopt isolation for rejectable residual updates
F2.6 optional persistent residual lineage only when beta_lin demands it
F2.7 stable typed composition boundary to predictive core
F2.8 residual factors may use heterogeneous realization families
```

## 3.3 Predicted regime

```text
RQM sparse-residual regime
+ high residual update rate
+ local Delta_U
+ strong verifier / rejectability
+ high retention or lineage demand
+ long broad-core reuse
```

## 3.4 Parent first refusal

```text
VLC
RAG with versioned stores
transactional databases + LLM
modular continual-learning systems
microservice-like AI compositions
persistent data structures
```

## 3.5 Novel discriminator

VRQM requires the *joint* prediction that versioned locality migrates to the residual layer when broad predictive state is stable, and disappears from that layer when residual update/retention/lineage pressure is removed.

Kill:

```text
RESIDUAL_LOCALITY_DOES_NOT_CONTROL_WHERE_VERSIONING_CONCENTRATES
```

# 4. Candidate F3 — Verifier-Gated Speculative Compiler (VGSC)

## 4.1 Derivation

Suppose candidate generation is cheap and high-coverage but not authoritative, while a stronger verifier can reject bad candidates at nontrivial cost.

If successful verified candidates are reused many times, GMI predicts a three-stage morphology:

```text
generate/propose cheaply
        ->
isolate + verify before authority
        ->
compile admitted result into cheap serving state
```

This is a generalization of A2 + A4 under asymmetric generation/verification/serving prices.

## 4.2 Frozen property vector

```text
F3.1 high-entropy cheap proposal mechanism
F3.2 proposal state cannot directly become authoritative
F3.3 external/independent verifier or evidence contract
F3.4 failed candidates are charged and discarded/retained by policy
F3.5 accepted candidates enter authoritative developmental state
F3.6 repeated accepted knowledge is compiled/cached into cheaper serving form
F3.7 abstention or incumbent serving while candidate is unresolved
```

## 4.3 Predicted regime

Let:

```text
c_g  proposal cost
p_a  probability a candidate is admissible
c_v  verification cost
c_s  post-admission serving cost
R    expected reuse count
L_f  loss of serving a false/unverified candidate
```

VGSC becomes attractive when cheap generation gives broad search coverage, false-adoption loss is high, and verification+compilation amortizes over reuse.

No universal scalar threshold is claimed without a registered price/loss map.

## 4.4 Parent first refusal

```text
generate-and-test AI
proof search + proof checker
program synthesis + test suite/formal verifier
AlphaZero/MCTS-like proposal/evaluation patterns
speculative decoding
transactional admission systems
scientific hypothesis generation + experiment
```

## 4.5 Novel discriminator

The claimed form is not the existence of verification. It is the prospectively predicted **authority/serving lifecycle** and its phase response to generator quality, verifier price, false-adoption loss and reuse.

Kill:

```text
VGSC_PHASE_DOES_NOT_RESPOND_TO_GENERATOR_VERIFIER_REUSE_PRICES
```

# 5. Candidate F4 — Interventional Quotient Learner (IQL)

## 5.1 Derivation

Prediction-only learning fails whenever histories/worlds are observationally equivalent but target-distinct.

If legal interventions can split those aliases, the machine should value interventions by the target-semantic ambiguity they remove per burden—not merely predictive surprise.

Define current target ambiguity conditionally on legal evidence state `E_t` as an appropriate finite entropy/cardinality or registered uncertainty functional

\[
A_t = \mathcal A(S_O\mid E_t).
\]

For legal intervention `j`, define expected quotient-information value schematically as

\[
IG_O(j)
=
A_t-
E[A_{t+1}\mid do(j)].
\]

An IQL allocates experimentation toward high target ambiguity reduction per charged intervention cost.

## 5.2 Frozen property vector

```text
F4.1 explicit representation of unresolved target-semantic aliases
F4.2 legal intervention/probe generator
F4.3 intervention choice sensitive to target quotient ambiguity, not only observation prediction error
F4.4 evidence update that refines target developmental state
F4.5 stop/abstain rule when remaining ambiguity is below registered need or intervention cost dominates
F4.6 learned reuse of intervention policies across structurally related ecologies
```

## 5.3 Predicted regime

```text
large prediction-target residual
interventions available
intervention outcomes informative
wrong causal/authority state costly
intervention burden lower than downstream ambiguity burden
```

## 5.4 Parent first refusal

```text
active learning
Bayesian experimental design
causal discovery / active causal learning
POMDP information gathering
scientific discovery agents
exploration in RL
```

## 5.5 Novel discriminator

A new-form claim requires a cross-paradigm law tying intervention policy to **target quotient refinement** and residual collapse, not merely uncertainty reduction in a chosen model.

Kill:

```text
TARGET_QUOTIENT_INFORMATION_VALUE_ADDS_NO_PREDICTIVE_POWER_OVER_PARENT_ACTIVE_LEARNING_CRITERIA
```

# 6. Candidate F5 — Locally Morphogenetic Heterogeneous Mesh (LMHM)

## 6.1 Derivation

Static MoE chooses among fixed experts. Standard NAS searches a largely global architecture before/around training.

GMI predicts a stronger form when:

```text
different semantic/dependency regions face different demand signatures;
those signatures drift at different rates;
no one realization family is frontier-optimal everywhere;
local structure can change without invalidating unrelated regions;
stable semantic interfaces permit recomposition.
```

Then `Gamma` should act **locally**, and local factors should be allowed to change realization family over developmental time.

## 6.2 Frozen property vector

```text
F5.1 semantic/dependency-aligned factor graph
F5.2 stable typed interfaces between factors
F5.3 factor-local response measurements and resource receipts
F5.4 local Gamma can change topology/algorithm/representation family
F5.5 unaffected factors remain authoritative during local morphogenesis when legal
F5.6 heterogeneous factor families allowed: neural, retrieval, probabilistic, symbolic, programmatic, search, etc.
F5.7 migration/search cost charged explicitly
F5.8 local form choice responds to local Xi/P, not a global architecture label
```

## 6.3 Predicted regime

```text
high demand heterogeneity across factors
local Delta_U and/or Delta_Q
nonstationary local regimes
large differences in family response functions
high cost of global retraining/recompilation
sufficiently stable interfaces
```

## 6.4 Parent first refusal

```text
Mixture-of-Experts
modular neural networks
AutoML/NAS
multi-agent systems
plugin/tool routers
microservice architectures
neuro-symbolic systems
mixture-of-algorithms / algorithm portfolios
```

## 6.5 Novel discriminator

LMHM is not “many experts.” It requires **development-time local family change** under a prospectively measured local demand signature, while preserving global semantic obligations and charging migration.

A decisive protected test varies one factor's local regime while holding others fixed.

Prediction:

```text
only the affected factor should undergo morphology change when local migration dominates global rebuild,
and its chosen family should change in the direction predicted by local response economics.
```

Kill:

```text
LOCAL_DEMAND_SIGNATURE_DOES_NOT_PREDICT_LOCAL_MORPHOGENESIS
```

# 7. Candidate F6 — Self-Compiling Developmental Intelligence (SCDI)

## 7.1 Derivation

The semantic quotient and developmental side-information theorem distinguish rich developmental state from serving state.

If one authoritative developmental state must support many repeated task/hardware/query regimes, GMI predicts maintaining richer state and compiling multiple disposable serving realizations rather than forcing one representation to be optimal for all uses.

## 7.2 Frozen property vector

```text
F6.1 authoritative developmental state preserves future-learning/verification distinctions
F6.2 compiler(s) produce task/substrate-specific serving realizations
F6.3 serving realization may discard developmental distinctions only if recoverable from authority state when future obligations require them
F6.4 cache/recompile policy responds to reuse, invalidation and hardware price
F6.5 multiple serving morphologies may coexist
F6.6 compiler/search burden is part of lifetime cost
F6.7 semantic equivalence checked at registered serving obligation
```

## 7.3 Predicted regime

```text
rich developmental state
many heterogeneous serving contexts
long/repeated serving horizons
changing hardware/latency/energy prices
serving obligations narrower than developmental obligation
compilation cheaper than maintaining one universally efficient serving form
```

## 7.4 Parent first refusal

```text
knowledge distillation
model compilation
JIT compilation
caches/materialized views
teacher-student systems
multi-head/task-specific models
edge/cloud model deployment
```

## 7.5 Novel discriminator

Strong support requires a machine to **select and regenerate serving morphology from developmental state as context prices/tasks change**, while preserving the authoritative state and beating fixed-form parents after compiler/search costs are charged.

Kill:

```text
SELF_COMPILATION_ADDS_NO_FRONTIER_VALUE_AFTER_PARENT_COMPILERS_AND_CACHES_RECEIVE_FIRST_REFUSAL
```

# 8. Relations among predicted forms

These forms are not mutually exclusive architecture brands.

A developmental system can instantiate a lattice:

```text
RQM
  |
  +-- VRQM          residual state becomes local/versioned
  |
  +-- IQL           interventions acquire missing residual distinctions
  |
  +-- VGSC          candidate residual updates require verification/admission
  |
  +-- LMHM          local factors can change realization family
  |
  +-- SCDI          rich authority state compiles context-specific serving forms
```

A strong future GMI system might instantiate several simultaneously.

The scientifically meaningful prediction is **which mechanisms activate under which demand/context**, not which marketing name wins.

# 11. Parent-reduction protocol

For every recovered candidate form:

1. identify the closest parent families;
2. allow parent experts to tune them under the same information/resource contract;
3. construct a compiler/reduction from candidate to parent where possible;
4. charge compiler/search/state inflation;
5. compare protected capability/resource frontier;
6. repeat under semantic remint and alternate substrate;
7. withhold novelty language if bounded parent reduction survives.

Terminals:

```text
PARENT_FIRST_REFUSAL_WINS__NO_NEW_FORM
```

# 12. Strongest current prediction

Among the six candidates, the most sharply theorem-derived new property prediction is:

> **RQM/VRQM:** broad predictive state should be augmented only by the target distinctions that remain unresolved inside predictive equivalence classes, and under local verified change the versioned/update-heavy machinery should concentrate around that residual rather than the whole predictive substrate.

This prediction has:

```text
an exact finite lower bound;
a zero-residual negative twin;
a causal/provenance/lineage interpretation;
a locality/versioning extension;
a direct neutral-search test;
a direct parent-reduction test.
```

It should therefore receive first experimental priority among the new-form candidates.
