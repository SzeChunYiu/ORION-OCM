# Fundamental Basis Acceptance v1

Status: **claim gate**, not evidence that any current basis passes.

Track B must not call a tuple, state machine or operator set a “fundamental cognitive unit” because it is compact, elegant or computationally universal.

A candidate `B` may receive only the status `CANDIDATE_ADAPTIVE_BASIS` until the applicable gates below are satisfied.

---

## F0 — Parent non-redundancy

Question:

> Is the candidate more than a renamed mature formalism?

Required attacks include:

```text
automata / Moore / Mealy machines
universal coalgebra / dynamical systems
learner/lens/category formalisms
universal program/interpreter
probabilistic programming / Markov categories
transformation semigroups / universal algebra
```

If the candidate adds no nontrivial developmental/resource result beyond a parent:

```text
PARENT_FORMALISM_SUFFICIENT
```

---

## F1 — Non-vacuity

A basis that contains an arbitrary universal interpreter, arbitrary `UPDATE(machine,experience)`, arbitrary stochastic kernel, or opaque black-box morphism can “derive” anything by definition.

Required:

- restricted typed primitives;
- explicit composition law;
- explicit update law family;
- measurable description/execution/update resources;
- no architecture-specific macro hidden in a primitive.

Kill terminal:

```text
UNIVERSAL_COMPUTATION_ONLY
```

---

## F2 — Compensation-aware minimality

For each primitive `p`:

\[
B^{-p}=B\setminus\{p\}.
\]

Do not declare `p` irreducible immediately. Permit legal compositions/alternative implementations from `B^{-p}`.

Then classify:

```text
ALGEBRAICALLY_REDUNDANT
ALGEBRAICALLY_IRREDUCIBLE_AT_SCOPE
RESOURCE_IRREDUCIBLE_AT_SCOPE
LEARNING_IRREDUCIBLE_AT_SCOPE
EPISTEMIC_IRREDUCIBLE_AT_SCOPE
NON_IDENTIFIABLE
```

A field is not fundamental merely because deleting it from one implementation breaks tests.

---

## F3 — Basis non-uniqueness / equivalence

Search explicitly for a different basis `B'` such that:

\[
B \approx^{dev}_{E,R,V} B'.
\]

If several minimal bases mutually compile within the registered bounds, report:

```text
MULTIPLE_EQUIVALENT_MINIMAL_BASES
```

not a unique atom.

A uniqueness claim requires excluding all registered alternative bases, not failing to think of one.

---

## F4 — Cross-paradigm bounded sufficiency

The same frozen basis must support at least tiny instances of multiple major morphology families without architecture-labelled primitives.

Minimum target set:

```text
neural/differentiable
symbolic/production/rewrite
probabilistic/generative
programmatic/library-learning
```

Later strengthen with:

```text
reservoir/dynamical
vector-symbolic/hyperdimensional
locally developmental/cellular
hybrid parent product
```

For each target report:

```text
D0 representability
D1 bounded compilation
D2 developmental acquisition
```

If one paradigm requires a special new primitive, record the obstruction; do not hide it.

---

## F5 — Developmental sufficiency

A cognitive basis must explain **change under experience**, not only static computation.

Required:

- distinguish current behavior from update behavior;
- represent at least two non-equivalent learning/update laws;
- measure information needed by the update;
- measure update/locality/maintenance costs;
- support retention/plasticity tests.

The exact Stage-B witness already proves why current functional equivalence is insufficient.

---

## F6 — Resource-bounded predictions

A proposed basis must predict more than reachability.

At minimum it should make one falsifiable statement about:

```text
compilation depth/size
learning/update work
memory
communication
reuse horizon
revision cost
search burden
```

that differs between candidate morphologies or bases and survives a parent explanation.

If all predictions reduce to “it can simulate it eventually,” fail F6.

---

## F7 — Prospective morphogenesis / phase prediction

Before calling the basis intelligence-specific, require at least one prospective statement of the form:

\[
(E,R,V)\in\mathcal R_i
\Rightarrow
M_i\in Frontier(E,R,V)
\]

or a quantitative boundary prediction, frozen before protected morphology-search outcomes.

The registered search must then recover the predicted region on disjoint ecologies better than incompatible predictions.

This is the strongest guard against a universal-language theory that explains everything after the fact.

---

## F8 — Negative / parent-favoring regions

A valid theory must predict where the candidate basis/morphology **should not** win.

Required:

- parent-favoring ecology;
- no-transfer ecology;
- harmful-transfer ecology;
- resource regime that reverses a previous winner;
- representation/update regime where another basis is predicted superior.

A “theory” that predicts its favorite morphology everywhere is incompatible with the programme doctrine.

---

## F9 — Heterogeneous external validity

Only much later, the same theory must survive validation regimes beyond toy finite worlds, ideally using Track-A domains:

```text
formal mathematics
execution-verified code/tools
language-mediated tasks
science/empirical evidence
```

The basis need not use one solver in every domain. The claim is about the generating/developmental law.

---

# Claim ladder

```text
CANDIDATE_ADAPTIVE_BASIS
  -> MINIMAL_AT_FINITE_SCOPE
  -> CROSS_PARADIGM_BOUNDED_BASIS_AT_TINY_SCOPE
  -> DEVELOPMENTAL_BASIS_SUPPORTED_AT_SCOPE
  -> PREDICTIVE_MORPHOGENESIS_BASIS_SUPPORTED_AT_SCOPE
  -> HETEROGENEOUS_GENERATIVE_BASIS_SUPPORTED
```

Only after the latter stages should language such as “fundamental cognitive basis” be considered, and even then prefer:

```text
MINIMAL_GENERATING_BASIS_SUPPORTED_UNDER_REGISTERED_ASSUMPTIONS
```

rather than metaphysical atomicity.

```text
NO_FUNDAMENTAL_BASIS_ESTABLISHED
```
