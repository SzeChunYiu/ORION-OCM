# GMI Developmental Realization — parent assumption map v1

Status: **ADOPT PARENT MATHEMATICS; DO NOT REINVENT**

This map supports `GMI_DEVELOPMENTAL_REALIZATION_PRINCIPLE_V1.md`.

Its purpose is not to prove novelty. It states which mature theories GMI is explicitly allowed to import, which assumptions travel with the import, and what remains outside each parent's scope.

---

## 1. Information Bottleneck / rate-distortion

Primary anchor:

- Tishby, Pereira & Bialek, *The Information Bottleneck Method* (1999).

Parent object:

```text
compress X
while preserving information relevant to Y
```

Canonical form trades representation complexity/information against relevance/distortion.

### GMI adoption

Use as a parent whenever the realization question is:

```text
what compact representation/state preserves the registered task-relevant distinctions?
```

It directly informs:

- semantic-state approximation under an explicitly registered distortion contract;
- representation/factorization tradeoffs;
- compression-vs-capability frontiers;
- some phase transitions in representational complexity.

### Assumptions/boundary

Information Bottleneck alone does not supply:

- the external verifier/authority constitution;
- arbitrary lifecycle revision/revocation semantics;
- the full multi-resource build/serve/update/verification vector;
- the morphogenetic process that discovers a representation;
- proof that a practical learner reaches the normative optimum;
- one universal notion of task relevance across domains.

### GMI rule

If an apparent GMI result is exactly a rate-distortion/IB result after mapping the variables:

```text
PARENT_REALIZATION_THEORY_SUFFICIENT__INFORMATION_BOTTLENECK
```

is the correct theoretical disposition.

## 2. Information-theoretic bounded rationality / free utility

Primary anchors:

- Ortega & Braun, *Information, Utility & Bounded Rationality* (2011 preprint);
- Ortega & Braun, *Thermodynamics as a theory of decision-making with information-processing costs*, Proc. R. Soc. A 469:20120683 (2013).

Parent object:

```text
maximize expected utility
minus information-processing cost
```

with relative entropy/KL as the processing-cost term in the canonical free-energy formulation.

### GMI adoption

Use as a parent when a morphology/control realization trades:

- task utility/capability;
- information-processing complexity;
- adaptation from a prior/default policy;
- limited decision capacity.

### Assumptions/boundary

The canonical parent uses a particular information-cost formalism. GMI's raw resource vector is more general and may contain:

```text
CPU/GPU/wall
verification calls
storage
communication
maintenance
revision/retraining
human intervention
```

Those coordinates should not be silently rewritten as KL bits unless a justified model establishes the mapping.

The parent is normative. It does not prove the actual developmental process realizes the bounded-optimal solution.

---

## 3. Bounded rationality → abstraction / hierarchy

Primary anchor:

- Genewein, Leibfried, Grau-Moya & Braun, *Bounded Rationality, Abstraction, and Hierarchical Decision-Making: An Information-Theoretic Optimality Principle* (2015).

Parent result/programme:

Limited information-processing capacity can induce abstraction and hierarchical information-processing organization under an information-theoretic objective.

### Consequence for Track B

Do **not** claim as a new GMI discovery:

```text
resource constraints cause abstraction
resource constraints cause hierarchy
information bottlenecks produce specialized modules
```

in that broad form.

### GMI adoption

This parent is a direct model for one class of morphology phase law:

```text
resource capacity / information budget changes
-> optimal organization changes
```

Track B should reproduce such parent phase laws as calibration before searching for a more general empirical law.

## 4. Resource-rational analysis

Primary anchor:

- Lieder & Griffiths, *Resource-rational analysis: Understanding human cognition as the optimal use of limited computational resources* (2019/2020 BBS).

Parent object:

```text
choose cognitive mechanisms/strategies as an approximately optimal use of limited computational resources
```

### GMI adoption

This is a close parent of the normative realization principle:

```text
semantic/capability obligation
+ limited resources
-> resource-rational realization
```

GMI should use it rather than claim the general phrase “optimal cognition under limited resources.”

### Important hostile

A normative resource-rational analysis used by the researcher must not be confused with an empirical statement that the actual machine/developmental process is resource-rational.

Therefore GMI preserves:

```text
NORMATIVE_REALIZATION_FRONTIER
!=
MORPHOLOGY_ACTUALLY_FOUND_BY_GAMMA
```

This distinction is load-bearing.

## 5. Rational metareasoning / value of computation

Primary anchor:

- Russell & Wefald, *Principles of metareasoning*, Artificial Intelligence 49 (1991), 361–395.

Parent object:

```text
computation is itself an action
whose value derives from how it changes external decisions
```

### GMI adoption

Use as first-refusal theory for:

- whether more search is worth doing;
- whether to verify more;
- whether to retrieve/refine/probe;
- serving-time executive choices;
- cost-aware cognitive control.

### Boundary

Classic metareasoning does not by itself specify:

- the semantic developmental quotient;
- persistent morphology construction over a lifetime;
- morphology discovery cost across generations;
- cross-domain epistemic/governance semantics.

Those can be composed with the parent rather than rebuilt.

---

## 6. Algorithm selection

Primary anchor:

- John R. Rice, *The Algorithm Selection Problem*, Advances in Computers 15 (1976), 65–118.

Parent object:

```text
problem/instance features
-> select an algorithm
under a performance criterion
```

### GMI adoption

If the candidate morphology portfolio is fixed and known, and the problem is to route tasks/regimes to the best member, Rice-style algorithm-selection theory receives first refusal.

### Kill gate

A result of the form

```text
features predict whether neural vs symbolic method is cheaper
```

is not by itself a new morphogenesis law if it is simply fixed-portfolio algorithm selection.

### Residual question

Track B moves upward only when the candidate organization itself is generated/changed and the developmental process/search cost is part of the scientific object.

---

## 7. AutoML / NAS / evolutionary whole-algorithm discovery

Primary anchor:

- Real et al., *AutoML-Zero: Evolving Machine Learning Algorithms From Scratch*, ICML 2020.

Parent result/programme:

A search over relatively primitive mathematical operations can rediscover recognizable learning algorithms including two-layer neural networks/backprop-like machinery and can produce task-dependent algorithmic structures.

### Consequence for the original Track-B question

The statement

```text
basic primitives can evolve into a neural-network-like learning algorithm
```

is **not** an ORION novelty claim.

It is an already demonstrated parent phenomenon.

### GMI adoption

AutoML-Zero/NAS/evolution are candidate implementations of

```text
Gamma_g
```

the morphogenetic search process.

GMI evaluates them with:

- semantic-admissibility constraints;
- complete search/discovery cost;
- capability/resource realization frontiers;
- developmental history;
- generality across ecologies;
- external verification/governance.

### Boundary

A successful AutoML search is not automatically:

- a minimal fundamental basis;
- a universal phase law;
- open-ended development;
- K2/K3;
- evidence that its search encoding is unbiased.

---

## 8. Levin search / OOPS / bias-optimal programme search

Parent anchors:

- Levin universal search;
- Schmidhuber OOPS and related bias-optimal programme-search work.

Parent object:

```text
search over programs using a prior/description-length/time allocation
```

with theoretical universality/bias-optimality properties under explicit assumptions.

### GMI adoption

Use for:

- programmatic morphology search;
- library/search-prior capital;
- description-length → proposal-mass relations;
- incremental reuse where the mapping is valid.

### Boundary

Universal/bias-optimal search can have enormous constants and does not supply a practical prospective morphology phase law for arbitrary real machine families.

Therefore:

```text
universal search exists
```

does not answer which bounded morphology is economical at a practical horizon.

---

## 9. Factored models / graphical representations / modularity

Parent families:

- factored MDPs;
- dynamic Bayesian networks / graphical models;
- modularity/evolvability theory;
- dependency-graph and sparse-factorization methods.

### GMI adoption

Use whenever the result is fundamentally:

```text
global state has compact factorization
local dependencies reduce representation/update work
modularity follows task/dependency structure
```

### Boundary

GMI should not rename factorization as a “new cognitive atom.”

The live question is which factorization preserves the semantic obligation and occupies the best lifetime frontier under the actual ecology/resources.

---

## 10. Database/materialized-view/cache economics

Parent families:

- materialized-view selection;
- cache admission;
- rent-vs-buy / ski-rental;
- indexing/query planning.

### GMI adoption

Use for:

```text
build expensive reusable structure now
vs
recompute later
```

including many apparent “developmental memory” phase boundaries.

### Boundary

If ordinary view/cache economics explains the complete effect:

```text
PARENT_REALIZATION_THEORY_SUFFICIENT__LIFECYCLE_ECONOMICS
```

is the correct result.

The higher GMI question is whether the machine learns/changes the realization policy across heterogeneous cognitive obligations in a way not already exhausted by the parent product.

# 11. Parent composition is allowed

GMI-v1 does not require one parent theory to cover the complete object.

A valid explanation may be:

```text
predictive-state sufficiency
+ rate-distortion representation
+ resource-rational metareasoning
+ algorithm selection
+ AutoML search
+ database lifetime economics
+ external formal verifier
```

If that parent product explains the registered phenomenon:

```text
PARENT_PRODUCT_SUFFICIENT
```

is a successful theoretical answer.

ORION should adopt the composition rather than rebuild it.

---

# 12. What remains for GMI even under parent sufficiency

Even if all local mathematics is parent-owned, GMI can still be established as a useful general theory if one coherent object consistently expresses:

```text
semantic developmental sufficiency
+ heterogeneous morphology realization
+ raw lifetime resource frontier
+ development/update law
+ morphogenetic search law
+ discovery cost
+ external verifier/constitution
+ ecology-indexed generality
+ K0/K1/K2/K3 attribution
```

across neural, symbolic, probabilistic, programmatic, evolutionary and governed explicit systems.

That is **theory synthesis**, not component novelty.

A stronger new-law claim requires prospective predictive evidence beyond the parent product; it is not required merely to use GMI as the project's general machine-intelligence theory.
