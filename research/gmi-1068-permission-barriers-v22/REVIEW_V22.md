## Actual implementation

Read all four production modules: core, execution, contexts and families_v22.
PermissionMachine validates every annotation, including unused/absent edges;
requirements belong to actual state/action cells. support validates the whole
word before walking the physical transitions. gate builds an actual immutable
V8 Machine and preserves observations, payloads and destinations exactly.
No permission creates a missing physical edge.

restricted_context uses the proved support-containment characterization to
construct admission, retaining actual V15 E/values/preorder. The oracle instead
traverses the actual gated transitions before comparing admission and all three
observation tags. Thus a matching supplied-answer filter is not its sole check.
Raw histories have stable indices; target_witnesses keeps every eligible ID and
support, excluding P-illegal, undefined, unselected and physically failed words.

minimal_additions filters off-available supports and minimizes actual deficits.
It returns permission sets; history backpointers are recovered from the retained
complete target_witnesses records, not an undocumented returned certificate.
minimal_blockers enumerates subsets against precisely the currently available
supports. blocker_certificate checks blocking before its private-witness test,
and returns an eligible actual history ID for each deleted permission. Empty
certificates and None consequently have different meanings. minimal_supports
groups equal supports with all their IDs but discards strict-superset histories;
only Boolean capability/blocker preservation is claimed for that reduction.

## Primary oracle and tests inspected

Read oracle_v22 and tests for execution, contexts, families, controls and hostiles.
The oracle imports no production code. Its execution routine traverses the raw
rows, and its addition/blocker answers enumerate interventions directly.
Execution tests compare actual V8 gated responses, support composition at every
cut and complete successful responses. Context tests compare actual P/E fields,
every observation, image, target IDs and relative interventions.
Family tests range over every frozen small family and available subuniverse,
including off-universe supports, all additions/deletions and permission relabels.
The tests separately check that blocking AND private witnesses characterize the
minimal answers. Duplicate identities are not silently lost by value projection.

Actual controls include two-action equal-payload edges with different requirements,
a return-to-start history target, fixed resource admission, conjunction/alternative
supports, unequal inclusion/cardinality/price minima, mandatory overhead, negative
permissions and restricted allowed interventions. The old one-step helper is
loaded from its immutable original file and checked against its actual fixture.
These finite controls do not establish all-history completeness or causal meaning.
The infinite-tail obstruction has a separate general kernel proof as well as
a paper argument; it is not inferred from finite calibration.
