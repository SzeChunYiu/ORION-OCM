## Context and specialization semantics

core_v17 uses the actual V15 Context class and validates the imported module
path. Primitive constructors validate their value types before deduplication;
bool/int/float aliases cannot silently merge utility or confidence values.
Encoded retains a table of actual attained ambient values and their indices,
including values defined on illegal histories. Decoding observes admission first.
The finite table presents the tested values and their inherited order; it is
not a new general-purpose proof about every value in an infinite codomain.

map_values accepts any validated total map between the supplied finite
preorders; postcompose additionally requires global monotonicity, even if no
active history exposes the failing pair. Comparison reflection is checked as
a separate property. Dual transposes order while preserving all values/domains.
An injective map from a discrete preorder into a chain remains a valid
counterexample to unjustified order reflection.

Independent products intersect evaluator domains; shared products require the
same supplied domain. Mixed-radix coding agrees with product_labels and actual
component values. Missing components are not filled. Empty shared families
retain E; empty independent families return a defined empty tuple for admitted
histories. Incomparable vectors are not scalarized. Lower-cost preference is
explicitly reversed, and acceptance0/1 preserves the actual acceptance order.
Nonempty uncertainty subsets use reverse inclusion; empty subsets are rejected.
No observed precision is interpreted as truth, probability or calibration.

## Viability and oracle independence

Production eliminates states lacking a successor within the current safe set.
Because the iterates decrease from K, this equals iteration of K∩Pre_exists.
A deadend is removed; a self-loop counts only if explicitly in the input matrix.
The Context constructor evaluates actual endpoints against the resulting set,
while keeping illegal, undefined and false viability distinct.

The independent primary oracle computes positive-length transitive closure and
reachability to an actual safe cycle. It does not insert identity edges. A
second oracle enumerates all safe postfixed subsets and unions them. The
independent larger-model review uses recursive path exploration and repetition,
not the production elimination loop. Existential and adversarial continuation
are explicitly separated by the loop/deadend branch control.
General infinite-state claims rest on the paper and kernel proofs; finite
algorithms and corpus agreement do not establish them by extrapolation.
