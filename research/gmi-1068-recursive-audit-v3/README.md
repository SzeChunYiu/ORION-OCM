## Scientific result and current limit

useful common language for possibility, observation, evaluation and comparison.
That definition alone neither generates a learning algorithm nor explains which
architecture succeeds in a particular world. Those claims need explicit
representation, search, feedback, cost and environmental hypotheses. Ordinary
category/resource/control/learning mathematics keeps its original ownership.

programme must disclose its interface, primitives, encoding, task class,
objective, search schedule and budget. Removing pretrained weights or neural
architecture templates is a different, testable goal. A finite completion audit
is relative to its registered statements; it cannot exclude unknown gaps.
