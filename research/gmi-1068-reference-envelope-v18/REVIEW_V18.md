## Sources read and scientific/API findings

Read core_v18.py, prefix_v18.py, measures_v18.py, resources_v18.py and
interaction_v18.py, plus oracle_v18.py and the prefix, measure, resource and
boundary test modules. No scientific or API defect was found in the reviewed
current implementation. This finding does not replace its primary calibration.

The finite Book validates actual prefix conflicts before canonicalization.
Wrapped reserves exact singleton0, removes exactly L leading ones, and delegates
the remaining programme to the actual base interpreter. Padding1 is permitted
and correctly distinguished from the stronger main L≥2 concentration convention.
Shortest-output weights collapse equal-output aliases by minimum length; they
are not sums over descriptions. Missing outputs contribute zero and ε-only
nonuniversal bases are supported. No finite book is described as universal.

Measures validate exact Fraction probability vectors before deduplication,
retain zero weights, reject absent/empty families, and use actual expectation
or minimum evaluations. Context constructors reuse the real immutable V15
interface through V17 encoding. They preserve admitted and defined flags
separately, including an ambient value on an illegal history. Unit-interval
profiles are the executable contract; unbounded Real values are not accepted
merely because the general paper expectation theorem admits them.

Conditioning explicitly requires positive event mass under every prior used.
recursive_lower rejects a branch that has zero mass for any prior; it does not
invent a null-event update. Its one-stage partition computation is sufficient
for the registered counterexample and rectangular repair. It is not a general
dynamic-consistency theorem or arbitrary-horizon controller.

Resource conversion validates a reflexive/transitive Boolean relation and
constructs target contexts from its actual entries. The direction is source
indicator≥destination indicator. Equivalent but distinct resources are retained.
The general proof derives conversion from real free-arrow witnesses; the
finite relation is its thin-category model, not evidence for physical freeness.
The interaction function implements environment-first timing: initial reward0,
one possible reward after the first action, and zero for longer histories.

## Primary oracle/test design and custody review

The prefix oracle enumerates flat antichains and literal string programmes,
while production uses a trie and Boolean tuples. It checks actual decoding,
compiled domains, shortest-code weights and exact tail inequalities. The same-
output, empty/ε, padding-tie and tiny-positive controls exercise missing premises.
The finite score/simplex and resource corpora enumerate the frozen candidates;
Dirac-family completeness there is not called universal-machine completeness.
Actual policy values come from the environment function before scoring, rather
than policy-name selectors. Nonrectangular conditional values and its four-prior
repair are independently calculated. Tests preserve the declared paper/kernel
boundary; finite examples do not claim Real infinite-sum or TM universality proofs.
