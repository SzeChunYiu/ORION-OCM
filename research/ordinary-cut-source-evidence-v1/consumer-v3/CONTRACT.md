# Consumer transport correction

## Fixed scope

Input schemas remain ordinary.training-trace-packet.v2 and
ordinary.native-P1-inventory.v2. The consumer request/result schema advances to v3.
The two-node cut adapter, ordinary matcher, typed constructor and native observer
remain unchanged. Only input binding/transport validation changes.

The source-defined population stays 4,095 original theorems plus exactly the next
128 positions, with all explicitly qualified prefix axioms. Excluded rows remain
stubs. Trace usability cannot remove released whole theorems from P1.

## Exact native authority

Root must independently qualify and bind the actual native authority, packet and
P1 before any consumer use. The consumer checks the authority's exact corpus,
release, scoped registry, original P0, prefix identity, 4,223 verified-label order,
all prefix axiom contracts/raw identities and declared added axiom labels.

Every released root has a native selected-scope binding, including whole-contract,
source/proof raw identities and its source context. Ready-trace membership and
dispositions must agree exactly between packet and authority.

A saved terminal or marker alone never grants that external qualification.
No native checker is invoked by this consumer, and candidate cut outputs do not
become admitted theorems.

## Hypotheses and spans

Each TRACE_READY row is bound by canonical-newline SHA-256 identities for its
complete trace and used-contract map. The map must contain exactly the labels
used by the trace. Hash equality preserves the exact native-index spans;
a source-order inequality alone is insufficient.

Used floating/essential contracts have exactly label, kind, statement and span.
Each matches the current source theorem's mandatory floating or essential context,
respectively. Used ordinary contracts have exactly the six ordinary fields plus
span; their projections equal the already qualified complete P1 contracts.
Referenced ordinary proof bodies or extra history fields are refused.

Spans are two plain integers with nonnegative start and positive length.
A used source statement ends no later than the theorem start. Source, active and
used ordinary DV remain empty for ready transport, and traces have 1–256 nodes.

These are transport prerequisites. The unchanged constructor still checks exact
three-parameter typing, graph/stack correctness, source order, bijection,
remaining bounds and reconstruction. A later per-root constructor refusal remains
UNKNOWN_INTERFACE for opportunity coverage; P1 stays intact.

Native-valid proofs outside mandatory-hypothesis/DV/node transport scope are
TRACE_UNUSABLE with null trace and empty contracts in the teaching packet.
Their full trace belongs only to the separate custodian artifact. Every released
whole theorem remains in P1.

## Qualification limits

The authored test fixture uses the unchanged structural fixture builder, with a
fabricated authority explicitly labelled as a double. It tests the input validator;
it does not invoke a native verifier, exporter, extractor, alias screen, learner,
driver census or evaluation. Complete native packet interoperability remains
subject to the separately qualified real inputs and execution gate.
