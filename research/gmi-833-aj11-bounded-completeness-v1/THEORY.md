## Unbounded boundary

This finite completeness must not be extrapolated. For a Turing-complete finite syntax, program strings are effectively enumerable, but a terminating semantic catalogue that canonicalizes arbitrary programs by computed partial function would decide program equivalence. Standard computability results rule that out in general; Rice's theorem likewise blocks total decision of arbitrary nontrivial extensional semantic properties.

Therefore the unbounded GMI target is not a terminating list of all semantic intelligences. It is:

- open-ended generativity/enumerability where appropriate;
- explicit undecidability/unknown terminals;
- AJ9 blind known-family recovery;
- AJ10 prospective UNKNOWN discovery;
- scoped prediction/replication rather than universal semantic classification.
