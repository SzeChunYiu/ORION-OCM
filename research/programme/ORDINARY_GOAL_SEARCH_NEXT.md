# Next experiment: goal-only ordinary-lemma use

The next scientific step is to make acquired ordinary lemmas participate in
goal-only proof search. Another exposed supplied-proof refactoring pass is not a
prerequisite. The [native replacement result](../ordinary-hole-native-result-v1/CORE.md)
already establishes its authored integration boundary; it does not establish
learning, search utility or general substitution coverage.

This is a development decision, not an executed experiment or a completed run
registration. Freeze and review the concrete implementation, inputs, limits and
comparison before releasing evaluation data.

## Reuse the existing parent

The existing [finite-bank search](../g2-two-decision-search-v1/experiment.py)
already accepts a query and premises in `run_search`. Reuse its ordinary theorem
actions, typed contracts and proof construction where their source contracts fit.
Connect the complete generated proof to current native request/result checking.
Do not feed the refactoring caller a supplied target proof merely to manufacture
a search input. No replacement matcher, parser, miner or neural selector is needed
solely to open this experiment.

The old search allocation prioritized hits on official-proof label sequences.
That allocation policy must not be reused for an unhinted solving claim. Earlier
no-use results retain their original scope.

## Freeze one exact knowledge state

Use one declared ordinary-lemma cohort C with exact contracts, proof dependencies,
admission identities and eligibility. The reported historical 22 admissions and
the newer screen's 32 negative occurrences belong to different generations.
Do not combine their counts or substitute receipts. A fully bound historical
cohort can be used on its own; union with every newer candidate is not required.
Record unsupported members before target access, with no outcome-based backfill.

The common P1 library contains 4,223 theorems and 100 axioms, including the released
training theorems. Bind the exact P1+C prefix, ordered context, index and authority.
Qualify the full expected ordered P1+C theorem population and unchanged 100-axiom
inventory. Individually begin-label-checked admissions do not establish that joined
authority.
The authored caller's 4,096-proof/96-axiom receipt does not qualify that successor.
Selected-claim checking and complete-prefix checking have distinct scopes; reuse
previous authority only when the exact source and library bindings establish it.

## Withhold the solution from the solver

Seal a new allocation and its exposure/dependency policy before any search result
is observed. Previously inspected H1 or post-training tasks remain development
data. Renaming them does not create independent evaluation.

The solver receives the goal, scoped hypotheses, allowed syntax and the frozen
library. Build syntax banks from those permitted inputs, not official proof
intermediates. Withhold the official proof, target theorem label and prohibited
derived shortcuts. A separate data-preparation boundary may enforce exclusions;
it must not pass proof routes or outcome-based priorities to the solver.

## Compare causal use and complete cost

Begin with the conventional P1+C parent. Compare enabled C against the same
resident-but-disabled C and exact restoration. Disable every action alias for
the removed identities; keep acquisition, loading, storage and fallback costs.
Use the same task order, search resources, verifier and selection opportunities.
Hold syntax-bank contents and grounding policy identical across enabled, disabled
and restored arms. Removal changes eligible C actions, not the available term hints.

Count a result only when a complete emitted proof passes current native checking.
Separate attempted lemma use from a lemma causally consumed in the checked proof.
Report solved tasks, search expansions, failed attempts, checking, retrieval,
restart and acquisition costs. Finite enumeration and UNKNOWN do not establish
global non-derivability. No verified use is an informative bounded outcome.

This first experiment can establish causal use of training-derived methods and
bounded utility.
An OCM-specific contribution requires a subsequent concrete treatment that beats
the equally equipped ordinary parent. Proof shortening alone, a parent-matched
result or an unamortized warm-query gain cannot establish that contribution.
