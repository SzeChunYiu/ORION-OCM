## 1. The object being presented

A **presentation** is the 6-tuple

```text
P = (n, Sigma, I, s0, regime, prog)
```

- `n` — state-space size; the state space is `S_n = {0, ..., n-1}`;
- `Sigma` — an ordered list of exactly two distinct operation symbols `f0, f1`, each unary;
- `I : Sigma -> S_n^{S_n}` — the interpretation, a total map on the state space;
- `s0 = 0` — the start state, fixed for every presentation in the universe;
- `regime in {BINARY, FULL}` — the observation regime, fixing `out : S_n -> Obs`
  (`BINARY`: `out(s) = 1` iff `s = 0`; `FULL`: `out(s) = s`);
- `prog : A -> Sigma*` — for each letter of the fixed external alphabet `A = {a, b}`,
  the word of operation symbols that implements it, `|prog(x)| <= 2`.

The **presented semantic object** is the behaviour `beh_P : A* -> Obs`,
`beh_P(w) = out(I(prog*(w))(s0))`, where `prog*` is the monoid extension of `prog`.
This is the presentation-independent object of the AG3 row's own schematic; every strength
below is a relation between presentations, and every one of them is required to imply
equality of this object.

Two presentations are comparable only when they share `regime` and `A`. `n` may differ.

`reach(P)` is the set of state-space elements reachable from `s0` under `I(prog*(A*))`.

## 2. The four strengths, defined before any run

Each is a binary relation on the registered universe. The names are taken from the row.

**`L1` — SYNTACTIC_RENAMING.** `P ~1 Q` iff there exist a bijection `rho : Sigma_P -> Sigma_Q`
and a bijection `sigma : S_{n_P} -> S_{n_Q}` (so `n_P = n_Q`) with

```text
sigma(s0) = s0,  out_Q(sigma(s)) = out_P(s) for all s,
I_Q(rho(f)) o sigma = sigma o I_P(f) for all f in Sigma_P,
prog_Q(x) = rho*(prog_P(x)) for all x in A.
```

Nothing is recomputed: the interpretation table is carried across verbatim under a relabeling
of symbols and of states.

**`L2` — DEFINITIONAL_TERM_EQUIVALENCE.** `P ~2 Q` iff `n_P = n_Q` and there is a bijection
`sigma : S_{n_P} -> S_{n_Q}` with `sigma(s0) = s0`, `out_Q o sigma = out_P`, such that

```text
sigma . <I_P(Sigma_P)> . sigma^-1  =  <I_Q(Sigma_Q)>          (generated monoids equal)
I_Q(prog_Q(x)) o sigma = sigma o I_P(prog_P(x)) for all x in A  (same external actions)
```

`<X>` is the transformation monoid generated by `X` together with the identity. Monoid equality
is exactly mutual term-definability: every `Q`-symbol is the interpretation of a `P`-word and
conversely. This is the row's "definitional/term equivalence", and in the unary case it is also
the Lawvere/clone-isomorphism reading of "categorical equivalence" — the coincidence is a
result of this package, not an assumption, and is reported either way.

**`L3(k)` — COMPILER_EQUIVALENCE_WITH_OVERHEAD, overhead factor `k` (a positive integer).**
`P ~3(k) Q` iff there are maps `e : reach(P) -> S_{n_Q}` and `d : reach(Q) -> S_{n_P}`, each
injective, with `e(s0) = s0`, `d(s0) = s0`, `out_Q o e = out_P` on `reach(P)`,
`out_P o d = out_Q` on `reach(Q)`, and for every letter `x in A`

```text
exists w in Sigma_Q* with |w| <= k * |prog_P(x)| and I_Q(w) o e = e o I_P(prog_P(x)) on reach(P);
exists v in Sigma_P* with |v| <= k * |prog_Q(x)| and I_P(v) o d = d o I_Q(prog_Q(x)) on reach(Q).
```

The compiled word is chosen by the compiler; it need not be the target's own `prog`. Only
reachable configurations are simulated, as in every compiler-correctness statement. The state space
may change, which is what distinguishes this level from `L2`. `k` is charged and never hidden:
the level is a family indexed by `k`, and the registered ladder is `k in {1, 2, 3, 5}`, with
`k = 5` fixed by the merged parent `gmi-833-aj5-g0-lowering-v1`'s own `lower_ops <= 5 * G0_steps`.

**`L4` — MODEL_EQUIVALENCE.** `P ~4 Q` iff `beh_P = beh_Q` as functions `A* -> Obs`. By the
Myhill-Nerode argument for finite Moore machines this is equality of the minimal Moore
automaton up to isomorphism, and for these deterministic total systems it is output-respecting
strong bisimilarity; the merged parent `gmi-833-parent-equivalence-v1` owns both identifications.
Behaviour is decided on the finite window `|w| <= W` with `W` declared in section 3; the package
must prove the window is sufficient for the universe.

## 3. The registered universe, fixed before any run

`T_2 = [id, swap, const0]`
`T_3 = [id, succ, pred, const0, tau01]`
where `succ(s) = s+1 mod n`, `pred(s) = s-1 mod n`, `const0(s) = 0`, `tau01` transposes `0` and
`1` and fixes everything else, `swap = tau01` on `S_2`.

The universe `U` is every presentation with `n in {2, 3}`, `Sigma` an ordered pair of two
**distinct** members of `T_n`, `prog(a)` and `prog(b)` words over `Sigma` of length at most `2`,
`s0 = 0`, and `regime in {BINARY, FULL}`. Sizes are a consequence of this definition and are
published in the receipt, not fixed here.

Behaviour window `W = 6`. The sufficiency requirement: the induced `A`-automaton of any `P in U`
has at most `n <= 3` states, so two behaviours that agree on all `|w| <= 2*3 - 2 = 4` agree
everywhere (Moore equivalence of `m`- and `m'`-state machines is decided at depth
`m + m' - 1`); `W = 6` exceeds the bound and the executor asserts the margin by recomputing at
`W` and at `W - 1`.

The **witness set** `Wit` is four pairs declared here, each naming the gap it is built to
separate. They are members of `U` except where a larger state space is explicitly stated, in which
case the pair is checked but excluded from the universe-wide relation counts:

- `W-RENAME` — separates `L1` from `L2`. `P`: `n=3`, `Sigma=(succ, id)`, `prog(a)=f0`,
  `prog(b)=f0 f0`. `Q`: `n=3`, `Sigma=(succ, pred)`, `prog(a)=f0`, `prog(b)=f1`.
- `W-STATESPACE` — separates `L2` from `L3(1)`. `P`: `n=2`, `Sigma=(swap, id)`, `prog(a)=f0`,
  `prog(b)=empty`. `Q`: `n=3`, `Sigma=(tau01, id)`, `prog(a)=f0`, `prog(b)=empty`.
- `W-OVERHEAD` — separates `L3(1)` from `L2` in the other direction and from `L4`. `P`: `n=3`,
  `Sigma=(succ, id)`, `prog(a)=f0`, `prog(b)=empty`. `Q`: `n=3`, `Sigma=(pred, id)`,
  `prog(a)=f0 f0`, `prog(b)=empty`.
- `W-BEHAVIOUR` — separates `L3(5)` from `L4`. Constructed by the executor as the
  lexicographically first pair of `U` in `L4` and in no `L3(k)` for `k <= 5`; if no such pair
  exists in `U` the executor must publish `L3(5) = L4 ON U` and say so, and the corresponding
  strictness claim is withdrawn rather than restated.

## 4. What is computed

1. every relation above, on every ordered same-regime pair of `U`;
2. the full `4 x 4` inclusion matrix over `{L1, L2, L3*(1), L4}` where `L3*(k)` is the
   transitive closure of `L3(k)` — `L3(k)` is only reflexive and symmetric by construction,
   because composing two compilers of overhead `k` gives overhead `k^2`, so it is a tolerance
   and not an equivalence, and only its closure has a place in a lattice of equivalences;
3. whether `L3(k)` is in fact transitive on `U` (an explicit non-transitive triple, or the
   statement that none exists at this scope);
4. the sublattice of the partition lattice on `U` generated by
   `{L1, L2, L3*(1), L3*(2), L3*(3), L3*(5), L4}` under meet = intersection and
   join = transitive closure of union: its element count, its Hasse diagram, and whether the
   meet and join of any incomparable pair are new elements;
5. `k*`, the least `k` for which `L2` is contained in `L3(k)` on `U`, or the statement that no
   `k <= 5` suffices;
6. the exact level of each registered witness: the finest level at which the pair holds together
   with certified failure at every finer level.

## 5. The gates, fixed before any run

`status: GREEN` requires **all** of:

1. every relation is reflexive and symmetric; `L1`, `L2`, `L4` are additionally transitive
   (an equivalence relation) and the executor proves it by exhaustive triple check;
2. `L1`, `L2`, `L3(k)` for every registered `k`, and `L4` all imply equality of `beh` —
   checked on every related pair, with zero exceptions;
3. **anti-vacuity**: every level is strictly between the identity relation and the total
   relation on `U` — neither a level that relates nothing beyond `P` to itself, nor one that
   relates everything, may be published as a level;
4. every claimed strict inclusion carries an explicit separating pair, and every claimed
   incomparability carries a pair in each direction; a claimed strict inclusion with no
   separator is republished as an equality;
5. route A and route B agree on every published quantity, route B importing nothing from route A;
6. every declared hostile is detected, each paired with a control proving the perturbation moves
   the quantity it claims to move;
7. the null reproduces the certified witness placement in `0` of its live draws;
8. the no-alarm case is asserted: on the unperturbed configuration every detector is silent.

Any failure publishes `status: RED` with the failing gate named. A red result is a result.

## 6. Falsifiers, fixed before any run

- If `L1` is not contained in `L2` on `U`, the claimed bottom of the lattice is wrong and the
  order claim is void.
- If `L2` and `L3(1)` turn out to be comparable on `U`, the diamond claim is withdrawn and the
  computed chain is published in its place.
- If any level relates a pair whose behaviours differ, that level's definition is wrong and the
  level is withdrawn, not repaired after the fact.
- If `L3(k)` is transitive on `U` for every registered `k`, the tolerance-versus-equivalence
  distinction is not exhibited at this scope and must be reported as unexhibited rather than
  asserted from the `k^2` argument alone.
- If the observation window `W - 1` and `W` disagree on any `L4` verdict, the window is
  insufficient and every `L4` number is void.
- If a randomized level assignment reproduces the certified witness placement, the placement is
  not identifying and the placement claim is withdrawn.

## 8. What is not claimed novel

Term equivalence of algebras and clone equality (Birkhoff 1935, doi:10.1017/S0305004100013463;
Lawvere 1963, doi:10.1073/pnas.50.5.869; Taylor's clone theory), the Myhill-Nerode theorem
(Nerode 1958, doi:10.1090/S0002-9939-1958-0135681-9; Myhill 1957), strong bisimulation
(Park 1981, doi:10.1007/BFb0017309; Milner 1980, doi:10.1007/3-540-10235-3), compiler
correctness up to a simulation relation with a charged overhead, and transformation-monoid
generation are all parent mathematics. They are pinned in `PARENT_LEDGER.md`. The residual
contribution of this tranche is the exact order computation between these four already-classical
notions **as strengths of presentation equivalence over one registered finite universe**: the
inclusion matrix, the strictness certificates, the incomparability, the generated sublattice, and
the exact placement of each registered witness.
