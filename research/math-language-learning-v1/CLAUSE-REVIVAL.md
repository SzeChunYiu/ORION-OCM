This is default-off supplied symbolic machinery. It does not invent resolution.
The constructor fixes one complementary-pivot, two-clause, three-role topology.
Observed training proofs determine the actual cover, pivot position, original
residual expressions, substitution and intermediate-to-query weakening linkage.
Different valid traces can therefore activate the same generic resolution schema.
This strengthens the available mechanical repertoire; it does not establish
endogenous generation of a new method structure.

The independent universal checker and ordinary rule data schema are unchanged.
The >=2 distinct original semantic-task support criterion remains an acquisition
criterion, not a requirement for mathematical soundness. Alias tasks cannot supply
a second support. Logical validity, observed discovery, development selection,
current proof authority and use remain separate.

  The independent support checker additionally checks the original instantiated
  dependencies, their essentiality and exact original certificate cover.

- acquire_selected(..., dependency_donor=False) and both store adapters forward

- The old structural application route runs first. On a miss, normalized matching
  can assemble an ordinary answer certificate plus a clause-link record. Direct
  AST/model checks independently validate source/instance equivalence and
  resolvent-to-target implication; no optimized query solve is called.
- Shared postings expose eligible rules to both equivalent universal surface
  kinds, preserving sorted method order and current liveness checks. Both arms
  charge the additional postings/probes. This matching treatment is supplied to
  the conventional parent too, even when the new donor is disabled.
- The donor-off developmental comparison therefore isolates donor activation

pivot/complement attempts, subset tests, role/mapping/binding work and independent

are not fully represented by those logical counts; outer CPU/wall observations
remain necessary. Fixed selector tie fields are not redefined as a complete cost.

is included. The process/containment route has not been requalified on this source.

recovery, or a new scientific replication. Any final evaluation stays separate.
