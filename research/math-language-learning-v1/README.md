A checked training answer can expose a universal witness cover. The miner enumerates
proper two- or three-premise subsets, canonicalizes their Boolean predicate parameters,
and checks every point assignment independently. Every premise must be essential:
deleting it must admit a counterassignment. Tautologies, one-premise primitives and
irrelevant padding cannot count as composite methods. Two supports must have distinct
training-only semantic fingerprints after all predicate renamings.

The matcher instantiates an acquired schema on Boolean expressions, builds a cover
certificate, and returns a proposal. The original independent unary verifier checks
that proposal against the complete task. Successful proposal construction is neither
admission nor proof authenticity. The separate [runtime seam](RUNTIME-CONTRACT.md)
supplies checked issuance, live support and final answer checking.

The prepared exact parent is shared with both prospective adaptive arms. Preparation
compiles premises and proves base consistency; it does not compute either query branch.
Completing the parent reuses its allowed-region aggregate and existential obligations.
