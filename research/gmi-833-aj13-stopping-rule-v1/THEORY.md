# AJ13 — recursive foundation-descent stopping rule

## Purpose

AJ does **not** stop because a vocabulary sounds fundamental. It stops only when every remaining lower assumption is explicitly outside hidden machine-intelligence mechanism content, each retained operational role has a demonstrated scope-relative necessity, higher results survive registered alternative presentations/foundation styles, and parent ownership is explicit.

The registered stopping predicate has six conjuncts:

1. **Tagged residual assumptions.** Every unresolved base assumption is typed as `MATHEMATICAL_FOUNDATION`, `LOGIC/METATHEORY`, `PHYSICAL_SUBSTRATE_LAW`, `RESOURCE_MODEL`, or `VALUE/REQUIREMENT_INPUT`.
2. **No MI-specific base primitive.** The AJ1 operational base contains only typed process/interface/composition/admissibility/observation roles; named mechanisms such as neuron, memory, attention, planner, world model or backpropagation are forbidden at the bottom.
3. **Removal has a demonstrated boundary.** AJ1's requirement-relative irredundancy map supplies a loss witness for the registered operational roles `TYPE`, `SEQUENCE`, `PARALLEL`, `NO_CHANGE`, `SUBSTRATE_ADMISSIBILITY`, and `OPERATIONAL_OBSERVATION`.
4. **Higher results survive alternative presentations.** AJ5 supplies a lower-process-to-G0 derivation/presentation-invariance tranche and AJ12 supplies a two-style foundation/formalization transfer audit.
5. **Strongest parents retain ownership.** Process/category/operational semantics, model/foundation theory, computability and physical-computation parents are not renamed as GMI discoveries.
6. **Further descent changes domain.** The remaining downward questions concern logic/metatheory, mathematical foundation, physical law, or normative/value input rather than a concealed architecture or intelligence-specific mechanism.

If all six hold at the registered AJ scope, the permitted terminal is:

`FOUNDATION_RELATIVE_GMI_CORE_STABLE_AT_REGISTERED_SCOPE`.

This is a **relative scientific stopping rule**, not a metaphysical finality claim. The terminal

`ABSOLUTE_BOTTOM_OF_MATHEMATICS_OR_REALITY_PROVEN`

is forbidden.

## Recursive hostile rule

The executable checker mutates one stopping condition at a time: invalid assumption tag, injected MI-specific primitive, removed AJ1 loss witness, removed cross-foundation evidence, missing parent ownership, and absolute-bottom promotion. Every hostile must reject the stopping terminal.
