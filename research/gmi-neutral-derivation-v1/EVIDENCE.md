## Mathematical and implementation controls

The orbit compiler's generic RREF kernel is checked against independent full
finite-action orbits and Burnside counts, followed by table execution. Complete
raw tables, not chosen sample rows, are checked for affinity and symmetry.
An exact finite noise distribution checks the projection-risk identity.

Memory search generates every set partition of eight database states into
at most four retained symbols, including nonlinear codes. Synthesized
acquisition and retrieval trees execute on every relevant state. A separate
exhaustive full-read-order oracle checks all canonical Boolean encoders on
three inputs and all partitions on two inputs. The general entropy law proves
the minimum projected cost. Complete optimal memory-size fibers are also
checked in the registered finite cases, not asserted as an additional general
theorem about all equality cases.

The neutral search preserves complete truth and per-input resource traces
under syntax composition, retains multiplicities, and has an independent
raw enumerator at the development bound. The larger three-input bound has
12,923,905 raw terms, represented by exact trace fibers. It does not enumerate
every unbounded program or identify arbitrary syntax from trace equivalence.
Correct class minima and all tied properties are checked, along with altered
programs, traces, multiplicities and omitted/duplicated optimum controls.

Factor programs are checked against independent complete assignment
enumeration. Tests cover inconsistent global constraints with local support,
isolated variables, zero/scalar factors, nonuniform domains, infinity,
unfavorable orders and complete ties. Scalar operations and order-search
work are charged under the declared abstract schedule.

Analytic proofs and the implementations received an independent agent review.
That review found a neutral certificate metadata gap: the initial optimum
checker did not bind representative program/multiplicity or reject duplicated
winners. The repaired checker adds those obligations; the registration and
mathematical predictions are unchanged. First-run source and measured receipts
are preserved under `raw/`, with their separate bindings. Their timing is a
single-run implementation observation, not a hardware scaling law.

## Reproduce on the verification host

From the repository root, on laptop billy or an authorized verification host:

```sh
python3 -I -B research/gmi-neutral-derivation-v1/verify_unit.py --receipt /tmp/gmi-neutral-normal.json
python3 -I -O -B research/gmi-neutral-derivation-v1/verify_unit.py --receipt /tmp/gmi-neutral-optimized.json
cmp /tmp/gmi-neutral-normal.json /tmp/gmi-neutral-optimized.json
python3 -I -B research/gmi-neutral-derivation-v1/verify_controls.py --receipt /tmp/gmi-neutral-controls.json
python3 -I -B research/gmi-neutral-derivation-v1/verify_manifest.py
```

`UNIT_FREEZE.json` binds source bytes, registrations, the test inventory and
complete deterministic replay. `SHA256SUMS` binds that freeze. The verifier
compiles inventoried module bytes directly, defeating stale bytecode; it
checks custody again after execution. Exit0 means CHECKED,1 a witness failed,
and2 NOT_CHECKED. Missing or altered inputs are never treated as a success.

The integrity controls run the actual unit in an unchanged copy and with
valid-looking stale bytecode, then attack source, registration and freeze
bindings. `MANIFEST_V1.json` separately binds every delivered payload except
itself, including raw evidence and both final replay receipts. No test suite,
scratch checkout or worker pool is run on the Mac.

## Limits that passing cannot remove

These are exact finite executions plus reviewed analytic derivations, not
proof-assistant kernels, noisy real-world ecology studies, broad neural
training comparisons, independently held-out families or new-form evidence.
Scalar arithmetic/access accounting is distinct from actual precision, CPU,
energy, code/index and communication costs; each theorem names its boundary.
The [six-gap map](SIX_GAPS.md) retains those concrete outstanding obligations.
