# Executable synthesis and quantitative architecture selection

This supplement generates executable programs, verifies every finite input, and measures their actual instruction traces. The first protected laptop replay matched all **13** registered scenarios: four development cases, eight parameter holdouts and one function holdout. This is a complete result for the bounded grammar below, not recovery of neural learning or a previously unseen architecture family.

## 1. Frozen operational model

For input arity d≤16, programs are ordered expressions generated by

    P ::= constant(0) | constant(1) | read(i)
        | binary(t,P,P) | if(P,P,P),       0≤i<d, 0≤t<16.

`binary` eagerly evaluates both children and returns bit (2a+b) of its four-bit truth table t. All sixteen tables are generated; no target function receives a privileged named instruction. `if` evaluates its first child and only the selected arm. Constants, reads, binary instructions and branches have fully specified executable semantics in [neutral_machine.py](neutral_machine.py).

Every expression node occupies **seven description bits**, including three opcode bits and four parameter bits. The binary truth table and read index therefore have an explicit storage charge. Fixed arities make the prefix encoding uniquely parseable. Unused parameter bits are fixed to zero. The complete expression is stored, including unevaluated arms. Repeated reads incur a new observation charge each time; there is no free cache or implicit common-subexpression sharing.

For a program with n nodes and independent Bernoulli-p input coordinates, define

    J(P)=7sn + E[q·reads(P,X)+a·binary(P,X)+b·branches(P,X)].

All probabilities and prices are exact rational numbers. The resource quantities come from execution traces; these prices are registered abstract prices, not measurements of a particular processor. The protected contract uses q=1, a=1/10, s=1/700, positive branch prices, and 0<p<1.

The input is a supplied complete truth table. Programs must match **every** input, including low-probability inputs. This unit synthesizes exact realizations; it does not learn truth tables from partial observations.

## 2. Complete enumeration theorem

The finite scope is d=2 with at most four nodes, and d=3 with at most seven nodes. There are no family candidates, supplied program costs, heuristic rankings, stochastic proposals, or expected-property filters in [neutral_search.py](neutral_search.py).

**Theorem N1.** `enumerate_space(d,C)` covers every ordered expression of size at most C, modulo an equivalence preserving its complete truth table and every input's read count, binary count, branch count and read mask, at the same description size. Its multiplicities count all raw expressions. Minimization returns every optimal equivalence class, not one tie-broken representative.

**Proof.** Constants and indexed reads exhaust size one. An expression of size n>1 has either a binary root, sixteen possible parameters and children of sizes i+j=n−1, or an `if` root with child sizes i+j+k=n−1. Enumeration takes every positive size partition and every ordered child class. The output and four trace quantities of each parent are determined solely by its children's signatures; for `if`, the condition's output determines which child contributes its trace. Equal signatures at equal size are therefore a congruence for every grammar context. Replacing a child by its representative loses neither a parent signature nor its exact price. Induction proves exhaustive coverage and quotient soundness.

For multiplicities, each root constructor and ordered child tuple identifies a unique raw expression. Multiply child multiplicities, then add over collisions. Consequently raw counts satisfy

    A₁=d+2,
    A_n=16 Σ_(i+j=n−1) A_i A_j + Σ_(i+j+k=n−1) A_i A_j A_k.

The implementation checks this independently computed recurrence at every size. It retains all minimum-cost classes across all eligible sizes. ∎

An independent raw enumerator, [neutral_oracle.py](neutral_oracle.py), constructs actual expressions without quotienting. At the complete development boundary it agrees on **every signature and multiplicity**, and its programs are evaluated by the independent trace interpreter rather than the synthesis composition equations. At the larger boundary, completeness follows from N1 and the checked recurrence; no claim is made that the raw oracle separately materialized every larger expression.

The quotient preserves the declared execution properties and objective. It does not preserve arbitrary syntax, authorial intent, internal naming or unrecorded side effects. One canonical program and the exact raw multiplicity represent each class; syntax-based property claims would need a finer quotient.

## 3. Quantitative derivation: three-input conjunction

For AND of d independent identically distributed Bernoulli-p bits, every exact evaluator must keep inspecting when its observations are all ones and an input remains unread: flipping an unread bit to zero changes the correct answer while preserving its observed transcript. Each fresh inspection returns one with conditional probability p. Thus the minimum expected number of reads is 1+p+...+p^(d−1), attained by stopping at the first zero. This is an observation lower bound, not by itself a minimum-total-cost claim.

For d=3 and the seven-node grammar boundary, every expression with B binary nodes and I branches has size 1+2B+3I. Therefore its only potentially optimal exact cases are I=0, I=1 or I=2.

* **I=0:** dependence on all three bits requires at least three reads and two binary nodes. A five-node program attains cost E=3q+2a+35s. Larger eager programs cannot reduce either lower bound and have greater description cost.
* **I=1:** without a binary node, a four-node branch over leaves cannot express three-input conjunction. With one binary node there are six nodes. The cheapest placement tests one input, returns zero immediately on zero, and otherwise eagerly combines the remaining two inputs. It attains M=q(1+2p)+ap+b+42s. If the binary node instead forms the condition, the best corresponding charges are q(2+p²)+a+b+42s; these exceed M by q(1−p)²+a(1−p). If the binary node is above the branch, its best charges are q(2+p)+a+b+42s, exceeding M by (q+a)(1−p). These exhaust the single-binary/single-branch placements; constants losing a required variable are inadmissible, and rereading an already fixed condition value cannot improve these bounds.
* **I=2:** there are exactly seven nodes and no binary nodes. The read lower bound is 1+p+p². At least one branch always executes; on an initial one, two further relevant inputs must still be distinguished, requiring the second branch. Placing a branch inside the outer condition executes both branches unconditionally and cannot improve this bound. A nested conditional program attains C=q(1+p+p²)+b(1+p)+49s.

Thus for strictly positive prices and 0<p<1 the complete minimum is

    min_P J(P) = min{E,M,C}.                              (N2)

This compares all grammar programs by their possible node counts and placements, rather than supplying those three programs as the search universe. The synthesized program certificates and complete enumeration independently check the registered instances of the law.

The conditional/mixed tie occurs at b₁=q(1−p)+a−7s/p. The mixed/eager tie occurs at b₂=2q(1−p)+a(2−p)−7s. Their difference is (1−p)(q+a+7s/p)>0. When b₁>0, increasing the branch price therefore selects conditional execution, then mixed execution, then eager execution; both neighboring properties belong to the optimum at each boundary. When b₁≤0, the conditional interval may be absent for positive branch prices.

At p=1/2 and the registered prices, b₁=29/50 and b₂=57/50. The three protected representative minima are 439/200 at b=1/4, 143/50 at b=3/4, and 13/4 at b=3/2. Both exact ties and three p=2/3 parameter holdouts were registered before execution and recovered. “MIXED” is an observed combination of branch execution and binary computation, not a new historical architecture claim.

## 4. Function holdout and universal quantifiers

Three-input parity is a **function holdout**, not an unseen family. Every exact parity transcript must read all three distinct inputs, since flipping any unread input flips parity without changing the observed transcript. Eager five-node programs attain three reads and two binary operations. Within seven nodes a branch representation cannot improve this: one branch plus at most one binary node lacks the complementary two-input computations needed in its two arms, while two branches without binary nodes cannot represent all eight parity assignments. Complete search recovered the eager optimum 13/4.

A minimum is not established by beating one convenient witness. We compare minima over the complete registered space and retain all optimal trace fibers. The corrected property statement is about the entire optimal fiber: a non-F winner alone does not exclude an equally optimal F realization.

## 5. Registration, receipts and measured acquisition work

[neutral_registration.json](neutral_registration.json) was frozen before any synthesis run with SHA256 `3f9690238b81bf06b70e09763396e245a4ebcc942af7ab45df2af25da0fba1a3`. Expected properties and costs are checked only after complete enumeration and ranking. They do not enter candidate generation or the objective.

The first protected receipt is preserved at [raw/NEUTRAL_FIRST_RECEIPT.json](raw/NEUTRAL_FIRST_RECEIPT.json), with its original source snapshot under `raw/first-source/`. It records all 13 predictions as checked. For arity three, raw exact-size counts were `[0,5,0,400,125,64000,50000,12809375]`; trace-class counts were `[0,5,0,74,77,286,2826,3057]`. Enumeration required 169391 class compositions and 1355128 signature-cell calculations; the reported laptop enumeration time was approximately 0.779 seconds. These are measured counts and one runtime observation, not a scaling-law estimate.

Synthesis cost is reported separately from candidate operation cost. It is shared by every candidate selected from this one complete enumeration, so adding that common acquisition work cannot change its within-space minimizer. End-to-end comparison against a previously available program must charge acquisition, verification and encoding, then serving over the declared lifetime. This unit does not establish a lifetime-cost advantage over such a baseline. `neutral_runner.py` records resource counts, runtime and process peak memory; `deterministic_receipt` removes only the three named timing/memory fields for exact scientific replay. Exclusive receipt writes preserve the first result.

## 6. Controls, parents and claim boundary

[test_neutral_synthesis.py](test_neutral_synthesis.py) contains thirteen development control methods, including exhaustive raw-oracle agreement, duplicate-read charging, full semantic replay, both tied property types, omitted optima, altered traces, forged multiplicities, substituted representatives, duplicate winner entries and false predictions. A grammar miss has a distinct error from a false prediction. Verification runs belong on the designated laptop.

The bounded grammar/specification formulation adapts [Alur et al., *Syntax-guided synthesis* (2013)](https://escholarship.org/uc/item/1g67m7hp). Exhaustive size enumeration and observational quotienting are known synthesis techniques; the new unit supplies this concrete trace-cost contract and auditable execution. Its exact truth tables replace a solver-based semantic oracle; there is no claim to reproduce the paper's CEGIS implementations.

The indistinguishable-transcript arguments use the decision-tree/certificate-complexity framework described by [Buhrman and de Wolf (2002)](https://homepages.cwi.nl/~rdewolf/publ/qc/dectree.pdf). Our finite priced-expression frontier additionally charges binary instructions, branch instructions and stored opcode parameters. These charges are model assumptions, not consequences of GMI without an observer and resource contract.

Operational neutrality means every admitted primitive and term is treated by the same registered rules. It does not mean prior-free computation or invariance under arbitrary changes of grammar, encoding, observer, resource prices or semantic obligations. No independently authored second expressive grammar, neural learner, general learning theorem, unbounded synthesis procedure, new physical machine or novel intelligence family is established here.
