# R3 — contextual attainability as the master derived object

For start configuration x and context kappa, let Hist_S(x) be the admissible finite histories beginning at x. Define

A_kappa(x) = { nu_kappa(h) | h in Hist_S(x) }.

For a budget predicate B, define Hist_S^B(x) as the histories satisfying B and A_kappa^B(x) as its contextual image.

## R3-1 monotonicity
If H1 is a subset of H2 then image_nu(H1) is a subset of image_nu(H2). Hence increasing the admissible/budgeted history set cannot delete an attainable contextual value.

## R3-2 frontier
At finite registered scope with a declared preorder, the frontier is the set of attainable values not strictly dominated by another attainable value. No existence of maximal elements is asserted for arbitrary infinite preorders without compactness/well-foundedness/etc.

## R3-3 derived objects
- capability relative to a success predicate G is simply existence of w in A with G(w);
- resource response is projection of A to declared resource coordinates;
- impossibility of target T is A intersect T = empty;
- a registered barrier is an identified missing history/condition whose admission would make the target intersection nonempty;
- selection/preference is maximality/frontier under the context order;
- parameter-driven phase change is a change in frontier/selected argmax as context parameters vary.

Thus Gamma/Pref/SEL are permitted abbreviations for projections/order operations but are removed from the universal foundation.

## Scope boundary
This does not auto-transport every historical Gamma theorem; each theorem must be checked against the new definitions and its old quantifiers.
