# AJ9h freeze — five remaining known-family holdouts

This commit freezes the five remaining AJ9 holdout tasks **before** blind implementations/outcomes/post-hoc family adjudication.

## Allowed causal inputs

The blind lane may see only the registered operational substrate, task/environment dynamics, protected acceptance conditions, generic data structures/operations, raw resource costs, and generic search/development operators. It may not read `KNOWN_FAMILY_BENCHMARK_V1.json`, any family id/name/fingerprint, or any post-hoc adjudication artifact.

Frozen task contracts:

1. `future_consequence`: finite two-step controlled transition system with an immediate-score trap; success requires the first external choice maximizing total registered horizon return, not immediate score.
2. `keyed_store`: three persistent key/payload records; a later two-bit query must cause the corresponding payload to affect the protected output. Generic equality/Hamming comparison, finite indexing and conditional choice are allowed.
3. `set_variation`: finite search state may retain zero, one or two descriptions; generic component-copy/combination and a frozen score function are allowed. Success requires reaching a target that the best one-retained-description greedy law cannot reach under the same two-round/evaluation budget.
4. `expression_output`: finite expression language `{x0,x1,0,1,NOT,AND,OR}` plus protected I/O specification. Success requires returning an executable expression satisfying all tests; no target expression/template is supplied.
5. `persistent_change`: two-task sequence over a generic reusable-operation library. Development may propose an admitted persistent library addition only through the AJ6/AJ5 generic development/adoption interface. Success requires lower cumulative charged cost on task 2 while preserving protected semantics; direct target installation is forbidden.

## Frozen bias / prior boundary

These are **ecology-conditioned blind-recovery tests**, not literal historical-ignorance simulations. Task authorship, primitive basis, horizon/budget, resource prices, and evaluator contract are explicit priors. A positive result supports `RECOVERED_AT_REGISTERED_TASK_AND_BASIS_SCOPE`, not `INEVITABLE_WITHOUT_ANY_PRIOR`.

Two materially distinct procedures are required for every task: one exhaustive/enumerative route and one independently structured dynamic/constraint/branch route. Failure is allowed and must return `NOT_RECOVERED_AT_SCOPE`.

Post-hoc family mapping may run only after blind outcomes are frozen. The benchmark remains the frozen AJ9a blob already on `main`.

Claim ceiling if all five recoveries pass: `AJ9_K07_K11_BLIND_RECOVERY_AT_FROZEN_TASK_AND_PRIMITIVE_BASIS_SCOPE`.

Forbidden: literal human-history counterfactual proved; family inevitability; universal optimality; `PREDICTED_SELECTED`; complete GMI.
