# GMI development spine v1

This research capsule supplies the bounded exact H-section spine for issue #602 before any broad G7 developmental claim is attempted.

It defines and tests seven objects: current capability versus future learning potential, adaptation burden, useful-descendant mass/evolvability, morphology-search burden, transfer benefit/harmful transfer, developmental path dependence, and optional inheritance monotonicity at its actual free-option scope.

The executable model uses finite developmental state graphs with nonnegative fully charged transition costs. `FORMALIZATION_V1.md` gives the shortest-path and feasible-set proofs; `DEVELOPMENT_SPINE_V1.json` fixes scope, parents, twins and falsifiers; `test_development_spine_v1.py` includes constructive witnesses, hostile scope checks and an exhaustive 729-relation optional-inheritance control.

Claim ceiling: **G2**. This capsule is not evidence that continued development empirically beats reset, that inherited structure is free, or that open-ended evolvability has been achieved.
