# Parent literature anchors for #833 foundation v1

This list is a terminology/proof boundary, not a priority claim.

- John R. Rice (1976), “The Algorithm Selection Problem,” *Advances in Computers* 15:65–118. DOI: `10.1016/S0065-2458(08)60520-3`. Parent for problem/feature/algorithm/performance-space selection framing.
- David H. Wolpert and William G. Macready (1997), “No Free Lunch Theorems for Optimization,” *IEEE Transactions on Evolutionary Computation* 1(1):67–82. DOI: `10.1109/4235.585893`. Parent for the requirement that algorithmic advantage depends on restricted problem structure/distributions.
- Sumit Gulwani, Oleksandr Polozov, Rishabh Singh (2017), *Program Synthesis*, Foundations and Trends in Programming Languages. DOI: `10.1561/2500000010`. Parent for specification/program-space/search framing.
- Jan Leike and Marcus Hutter (2015), “Bad Universal Priors and Notions of Optimality,” COLT/PMLR 40:1244–1259. Parent warning on universal-machine/prior dependence.
- Standard formal-methods terminology: a formal specification mathematically describes intended system behavior; verification is a separate conformance/proof activity.
- Standard multiobjective optimization: Pareto order is primary; positive weighted sums are monotone for dominance, while weighting imposes a preference among incomparable vectors.
- Myhill–Nerode/minimal-state, bisimulation/state abstraction, sufficient-statistic and predictive-state literatures are parents for exact/approximate behavioral-state quotients. Detailed subsumption boundaries are deferred to the dedicated #833 child audit.
