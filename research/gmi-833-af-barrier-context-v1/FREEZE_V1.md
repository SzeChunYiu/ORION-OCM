## 2. Frozen AF1 object — developmental capability response

For registered substrate/context `S`, initial machine/state `M0`, admissible development law family `Delta`, provenance-bearing information/development channels `Pi`, resources `R`, horizon/history budget `H`, requirement family `Q`, and verifier/governance contract `V`, define the set-valued response

`Gamma_{M0,Delta}^S(Pi,R,H,Q,V)`

as the set of reachable **capability/resource/provenance profiles**, not a scalar winner.

A profile in this tranche has fields:

- `capability`: exact registered task score vector;
- `resources`: raw finite resource vector;
- `provenance`: set/multiset of channels actually consumed on the path;
- `machine`: terminal finite machine identifier;
- `history`: finite development trace.

Architecture names are forbidden from the object definition.

The current realized capability is the zero-development/current-state slice and does **not** determine `Gamma` in general.

The data-independent possibility set `M(S)` is distinct from the history/context-conditioned reachable set. Membership in `M(S)` does not imply reachability.

Frozen provenance tags:

1. `INITIAL_OR_INHERITED_ORGANIZATION`
2. `EXTERNAL_OBSERVATION`
3. `REWARD_OR_EVALUATOR_SIGNAL`
4. `ENDOGENOUS_COMPUTE`
5. `STOCHASTIC_VARIATION`
6. `ORACLE_ADVICE_OR_TOOL`
7. `SOCIAL_OR_CULTURAL_TRANSFER`
8. `PHYSICAL_OR_ENVIRONMENTAL_SIGNAL`

Any capability gain using a target-correlated imported channel must retain that provenance in the emitted profile.

### AF-T01 — Null Target-Information Acquisition [P1 parent-specialization]

Let target `Theta` be independent of `Z=(M0,W)`, where `W` includes all internal randomness and all channels admitted under the chosen null condition. If terminal state `Mt=f(Z)` is a deterministic measurable function of `Z`, then

`I(Theta; Mt) = 0`.

This is an elementary independence/data-processing specialization. AF does not claim a new information theorem.

Load-bearing assumptions: target independence from `Z`; no hidden target-correlated channel; the declared channel set is complete for the run.

The finite checker must include all four frozen distinctions:

- dormant target information already present in `M0`: capability/accessibility may rise under compute-only unfolding with no **new** target information;
- independent random novelty: output entropy may rise while target mutual information stays zero;
- target-correlated oracle/advice: capability may rise but terminal is `IMPORTED_ORACLE_OR_ADVICE_POWER` rather than no-information creation;
- genuinely no target information: terminal `NO_TARGET_INFORMATION_ACQUIRED`.

A barrier context is

A barrier transition record must carry:

- source context/status;
- target context/status;
- changed axis/axes;
- original premise set;
- retained premise set;
- extra power and/or weakened output requirement;
- nearest residual barrier;
- classification among domain restriction, promise problem, approximation, semidecision, abstention, list/set output, certificate, interaction/query, oracle/advice, randomness, resource relaxation, substrate expansion, or literal contradiction.

### AF-T02 — Optional-extension monotonicity [P1 corollary; parent HST-T01]

If target context adds only **optional** resources/channels, every old strategy remains admissible with identical semantics and zero mandatory overhead, and the objective/order is unchanged, then the old reachable profile set embeds in the new one. Corresponding best-achievable capability cannot worsen at fixed resource accounting.

This is not a new theorem; it is a context-level corollary of HST-T01.

The checker must include a mandatory-overhead hostile where adding a channel/resource makes the net registered objective worse, proving that naive unconditional monotonicity is false.

### AF-T03 — No barrier-breaking by premise change [governance rule]

The label `BROKE_<THEOREM_OR_BARRIER>` is rejected unless:

1. the original theorem/barrier premise identifiers are all retained;
2. the source and target problem/output contracts are extensionally the same at the registered scope;
3. an explicit contradiction witness is provided and independently checkable.

Otherwise the transition must be typed as displacement, relativization, contract weakening/change, approximation, extra information/advice, or another frozen transition class.

The checker validates this record discipline; it does not decide arbitrary mathematics.

No terminal may be `SOLVED_FOREVER`.

## 5. Frozen finite microscope fixtures

The post-freeze executor must use only the following fixture families unless a new freeze supersedes this document.

### F1 — same current capability, different developmental response

Unary Boolean task, current constant-0 policy for both systems. System A may perform one registered table-entry repair; system B is frozen. Both start at accuracy 1/2; A can reach 1 while B remains 1/2.

### F2 — different current capability, same reachable envelope

Identity and NOT initial policies are both permitted a registered reset-plus-repair path whose reachable terminal policy set is the same complete four-policy unary-Boolean set. Initial scores differ; reachable capability set is identical.

### F3 — null compute unfolding

Target bit is already encoded in dormant initial state but the initial action head is constant. A deterministic internal reveal exposes the stored bit to the action head. Accuracy rises 1/2 -> 1 with zero new external observations and no new target information.

### F4 — random novelty

Independent fair target bit and fair random bit. Random output has one bit of entropy, zero mutual information with target, and expected target accuracy 1/2.

### F5 — imported advice

An oracle channel returns the target bit. Perfect accuracy is allowed only with `ORACLE_ADVICE_OR_TOOL` provenance and `IMPORTED_ORACLE_OR_ADVICE_POWER` terminal.

### F6 — optional-vs-mandatory resource extension

Base has strategy A with benefit 10 and cost 2. Optional extension adds strategy B but preserves A at cost 2, so optimum cannot worsen. Mandatory extension imposes overhead 12 on every strategy, making the previous net objective strictly worse. Numbers are fixed now to prevent outcome tuning.

### F7 — barrier-transition typing

Static records only:

- unrestricted exact verification -> sound incomplete abstraction: approximation/contract route, never contradiction;
- undecidable general problem -> decidable finite promise slice: domain restriction/promise route;
- single-answer identification -> finite-list identification: output-contract weakening;
- base computation -> oracle-relative computation: extra-power/relativization route.

These records inherit parent statuses. The executor checks classification invariants; it must not present F7 as independent proofs of the parent theorems.
