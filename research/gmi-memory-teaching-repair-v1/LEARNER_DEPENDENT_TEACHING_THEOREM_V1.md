# Adequate teaching before amortization

The immediate mechanism parent is machine teaching's encoder/learner constraint
A(D)=h (Zhu, Singla, Zilles, Rafferty, arXiv:1801.05927, section 2).
The cost comparison is inherited PVR-3. Neither identity alone creates a learner.

## MTT-1: a finite learner and a constructive encoder

Let H be all four Boolean functions on X={0,1}. An authoritative exact oracle
returns h(x). Teacher acquisition reads both bits. A message supplies, separately
at each x, either no label, label 0, or label 1: nine possible messages.
The learner is the lexicographically first or last hypothesis consistent with
the supplied labels, according to its registered one-bit mode.

For each h and mode, enumerate all nine messages; retain those with truthful
labels and learner output h; choose one with fewest supplied labels, breaking
ties by the fixed message order. Full labels always leave exactly {h}, so an
adequate message exists. Exhaustive filtering then proves cardinality optimality
within this message alphabet and this learner. It is not a universal teaching
dimension theorem. The independent oracle enumerates hypothesis/message truth
relations without calling the learner implementation.

The target 00 needs no labels under the first learner but two under the last.
A message for an unregistered decoder need not teach its intended target.
Re-encoding for the actual learner repairs this failure at a charged cost.

## MTT-2: explicit transfer, not an asserted success flag

A message is two two-bit status symbols, plus the one-bit learner mode: five
bits even when there are no labels. The unused status symbol is rejected.
A receiver checks format and mode, executes its learner on those labels, checks
consistency, and stores the resulting two-bit hypothesis. Subsequent queries
read this stored hypothesis. Every h, both modes, and both query inputs are
checked. Transfer is an actual encoder/decoder composition.

Truth comes from exact teacher acquisition plus the faithful channel and the
verified teacher algorithm. Format and consistency checks do not authenticate
an untrusted teacher. The empty message consistently decodes to 00 under the
first learner and is wrong for the other three targets. More arithmetic spent
checking the same empty message cannot recover its absent information.
A receiver with access to the exact oracle can instead acquire both labels,
paying that access and storage cost. This is a constructive adequate fallback.

The learner needs no neural model. This four-function apparatus does not claim
a new acquired executable skill, broad language, innovation, or cultural growth.

## MTT-3: a fully declared finite ledger

The implementation records logical events for oracle access, finite search,
each hypothesis/label check, message read/write and checking, model storage,
retention, runtime installation, and serving. A supplied finite price vector
values every event. The common interpreter/program reservation B, installation,
and bit-time retention are charged to all agents. The rule code is a common
primitive of this declared machine, not a free native-program or hardware claim.
Temporary teacher/message state and per-agent model state are separately priced.
One broadcast writes the message to a shared channel; each receiver pays its
own read, verification, learning, storage, and eventual release. A different
network charging per-recipient transmission must charge those deliveries.

For a fixed target, learner, service schedule, and retention horizon, let C be
the complete cost of independently acquiring and then serving one agent.
Let S be teacher message synthesis, temporary retention, and the one broadcast,
in addition to the teacher's own C. Let U be a complete receiver lifetime.
Compare exactly these two adequate policies:
independent cost n C; teaching cost C+S+(n-1)U.

Thus teaching is strictly cheaper iff (n-1)(C-U)>S. If C<=U and S>=0,
there is no strict saving; otherwise the first integer n is
floor(S/(C-U))+2. Equality is a tie. The checker obtains C,S,U from the actual
recorded events and compares their literal sum at the boundary. Nonnegative
rational price examples are authored contracts, not empirical estimates.
An independent two-oracle-query comparator uses the same service and storage
interface. Two one-bit replies are necessary in the worst case to identify
four unconstrained possibilities, but this does not prove that comparator
globally optimal in all program representations or real resource ledgers.

## MTT-4: repeated transmission boundaries

For a fixed already acquired h and stable validity, repeated reuse can amortize
one-time synthesis. If new generations require new broadcasts, verification,
retention, or reacquisition, their costs recur. A fixed one-time remainder suffices for a limit equal to U. More generally,
for nU+R_n the average tends to U exactly when R_n/n tends to zero; an unbounded
sublinear remainder also qualifies. Naming a process “culture” proves neither. This apparatus transmits a fixed finite target and creates
no sequence of new skills. Sender incentives, adversarial trust, changing
learners, noisy channels, and evolving tasks require separate mechanisms.

A finite price inequality is a selection condition after adequate transfer;
it is not sufficient to establish that transfer or its causal effect.
