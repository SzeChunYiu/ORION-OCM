## Literal machine costs and exclusions

The memory representation has an exact bit layout for all local programs and
data. The common ISA interpreter is a supplied primitive with reservation B,
installation and retention costs. B is not measured native source length.
For the teaching apparatus the known common learner/teacher rule is likewise
part of the supplied runtime contract; its reservation is charged to each
agent, including the matched independent-acquisition comparator. No claim
that an arbitrary given B suffices to implement native Python is made.
Changing this common reservation does not change the compared saving.

Logical instructions are the registered cost units, not host CPU opcodes.
Memory reports separate instruction, read/write/validation, retention,
intervention, release and workspace coordinates. Teaching prices every
registered event with exact nonnegative rationals. Search charges nine message
scans and all learner hypothesis/label comparisons; the full candidate-output
table has 63 bits reserved during synthesis. Common control/interpreter
workspace belongs to the runtime reservation; the current target is the
teacher's retained two-bit model. Communication is one declared multicast
write plus separate receiver reads, checks, learner work and model storage.
Per-agent serving and retention are included in C and U. The common supplied
retention horizon covers the whole declared lifetime, including acquisition
and synthesis; it is not inferred native elapsed time. Teacher synthesis
actually precedes its model release in the comparison implementation.

Thus these are complete costs within the declared logical interface and
supplied reservations. They exclude unsupported claims about a real network,
hardware time/energy, minimum code over all representations, independently
learned algorithms, or a globally optimal competitor. If actual runtime,
teacher fidelity, access, storage or delivery costs differ, the complete
contract must be supplied before reusing the price comparison.

Event maps are complete lifetime counts, not Python object lifetimes.
The multicast buffer release is scheduled after the last receiver delivery.
Its returned audit string is a retained record, not physical storage reused
after release. One deterministic receiver trace prices each identical copy;
the charge sums include all n-1 copies, with no shared model or free read.
