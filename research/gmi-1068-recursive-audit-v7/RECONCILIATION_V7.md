## Positive result and exact assumptions

The theory compares deterministic observations using the decisions they permit,
without a probability distribution over worlds. Refinement transports every
coarse policy to a fine policy with the same pointwise loss. The converse uses
a binary-loss decision problem to expose any fine signal that merges worlds
separated by the coarse signal. This is a deterministic specialization of
established information-order and minimax theory, not a new universal optimum.

A constant price for information changes the value comparison by exactly that
price. Changes to available actions, admissible policies, losses, world sets,
stochastic observations or adversary timing invalidate the unqualified theorem.
These are tested boundaries, not silently supplied assumptions.

## What “no prior” means here

There is no chosen probability distribution on worlds. There is still a
declared possibility set, observation system, loss, action set, policy class
and resource model. The earlier R2 repair permits worst-case aggregation
without a fixed measure; V7 supplies a substantive decision theorem for that
choice. It does not show that every reasonable objective must be worst-case,
or eliminate assumptions from cognition.

For binary matching, internal randomization can reduce worst-case expected
loss when the adversary cannot observe the realized random action first.
That probability is a policy mechanism, not an environment prior. Changing
the timing changes the decision problem.
