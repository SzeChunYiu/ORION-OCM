The first external parent explicitly shows multiplicativity of fractional
packing/covering by primal/dual product arguments. It does not license replacing
an integral cover number by that fractional optimum. The JRC incidence proof
is direct finite counting, not an invoked unverified LP solver. Primary PDFs
are linked; exact internal parent bytes and commit are in SOURCE_PARENTS_V1.json.

No novelty is claimed for set cover, rectangle cover, conflict hypergraphs,
zero-error nonadditivity, integer rounding or the five-cycle. The contribution
is a complete scoped composition bridge with constructive finite witnesses and
independent checks for this repository's existing adequacy interface.

## Full relevant costs remain explicit

The optimized coordinate is the number of used symbols in one noiseless
classical message, or its optimally packed fixed binary width. Repeated uses of
a one-bit carrier are not a one-symbol transcript. No average-length, entropy,
variable-length, quantum-dimension or asymptotic rate assertion is made.

Register, separately, the costs of acquiring and verifying Γ, constructing the
cover, storing the relation and code, compiling the encoder/decoder, obtaining
both inputs, encoding, transmitting, decoding and producing the actual outputs.
A lifetime comparison must use one realized architecture on both sides, e.g.

    acquisition + synthesis + compilation + retained-storage rental
    + sum over deployments(encoding + transmission + decoding + output work).

The supplied exact solver counts uncovered-set states and candidate branches;
the selector oracle counts completed assignments; the C5 constructor counts
eight-element subsets examined. These counts describe those algorithms, not
minimum synthesis work, CPU time, energy or memory over all implementations.
Input labels, relation records, cached search states, code and witnesses occupy
storage beyond transmitted bits. Classical access to both inputs is an explicit
interface premise; adding a distributed acquisition link would need accounting.

The code constructs explicit finite lookup witnesses, but reports no table-bit
advantage. A literal-table comparison would have to permit equally shared,
deduplicated and optimized relation/code tables for the product parent. Even
that comparison would concern only its declared representation grammar, not
minimum length over arbitrary programs. The matched alphabet parent here is
already optimized over all legal local encoders and decoders and then packs
the product alphabet without padding.

The three-action witness saves an alphabet symbol but no fixed bit. The C5
witness saves one fixed bit per transmission under the registered interface.
It can still lose on total code, synthesis or lifetime cost. No global physical
Pareto winner, new empirical performance or completion of all GMI gaps follows.
