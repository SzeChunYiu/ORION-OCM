# Parent/result boundary

This lane absorbs prior work rather than renaming it.  The bridge claim is the **GMI-specific integration and evidence contract**, not invention of self-reference, self-modifying agents, evolutionary agent search, or metaproductivity.

| Parent | Donor result used here | Boundary / what GMI does not rename |
|---|---|---|
| Schmidhuber, **Gödel Machine** | Self-referential improvement machinery; verified rewrite concept; improvement process can be an object of improvement | GMI does not claim origin of provably self-referential self-improvement |
| **STOP: Self-Taught Optimizer** (arXiv:2310.02304) | Recursive scaffold improvement with a fixed underlying LM; useful negative boundary for “full” RSI | Repeated scaffold optimization is not automatically R3 in this taxonomy |
| **Gödel Agent** (arXiv:2410.04444) | Agent dynamically modifies its own logic/behavior under high-level objectives | Self-modifying agent logic is parent-owned; GMI adds the matched causal/authority boundary |
| **Darwin Gödel Machine** (arXiv:2505.22954) | Open-ended/evolutionary archive of self-modified coding agents and empirical descendant search | Archive-based self-modification/search is parent-owned |
| **SEAL** (arXiv:2506.10943) | Model-generated self-edits that can induce persistent weight updates | Persistent adaptation is not by itself evidence that `D` improved |
| **Absolute Zero** (arXiv:2505.03335) | Self-generated curriculum/reasoning tasks | Self-generated training data/curricula are a possible modification surface, not sufficient R3 evidence |
| **Huxley–Gödel Machine** (arXiv:2510.21614) | Explicit **metaproductivity-performance mismatch**; descendant/clade performance as signal of future improvement potential | GMI adopts the distinction, while keeping resource profiles and frozen-D causal comparison explicit |
| **Hyperagents** (arXiv:2603.19461) | Task agent and meta-agent in one editable program; meta-level modification procedure itself editable; reported accumulation/transfer of meta-level improvements | Editable modifier-of-modifier is a direct R3 parent; GMI does not claim this architecture/result as novel |

## GMI-specific synthesis target

The candidate contribution of this capsule is the conjunction:

```text
existing G6 evolvability triad (κ, Ω, χ)
+ explicit development operator D
+ recursive triad (κ_D, Ω_D, χ_D)
+ resource-matched frozen-D descendant counterfactual
+ protected evaluator/constitution boundary C
+ G7 lineage/heredity
= governed recursive evolvability evidence contract
```

No parent is weakened by this vocabulary.  If a parent uses a different self boundary or criterion, it should be classified under that parent’s stated definition first and only secondarily mapped into R0–R5.
