### The ecology, registered before it is built

`F08` (`SIGMA_H08R`). Tokenise `D` into its 104,334 whitespace-separated
tokens. The rule table is the **descriptor closure**: for every token `w`, all
prefixes of `w` of length ≥ 2. The exact total is

```
T = sum(len(w) - 1 for w in words) = 776,142 descriptors
```

A task is a query descriptor. The family is **rule systems / decision trees**:
a query is classified by testing threshold conditions against its own
properties (its length) and against its **stored context** (whether and how
often the query occurs among the stored descriptors, and which distinct
letters immediately follow it across stored descriptors — the trie fan-out at
the query). A decision rule is a conjunction of such tests. The stored-context
table of a stored descriptor `q` is

```
cnt(q)  = the number of stored descriptor occurrences equal to q   (membership count)
A(q)    = the set of distinct letters immediately following q across stored
          descriptors of length >= 3                              (association fan-out)
```

The protected interface is held-out exact prototype-agreement and held-out
exact sign-decision error count, over the exact decisions

```
y(q) = 1 iff len(q) <= 9 AND source-count(q) >= 2
```

where `source-count(q)` is the number of source tokens that have prefix `q`
(equivalently the number of descriptors equal to `q` over the full closure).
The label is a **threshold conjunction over the source**: a descriptor is
positive exactly when it is short (length ≤ 9) AND shared (recurring across
the vocabulary). This is the property a rule system would express as the
two-condition decision rule `LEN<=9 AND count>=2`.

Slices, fixed here before any fit: the descriptor list is partitioned by a
deterministic 7:1 rule registered below (see FREEZE_V1_SLICE_ADDENDUM.md for
the exact arithmetic form), giving

```
n_fit = (T * 7) // 8 = 679,124  >= 100k
n_held = T - n_fit = 97,018    >= 20k
```

which clears the R11 real-scale bar (n_fit ≥ 100k / n_held ≥ 20k on a
sha256-bound external REAL source, exact arithmetic, independent oracle).

## 5. Grammar

`G_DT`: a family-blind grammar derived ONLY from the sha-bound bytes of `D`.
Descriptor closure over the token vocabulary (prefixes of length ≥ 2), the
stored-context table (membership count and trie fan-out over the stored
descriptors), and a charged-cost model over stored-context-table size and scan
cost. No family-level macro, no hand-encoded decision-tree routine, no
reference to any external implementation. Section R03 asserts the grammar
contains no rule-system macro, and R04 recovers the family from the grammar
alone.

## 6. Arithmetic

Exact integer arithmetic for every reported quantity: every claimed number is
an exact integer decision count (prototype agreement, sign-decision errors,
null errors, ladder errors, charged-cost units, crossover index). No float
enters any comparison, count, loss, or claim. There is no real-valued fitting
routine whose output requires a rationalisation operator, so this package
carries no arithmetic addendum: the exact-integer form is complete in this
freeze and the slice addenda.

## 7. Budget

Registered node and index budgets for the family-blind search, stated before
any fit, identical for every arm: the descriptor-closure vocabulary index, the
stored-context table, and the scan window are all bounded and fixed in the
executor. Resource crossover (`R07`) varies these budgets and asserts the
held-out error is monotone in them.

## 8. Predictions, frozen before any outcome

Held-out frozen predictions are written to the frozen-prediction record
(`R08`) before the oracle is run, exactly as in
`gmi-833-h-real-scale-classical-v1`: the fit is completed on `n_fit`, the
prediction for each held-out query is emitted to the frozen record, and only
then is the independent oracle (Section R09) run and compared.

## 9. Falsifiers

A held-out exact prototype-agreement below the registered baseline, an
exact sign-decision error count above the registered bound, a null that
performs comparably to the family on the same slice rule, or any cross-scope
gate composition — any one falsifies the claim ceiling.

## 10. Controls

Matched negative control (`R05`): a shuffled-label null with equal sample size
on the identical slice rule must perform at chance, and a shuffled-store
design null must fail to recover the family. The screen asserts `CLEAN` only
when the no-alarm case also fires (the checker's own controls are asserted to
fire).
