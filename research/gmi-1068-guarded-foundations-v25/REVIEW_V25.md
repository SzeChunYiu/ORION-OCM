## Primary oracle and hostile design inspected

The oracle enumerates endpoint assignments satisfying all typed category laws,
rather than calling production reconstruction. Bracketed recursion is separate from
word folding. Ambient padding and guards are computed independently. Recovery tests
enumerate actual decoder outputs on attained code sets, rather than merely copying
the production fiber predicate. Full recursive exact-type certificates reject
bool/int aliasing and changed output container shapes.

A–F formulas are reconciled to measured lawful models, not hardcoded as the proof
of acceptance. Lawless tables have a separate interpreter; guarded-fold agreement
is only required under strong associativity. Every rejected associativity table
gets a real triple disagreement, whereas other law failures are not mislabeled
as associativity failures. Repeated identical models in decoder pairs are included.
The named strata group by fixed ambient/object interfaces; no comparison silently
changes the query type. The full primary corpus is not rerun by this reviewer.
