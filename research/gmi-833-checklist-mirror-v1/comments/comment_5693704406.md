## AI8 — Blind architecture-discovery criterion: neural networks must be derivable by a civilization that has never seen them

This amendment strengthens AI1–AI7. The relevant thought experiment is not “can GMI compile or rediscover a neural network after humans already know what neural networks are?” It is:

> **Suppose a scientific civilization possesses the GMI theory and its registered elementary computational/process substrate, but the concepts `neuron`, `layer`, `neural network`, `backpropagation`, `CNN`, `RNN`, `attention`, etc. have never been invented. Given only environments/tasks/data/resource prices and the generic GMI laws, can the theory lead them to a neural-like organization when that organization is useful — and to different organizations elsewhere?**

This is the minimum credible standard for claiming that GMI can discover both seen and unseen forms of machine intelligence.

### AI8.1 — Architecture names and target morphology are hidden from both generator and selector

For the blind derivation experiment, freeze before search:

```text
KNOWN TO GMI
  elementary process/substrate theory F
  legal composition/development rules Delta
  observations/data D
  external task/specification family Q
  resource vector/prices R
  verifier V
  uncertainty model U

NOT KNOWN / NOT SUPPLIED
  neural-network architecture names
  neuron/layer abstractions
  a neural morphology classifier used as reward
  backpropagation as a privileged update macro
  expected depth/width
  connectivity template
  human neural exemplars
  target architecture ID
```

- [ ] Extend the no-smuggling audit so forbidden architecture information is blocked not only from the grammar, but also from search heuristics, priors, stopping rules, evaluator features and morphology labels.
- [ ] The search/evaluator may score only external capability, verification and resource consequences that would have been available to the hypothetical pre-neural civilization.
- [ ] Post-hoc morphology labels may be applied only after candidate generation, using a separately frozen classifier/structural analysis that had no causal access to search.

### AI8.2 — GMI must expose a discovery operator, not merely a possibility space

A complete discovery story needs three objects:

```text
M_B(F)                 bounded machine possibility space generated from the elementary substrate
Reach_Delta(M0,...)    developmentally/search-reachable subset
Frontier(Q,D,R,V,U)    capability/resource Pareto set under the registered ecology
```

The architecture-discovery operator is therefore schematically:

```text
DISCOVER_GMI(F, Delta, D, Q, R, V, U, B)
  -> ParetoMin / preferred regions of Reach_Delta(M0,...)
```

with architecture names absent from the input and output ontology.

- [ ] Formalize `DISCOVER_GMI` separately from mere enumeration.
- [ ] Require it to return unclassified process organizations first; architecture-family mapping occurs only afterward.
- [ ] Require an `UNKNOWN_MORPHOLOGY` output so the machinery can return structures unlike the current catalog.
- [ ] Distinguish `NOT_GENERATED`, `GENERATED_NOT_REACHED`, `REACHED_NOT_SELECTED`, `SELECTED_UNKNOWN`, and `POSTHOC_MATCH_<family>`.

### AI8.3 — Analytical derivation route: environmental assumptions should imply structural pressures

The strongest target is not brute-force luck. Derive intermediate design pressures from registered environmental/task properties without architecture vocabulary.

Examples to test, not assume:

```text
many related input coordinates + reusable smooth/local regularity
    -> pressure for reusable parameterized transformations

high-dimensional approximation + finite description/resource budget
    -> pressure for factorized/compositional representations rather than a table

nonlinear target relation
    -> linear-only organizations incur an approximation/capability ceiling

repeated low-arity compositional structure
    -> pressure for repeated local transforms / depth

sample-based adaptation with a differentiable composite program
    -> reverse derivative propagation becomes a low-cost credit-assignment candidate

shared symmetries/locality
    -> pressure for parameter sharing / equivariant local computation

temporal partial observability
    -> pressure for persistent/recurrent state

variable context-dependent relevance
    -> pressure for dynamic content-dependent routing
```

- [ ] Turn each arrow into either a theorem with explicit assumptions or a prospectively falsifiable hypothesis.
- [ ] For each pressure, produce a nearest counterexample ecology where the predicted structure should not appear.
- [ ] Combine pressures only after individual effects are measured; do not reverse-engineer a full neural architecture in one step.

### AI8.4 — Neural-like morphology is a derived intersection of lower structural properties

Do not search for `NEURAL`. Search for independently motivated properties and inspect their conjunction afterward.

Candidate post-hoc structural fingerprint:

```text
P1 parameterized reusable local transformations
P2 many-to-one aggregation / mixing of multiple incoming values
P3 non-affine/nonlinear transformation
P4 repeated composition of P1-P3
P5 distributed adjustable state/parameters
P6 trainability from task evidence under generic developmental law
```

A neural-like family is then only a retrospective region such as

```text
NN_like := P1 ∩ P2 ∩ P3 ∩ P4 ∩ P5 [∩ P6 for trainable forms]
```

not a primitive category.

- [ ] Prove the fingerprint does not collapse trivially to all universal programs or all adaptive machines.
- [ ] Include structurally different non-neural systems satisfying subsets of P1–P6 as negative controls.
- [ ] Audit whether the fingerprint accidentally encodes modern neural-network conventions.

### AI8.5 — The correct scientific claim is conditional emergence, not unique inevitability

GMI must not claim that a neural network is the unique rational consequence of generic intelligence. Multiple machine organizations can realize the same external behavior and can be Pareto-incomparable.

The target claim form is:

```text
Under registered ecology/resource conditions A,
organizations with structural properties P1..Pk enter or dominate part of the reachable Pareto frontier;
under matched conditions B, they disappear or are dominated.
```

If the resulting frontier includes a family later recognized as neural-like, this is a successful blind derivation/recovery at scope.

- [ ] Require at least one non-neural co-optimal/Pareto-incomparable control where theory predicts coexistence.
- [ ] Require at least one regime where neural-like organization is absent/dominated.
- [ ] Forbid “GMI proves neural networks are inevitable” without an actual uniqueness theorem under explicit assumptions.

### AI8.6 — Discovery ladder for known and unseen MI

Use the same ladder for every architecture family, including ones not yet known to humans:

```text
L0 EXPRESSIBLE       candidate exists in M_B(F)
L1 REACHABLE         generic development/search can reach it
L2 FUNCTIONAL        it satisfies an external specification
L3 RESOURCE-USEFUL   it lies on a capability/resource frontier
L4 BLIND-RECOVERED   it emerges without architecture-specific priors
L5 PREDICTED         frozen GMI conditions predicted its emergence
L6 REPLICATED        independent basis/search reproduces the structural region
L7 NOVEL             candidate remains unmatched to known parent architecture families
L8 REAL-SCALE        utility/transition survives real systems and complete cost accounting
```

- [ ] Apply this ladder to neural, symbolic/rule, lookup/direct, recurrent/stateful, local/shared, routing/attention-like, evolutionary/search and at least one `UNKNOWN` family.
- [ ] A future unseen MI form is scientifically discovered when it reaches at least `L4` without a known-family target and then survives novelty/parent-subtraction review; higher levels strengthen the claim.

### AI8.7 — Bounded completeness versus unbounded openness

“All forms of MI” must be stated carefully.

For finite registered substrate/budget/horizon where the candidate universe is finite and executable:

```text
M_B(F)
```

may be exactly enumerated and evaluated, permitting a complete bounded MI atlas.

For unbounded universal computation, syntactic programs may be enumerable but complete effective semantic classification/equivalence/behavior prediction is blocked in general by standard computability limits.

Therefore the flagship target is:

```text
exact bounded completeness
+ architecture-uncommitted generative coverage
+ open-ended expansion of the bounded atlas
+ explicit UNKNOWN
+ theorem-level unbounded limits
```

not a false promise that one terminating algorithm will identify and rank every semantically possible intelligence in an unbounded universe.

### AI8.8 — Decisive pre-neural-civilization experiment

Build a frozen experiment in which the implementation team is denied neural-family templates/macros and is given only:

```text
F, Delta, task/ecology generator, resource accounting, verifier
```

Run multiple independent low-level bases and search procedures. Before outcomes, freeze predictions about structural pressures (e.g. nonlinearity, composition, parameter reuse, local sharing). After generation:

1. cluster candidates only from architecture-independent structural/behavioral descriptors;
2. expose known architecture names only to a separate post-hoc mapping lane;
3. measure whether any cluster matches neural-like organization;
4. preserve any high-performing unmatched cluster as an `UNKNOWN_MORPHOLOGY` candidate rather than forcing it into a known family;
5. repeat under ecologies predicted to suppress the neural-like region.

Strong precedent, but not closure: Real et al. `AutoML-Zero` showed evolutionary search over basic mathematical operations can rediscover two-layer neural networks trained by backpropagation. GMI must go further by deriving why such motifs should emerge, auditing all remaining grammar/search/ecology biases, predicting negative regimes, using multiple bases/searches, and retaining unknown organizations.

### AI8.9 — Claim ceiling

Until the blind experiment and prospective selection law are passed, the strongest allowed wording is:

> GMI contains a programme for architecture-unnamed generation and conditional selection of machine organizations, with neural networks serving as the first known-family falsification target.

Do **not** claim `GMI_DISCOVERS_ALL_MI` from finite recovery of known architectures. The desired stronger result is a validated discovery mechanism that recovers known forms without naming them, predicts when they should emerge, and can return persistent high-capability `UNKNOWN` forms for independent novelty review.
