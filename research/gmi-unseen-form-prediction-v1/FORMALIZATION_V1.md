## 2. Objects

Histories `H`, predictive quotient `q_P: H -> S_P`, target quotient `q_O: H -> S_O`.
Fiber multiplicity `m(p) = |{q_O(h) : q_P(h)=p}|`. Residual alphabet lower bound
`|R| >= max_p m(p)` (PRQ-1).

A label-free machine is a triple `(P_assign, R_assign, decoder)` with cost

```text
C = |range(P_assign)| + |range(R_assign)|.
```

Architecture macros (`RQM`, `RAG`, `Transformer`, …) are forbidden in the search grammar.

strictly cheaper than the flat history/target table parent at cost 6. The
pure-predictor parent under `q_P` fails because `m(0)=3 > 1`.

alphabet size `< max_m`, while the canonical fiber labeling achieves size
`max_m`. Hence min residual cost under the registered predictive quotient equals
the PRQ-1 bound.
