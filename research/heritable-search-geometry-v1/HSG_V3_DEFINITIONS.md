## 3. Context-dependent epistemic proximity

Retrieval kernel `P_t(y | x, c, H_t)`; directed distance `D_t,c(x→y) = −log P_t` — possibly
asymmetric, no triangle inequality assumed. Charts/resolutions (portfolio, not one embedding):
surface/lexical, semantic, causal, functional, dynamical, symmetry/invariant,
variational/optimization, algebraic, geometric/topological, information-theoretic,
universal-property/domain-free skeleton. **Remote donor ≡ D_surface large, D_structure small.**
Learned bridges persist → retrieval distance decreases developmentally. (HSG-T56 additive path
cost; HSG-T63 exploration necessity.)

## 5. A↔M↔D factorization (rejection of exhaustive A×D)

Maintain once-mined discipline signatures `Ψ(d)` and per-atom structural-need signatures `Φ(a)`;
route `a → Φ(a) → motifs M → Ψ(d) → selective deep inspection`. Deep discipline reads amortize
across atoms (HSG-T61: per-atom cost `C_d/m + (1/m)Σc_i`). Low-rank hypothesis about the
relevance matrix `R[a,d]` is **conditional and measured, never presupposed** (HSG-T62).

## 6. Multi-fidelity ladder + coarse→fine policy

`L0` metadata/survey index → `L1` abstracts/reviews → `L2` selected primary sections → `L3` full
reconstruction + assumptions → `L4` explicit structure map → `L5` proof/counterexample/experiment.
Action `q = (a, d, l)` with cost `c(q)`, observation `Y_q`. Default policy: broad cheap scan →
structural shortlist → diversity/uncertainty shortlist → successive-halving deeper reads → full
reconstruction for survivors → theoremize / reject / CANNOT_CHECK. Literature analogue of #221
multi-fidelity morphology search.

## 7. DonorSearchActionV1 (D11 apparatus — research navigation only)

Action score components: predicted structural relevance, uncertainty, novelty/domain distance,
expected theorem strength, expected kill/merge power, expected cross-atom reuse,
reading/mapping/validation costs. Approximate expected-value-per-complete-cost selection with a
prospectively frozen exploration share (calibrated on pilot, sensitivity recorded — no arbitrary
percentages in theory). Negative outcomes carry value: parent absorption, counterexample, new
impossibility boundary, new equivalence, transferable motif. Rational stop/redirect rule per
HSG-T64 (bounded-rational control objective, exact only in special cases).

## 8. LBD correction (Swanson)

Open discovery (A → unknown C via bridges) and closed discovery (A, C → bridges B) generalize
from word/co-occurrence bridges to **structure-preserving theory motifs and maps**; motif
factorization + multi-fidelity allocation + cost-aware routing address the ABC combinatorial
blow-up. Parents: Swanson 1986/1987; LBD review (PMC7924697).
