# A_T08 @ R6 — Blackwell dominance with an evolving experiment choice

**Verdict: LIFT_CONDITIONAL.** Condition: the kernel-selection rule is
measurable with respect to the sigma-field generated by the (dominating)
experiment history — i.e. the choice of which experiment to run next carries
no side information. Under that condition garblings compose and the Blackwell
order is preserved along the kernel-valued process; without it, the selection
channel is itself an unaccounted experiment and dominance can invert.

## Parent invoked

Blackwell 1951/1953: experiment E dominates F iff every decision problem has
weakly higher value under E than F, iff F is a garbling of E (F factors
through E by a stochastic post-processing matrix). Standard corollary used
here: garbling composes — a garble of a garble is a garble, and functions of
dominated information remain dominated.

## Lift

Setting: a kernel family {K_θ} is available at each step; the process selects
θ_{t+1} = s(history) based on past performance, then observes an outcome.
Question: if every K_θ in the family is garbled by a fixed sufficient
experiment E, does the *adaptive mixture* remain garbled by E?

1. Fix the filtration (G_t) generated by E's outcomes (equivalently by any
   statistic sufficient for the family). Suppose s is (G_t)-measurable.
2. Then the adaptive experiment "run K_{θ_{t+1}}, θ_{t+1} = s(G_t)" is a
   random garbling chosen G_t-measurably; a G_t-measurable mixture of kernels
   each of which factors through E still factors through E (the post-processing
   matrix is selected by a function of E's own output). So the composite
   adaptive experiment is a garble of E and Blackwell dominance survives the
   self-referential selection. This is the R6 statement: performance-based
   kernel selection does not, by itself, escape the information order.
3. **Leak mode (why only conditional).** If s reads any signal not measurable
   in E's sigma-field — external evidence e_t, side observations, task inflow
   from R7 — the choice variable itself transmits information: the selection
   pattern is an experiment about the selector's inputs. An observer (or the
   process itself, via K_{t+1}) can extract that information, and the adaptive
   mixture can strictly dominate E. The kernel-valued process
   K_{t+1} = K(Σ_t, x_t, e_t) sits exactly on this boundary: e_t is in the
   signature, so the lift holds only on the sub-process where e_t is
   Σ_t(x_t)-measurable.

## Condition (named)

SEL-MEAS: the selection rule is measurable in the dominating experiment's
sigma-field. Under SEL-MEAS, dominance is preserved at every step and hence
along every R6 trajectory. Violation is not exotic — it is the normal case
once e_t carries state beyond the rung's own observations, which is the R7
boundary condition (see T17: the same selection channel is the tamper
channel).
