# A_T04 @ R6 — coded-search share 2^{-Δ} under self-extending code

**Verdict: LIFT_CONDITIONAL.** Condition: every amendment's own description is
charged, bit for bit, to the acting macro's prefix budget (the constitution's
changelog is part of the code). Under that charge discipline the Levin share
survives as a conditional, amortized statement; without it, self-extension can
self-allocate share and the bound dies.

## Parent invoked

Levin universal search / Schmidhuber OOPS (probability of a search program of
length l under the universal semimeasure is ~2^{-l}; optimal ordering of
macros by description length). No parent-text uncertainty flag needed for the
qualitative form used here.

## Lift (definitions, what survives)

Setting: at time t the frozen constitution C_t induces a prefix-free macro set
M_t with description-length gap Δ_t between the acting macro and the shortest
competitor covering the same sub-search. Parent gives share 2^{-Δ_t} over
C_t's code space. R6 complication: M_{t+1} can contain macros written by
macros executed under C_t (macro set grows by its own action), so Δ_t is
trajectory-dependent and the code is not fixed at launch.

1. **Conditional survival.** For each frozen C_t, the parent argument applies
   verbatim: share of any macro in M_t is 2^{-Δ}, Δ measured in C_t. The
   kernel-valued law K_{t+1} = K(Σ_t, x_t, e_t) inherits this as a per-rung
   bound, one per frozen frame.
2. **Amortized form (the actual lift).** If each amendment appends a
   description d_t to the changelog, the total measure ever allocated to a
   lineage is bounded by the initial 2^{-Δ_0} times the product of branch
   factors, i.e. the lineage's share is ≤ 2^{-Δ_0} because the changelog
   prefix is itself charged: a lineage that self-extends by d bits pays 2^{-|d|}
   of its own share. Prefix-freeness is preserved iff appended changelogs are
   self-delimiting extensions.
3. **Failure mode without the charge.** If amendments are free (uncharged),
   the process can emit a macro granting itself and its descendants maximal
   share: code-space measure is then reallocated by self-interested action and
   the share is not a complexity measure at all — it is a negotiated outcome.
   This is a real counterexample class, so the unconditional lift FAILS.

## Condition (named)

CHARGE: amendment descriptions are self-delimiting and billed to the acting
lineage's bit budget, with the changelog included in C_t. Under CHARGE,
E[2^{-Δ_t}] over the process's own randomness still upper-bounds expected
coded-search share of any self-produced lineage, and Jensen (2^{-x} convex)
gives E[2^{-Δ_t}] ≥ 2^{-E[Δ_t]} — share can only be diluted, never minted, by
self-extension.

## Note for the registry

The governed-amendment gate at R6 is therefore not decoration: it is exactly
the mechanism that makes CHARGE enforceable. Ungoverned self-extension is the
minimal counterexample (see hostiles note in registry row if the freeze
disagrees with CHARGE).
