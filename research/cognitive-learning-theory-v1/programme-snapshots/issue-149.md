# OCM self-evolution lane — M11 × cognitive ladder

Parents: #143 empirical ladder, #144 publication constitution, #145 theory bridge,
#93 field, #50 persistent intelligence, #62 consolidation, #72 executive control.

## Central hypothesis and claim boundary

Can persistent OCM diagnose its own observed learning/reasoning failures, choose
informative interventions, propose the smallest sufficient cognitive change,
predict its effects, and improve its capability/resource frontier through
externally governed generations? The research team currently supplies much of
this meta-cognition. This lane measures that gap rather than renaming external
repairs as autonomous evolution.

Use the existing M11 `FailureRecord`, `SelfModel`, diagnosis, proposal, prediction
receipt, shadow, assurance, external adopter, migration and rollback machinery.
Its original scenario benchmark supplies fixes and causal labels, and is not
evidence of blind failure localization. M11 assurance must additionally check
resource improvement and prediction calibration for cost-only changes.

## Two ecologies

**DEVELOPMENT:** outcomes, traces, paid counterfactuals, C0–C5 cognitive changes,
router/learner training, operator/representation proposals, challengers and
self-improvement experience are admissible. Every consumed semantic task ID
remains in the exposure ledger even after a failed run or rollback.

**PROTECTED:** freeze generation, architecture/field/operators, full
self-improvement history, candidate/proposal source identities, comparator,
information and resource envelopes before execution. Protected results are
output-only assessment. They never reach the proposer, development history or
successor-selection policy. A generation fork may resume only from its
pre-protected history; researchers exposed to protected results cannot silently
redesign the next confirmatory study. Protected execution remains NOT RUN here.

## Required lifecycle and generation criterion

`OCM_g → actual failure/opportunity → bound FailureRecord → competing D0–D8
diagnoses → paid discriminating intervention → tested responsibility layer →
lower-alternative checks → independently checked obstruction if needed → bounded
candidate → benefit/regression/resource prediction receipt → incumbent and
challengers in development shadow → assurance → external decision → migration
and reopening → durable restart → fresh development use → OCM_(g+1)`.

Repeat with disjoint semantic development experiences. A full lane success needs
at least three earned transitions `OCM_0 → OCM_1 → OCM_2 → OCM_3`, preservation,
fresh post-restart effects and compensated causal ablations. Three loop calls,
three relabeled tasks, or three supplied patches do not establish this result.
An attempted cycle increments the generation only after an actual approved,
verified adoption. Keep failed proposals, regressions, stops and rollbacks.

The minimum successful **tested intervention layer** is not necessarily the
unique causal source of failure. Unprobed layers remain UNKNOWN. An obstruction
is scoped to the complete registered alternative set and budget; a timeout is
not evidence that a representation/operator language is insufficient.

## Cognitive changes and origins

C0 parameter/search allowance (within externally fixed envelope); C1 routing or
index policy; C2 operators/composition; C3 field/representation; C4 learning or
method discovery; C5 cognitive organization. Constitution, checker, meter,
protected evaluation and adoption authority are outside the write set. C6 is a
recommendation to external governance only.

Origin is mandatory: existing internal alternative, composition/recombination,
cross-domain transfer, learned proposal, bounded synthesis, ORION-V2 theory
import, or human supplied. Existing M11 origin enums are supplemented by an
origin reference when a finer source is required. Automatically selecting a
human-authored library member is not autonomous invention. The concurrent
polynomial semantic-reuse repair is explicitly HUMAN_SUPPLIED_REPAIR.

## Comparison programme

Each parent receives matched development information, candidate libraries,
checker/probe access, adaptation permissions, budget and stopping rules.
Register random search, Bayesian optimization/AutoML, evolutionary search,
program repair, meta-learning/learned selector, reflection/retry, and the
human/Claude-designed repair. Implement faithful versions before claiming their
subtraction; missing comparisons remain NOT RUN rather than weak stand-ins.

Measure correct/ambiguous localization, useful information per probe, challenger
evaluations, change size/class, quality, regression, preservation, rollback and
reopening, calibration, and total proposal/acquisition/search/adoption cost.
Finding a working configuration alone is insufficient. A standard controller
using the same finite search policy is an identity-by-construction parent.

Later compare an equally adaptive neural trajectory with continual adaptation,
memory, adapters/fine-tuning, meta-learning and tools/retrieval as appropriate.
An evolving OCM versus a frozen neural model cannot answer which architecture
improves faster. No neural comparison is executed by this tranche.

## Frozen machine-quality contract and scaling

Track Q_g, new-task acquisition, new information, query/reasoning and revision
work, persistent bytes, active k/N, maintenance, method yield, negative transfer,
proposal count, challenger count, proposal compute, preservation failures,
rollbacks and prediction calibration. Quality noninferiority and invariant
preservation are hard gates. Treat compute/IO/storage as a vector; distinguish
additive work from peak storage, count rejected changes and challenger work,
and plot the trajectory against cumulative self-improvement expenditure.

Use a frozen nondominance/threshold rule and report tradeoffs, including cases
where proposal costs exceed downstream savings. Every claim gets a
Theory→Prediction→Falsifier registry entry and #143 rung. E2 calibration and
session-authored continuations do not become E3–E5 through internal AI review.

`SELF_DIAGNOSIS_NOT_IDENTIFIABLE`, `SELF_CHANGE_SEARCH_DOMINATES`,
`AUTOML_PARENT_SUFFICIENT`, `HUMAN_REPAIR_DOMINATES`, `SELF_EVOLUTION_REGRESSES`,
`NO_MULTI_GENERATION_IMPROVEMENT`, `ARCHITECTURE_CONVERGES_TO_PARENT`,
`PROPOSAL_COST_DOMINATES`, `SELF_EVOLUTION_SUPPORTED_BOUNDED`.

Checkpoints report theory question, hypothesis, strongest tested/unrun parents,
formal machine object, frozen prediction/falsifier, V1/V2/V3 route and rung,
result/negative, removals/merges, survivors, claim ceiling, exact artifacts and
next decisive test. Never summarize this lane as merely tests passing.

The acceptance criterion remains the user's full multi-generation hypothesis.
A functional governor, a supplied library search and a bounded engineering
improvement are useful intermediate results with separate claim ceilings.
