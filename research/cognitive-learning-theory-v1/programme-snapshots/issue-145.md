## Status and role

**FOUNDATIONAL THEORY↔EMPIRICAL BRIDGE.**

This issue does not replace #143 and does not authorize a claim that a universal cognitive operator basis exists. It defines how ORION-OCM will theoretically derive, experimentally minimize, and prospectively test candidate generative cognitive operators and candidate epistemic-field organizations.

The empirical ladder #143 answers increasingly difficult capability and transfer questions.

This issue answers a deeper structural question:

> **What is the smallest resource-bounded, epistemically preserving operator algebra and field organization from which heterogeneous cognition can be generated primarily by composition, representation change and learned specialization?**

The field and operator set must be co-designed and jointly tested. A richer field can make some operators unnecessary; a poorer representation may require more complex operators. Therefore there is no scientifically meaningful operator-minimality claim without declaring representation, task ecology, resource envelope and epistemic invariants.

# 1. Fundamental scientific questions

## Q1 — Is there a compact cognitive generating basis?

Does there exist a small operator basis `O*` such that, under registered field `F`, task ecology `T`, resource envelope `B` and constitution/invariants `C`, most useful cognitive transitions are generated by compositions of `O*` rather than by continually introducing new domain-specific primitives?

## Q2 — Is the basis unique?

Likely not. Define and search for **equivalence classes of operator bases** whose members compile into one another while preserving registered epistemic behavior with bounded overhead.

## Q3 — What is irreducibility?

Distinguish:

```text
ALGEBRAIC IRREDUCIBILITY
RESOURCE IRREDUCIBILITY
EPISTEMIC IRREDUCIBILITY
```

An operator may be computationally simulable but still deserve primitive status if every replacement has unacceptable resource overhead or fails to preserve warrant/scope/dependency/revision semantics.

## Q4 — What field organization minimizes lifetime cognitive cost?

Compare field families rather than assuming the current hypergraph/fibred design is optimal.

## Q5 — Does primitive pressure converge?

As domains are added, does the number of genuinely new primitive operators approach zero while learned compositions/macros continue to grow?

Candidate closure hypothesis:

```text
new_primitive_pressure(domain_j) -> 0
```

Candidate alternative:

```text
persistent nonzero primitive pressure
```

which would support an open-ended self-expanding cognitive language instead of a fixed Grand Unified basis.

## Q6 — Can the machine expand its own operator/field language when bounded insufficiency is independently witnessed?

Required lifecycle:

```text
certified bounded insufficiency
→ proposed new operator/representation
→ predicted reach expansion before protected outcome access
→ independent validation
→ persistent admission under external authority
→ restart
→ fresh causal reuse
→ ablation
```

# 2. Definition of the scientific object

A candidate machine is treated as:

```text
M_t = (F_t, O_t, Π_t, C)
```

where:

- `F_t` — persistent typed epistemic field / state organization;
- `O_t` — executable cognitive operator algebra, including learned methods/macros;
- `Π_t` — small executive/routing/composition policy;
- `C` — external constitution / authority/check/commit boundary.

Operator minimality is always relative to:

```text
(F, task ecology T, resource envelope B, invariants/constitution C)
```

Never claim an absolute metaphysical minimum.

# 4. Formal theory lane

## TH-1 — finite transformation systems

For exact finite worlds:

```text
X = registered epistemic/cognitive states
S = useful/allowed transformations over X
```

Treat operators as partial/total transformations and study the generated semigroup/monoid:

```text
<O> = closure under composition
```

Use established transformation-semigroup rank/generator theory where applicable; this mathematics is parent-owned.

Questions:

- [ ] compute exact minimal generator rank for bounded worlds;
- [ ] identify non-unique minimal generating bases;
- [ ] measure compilation depth/cost between bases;
- [ ] separate exact behavioral generation from epistemic-state preservation.

## TH-2 — bounded cognitive reach

Define:

```text
Reach_B(F, O, C, task_family)
```

= registered contracts reachable within resource bound `B` while preserving required epistemic invariants.

All claims about Jump/operator invention should distinguish:

```text
SEARCH_HARD
```

from

```text
OUTSIDE_REGISTERED_BOUNDED_REACH
```

Timeout is not an insufficiency proof.

## TH-3 — operator equivalence

Define candidate equivalence relation:

```text
O_A ≈_{T,B,C} O_B
```

when each basis can compile the other's registered behavior with bounded overhead while preserving required outputs, warrant, scope, authority, dependencies and revision behavior.

## TH-4 — field/operator/executive trade-off

Study a Pareto object such as:

```text
Complexity(F)
↔ Complexity(O)
↔ Complexity(Π)
↔ C_lifetime
```

A field that simplifies operators but explodes state/navigation may lose.

## TH-5 — lower bounds / necessity

For candidate primitives or field distinctions, construct families where:

```text
Reach_B(F, O \ {o}) < Reach_B(F, O)
```

or where removing a field coordinate forces a registered resource/epistemic failure.

## TH-6 — closure versus open-ended basis

Formalize measurable primitive pressure across domain sequence `D_1...D_m`:

```text
P_j = |primitive(O_j) \ primitive(O_{j-1})|
```

Do not assume `P_j -> 0`; treat convergence, persistent growth and domain-specific plateaus as competing hypotheses.

# 5. Three verification routes

Every theoretical statement must have exactly one declared primary verification route, optionally supported by others.

## V1 — formal proof

Use when a theorem can be established under explicit assumptions.

Examples:
- dependency-cone locality under complete declared dependency semantics;
- generator/closure facts on specified finite classes;
- representation-sufficiency or lower-bound statements.

## V2 — exact computational verification

Use exhaustive finite enumeration / exact oracle / independent checker when the bounded universe is complete.

Examples:
- enumerate all states/transitions;
- compute exact generated closure;
- find minimum generators;
- construct counterexamples;
- verify same-output/different-lifecycle cases.

## V3 — prospective empirical verification

Use for transfer, scaling and heterogeneous-domain claims that cannot be proven universally.

Requirements:
- theory frozen first;
- quantitative prediction frozen;
- protected families held out;
- causal ablation;
- strongest matched parent;
- negative/control family;
- uncertainty/statistics;
- honest scoped terminal.

No empirical transfer result is described as a universal proof.

## Field hostiles

- [ ] field wins only because it embeds target labels;
- [ ] latent system receives weaker revision requirements;
- [ ] explicit system receives privileged semantic structure;
- [ ] hypergraph advantage disappears after indexing cost;
- [ ] fibred field hides global routing work;
- [ ] field becomes domain-specific and violates one-field hypothesis;
- [ ] same task can be solved with a simpler parent at lower total cost.

## Field terminal

Do not require one universal winner. Valid result may be a Pareto family or domain-dependent phase diagram.

# 17. Completion criterion

This issue is scientifically successful if it yields one of two broad outcomes:

### Compact-basis outcome
A small resource-bounded epistemically preserving operator basis remains stable across prospectively held-out validation domains, with most later cognition generated through composition/macros and a superior field/operator lifetime frontier.

### Open-ended outcome
Repeated protected domain additions continue to expose irreducible new operator/representation requirements, establishing that general cognition requires an expandable cognitive language rather than a fixed small basis.

Both are foundational answers.

Close only when the theory registry, exact finite studies, operator-reduction campaign, field comparison and at least one prospective cross-domain test have bounded scientific dispositions. Otherwise remain open with exact unresolved obligations.
