# Actual-source learning of evidence-retention structure

Status: E0 design until the registration and executable hashes are reviewed and
frozen. The authorized execution is a bounded **new E2 development census**.
It is not a protected experiment, independent family replication, new OCM
generation, or a demonstration of general structure discovery.

The latest local snapshots of #143, #144 and #145 were reviewed before this
design. Their protocols, outcomes and issue bodies are unchanged. The source
ecology has already been exposed to the research team. Every original
self-evolution and payback task in `DEVELOPMENT_REGISTRATION_V1.json` and
`PAYBACK_REGISTRATION_V1.json` remains development evidence; none is recycled
as a protected holdout by changing its display name.

## Concrete architectural gap

The previous self-evolution pilot persisted a dispatch configuration and M11
history. Its runner rebuilt donor methods/indexes per task. The two dispatch
coordinates and their correspondence to relevance/dependency tasks were
supplied. Counterfactual search chose existing implementations; it did not
learn the machine's dependency structure or invent the replacement algorithm.

This tranche adds a persistent **learned effect object**, acquired by actual
source interventions. The smallest runnable question is whether it can predict
retention of an existing method's induced representation after evidence is
withdrawn. It does not yet learn global component grouping, diagnose all D0–D8,
choose general machine repairs, or discharge `OCM_0 -> OCM_1 -> OCM_2 -> OCM_3`.

## Scoped A: learn a four-block retention property

Take **all 16 methods** in the original scale-one dependency catalogue, without
selecting successful or redundant-support families. Each has four original
evidence blocks, giving 16 possible live sets. The learner receives opaque,
occurrence-and-content-bound block identities and its current baseline representation ID.
It does not receive role names, LOO edges, joint witnesses, root-cause labels,
or the effect table. Ordering block handles by opaque source-occurrence tokens conceals the
original ordinal names; it does not make known content confidential. Each token
binds the pinned manifest, original block occurrence ID and payload. Identical
payloads in different evidence occurrences remain distinct revocable objects.
An opaque method-occurrence token similarly binds the original source method
ID; the snapshot identity also binds its block occurrences, content and baseline.
The executor verifies unique method occurrences and all semantic contracts,
so equal-content source families cannot overwrite one another's snapshots.

**The four-block candidate membership per method is supplied.** This is an
explicit structural prior available to every parent. Successful learning here
cannot establish discovery of global module boundaries or factorization.

For one method, let `E0` be its complete original evidence and let `r=L(E0)`
be the donor's selected `(preperiod, period, values)` representation. The target
is the Boolean function

`retains_r(S) = [L(S) == r]`, for every `S subset E0`.

Equality is exact representation/dataclass equality, not equivalence of all
represented Grundy functions. A false retention answer says to reopen the
baseline; it does not identify the new rule or assert that no method exists.
An unanswered mask remains UNKNOWN and requires paid reinduction. No learned
effect substitutes for a required new task's object-level checker.

## Why the monotone hypothesis class is justified here

Fix the finite hypothesis set and the data-independent total order
`(code_bits, period, preperiod, lexicographic values)`. The pinned source scans
period then preperiod, keeps the first strictly shorter code, and fills free
slots with zero: this is the lexicographically least consistent table for each
shape. The source uses `max_value=8 > 1`, so sorting by `q+p` is equivalent to
sorting shapes by its code length. The independent checker asserts that bound.

Consistency is conjunction over observations. If `L(S)=r` and
`S subset T subset E0`, then r still fits T, while every candidate preceding r
already rejected by S remains rejected by T. Therefore `L(T)=r`. The host
checks r against every original observation and pays for the baseline witness.

This establishes monotonicity of **fixed baseline retention only**. It does
not establish monotonicity of the changing induced output, extrapolated game
truth, new evidence outside E0, revised authority, or data-dependent hypothesis
generation/order. A scope change reopens the effect record. A complete
independent mask census also checks the implementation; any violation is a
model failure retained in the results.

## Competing learners and treatment provenance

| Arm | Acquisition / retained structure |
|---|---|
| `active_monotone` | Explicit finite version space of monotone retention functions; choose the mask minimizing the larger surviving hypothesis partition; stop when every mask's value is determined |
| `antichain_parent` | Conventional positive/negative order closure; choose the mask minimizing the worst number of unresolved masks; retains the same kinds of learned sufficient supports |
| `eager_table` | Query every missing mask, paying for all acquisitions; may exploit/compress monotone relations just as OCM may |
| `lazy_cache` | No advance discovery; reinduce an unknown requested mask and persist its exact answer |
| `loo_ablation` | Probe single deletions and use the known weak dependency-graph rule; guesses are explicitly marked UNSOUND_ABLATION |

All arms receive the same baseline witness, candidate block set, language,
allowed interventions, memory and checking permissions. All may persist learned
structure. Eager acquisition of a later service mask is legal and charged;
these are development masks, not protected checker queries. Its lack of
unqueried masks after acquisition is N/A for generalization, not an exclusion.

Every algorithm is externally supplied conventional machinery. No autonomous
invention claim is admissible. Version-space learning, active learning,
antichain/ATMS support representations, cache/library learning and incremental
recomputation own the relevant mechanisms. EC2/HEC own related decision-region
probe objectives; this pilot instead acquires a complete retention function,
and its minimax split is not claimed to optimize full lifetime repair cost.

## Execution, persistence and semantic separation

1. Run each arm in a separate process with a fresh output directory and the
   same original 16 methods. Instantiate the generic four-bit version-space
   library once per active arm and charge it; reusing it across methods is
   allowed and explicitly reported.
2. Acquire effects through the pinned source induction routine. Retain every
   probe's content-bound semantic ID, mask, result and source-work receipt
   immediately, before feeding its result back to the learner.
3. Persist the learned object as canonical plain data, including context,
   observations, alternative hypotheses and prediction status. Record its
   externally expected digest. Destroy/reconstruct the learner from those
   bytes and validate exact context/hash before serving masks. This is a
   file-reload restart of a learner inside an arm process, **not** a complete
   OCM/M11 field migration or a newly spawned post-adoption machine.
4. Serve every mask once, in the registered content-hash order. Record the
   prediction before any fallback probe. Mark masks unqueried at restart and
   count sound inferred answers on those masks separately from observed-mask
   reuse. These are within-method interpolation tests, not family transfer.
5. Execute a separate removal counterfactual retaining the same acquired exact
   mask answers but removing generalization. It pays for formerly inferable,
   unobserved masks. Removal keeps ordinary caching; it does not reset the
   parent to ignorance.
6. Only after all arm-local predictions are recorded, an external checker
   independently ranks feasible shapes and checks every live mask. It also
   compares full induced representations with the source routine. All scorer
   discrepancies and negative predictions are retained before refusal.

Semantic identity binds donor manifest, language, original method/evidence
occurrences, method evidence content, baseline identity and live mask. Arm name, display name and acquisition/service
phase cannot create a new contract. Acquisition and unseen-mask inference
sets are distinguished per arm; no inference claim counts an observed mask.
Repeated source families and four-bit masks are not independent observations.

## Resource and preservation contract

Record real source induction calls including baseline, shape checks, observation
reads, learner enumeration/filtering/probe scoring/closure/compression operations,
serialization bytes read/written, persisted effect bytes, generic library bytes,
wall time, CPU time and peak process RSS. Every source membership query actually
executes; no scorer memo table is available to an arm. The initial baseline
method/catalogue is common prior state; its generation/import time remains
inside the arm process envelope. Generic learner construction is paid once,
not omitted and not charged once per method when genuinely reused.

The deterministic operation sum is a declared **instrumentation proxy**, not
an exhaustive bit-complexity measure: Python container/hash/serialization and
source catalogue construction costs are captured by process CPU/wall and
memory, not all by the custom operation count. Source shape checks and evidence
reads remain separate coordinates in addition to the displayed sum.

Treatment counters exclude removal/scorer operations, which have separate
receipts. Whole-process wall/RSS includes those external audit operations and
output writing. It must not be described as clean deployment runtime. Report
the vector and this scope; no arbitrary scalar or operation-only ratio
establishes full lifetime Pareto dominance.

Correctness is exact on the registered finite domain. Zero stale retention and
zero collateral reopening are required for a sound-arm success statement.
Failures and UNKNOWN fallbacks remain in the denominator. LOO is intentionally
unqualified and its errors are retained; it never licenses effect admission.

| ID | Prediction | Decisive falsifier / outcome |

The substantive improvement threshold for this development tranche is exact
quality plus demonstrably useful learned retention beyond stored individual
mask answers. It is **not** a promise of superiority over the antichain parent.
The minimum source-readiness gate must pass before any protected study exists.

## Statistics, stop and claim ceiling

This is a complete finite census of 16 original methods, with 16 correlated
masks each. Report exact counts and per-method paired resource differences,
median/range only as descriptive summaries. Do not assign 256 independent
samples, confidence intervals over relabelled masks, or population p-values.
There is no population-generalization power claim. A future confirmatory
protocol must select independent trajectories/families and freeze power,
noninferiority margins, comparators and stop rules before protected access.

Stop after the registered five arms and all original methods/masks, or a hard
integrity/model-assumption failure. Preserve completed and current raw receipts
and report any remaining arms NOT_RUN; do not replace failures with easier
families, new scales, alternate seeds or extra generations. Any successor
changes get a new version while preserving this run.

Allowed terminals include `PARENT_SUFFICIENT`, `NO_UNSEEN_MASK_INFERENCE`,
`ACQUISITION_COST_DOMINATES`, `MONOTONE_MODEL_ASSUMPTION_REFUTED`,
`INDEPENDENT_INDUCTION_CHECK_FAILED`, and
`LEARNED_BASELINE_RETENTION_SUPPORTED_AT_SOURCE_SCOPE`. None promotes this
tranche to a protected #143 rung exit or field-level evidence.

## B remains E0: learn hidden grouping and wider cognitive effects

The next scientifically broader test must hide method-to-block grouping and
component-to-contract routing, allow all matched parents to infer them from
equal paid interventions, predict unobserved lifecycle effects, and charge
structure discovery/maintenance and safe fallback. The current adapter exposes
`route_s`/`route_d`, and the F4 candidate block memberships are given. Merely
renaming their coordinates would not remove this gift.

Missing apparatus: a source-faithful intervention service with opaque global
handles and no family/role labels; an explicit information/access manifest;
persistent full field rather than just effect records; source-specific
independent trajectories; matched adaptive structure learners and neural
comparators; and a separately frozen protected protocol. Original F1/F5/F6
traces remain missing. B cannot be claimed complete from A, and no arbitrary
new self-reorganization fixture or third generation is added to make it pass.
