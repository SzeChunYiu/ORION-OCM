# Learning operators: donor reduction and next decisive tests

Status: **E0 theory/protocol design; no new empirical result and no unique Machine Epistemics residual established.** Primary sources checked 2026-09-08. Programme snapshots #143, #144 and #145 in `research-context` were read before this review. This map proposes experiments; it neither changes protected protocols nor attributes these externally supplied ideas to autonomous OCM invention.

The useful engineering target is a machine that acquires a reusable transformation, chooses when to use it, and preserves its validity through change. The relevant prior art already supplies substantial mechanisms for all three. A larger named operator list is not evidence of additional cognitive reach.

## Taxonomy and ownership

Classification is relative to the declared field, executable language, task ecology, resource vector and constitution. A change class says where an implementation changes; it does **not** prove algebraic, resource or epistemic irreducibility. In particular, admitting a function composed from existing instructions normally adds a **macro**. A learner producing that function changes the **learning policy**. Altering the equality relation or evidence representation changes the **field/representation**. None automatically creates a primitive.

## Executable contracts and pressure tests

**L0 — Decision-sufficient active learning (highest-priority theoretical parent).** A machine need not identify the full hidden world to act correctly. Javdani et al. formulate overlapping decision regions, seek tests that place all consistent hypotheses inside a common region, and give necessary/sufficient identifiability conditions and the HEC algorithm. Thus “learn only enough to make the decision” is already a parent-owned objective. EC2 supplies a closely related strong active-learning parent for costly tests and noisy observations; noise, prior and test assumptions must be matched. [Javdani et al., AISTATS 2014](https://arxiv.org/abs/1402.5886), [Golovin, Krause and Ray](https://arxiv.org/abs/1010.3091).

OCM adaptation: define regions by repairs whose registered quality/resource/preservation contracts hold, not by the author's preferred diagnosis. Input is the declared hypothesis/repair/probe space; output is a chosen probe or a common admissible repair with its witness. Charge model construction and acquisition-function evaluation as well as probes. Parent: exact finite optimal policy where tractable, HEC, EC2 where assumptions apply, and equal-information greedy policies. Ablation forces full hypothesis identification; compensation allows ordinary decision-region stopping. Negative twin: every hypothesis requires a different action, or no common action is verifiable. Residual candidates concern the cost of learning and maintaining these decision regions under revision, not the basic stopping principle. A supplied region/hypothesis map is prior information in every arm.

**L1 — Trace-derived library induction.** Input is a corpus of actual checked solution traces with parameter bindings, component/checker versions and provenance. Output is a method body in the existing DSL, substitutions for its occurrences, explicit applicability conditions and the evidence linking occurrences to the learned object. DreamCoder jointly develops symbolic abstractions and neural search guidance; Stitch supplies a more direct corpus-guided library learner. [DreamCoder](https://arxiv.org/abs/2006.08381), [Stitch](https://arxiv.org/abs/2211.16605).

Preservation requires checking the generalized body, its substitution rules and every fresh application under the original task contract. Syntactic anti-unification alone proves neither universal soundness nor usefulness. Charge trace extraction, abstraction search, failed candidates, validation, compilation, selection, storage and later maintenance. The causal ablation replaces acquired methods with compensation using the original DSL and equal search budget. A second arm gives the learned library to the parent to isolate acquisition from execution. Negative twin: distinct episodes with no useful recurring structure, plus aliases of one semantic episode that must not count as independent support. Primary prediction: related fresh-task savings repay acquisition at a registered recurrence range. Compression without measured fresh benefit falsifies the useful-acquisition claim.

**L2 — Library induction modulo sound equations.** Input adds an externally declared equational theory to L1. Output is an abstraction whose occurrences can be witnessed through equivalence-preserving rewrites. Babble explicitly addresses syntactic variation by equality saturation and e-graph anti-unification; this is a closer donor for F1 than an unqualified instruction to “invent abstractions.” [Cao et al., babble, POPL 2023](https://arxiv.org/abs/2212.04596).

Preservation requires independently sound equations, typed substitutions and retained rewrite witnesses. Logical truth equivalence must not erase which assumptions or authorities supported a claim. Charge equation/code priors, saturation and witness bytes, normalization work and subsequent lookup. Parent: the same library learner and rewrite theory without OCM-specific organization. Ablation removes the equivalence layer while retaining learner search budget; compensate with ordinary canonicalization. Negative twin: structurally similar but semantically different fragments, or equally true implications with different dependencies. Predicted gain is reduced fragmentation and improved fresh utility; a larger library alone is insufficient. Prefer a small proved normalizer before importing a general e-graph engine unless measured misses justify the latter.

**L3 — Active causal/experimental learning.** Input is a set of competing executable hypotheses, actual probe outcomes and the costs/permissions of additional interventions. Output is a next probe and posterior/version-space update, including unresolved equivalence classes. Active causal discovery already uses interventions to separate structures observational data cannot identify. Its assumptions about graph/model class must be declared rather than silently imported into D0–D8 diagnosis. [He and Geng, JMLR 2008](https://www.jmlr.org/papers/v9/he08a.html).

The check is whether an executed intervention discriminates registered hypotheses, not whether its name resembles the human diagnosis. Charge hypothesis generation, predictive simulation, probe selection and failed interventions. Parent: exact finite minimax/expected-information policy, cost-aware greedy policy and random search with identical interventions. Ablation randomizes choice while preserving paid probes and update rule. Negative twin: hypotheses indistinguishable by every allowed probe, or interventions that restore behavior at several layers. Output must remain non-identifying there. Expected prediction: fewer probes only within model classes where their partition structure supports it. Distinguish “which component caused the historical error?” from “which permitted repair restores the contract?”; these are different targets.

**L4 — Failure-to-constraint learning and counterexample loops.** Input consists of a failed executable hypothesis, exact example/checker response and, where available, its failing subprogram. Output is a scoped constraint excluding a justified family of later candidates. Popper's generate/test/constrain loop and its fine-grained failure explanations are direct parents. CEGIS supplies the candidate/verification/counterexample loop with a separately specified program space. [Cropper and Morel](https://arxiv.org/abs/2005.02259), [Morel and Cropper](https://arxiv.org/abs/2102.12551), [Solar-Lezama, sketching](https://people.csail.mit.edu/asolar/papers/Solar-Lezama09.pdf).

Require a justified exclusion rule: a timeout is not refutation and a failed composition does not invalidate each component. Tie constraints to environment/checker versions so revocation reopens candidates. Charge explanation, solving and constraint-store maintenance. Parent gets the same DSL, examples and explanations. Ablation forgets learned constraints but retains ordinary enumeration; compensation may use standard nogoods. Negative twin: changed premises or a related context where an earlier rejected candidate succeeds. Prediction: reduced repeated candidate work with no loss of valid reachable solutions under the registered semantics. This is learning-policy improvement, not evidence that FAILURE_LEARNING is primitive.

**L5 — Counterexample-guided representation refinement.** Input is an abstraction, a violating abstract trace and a concrete feasibility check. Output is either a real violation or a refined abstraction eliminating the demonstrated spurious behavior. This is the central CEGAR pattern. [Clarke et al., CAV 2000](https://link.springer.com/chapter/10.1007/10722167_15).

Require simulation/preservation conditions for the selected property; refining a representation is not licensed by low score alone. Charge concrete checking, refinements and expanded state/index maintenance. Parent: conventional CEGAR with the same predicate/feature language. Ablation compares fixed abstraction plus compensation by concrete search. Negative twin: the abstract counterexample is feasible in the concrete machine, so refinement cannot repair the actual defect. Predicted benefit is lower whole-lifetime verification work at the same correctness contract, not arbitrary finer representation. F6 labels are not such witnesses without underlying machine traces.

**L6 — Alternative support learning and maintenance.** Input is explicit derivation evidence or paid interventions over candidate supports. Output is sufficient support sets, with completeness stated separately. ATMS labels represent alternative minimal consistent assumption environments; this is an existing epistemic object, not a new OCM primitive. [de Kleer, 1986](https://dekleer.org/Publications/An%20Assumption-Based%20TMS.pdf).

Preservation checks the registered future revoke/restore behavior, including alternatives, authority and external assumptions. Black-box leave-one-out sensitivity is not complete support discovery: redundant alternatives can mask every singleton's effect. A minimal sufficient support is also not a necessary support. Charge acquiring justifications, group probes, label propagation, potentially exponential alternatives and migration. Compare exact ATMS/provenance parents and lazy recomputation; both receive identical information. Ablation replaces alternatives with a single union or singleton sensitivities, with a functional conservative fallback. Negative twins are global dependencies and many alternative supports, where compact locality may fail. Predict fewer stale survivors at matched information; any resource claim additionally needs acquisition amortization. Under unknown/nonmonotone semantics, exhaustive masks over a bounded declared universe provide a local oracle, not a universal discovery guarantee.

**L7 — Contextual routing and selective index maintenance.** Input is verified applicability/outcome and measured per-method/per-query resource experience. Output is a router, index choice or update schedule with exact fallback. Per-instance algorithm selection and contextual bandits already learn such control decisions. [SATzilla](https://arxiv.org/abs/1111.2249), [Li et al., contextual bandits](https://arxiv.org/abs/1003.0146), [AutoFolio](https://ml.informatik.uni-freiburg.de/wp-content/uploads/papers/15-AAAI-Autofolio.pdf).

Routing scores never grant warrant; missing approximate retrieval results trigger the registered exact recovery path. Charge feature computation, training, exploration, index construction, updates and stale repairs. Parent: equally adaptive portfolio/index tuner with the same candidate library, plus best fixed policy and exact scan. Ablation removes contextual selection; compensation includes incremental ordinary indexes. Negative twin: short lifetimes, unpredictable demand or rapid drift where indexing never repays. Prediction concerns a registered quality-constrained resource frontier. An increase in collision rate alone cannot distinguish missing representation from a poor key or insufficient maintenance policy.

**L8 — Behavioral representation learning.** Input is observed transitions and the contract-relevant outputs. Output is an embedding or quotient preserving a declared behavior relation. Bisimulation-based learning supplies a parent for representations that discard task-irrelevant variation while retaining control information. [Zhang et al., ICLR 2021](https://arxiv.org/abs/2006.10742).

For OCM, extend the observable alphabet to warranted answers, revocation, reopening and authority effects before claiming lifecycle preservation. Reward/transition similarity alone does not certify that extension. Charge encoder learning, updates, feature storage and downstream search. Compare exact partition refinement where finite, and a neural representation learner with identical experience. Ablation uses the original state plus sufficient indexing. Negative twin: states identical for the immediate task but different after a future support withdrawal. Treat exact quotient existence as V1/V2 and learned approximation/transfer as V3; do not merge their claim ceilings.

**L9 — Meta-learning, replay and adaptation.** Input is previous development tasks and update trajectories; output is an initialization, update rule or replay policy making later adaptation cheaper. MAML trains for effective subsequent adaptation, while Dark Experience Replay retains past predictive behavior through stored experience and distillation. Neither implies exact epistemic preservation. [Finn et al., ICML 2017](https://proceedings.mlr.press/v70/finn17a.html), [Buzzega et al., NeurIPS 2020](https://arxiv.org/abs/2004.07211).

Use independent exact check/adoption boundaries for each machine generation; changed evidence may require deliberate forgetting, not fidelity to old predictions. Charge all meta-training, replay, storage and tuning. Parent: an equivalently adaptive trajectory, with matched checker/tool/memory powers, rather than a frozen neural network. Ablation resets meta-state while allowing ordinary adaptation. Negative twin: unrelated or reversing task structure where old adaptation bias harms acquisition. Prediction: lower total adaptation cost at equal capability and regression constraints across disjoint development generations; task-sequence advantage alone is not architecture novelty.

## Three next mechanisms, conditional on real evidence

1. **Support-complete revision at declared scope (L6).** F4 is a correctness gap that can corrupt accumulated competence. Begin with the actual affected methods and a bounded, declared candidate-support universe. Compare individual and group interventions against exact subset evaluation. Expose candidate-set gifts, include lazy recomputation and preserve both baseline-rule retention and the newly induced rule as separate targets. A small exact table can establish a counterexample and scoped repair; it cannot establish discovery when relevant supports are hidden outside the supplied universe.
2. **Trace-derived abstraction across semantic equivalence (L1/L2).** For F1, first recover genuine checked trace bodies. Separate extraction failure, abstraction fragmentation, support thresholds and actual utility through competing probes. Compare small sound normalization, ordinary anti-unification and library induction under the same prior. Freeze before fresh development/final families; do not select a learner merely because it reproduces the human-proposed repair.
3. **Cost-aware incremental routing/indexing (L7).** For F2/F3, learn when lookup savings justify updates using actual operation counters. Ordinary incremental maintenance is a serious parent. Keep short-lifetime and changing-demand regions; a phase-dependent parent tie is valuable. Escalate to a richer field only after cheaper routing/key/update alternatives fail under declared compensation budgets.

L0/L3/L4 provide the **method of choosing among these changes**, not a preassigned diagnosis. HEC/EC2 have first right of refusal on the decision-sufficiency principle. L5/L8/L9 remain candidate donors until traces show that their additional complexity addresses an identified bottleneck. This ranking is an external engineering hypothesis and must not become an answer label supplied to blinded OCM.

## Evidence limits and publication consequence

The existing intake manifest pins original source commits/blobs. It contains F1's numerical acquisition funnel, F2/F3 arm-scale tables, F4 partial revision-step rows, F5 per-world aggregate costs, and F6 aggregate oracle disagreement. Original F1 task/certificate/acquisition traces were not recovered here. F5 has neither individual probe histories nor a measured augmented-cached-parent row in the pinned receipt. F6 has no complete retained per-instance repair-evaluation trace. F2 and F3 reuse the same observed source and are not independent studies for this intake. New runs would be new exposed-development experience, not automatically reconstruction of the historical causal facts.

Consequently, `SELF_DIAGNOSIS_NOT_IDENTIFIABLE` or a request for a discriminating probe is currently more defensible than a machine-produced correct-layer label based on these summaries. The distinction between injected faults, observable diagnoses, baseline choice and measured costs itself has mature prior art. [Pill and de Kleer, DX 2025, DOI 10.4230/OASIcs.DX.2025.5](https://dekleer.org/Publications/Pill2025a.pdf).

The surviving research question is whether **a particular combination** of evidence acquisition, scoped learned methods, selection and revision yields a measurable advantage after matching these parents and charging the full lifetime. This map establishes relevant donors and falsifiers; it does not establish that advantage, a smallest operator basis, autonomous invention, or publication readiness.
