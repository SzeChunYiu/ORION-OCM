# AI1–AI8 strongest-parent / novelty ledger

This package does not reclaim parent mathematics.

- **McCulloch & Pitts (1943), DOI 10.1007/BF02478259**: logical/threshold network constructions are a classical parent for fixed threshold-like network computation.
- **Circuit / finite-state / register-machine theory**: owns generic compilation and finite implementation of arithmetic/logical maps.
- **Rumelhart, Hinton & Williams (1986)**: classical weight-adjustment/back-propagation parent.
- **Automatic differentiation / reverse mode**, including Baydin, Pearlmutter, Radul & Siskind (JMLR 2018): owns reverse accumulation as general program differentiation; GMI novelty is not “backprop is chain rule.”
- **Cybenko (1989), DOI 10.1007/BF02551274**: approximation-capacity parent for sigmoidal feed-forward families; capacity is not a morphology-selection theorem.
- **Real et al., AutoML-Zero (ICML 2020)**: strongest empirical precedent that low-level mathematical-operation search can rediscover two-layer network-like learners including backpropagation. AI3's novelty target is therefore stricter causal separation, exact bounded search, dual presentations/searches, frozen negative regimes, full bias ledger and an explicit UNKNOWN channel—not rediscovery alone.
- **Program synthesis / enumerative search / MDL-like length bias**: parent for shortest-program search and its biases.
- **Pareto optimization / algorithm selection / switching-cost optimization**: owns generic selection/crossover mathematics.
