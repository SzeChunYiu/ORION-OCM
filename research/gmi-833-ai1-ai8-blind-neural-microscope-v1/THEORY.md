# AI1–AI8 — blind known-family derivation microscope

This package is a finite falsification microscope for the canonical GMI spine. It tests whether a familiar weighted/nonlinear compositional family can be compiled, recovered and prospectively selected without family-specific information entering the causal generator/search/evaluator.

## AI1 — claim types

Exactly three labels are used:

- `NN-D1 COMPILE`: a supplied family is compiled; proves expressibility only.
- `NN-D2 RECOVER`: architecture-denied lower-process search independently constructs a post-hoc matching organization.
- `NN-D3 PREDICT/SELECT`: a frozen law predicts where the recovered structural region enters/leaves the preferred frontier.

`NEURAL_NETWORK_DERIVED` is forbidden from D1 alone.

## AI2 — fixed computation from lower operations

The supplied two-branch acyclic numeric family is evaluated over integer coefficients `{-1,0,1}`. Scalar multiplication is implemented by repeated addition/sign, finite aggregation by repeated addition, and positive part by the generic transform `max(0,z)`; no transcendental functions are imported. Signed integers can be encoded as `(positive_part, negative_part)`.

The compiler checks all `3^6=729` coefficient settings on all four binary inputs in two low-level presentations: expression composition and a stack program. A separate finite behavioral compiler maps the same complete family to the already-merged G0 register presentation using signed-pair outputs with explicit program/step/register bounds.

A threshold process at this scope is a generic test/select construction `1[z>0]`; positive part is equivalently `SELECT(z>0,z,0)`. These are generic process constructions, not intelligence atoms.

## AI3 — blind recovery

The blind causal lane is frozen in `FREEZE_V1.md` and `BLIND_PROTOCOL_V1.json` before search implementation. It sees only two binary inputs, small integer constants, negation, addition, positive part, task behavior, exact verification and disclosed resource/search budgets.

For XOR/absolute difference, an affine-only organization is impossible because every affine function satisfies

`f(0,0)+f(1,1)=f(0,1)+f(1,0)`,

while XOR gives `0 != 2` on those sides.

Two different search procedures then recover the exact target:

1. bottom-up semantic expression DP ordered by primitive size;
2. breadth-first search over extensional stack states.

The matched identity task is solved at primitive size one, so nonlinear composition is not universally selected. A bijective surface relabeling control preserves the recovered semantics. The full grammar/search/ecology/resource/evaluator bias ledger is explicit; this is architecture-uncommitted only relative to those disclosed priors.

## AI4 — generic reverse differentiation as DEV

A finite acyclic arithmetic tape implements local derivatives and reverse accumulation independently of architecture names. Exact gradients on the registered supplied graph agree with symmetric finite differences away from positive-part kinks. Gradient computation is separate from parameter update; a generic update is just one developmental transformation.

Raw method costs remain vectors. Reverse accumulation trades fewer forward evaluations for a backward sweep and stored intermediates; finite differences use more forward evaluations but less stored activation state. Evolutionary mutation and exact grid search are included as other generic update/search references. No universal optimizer winner is claimed.

The fixed XOR computation still computes XOR when gradients are forbidden, separating architecture capability from learning-law availability.

## AI5 — frozen selection law

Before outcome implementation the registered raw vectors were frozen:

- COMPOSITION `(20,1,4)`;
- RULE `(2,3,1)`;
- TABLE `(100,1/2,100)`;

with raw Pareto vectors primary. One secondary frozen price projection is `C_H=build+H*per_use`.

It predicts RULE for low reuse, COMPOSITION for intermediate reuse, and TABLE for high reuse, including ties at `H=9` and `H=160`. Held-out horizons are frozen in the protocol. A symmetric switching cost produces a history-dependent persistence band. A matched resource-price hostile removes the COMPOSITION region, proving that the result is conditional rather than inevitable.

## AI8 — causal discovery separation

`DISCOVER_GMI` returns unclassified organizations first. On the primary task, exact arithmetic-composition, generic conditional-rule and finite-map mechanisms are capability-valid and all lie on the raw Pareto frontier. The frozen horizon then selects a mechanism class without family labels. Before taxonomy matching, selected arithmetic candidates are `SELECTED_UNKNOWN`.

Only afterward does `posthoc_analysis.py` apply the frozen P1–P6 structural fingerprint. The fingerprint itself is deliberately audited as a narrow, historically informed classifier and therefore cannot prove literal civilization-level ignorance. Its scientific role is only to test whether the causally blind result lands inside the separately registered structural region.

The discovery ladder is applied to the recovered region, rule/direct, lookup, recurrent/stateful, local/shared, routing-like, search/evolutionary and UNKNOWN channels. No L7 novelty or L8 real-scale claim is made here.
