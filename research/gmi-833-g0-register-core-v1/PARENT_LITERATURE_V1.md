# Parent literature ledger — G0-reg-v1

This file records parent ownership. It is not a novelty bibliography.

1. **J. C. Shepherdson & H. E. Sturgis (1963), “Computability of Recursive Functions,” Journal of the ACM 10(2), 217–255.** Register-machine computability is classical parent theory. #868 does not claim that `INC/DECJZ` universality or register simulation is new.
2. **Marvin Minsky (1967), _Computation: Finite and Infinite Machines_.** Counter/register-machine instruction bases and their relation to effective computation are parent material. `G0-reg-v1` is intentionally a disclosed specialization of this tradition.
3. **George H. Mealy (1955), “A Method for Synthesizing Sequential Circuits,” Bell System Technical Journal 34(5), 1045–1079; Moore/sequential-machine tradition.** Deterministic finite input/state/output machines are parent objects. #868 contributes only an exact compiler into its frozen G0 plus a bounded exhaustive certificate.
4. **Gordon D. Plotkin, structural operational semantics.** Rule-based small-step semantics is parent methodology; the rule format is not a GMI invention.
5. **Rajeev Alur et al. (2013), “Syntax-Guided Synthesis,” FMCAD 2013.** SyGuS makes the grammar/candidate set an explicit input to synthesis and anchors the warning that a search grammar is a syntactic inductive bias.
6. **Esteban Real et al. (2020), “AutoML-Zero,” ICML/PMLR 119.** Generic basic-operation spaces can support search for complete learning algorithms, but operation inventory and search remain design choices. #868 does not use this as evidence of unbiased discovery.
7. **Manuel Blum (1967), “A Machine-Independent Theory of the Complexity of Recursive Functions,” JACM 14(2), 322–336.** Complexity accounting depends on machine/program/coding choices unless conditions are stated. #868 therefore retains exact raw vectors and explicit compiler overhead instead of claiming a representation-free scalar cost.
