# V21 independent scientific and executable review

Reviewer authored the paper exposition but did not implement production or the
independent oracle. This is independent code/evidence review, not a second
independent paper authorship. FORMAL_REVIEW records the separate kernel audit.

## Actual implementation inspected

Read core_v21, execution_v21, images_v21 and resources_v21.
The source bridge imports actual immutable V8 and V15 types through V20/V17;
production rejects duck-typed machines. weighted_run follows actual edges and
accumulates their costs. budget_endpoint traverses the actual V8 budget_lift,
then decodes its state to physical endpoint and residual. Its cache stores real
lifts; it does not replace lifted admission with a second total-cost formula.
Whole action tuples are validated before execution can stop at a missing edge.

Image restriction checks every supplied raw history, even if it is unselected.
It updates admission by original P, selection, physical success and resource
feasibility, while preserving E, values and order. Joint images retain actual
cost/value pairings; threshold_witness returns an original roster index and its
cost. Duplicate image values collapse, but history-sensitive evaluation remains.
The generic roster API can contain several starts; the from-x specialization
uses a selected roster/subset of histories with that start, as specified in theory.
No runtime promise of from-x selection is manufactured by a nonexistent x field.

The standalone joint-image functions use Nat-labelled values, so targets outside
a particular attained image are valid and simply unachievable. The roster-based
witness API instead validates target indices against its declared finite Context
codomain. projection validates even unused coordinate-map outputs.

prefix_fold is a resource-only fold with an initial value and capacity. It
validates every cost first, returns every hypothetical prefix aggregate and an
all-prefix-affordable flag. It continues forming aggregates after a failure;
this is not a claim that a physical machine continued executing. Five concrete
resource laws are supplied. No generic Python ordered-monoid machine is claimed.

## Independent oracle and registered tests inspected

Read oracle_v21, test_execution_v21, test_images_v21, test_resources_v21,
test_controls_v21 and test_hostiles_v21. The oracle imports no production logic.
Its traversal accumulates literal costs and prefixes, then constructs expected
stopped observation/edge traces. Execution tests compare both the actual V8
budget argument and actual lifted machine, including full response equality on
success, every registered cut, endpoints, residuals and resource nesting.
The two execution corpora overlap; their model counts are not distinct totals.

Image tests build history-indexed witness fibers independently, compare the
actual admitted Context and all observation cases, and compute all registered
target thresholds and declared projections. Maximum finite corpus cost covers
its selected histories; this finite union test is not the all-Nat union proof.
Arbitrary target subsets are appropriate for exact image membership, whereas
V20 frontier pruning would require upward goals.

Resource tests compare all literal prefix aggregates, all registered cuts and
comparable capacities. Signed final-only failures are measured rather than
assumed. Their noncommutative control uses actual 3×3 matrices; the paper's 2×2
example is a separate direct mathematical illustration. Neither is silently
promoted to a universal tested matrix implementation.
Countermodels exercise residual resets, signed and peak semantics, opposite
joint pairings, changed targets/evaluators, lost history witnesses, incomparable
vector minima and initially unaffordable empty words. The Real nonattained
infimum remains paper evidence, not a finite-calibration conclusion.

Hostiles reject malformed suffixes after failing prefixes, unused data, empty
selection bypasses, duplicate sets, malformed tuples and Boolean/integer aliases.
The distinction between generic Nat targets and finite Context targets is tested
with both rejecting and valid empty-image controls.
