# V21 separating controls and explicit repairs

These are analytic falsifiers for the declared laws. The finite receipt must

## U5.1 — residual, prefix and peak semantics

Two successive costs1,1 with initial1 fail on the second action. Testing each
segment with a fresh1 would admit both. Retaining the actual residual0 repairs
composition. Truncated subtraction alone also fails: max(0,0−1)=0 does not
mean a cost1 action was admissible from0.

Signed costs+2,−2 with initial spent0/capacity0 have final total0, but the first
prefix spends2 and must fail. Maximum prefix demand2 restores the correct
condition. The empty prefix matters too: an empty word at spent0/capacity−1
is unaffordable. Nat cannot supply that negative capacity; the signed model can.

Peak demands5,5 combine by max to5 and both fit capacity5. Blindly subtracting5
after the first step incorrectly rejects the second. Use cumulative max rather
than force a consumable interpretation onto peak capacity. Vector addition and
mixed time-add/peak-max supply independent coordinates, not a hidden scalar sum.

## U5.2 — joint information and stable evaluation

Let J1={(0,bad),(1,good)} and J2={(0,good),(1,bad)}. Both have the same cost
marginal {0,1} and value marginal {bad,good}, but target{good} costs1 in J1 and0
in J2. Some cost/value association is indispensable; the full J need not be retained
(its per-value least-cost profile suffices). Relabelling the target to{bad}
changes capability while J itself stays fixed. Neither objectives nor costs
are recoverable from a bare unlabelled attainable-value set.

At a zero-cost empty history, an evaluator that returns the initial allowance b
has image {b}. Larger resources do not give set inclusion {b}⊆{b+1}.
Fix the evaluator on raw histories to revive the nesting theorem. Alternatively,
state a genuine comparison transport between contexts; no such transport is
automatically supplied by a numeric resource label.

Label two restrictions 0 and1 but choose disjoint singleton history sets. They
need not be nested. Operational Nat prefix admission supplies nesting only
because actual affordability was proved monotone, not because of those names.

## U5.3 — preserve histories and distinguish failure modes

A one-state machine has a self-loop, and E holds only for a word of length2.
The evaluated target is reached by two loops; the zero-length path at the same
endpoint is undefined. Erasing histories to endpoints or restricting to simple
physical-state paths destroys the only target witness. A sufficient finite
observer tracking word length could repair that representation, but is extra
structure that must be constructed and checked.

A V8 observation label None, absent edge, rejected P and false E are different:
only the absent edge prevents physical execution; rejected P excludes an
otherwise successful history; false E makes an admitted evaluation undefined.
A defined ambient value on an illegal history is preserved but not attained.
Validate malformed later actions even after a failed prefix or empty selection;
otherwise input acceptance depends on an accidental short-circuit path.

## U5.4 — scalar thresholds are conditional

Two target histories have vector costs(1,0) and(0,1). Both are minimal, but
neither is a least feasible vector cost, and (0,0) is not attained. Nat's least
scalar threshold theorem must not manufacture a least vector or scalarization.

For each n≥1 let a target history cost1+1/n in the nonnegative reals. Their
infimum is1: every cost exceeds1, and for every epsilon>0 some1/n<epsilon.
No history attains1, so capability at1 is false despite infimum≤1.
Nat well-ordering supplied an attained minimum; arbitrary Real infima do not.
Likewise a semiring aggregate need not be realized by any individual path.

Finally, all finite-length images may approach a missing limit value or have
arbitrarily long witnesses without an infinite witness. The two unions in U2.2
only collect values actually produced by some finite history. Infinite traces,
limits and almost-sure events require separate semantics and evidence.
