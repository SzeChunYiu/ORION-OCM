# Falsifiers and evidence boundaries

The [freeze](FREEZE_V26.md) fixes all A–C strata and iteration orders. Counts here
are planned candidate counts or inherited catalogue facts, not reported outcomes.
Only actual receipts and independent reviews establish completed checks.

## Independent finite design

A enumerates153 object/arrow-map candidates over every lawful labelled table with
0..2 arrows. Genuine functor validation checks endpoints, identities, then legal
composition; it must not assume reflected joins or injectivity. For accepted F,
all raw source trees with1..3 leaves are compared by independent recursion against
actual V25 evaluation. With a=n+k leaf symbols their count is a+a²+2a³;
total executed trees is the measured sum over accepted F. Every noninjective object
map has a literal two-Empty counterexample, not a random search for one.

B tests439 arrow subsets of all lawful tables with0..3 arrows. Original identity
retention and inherited composition closure are separate predicates. Each failed
case has an actual omitted identity or admitted pair with omitted product. Valid
subsets retain every object and have all restricted1..3-leaf trees compared with
their ambient images. The accepted-restriction and executed-tree counts are measured.
A retained idempotent does not license replacing an omitted original identity.

C uses the three-object chain, nine balance-state objects and fourteen arrows.
All196 ordered resource-arrow pairs and2331 same-word lift requests are checked.
The independent oracle checks typedness, balances, residuals and literal projected
words; it does not infer path existence from the composite arrow alone. Source
and target labels, including empty-word anchors, remain observable.
All labels and loop orders are fixed in the freeze, with no RNG or hidden sample.
The four-arrow indiscrete-equivalence control is separate from exhaustive A.

## Decisive mathematical controls

- BC2→terminal: object injection and full raw transport, but no output recovery.
- Discrete two objects→terminal: hom-faithful, yet failed Empty joins become valid.
- Indiscrete two objects→terminal: even full faithfulness/equivalence is insufficient.
- Nat P(n)≤1: identity retained, product1+1 missing; P(n)>0: converse law failure.
- Resource balance mismatch: valid individual edges project to a newly valid join.
- Coherent two-step lift: balance1 fails, balance2 revives; malformed base joins never revive.
- K_(1/3),K_(2/3): actual probability distinction despite identical support.
- Uniformized branching: (1/2,1/4,1/4) differs from (1/3,1/3,1/3).
- Reset monoid: any unchanged-category tensor contradicts necessary interchange/unit laws.
- Chosen nonbraided tensor: required cross-hom is empty; alternative tensors are not excluded.

Each negative is attributed to one premise or observer. Its valid conditioned
revival is stated; an enriched datum is not silently erased to force success.

## Hostile implementation and proof controls

Reject bool/float index aliases, wrong tuple shape/length, invalid unused map
entries, invalid categories, malformed later tree descendants and duplicate
restriction IDs. General functors intentionally admit repeated images. Semantic
incompatibility returns None rather than being confused with malformed input.
Mutate real mapped leaves, output arrows/endpoints and failure tags; coupled tree
and response edits must still satisfy the fixed supplied functor, not a new one.
A valid baseline precedes every mutation family, with actual rejection counters.

The six-row ledger guard binds exact original row order/component/status and its
reviewed evidence fields. Deletion/reordering/renaming tests exercise actual data;
string checks alone are not proofs of the claims or natural-language consistency.
Fresh isolated Lean replay registers exact types and constructor equations.
Four source-valid controls empty all sources or replace one of raw-transport iff,
restricted-history transport, and exact same-path lifting by True. Each changed
source must compile before the typed audit rejects its weakened statement.
Locally discrete operations/coherence remain explicitly registered independently.

Finite Python evidence is separate from generic kernel proofs and from paper
interpretations of standard enriched structures. Scope, receipt and source hashes
must agree; normal/-O test coverage and receipts must match. Missing prerequisites
are CANNOT_CHECK, never a successful empty audit. No whole-R1/full-GMI promotion.
