# R6 — blank-computer genesis

## 1. Architecture-blind discovery
Let e_S : N -> P_S be an effective enumeration of finite constructible process descriptions. A fair scheduler visits every finite index and dovetails evaluation of every candidate.

Finite discovery theorem: for any constructible candidate p*=e_S(k) whose registered evaluation terminates, a fair enumerator/evaluator eventually evaluates p*. If its contextual value is nondominated, it eventually enters the maintained frontier. This is coverage, not efficient search.

## 2. No literal prior-free finite-time search
On a countably infinite candidate set, no countably additive probability distribution can give every candidate the same positive mass: positive p makes the total diverge, while p=0 sums to zero. Any deterministic finite-time enumeration also visits some descriptions before others. Thus the valid standard is NO ARCHITECTURE-SPECIFIC PRIOR + DISCLOSED GENERIC PRIOR, not NO PRIOR.

This is consistent with No-Free-Lunch / universal-search parent mathematics.

## 3. Persistent state emerges
DELAY1 requires y_t=x_{t-1}, x_{-1}=0. Exhaust all 4 stateless Boolean maps and 256 one-bit Mealy tables on all 62 binary sequences through length five. No stateless map works; exactly one one-bit organization works. Persistent state is forced by future distinguishability rather than preloaded.

## 4. Representation emerges
Use R4's response-signature quotient: histories indistinguishable under every relevant continuation can share a representation; separated histories cannot. The representation is discovered as a resource-saving quotient, not an architecture primitive.

## 5. Abstraction emerges
Inlining a repeated subprocess q n times costs nL. Introducing a reusable abstraction costs D+nc, c<L. The abstraction is beneficial exactly when
D+nc < nL,
equivalently n > D/(L-c).
This gives a prospective resource crossover for primitive/library invention.

## 6. Learning emerges
Two equally likely hidden contexts map binary inputs by ID or NOT. The machine observes the label for x=0 and must answer x=1. Any fixed answer gets 1/2 average accuracy. Enumerating all four maps from training label to query answer gives exactly one perfect rule: answer 1-y_train. No learner macro is supplied.

## 7. Search adaptation emerges
With two equally likely solution targets A/B and a perfect one-bit cue, fixed order [A,B] or [B,A] costs 3/2 evaluations on average. Cue-conditioned order costs 1 plus cue cost c. Adaptive search is strictly better iff c<1/2, ties at 1/2, and loses above.

## 8. Reflective closure
If program descriptions P are process objects, an evaluator U is admissible, and modifiers m:P×D->P are admissible processes, then program modification is ordinary process composition. A modifier of a modifier is another encoded program/process. Any finite self-modification tower therefore remains inside the same reflective process universe; no primitive DEV/METADEV hierarchy is required.

## 9. UNKNOWN
The causal search emits opaque candidates and contextual values. Family labels are optional post-hoc metadata. UNKNOWN is a successful terminal, not a failure.
