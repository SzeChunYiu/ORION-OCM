## Conditional arguments connected to the code

**Continuation correctness.** For the declared total deterministic primitives, induction over suffix length establishes E(p·s,x)=E(s,E(p,x)). Each stored E(p,x) is independently checked by coefficient evaluation before indexing. Replacing that point call therefore leaves every subsequent branch of the unchanged deterministic solver identical. This argument assumes source/context integrity and excludes arbitrary side effects, undefined arithmetic and adversarial concurrency.

**Exact-parent sufficiency at the instruction coordinate.** P2 contains every P1 full-match certificate. On a full match, both skip the same work. On a proper-prefix match, P2 skips a nonnegative number of primitive steps while P1 skips none. On a miss, both execute the original program. Thus P2 weakly dominates P1, and P0, in interpreter-step count on every legal point call. The choice at this coordinate does not require a learned router; the validation selection is not evidence that policy learning is necessary.

**Support safety at the tested boundary.** Exact conjunctive warrants imply that losing either prerequisite removes representation liveness. The loader verifies the stored warrant shape, payload identity and source/context binding and chooses an exact fallback. This is checked through actual persisted withdrawal/restoration, not merely a callback flag. General atomic crash recovery, concurrent adoption, operator-language evolution and whole-runtime invariant refinement remain outside this contribution.

**No economic inference from instruction dominance.** Prefix reuse adds index work. At separate symbolic prices, the observed point-to-prefix comparison wins only if

    130377*w_instruction + 63924*w_dictionary
      > 236713*w_edge + 241253*w_terminal + C_extra.

If all lookups have a common unit price, the 130,377 saved interpreter steps must pay for 414,042 extra lookups plus additional construction, selection and lifecycle costs. These are symbolic prices, not measured physical conversions. No energy or active-k/N value is inferred.
