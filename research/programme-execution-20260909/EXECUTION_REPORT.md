### Mechanism and conditional foundation

The unchanged `ocm.learning.methods.solve` searches and checks exactly as before.
Its pinned source blob is `50323a33418b8ef8bb6500ddeba4b9d1f795e9e3`. A research-only,
single-threaded adapter substitutes a checked value for an otherwise identical
point-interpreter call, restoring the original function in a `finally` block.

Actual training mismatches produce records of the exact program, point, result,
mathematical target, budget, environment, source and outcome. The independent
symbolic coefficient evaluator checks each retained point value. The first 64
distinct program/point mismatches are selected in frozen training/search order;
there is no test-aware utility tournament. Incomplete search outcomes cannot become
failure certificates.

Conditional argument: if the deterministic interpreter in the bound context has
`E(program, x, context) = value`, substituting that checked value for the same call
preserves the solver's observed values. Induction over its unchanged search order
then preserves first solutions, result statuses, counterexamples and slot counts.
This does not preserve cost: validation, lookup, storage and lifecycle work replace
some interpretation. A previous mismatch with one target says nothing about task
impossibility or success against another target.

Budget/environment mismatch reopens actual interpretation; invalid certificate
source/domain and actual source-pin drift fail closed. Thus the frozen protocol's
broad source-change fallback prose is not a claim of automatic migration to an
unqualified new engine. Tests cover both behaviors. The index constructor and
single-threaded adapter are trusted internal paths, not a security boundary against
arbitrary Python callers.

The existing OCM evidence registry, support edge and warranted procedure/data object
persist the selected records. Actual `OCMRuntime.revoke` and `reinstate` alter
support. Every comparison consumer runs in a fresh OS process. The ordinary parent
receives the identical records, checks, index and solver. No learned router or new
cognitive core is introduced.
