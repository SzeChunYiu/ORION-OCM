# AG1 / AG8 parent ownership and residual contribution

## What is NOT claimed novel

- **Dependency graphs, typed provenance edges, topological ordering, transitive closure.** Standard
  graph theory (Kahn, *Topological sorting of large networks*, CACM 5(11), 1962,
  doi:10.1145/368996.369025).
- **The ten-layer stack itself.** `F0..F9` is quoted from issue #833 comment `5693520829` section
  AG1. AG1 formalizes it; it did not invent it.
- **Every node's mathematics.** Each of the 32 nodes is owned by a merged package or by external
  parent literature, pinned by path and git blob sha. In particular:
  `gmi-833-aj1-operational-process-base-v1` (process frame),
  `gmi-833-aj2-operational-equivalence-v1` / `gmi-833-aj3-distinguishability-v1` (operational
  theory), `gmi-833-aj4-process-organizations-v1` (machine space),
  `gmi-833-aj5-g0-lowering-v1` (lowering and overhead), `gmi-833-g0-register-core-v1` (`G0`
  semantics), `gmi-833-aj6-hst-layer-map-v1` and #233 HST/HSG (developmental dynamics),
  `gmi-833-aj8-intelligence-boundary-v1` (capability boundary),
  `gmi-833-aj11-bounded-completeness-v1` (bounded atlas),
  `gmi-833-aj12-foundation-substrate-relativity-v1` (foundation/substrate relativity and the five
  assumption classes), `gmi-833-aj7-objective-provenance-v1` (requirement provenance),
  `gmi-833-morphology-selection-v1` (selection).
- **Foundational pluralism.** Set-theoretic, type-theoretic/univalent and categorical foundations
  are established parent programmes; AJ12 already owns the repository's relativity result. The two
  `MUTUAL_INTERPRETATION` `F0` nodes exist because neither style is privileged, not because AG1
  proved anything about them.
- **The AI0 convergence spine.** `gmi-833-ai0-convergence-spine-v1` owns the interface-keyed
  authority DAG and the `NO_NEW_GMI_UMBRELLA_UNTIL_CONVERGENCE_V1` gate. AG1 is **not** a competing
  umbrella: it is layer-keyed where AI0 is interface-keyed, and each AG1 node cites its AI0 node.
- **The AG8 protocol steps.** Quoted from the same comment. The upward counterparts (AA/AD gap
  closure, HSG Reflexive Generalization Closure) are owned by #833 comment `5684607872` and #233.

   typed arrows, 21 blob-pinned parent packages — where the corpus previously had only an
   interface-keyed DAG.

   must exist in the cited receipt, no upward arrows, and same-layer refinements that must declare
   themselves.

   verified path down to `F0`.
4. **Primitive-provenance and bottom-exposure gates**, and the honest display of the one node whose
   lowering status is still `UNKNOWN`.
5. The **first-divergence layer `F6`** for a matched pair, consumed from AJ6's pinned receipt,
   which is the layer-indexed statement of why the grammar layer cannot be the intelligence
   boundary.
6. AG8's eight steps registered as **machine-checked downward obligations** cross-linked to their
   real upward counterparts.
