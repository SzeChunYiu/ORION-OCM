## Central hypothesis

OCM gains a lifetime advantage only if it can learn a sufficiently accurate, sparse causal factorization of its own cognition so that learning, reasoning, revision and self-improvement become local and amortize structure-discovery/maintenance cost.

The decisive question is whether learned structure makes future cognition/self-improvement cheaper **after discovery, routing, validation, maintenance and failure costs are charged**, and whether any residual survives strongest adaptive parents.

## Internal adversarial review roles

- **Causal/identifiability reviewer:** rejects task-ID/generator leakage, checks alternative-support identifiability and hidden-cause ambiguity.
- **Online/meta-learning reviewer:** strengthens adaptive symbolic, surrogate and search parents; audits amortization and drift.
- **OCM/M11 systems reviewer:** requires real diagnose → proposal → shadow → external adoption → restart → fresh-reuse lifecycle and exact resource receipts.
- **Publication-methods reviewer:** enforces exploratory/protected separation, frozen seeds, negative terminals, full vector reporting and claim ceilings.

No role may tune a comparator after protected outcomes.

## Frozen experiment families

### E150-A — reusable method discovery without task identity

**THEORY QUESTION** Can a learner recover reusable sparse methods from heterogeneous episodes when no task/family ID, routing key or generator metadata is observable?

**PREDICTION** A factorized learner should recover minimal reusable clauses and improve future held-out decisions only when episode features identify stable reusable structure.

**STRONGEST PARENT** Incremental symbolic DNF/version-space parent with the same observable episodes, exact episodic memory, minimal-clause caching and local invalidation. Global exhaustive refit and evolutionary clause search are secondary parents.

**RED COUNTEREXAMPLE** Exact or incremental symbolic parent matches factor recovery/capability at <= lifetime resource vector; donor composition helps neither.

**MECHANISM** Discover minimal sufficient conjunctions from success/failure episodes; reuse clauses across future episodes. No explicit task key is present.

**CAUSAL ABLATION** Reset learned clauses each generation; shuffle donor pool; exact-reuse-only; remove factor cache while retaining episodes.

**FALSIFIER** No protected held-out capability gain, no reduction in future discovery/update work, or adaptive symbolic parent matches/dominates.

**CLAIM CEILING** At most a regime-bounded learned-factorization residual; never OCM-specific if the adaptive parent matches.

### E150-B — higher-order and alternative dependency supports

**THEORY QUESTION** Can the learner discover all minimal alternative supports (DNF/hyperedge supports), rather than a supplied graph or leave-one-out single-parent proxy?

**PREDICTION** In identifiable sparse worlds, recovered minimal support antichain has high exact support F1 and enables local invalidation; dense/drifting worlds erase the benefit.

**STRONGEST PARENT** Incremental exact symbolic minimal-support learner over the same candidate grammar and observations.

**RED COUNTEREXAMPLE** Learned support is incomplete, spurious, or parent-owned; local maintenance exceeds lazy re-derivation.

**MECHANISM** Enumerate candidate conjunctions up to frozen width, keep clauses sufficient for positives and excluding negatives, then prune supersets to an antichain.

**CAUSAL ABLATION** Supplied support graph is forbidden; leave-one-out support learner is an explicit incomplete ablation; cache deletion and lazy re-derivation are controls.

**FALSIFIER** Exact-support F1 < 0.90 in sparse/stable protected worlds with enough identifying episodes, or no future locality advantage after maintenance.

**CLAIM CEILING** Identifiable bounded Boolean-support discovery only.

### E150-C — learned relevance/subspace without routing keys

**THEORY QUESTION** Can relevance be inferred from episodes alone and lower future work without maintenance domination?

**PREDICTION** Stable sparse worlds permit a reusable small relevant set; dense and drift regimes increase maintenance and coupling.

**STRONGEST PARENT** Symbolic parent derives relevance from its learned minimal supports; lazy parent recomputes from current episodes.

**RED COUNTEREXAMPLE** Relevance is merely a by-product available to the parent, or maintenance cost >= saved prediction/update work.

**MECHANISM** Relevant coordinates are the union of variables in live minimal support clauses; no routing key is supplied.

**CAUSAL ABLATION** Delete relevance cache but retain factors; random same-cardinality relevance; full-space parent.

**FALSIFIER** No protected resource-vector improvement in stable sparse regime, or adaptive parent matches.

**CLAIM CEILING** Subspace caching benefit, not a new cognitive primitive, unless parent subtraction leaves a residual.

### E150-D — hidden-cause failure diagnosis

**THEORY QUESTION** Can cause/layer be diagnosed when the oracle cause label is never an input?

**PREDICTION** With diagnostic intervention/ablation outcomes, the minimum sufficient repair can be inferred; symptom-only observationally aliased causes must return `CANNOT_CHECK`.

**STRONGEST PARENT** TMS/nogood + exact intervention-outcome table with the same observables; no oracle labels.

**RED COUNTEREXAMPLE** Diagnosis depends on hidden label leakage, frequency, or parent memory; aliased causes are guessed rather than refused.

**MECHANISM** Infer the lowest repair class whose intervention restores behavior, with obstruction evidence before escalation.

**CAUSAL ABLATION** Remove intervention channel; shuffle repair→outcome mapping; remove learned diagnosis state while retaining traces.

**FALSIFIER** Protected minimum-level accuracy <= parent, false-Jump rate > parent, or alias worlds do not produce `CANNOT_CHECK`.

**CLAIM CEILING** Intervention-identifiable diagnosis only.

### E150-E — multi-generation learned factorization / effective coupling

**THEORY QUESTION** Does learned factorization reduce the fraction of cognition touched by later changes over multiple generations?

**PREDICTION** Sparse/stable: coupling and update work decline after discovery. Dense: no locality. Drift: benefit survives only below a regime boundary where saved work exceeds rediscovery/maintenance.

**STRONGEST PARENT** Incremental symbolic factor learner with local invalidation; global exhaustive refit; evolutionary/global search; online surrogate parent.

**RED COUNTEREXAMPLE** OCM-like factorizer and strongest parent have equal factorization/coupling/cost, or maintenance dominates.

**MECHANISM** Retain learned minimal support antichains and refit only outputs contradicted by new evidence.

**CAUSAL ABLATION** Reset every generation; retain episodes but delete learned factor state; force global refit.

**FALSIFIER** No monotone reduction in median touched fraction after discovery in sparse/stable protected lifetimes, no amortization by generation 8, or adaptive parent matches/dominates.

**CLAIM CEILING** Regime boundary over sparsity × drift × horizon, not a universal law.

### E150-F — real M11 lifecycle bridge

**THEORY QUESTION** Can a learned failure/factorization signal drive the existing M11 governed lifecycle and yield fresh post-restart reuse?

**PREDICTION** Only an identified minimum-sufficient change should be proposed; it must be receipted before shadow outcome access, externally adopted, persisted/restarted, and improve fresh tasks without preservation regression.

**STRONGEST PARENT** The same M11 lifecycle driven by the strongest adaptive symbolic diagnosis/repair parent.

**RED COUNTEREXAMPLE** OCM proposal is broader, M11 refuses it, restart loses the learned state, fresh reuse disappears, or parent repair matches/dominates.

**MECHANISM** Existing `ocm.selfmodel` FailureRecord/diagnose/proposal/governance/adoption ledger; no simulated self-approval.

**CAUSAL ABLATION** State deletion before restart; broader-than-minimum proposal; prediction receipt after shadow; self-approval hostile.

**FALSIFIER** Any governance failure, no fresh-reuse benefit after restart, or strongest parent matches at <= resources.

**CLAIM CEILING** Governed reuse of a learned repair; not autonomous recursive self-improvement.

## Frozen worlds and seeds

Development seeds (exploratory only): `1..8`.

Protected seeds (never used for tuning): `9001..9040`.

Each seed produces three regimes with 12 observable Boolean coordinates, 4 output/repair families, 8 generations, 96 training episodes and 256 fresh evaluation episodes per generation unless an identifiability check requires additional frozen diagnostic interventions.

- `sparse_stable`: 2 alternative supports/output, conjunction width 2, supports fixed for all generations.
- `dense`: 2 alternative supports/output, conjunction width 6, overlap allowed, supports fixed.
- `drift`: starts as sparse; exactly one output support clause is replaced at the start of generations 3, 5 and 7 using that seed's independent RNG stream. Replacements cannot reuse the immediately prior clause.

No task ID, regime label, hidden support, cause label, generator seed, donor identity or routing key is included in learner-visible episode records. Regime is evaluator metadata only.

Protected generation uses separate RNG streams derived from `sha256("E150-V1|<seed>|<stream>")` for hidden structure, train episodes, evaluation episodes, drift and search-parent randomness. This prevents consumption-order changes from altering hidden worlds.

## Frozen candidate grammar / identifiability

Minimal-support learners may consider positive conjunctions up to width 2 in sparse/drift and up to width 6 in dense, but **the learner is not told the regime**. Therefore all arms use one frozen maximum width 6. To keep exact enumeration feasible, candidates are formed from positive examples then pruned against negatives; every primitive literal test is metered.

A support is identifiable only if the observed train set contains both positive witnesses and separating counterexamples for every proper subclause. Non-identifiable target supports are excluded from exact-support accuracy and counted separately as `CANNOT_CHECK_SUPPORT_IDENTIFIABILITY`; capability outcomes remain reported.

For hidden-cause worlds, causes that induce identical observable/intervention distributions are grouped into an equivalence class; exact cause identity is `CANNOT_CHECK`, never guessed.

## Frozen arms

1. `factor_local`: learned minimal support antichains + cached relevance + local invalidation.
2. `symbolic_incremental_parent`: exact symbolic antichain learner with episodic memory and local invalidation; receives every power of `factor_local` that is parent-owned.
3. `symbolic_lazy_parent`: retains episodes and re-derives supports only when queried; no eager maintenance.
4. `global_refit_parent`: refits every output from all retained episodes after each generation.
5. `evolutionary_parent`: population search over clauses with the same observed episodes and a frozen primitive-evaluation budget equal to `global_refit_parent`'s actual induction evaluations for that generation; no access to hidden supports.
6. `surrogate_parent`: online main-effect + pairwise-conjunction score model over observable literals, updated on every episode; no task key.
7. `reset_factor_ablation`: same algorithm as factor_local but learned factor state is deleted between generations.
8. `loo_dependency_ablation`: leave-one-out dependency proxy retained specifically to measure the known incompleteness.

A neural/Transformer adaptation arm is `CANNOT_CHECK_NEURAL_MATCHED` in V1 unless a pre-existing dependency-pinned implementation in the repository can be run without adding an unmatched pretrained information source. A weak from-scratch neural toy is not accepted as the strongest neural parent.

## Frozen resource vector

Every arm reports, without scalar collapse:

`[heldout_accuracy, support_precision, support_recall, relevance_precision, relevance_recall, primitive_literal_evals, induction_candidates, update_components_touched, prediction_literal_evals, validation_examples, state_bytes, maintenance_ops, rediscovery_ops, failed_repairs, proposals, shadow_examples, adoptions, restart_bytes]`.

Derived `effective_coupling = update_components_touched / total_components` is reported per generation. Any wall-clock values are descriptive only because Python/runtime noise is not the causal cost model.

## Protected decision rules

A claimed OCM-specific residual requires all of:

1. sparse/stable protected held-out capability is non-inferior to the strongest parent (paired seed median accuracy difference >= -0.01);
2. exact-support F1 >= 0.90 on identifiable sparse/stable supports;
3. by generation 8, factor_local has lower median touched fraction **and** no worse discovery+maintenance primitive work than the strongest adaptive parent on >= 30/40 protected seeds;
4. the advantage persists under full resource-vector disclosure and is not solely state-size/validation tradeoff;
5. reset/state-deletion ablation removes the future-cost benefit while retaining access to the same episodes;
6. dense and drift outcomes are reported and define a boundary rather than being omitted;
7. M11 fresh-restart reuse passes governance and beats the same lifecycle driven by strongest parent diagnosis/repair.

If `symbolic_incremental_parent` matches capability and has an equal-or-better resource vector, terminal is `PARENT_SUFFICIENT` even if factor_local beats global search.

If sparse/stable structure itself is not identifiable under the frozen generator, terminal for structure recovery is `CANNOT_CHECK`, not a favorable extrapolation.

If factor_local fails the sparse/stable mechanism checks, the corresponding hypothesis is `REFUTED`.

## Statistical/reporting rule

All 40 protected seeds are published. Paired bootstrap 95% intervals over seeds may be reported for descriptive differences, but no outcome-conditioned family removal is allowed. Multiple regimes/metrics remain a vector; no composite score authorizes the claim.
