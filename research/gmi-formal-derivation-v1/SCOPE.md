# Requested milestones and exact theorem scope

Status describes this formal unit, not the whole scientific programme.
"Conditional proof" means its displayed hypotheses are necessary parts of the
claim; it does not mean those hypotheses were experimentally established.

## Precise parent mappings

| Existing framework | Added specialization and conclusion |
|---|---|
| Bayesian inference | A prior, conditional likelihood and positive evidence probability yield MEM4/O3. Bayes is also a KL-plus-log-loss update; posterior calibration is not automatic. |
| Information theory | Full-profile distinguishability plus a finite deterministic fixed-width code gives MEM1's bit lower bound. Garbling gives attainable-risk inclusion, not a universal semantic-information scalar. |
| Statistical learning/PAC | Fixed measurable class, bounded loss and IID observations give L2. Summable all-time confidence plus class inclusion yields L3. |
| MDL/Occam | A declared prefix-free code sets prior mass via Kraft and therefore L2's complexity penalty. Interpreter constants, execution costs and incomputable optimum search remain separate. |
| Online learning | Full-information finite expert losses and entropy geometry give L4/O2. Adaptive loss sequences are allowed; hidden current sampled actions need the stated timing contract. |
| Reinforcement learning | Identified sufficient controlled state plus reward and horizon gives AG2/AG3; stochastic transitions do not themselves identify causal action effects. |
| Causal inference | Supplied structural intervention semantics gives CAU1; exchangeability/positivity/consistency give CAU3. Equal observations alone fail CAU2. |
| Active learning | Prospective query selection with a valid conditional evidence law fits ADAPTIVE; useful query selection uses RES2 and includes acquisition cost. |
| Neural computation | Supplied discrete encodings and gates give finite realizability; supplied differentiable layers and objective give O4/O5. These do not establish neural necessity. |
| Automata and sufficient state | Equality of complete future response profiles plus continuation closure gives recursive deterministic quotient machinery; measurability/closedness are additional in stochastic settings. |

## Boundary between a theorem and its physical application

To apply any row to a real OCM system, bind the claim to the actual source,
initial state, observed interface, environment version, evaluator and resource
instrument. A correct analytic theorem can have an incorrect software
implementation. An exact finite software witness can implement a model that
does not describe the deployment environment. Neither case is repaired by
renaming the failed result as a completed theory milestone.

This unit adds a coherent formal route. It does not assert that every open
question in GMI has been enumerated or solved, and preserves the existing
[scientific gap queue](../gmi-grand-unification-v1/SCIENTIFIC_GAP_QUEUE_V2.md).
