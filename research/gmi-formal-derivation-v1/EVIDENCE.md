## Analytic review corrections incorporated

- A global filtration and attained-visit stopping argument replace conditioning
  on whether an adaptively selected sample prefix exists. Birth allocations
  are measurable before scored outcomes, and their total is controlled pathwise.
- Zero probabilistic failure implies almost-sure safety; safety on every admitted
  path requires pointwise invariant preservation. Kernel comparison needs a
  common initial law and the functional's correct range factor.
- Local interfaces must discharge consumer premises. Lost versions, a shared
  hidden seed and uncharged extra failure events cannot be ignored by composition.
- Stochastic state substitution preserves the complete observed context, legal
  actions, joint register updates and initial correlations. Model-selection
  coverage is acquisition-measurable before applying deployment coupling.
- General e-processes must be adapted; stopping validity is imposed on each
  finite true-null birth event, avoiding vacuous premises on never-born paths.
- Lossless full-profile retention differs from mere relational task adequacy.
  Retention benefit is measured against the actual best discard/guessing policy.
- Finite enumeration needs effective objective bounds and valid comparisons.
  Reverse-mode work follows actual elementary-operation work; scalar slots do
  not bound arbitrary-precision storage bits.
- Acquired transducer deployment must restore or reconstruct the matching
  current state. Disjoint-union refinement improves the distinguishing bound
  to `2m−1`; maximal-length queries contain all shorter output prefixes.
- Support discovery explicitly requires a complete alphabet, predictable visits,
  birth-measurable parameters and a positive-mass floor. Singleton alphabets
  are excluded from the two-symbol impossibility examples.

These are substantive statement/proof repairs. A review reporting no additional
counterexample within stated scope is not an exhaustive mathematical audit of
all possible GMI theorems or a claim of independent human peer review.

## Finite mathematical witnesses

The test modules use exact rational or discrete arithmetic. They compare
Bellman backups against complete history-policy trees, acquired transducer
signatures against unrestricted reachable-product exploration, neural blocks
against transition tables, derivatives against exact polynomial differences,
and admission/settlement inequalities against independently summed costs.
Adaptive examples distinguish valid correlated evidence from replay,
postselection, optional monitoring and changed-target failures.

The finite test identities and count are recorded by the freeze rather than
manually copied into theorem claims. A finite replay does not prove the
countable/infinite quantifiers; the analytic proofs state and discharge those
under their explicit model assumptions. Nothing here is a Lean, Isabelle or
Coq proof-assistant validation, a measured hardware optimum or a new learner's
empirical superiority result.

## Run on laptop billy

From the repository checkout on the Linux verification host:

```sh
python3 -I -B research/gmi-formal-derivation-v1/verify_unit.py
python3 -I -O -B research/gmi-formal-derivation-v1/verify_unit.py
python3 -I -B research/gmi-formal-derivation-v1/verify_controls.py
```

The ordinary verifier returns 0 only after checking the source freeze, module
contracts and every finite witness. It returns 1 for a failed witness and 2
when source/schema/contracts cannot be checked. Its tests are compiled from
the inventoried source bytes, preventing reuse of timestamp-cached bytecode;
the input inventory and pre-existing freeze/binding bytes are checked again
after execution. Skips and expected
failures do not pass. `--freeze` is an explicit authoring operation and writes
new evidence only after a successful current run; it is not a repair command
for an unexplained failed replay.

The control runner uses disposable copies on the laptop. It challenges changed
theorem bytes, false Bellman selection, stale bytecode, masked failures,
concurrent source or bound-manifest mutation, malformed manifests and reset-versus-state
transport. It then replays the untouched real unit and verifies the original
payload remains unchanged. This tests the checker against the actual unit,
including its no-alarm behavior, rather than trusting its own happy-path output.
