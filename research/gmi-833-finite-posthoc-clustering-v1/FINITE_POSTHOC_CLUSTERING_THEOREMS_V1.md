# Finite post-hoc clustering theorems v1

## Scope and notation

The carrier is exactly the 576 presentations generated by PR #966 at budget
`(2,2)`, evaluated on the three protected words at step cap 6. PR #984 maps
them to 47 distinct morphology records and supplies the exact metric

`d_w = w_s d_sem + w_r d_resource + w_h d_development`

with base weights `w=(5,3,2)`, perturbed weights
`w'=(501/100,299/100,201/100)`, and the proved uniform pairwise bound
`|d_w-d_w'| <= 9/100` on this carrier.

The freeze commit is `9ae830c41eb773445b630af8303afa51ce59a083`.
It precedes all clustering implementation and result artifacts.

## ORDER-1 — post-generation clustering with complete retention

**Definition.** First generate all presentations, then evaluate all protected
observations/resources/histories, then write one immutable membership row per
presentation. Only the set of distinct completed morphology records is passed to
the clusterer. The presentation rows remain linked to their morphology and final
cluster.

**Proposition.** Clustering cannot affect generation or evaluation, and no
presentation is discarded.

**Proof.** The generator/evaluator returns a closed tuple of 576 snapshots before
the cluster function is called. The cluster function accepts only completed
morphology records and has no generator/evaluator callback. The membership
ledger is a bijection on the 576 stable presentation IDs and separately proves
that all 576 canonical program codes are unique; its cluster counts sum to 576.
Thus cluster state cannot enter the earlier functions, and every generated
presentation remains represented. QED.

## CLUSTER-1 — frozen threshold-component partition

Create an undirected graph on the 47 records with edge `{x,y}` exactly when
`d_w(x,y) <= 15/2`; clusters are connected components. A component medoid
minimizes total within-component distance, with canonical record serialization
as the tie-breaker.

**Proposition.** This procedure returns a deterministic partition of the full
47-record carrier.

**Proof.** The threshold predicate is symmetric because `d_w` is a metric. Every
vertex belongs to exactly one connected component, including isolated vertices.
Sorting carrier records, neighbours, medoid ties, and final component keys fixes
all implementation-order choices. The primary traversal is compared to an
independent union-find oracle built only from the exact distance matrix. QED.

This is one frozen operational clustering, not a natural/unique taxonomy.

## MAP-1 — causal separation and blind post-hoc exact mapping

The causal clustering module contains no mapper import and no supplied reference
label/fingerprint tokens. Only after completed clusters and medoids are returned
does a separate module load four frozen protected-evaluation fingerprints.

**Proposition.** The recovered partition and medoids are independent of the four
supplied reference-family labels and fingerprints.

**Proof.** Generation, evaluation, edges, components, aggregate costs, medoid
ties, and cluster IDs are computed in a module whose inputs are only morphology
records, metric weights, and threshold. A source-level denylist verifies that it
does not contain the mapper module name, any of the four labels, or the explicit
fallback token. The reference registry is loaded only by the subsequent mapper,
which cannot mutate frozen dataclasses returned by the clusterer. QED.

This is protocol-level blindness relative to the supplied registry. It is not a
claim of literal historical ignorance or architecture-prior-free discovery.

## UNKNOWN-1 — non-forcing total map

For a completed cluster medoid fingerprint `f`, let `R(f)` be the set of exact
matches among the four supplied references. Return the reference label only when
`|R(f)|=1`; otherwise return the machine-distinct label `UNKNOWN`.

**Proposition.** The post-hoc map is total and never forces unmatched or
ambiguous fingerprints into the known registry.

**Proof.** The three exhaustive cardinality cases are zero, one, and at least
two. The rule returns `UNKNOWN`, the unique label, and `UNKNOWN` respectively.
An unmatched hostile and a duplicated-reference ambiguity hostile replay the two
non-singleton branches. There is no distance or nearest-label branch. QED.

`UNKNOWN` means only “not uniquely equal to one of these four supplied exact
fingerprints”; it does not certify ontological novelty.

## STABLE-1 — certified remint equivariance and metric stability

**Surface-remint theorem.** Every one of the 120 certified #984 operation-token
remints decodes to the same typed program. Therefore each of 69,120 reminted
presentation checks has the same morphology record and the same component.

**Proof.** PR #984 proves record invariance under certified encode/decode
remints. Edges and components are functions only of records and metric values;
equal records induce equal metric rows. Hence candidate membership commutes with
each remint. QED.

**Perturbation theorem.** The base and perturbed metrics induce identical edges,
components, deterministic medoids, post-hoc labels, and `UNKNOWN` set.

**Proof.** The minimum base distance from any of the 1,081 unordered record pairs
to threshold `15/2` is `1/2`, while the parent uniform change bound is `9/100`.
Because `9/100 < 1/2`, no pair crosses the threshold, so the graphs and connected
components are identical.

For a component of size `n`, each candidate's aggregate cost changes by at most
`(n-1)9/100`; comparing two candidates gives the two-sided bound
`2(n-1)9/100`. Every nonminimal base aggregate cost has a strictly larger gap
than that bound. Every tied base minimizer has an identical aggregate component
vector `(sum d_sem, sum d_resource, sum d_development)`, so it stays tied under
the perturbed positive weights and the same canonical tie-break applies. Thus
every medoid is preserved. Exact medoid fingerprints then preserve every
post-hoc label and the `UNKNOWN` set. QED.

A semantics-changing decoder swap is rejected, and the out-of-bound weight
change `(6,3,2)` changes edges and the partition. Therefore the theorem is not
silently promoted to arbitrary remints or metric choices.

## Boundary

All results are exact only for the registered #966/#984 finite carrier, metric,
threshold, surface-remint group, perturbation, and four supplied post-hoc
references. They do not validate large-scale clustering, infer a universal
taxonomy, recover historical architectures, establish ontological novelty,
complete #220/#221 or #946, or imply complete GMI.
