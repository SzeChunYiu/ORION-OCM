# AB3 — stronger observations recover admission

## Complete generated raw source

Fix a labelled typed graph G and a predicate A on its edges.
Define Adm_A([] at x)=True and
Adm_A(e::w)=A(e) and Adm_A(w), on correctly typed paths.
For the singleton path [e], this definition reduces exactly to A(e).

Thus decode(S)(e)=S([e]) recovers A when S is Adm_A.
If Adm_A=Adm_B, evaluate at every singleton to obtain A=B.
Conversely A=B implies Adm_A=Adm_B by path induction:
the empty case is True and the recursive cases have identical edge tests.
This is actual V16 admitted_single, decode_admission and domain_eq_iff_admission_eq.

The graph and singleton embedding must be fixed. Swapping an edge codec without
transporting its label changes the question. There is no corresponding theorem
for an arbitrary source-membership callback. A callback may accept every singleton
but reject a legal two-edge path. Singleton extraction then remains a function,
but does not certify that the callback is the domain generated by the extracted mask.

## Three-tag admission decoder

For arbitrary history type H, admission P and actual V15 partial context k:
observe(P,k,h) is ILLEGAL if not P(h), UNDEFINED if P(h) but not E(h),
and VALUE(k(h)) if both P(h) and E(h).

If P(h), the response is UNDEFINED or VALUE, hence not ILLEGAL.
If not P(h), it is ILLEGAL. Therefore
P(h) iff observe(P,k,h) ≠ ILLEGAL.
This proof is pointwise and requires no finiteness, chosen history, inhabited
value type or choice of an evaluator value when evaluation is undefined.

For two models on the same labelled histories, equality of complete tagged
observation functions implies equality of P by this equivalence and extensionality.
More concretely, a decoder on attained tagged functions maps an observation f
to the predicate h↦(f(h)≠ILLEGAL). Composing this decoder with actual observation
returns P. The formula is explicit; an empty attained image causes no difficulty.

Consequently the AB2 pair cannot have equal full tags. At the false→true
singleton one response is ILLEGAL. The other is UNDEFINED or VALUE, according
to the fixed endpoint definedness. The distinction persists even if E is empty.

## What the active domain loses

The active domain is D=P∩E. If E=False everywhere, D is empty for every P.
Thus two different admission predicates can have the same active domain and
the same active value function. The evaluator's partiality is essential to this
particular control; if E=True everywhere, D=P and recovers admission.

Collapsing ILLEGAL and UNDEFINED to one failure tag destroys the displayed decoder.
With E empty the collapsed observation is the same constant failure function
for all P. The recovery difference is caused by the observation quotient, not by
a change in the process.

Illegal-but-defined ambient values are permitted by the actual Context storage.
They never appear in observe, because admission is checked first.
Removing such stored evaluations is unnecessary and could change the model.

## Finite certificates and exact codecs

Python recovery enumerates observation fibers using type-sensitive keys.
True, integer 1 and Fraction(1) are different external values even though Python
equality ordinarily identifies them. Nested tuple labels retain that distinction.
The actual V9 decoder has precisely the attained observation labels as its domain.

A valid certificate supplies the exact observation/target codebooks, their model
labels and an attained lookup. Verification checks codebook identity before
checking the lookup equations. No unobserved fallback value certifies recovery.

The four reverse views are intentionally computed separately. A test must never
reuse weak-state equality to certify full tagged equality, or claim complete
domain enumeration merely because the finite basis contains every singleton.
These boundaries preserve the original V16 qualified reading without broadening it.
