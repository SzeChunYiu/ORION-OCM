## 4. Judgment protocol (frozen before any judgment is recorded)

Each object's support is read from the actual artifact at its census locator (statement + proof/receipt section). Observed support kind maps to ladders as follows — this table is frozen here, derived from the v1 rubric alone:

| observed support | evidence_EV | maturity_M |
|---|---|---|
| `ANALYTIC_PROOF` (deductive argument) with explicit premises AND falsifiers | EV1 | M1 |
| `ANALYTIC_PROOF` without registered premises/falsifiers | EV0 (deductive content present; EV1's explicitness requirement unmet — recorded gap G6) | M0 |
| `MECHANIZED_PROOF` (machine-checked deductive) | EV1 | M1 |
| `EXACT_FINITE_CERTIFICATE` (exhaustive/executable checker, declared bounded universe) | EV2 | M2; M3 only if the P3/P4 prior-free condition is itself evidenced (v1 carve-out; expected count in this tranche: the `aj9*` blind-recovery family, verified individually) |
| `FROZEN_HELDOUT` (freeze artifact precedes outcome) | EV3 | M4 (never M5: intra-package ≠ independent replication, v1 rule 2) |
| `SAMPLED_STATISTICAL` / `EMPIRICAL_UNFROZEN` | rubric gap G2: the foundation ladder has no rung for unfrozen sampled evidence; it licenses no EV3 and is not exact (no EV2) → `evidence_EV="UNKNOWN"`, typed reason `UNFROZEN_SAMPLED_BELOW_EV3` | M0 |
| `PROTOCOL_ONLY` / `LEDGER_ENTRY` | EV0 | M0 |
| `NONE_FOUND` (claim asserted, support not located) | UNKNOWN, reason `SUPPORT_NOT_LOCATED` | UNKNOWN — unscored-with-reason, never guessed |

Union rule: an object with multiple support kinds takes the union EV (per v1 schema) and the M grounded by the strongest *grounding* kind; maturity never exceeds the ceiling map.

**Down-generation and verification (frozen):** prior standing for Gap 1 = census GREEN disposition + object class + census quantifier/proof-mode (no legacy package carries a foundation-ladder maturity claim — verified by sweep; the `M0..M5` tokens in `machine-intelligence-morphogenesis-v1` matrix/ledger files are REFERENCE-ROW names, a recorded terminology collision, gap G4 — never maturity levels). A score is DOWN-generating iff it changes that standing (object class THEOREM/LAW/COROLLARY/PROPOSITION placed below M1, or EV below the census's registered proof mode). **Every DOWN-generating score is individually verified by reading the object's statement and its proof/receipt** — no mechanical downgrades. MAINTAINS scores may be pre-clustered mechanically (same support kind + same package file cluster) and spot-verified at ≥10% per cluster (rate printed in the receipt). Conservative default everywhere: insufficient evidence → unscored-with-reason, never a guess.

**Quantifier overreach:** a UNIVERSAL claim on non-deductive support is recorded per object as `claim_evidence_gap: QUANTIFIER_EXCEEDS_EVIDENCE` (feeds §8 delta); it does not by itself move M/EV (which are receipt-grounded) and is cross-handed to the Section-B adjudication lane (`gmi-833-corpus-audit-close-v1`), which owns overstrong adjudication.
