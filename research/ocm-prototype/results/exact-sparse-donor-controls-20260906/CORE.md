## Implementation

ADAPT the current pre-gating structural denominators, conjunctive tail gates,
edge/destination gates, normalized head weights and additive incidence mechanics.
ADOPT SymPy 1.14.0 `DomainMatrix.from_dod` over QQ and `solve_den(method="rref")`.
No custom elimination, float arithmetic, dense candidate assembly or cross-call cache.
Each of the four current logical channels independently solves its full system.

The candidate verifies the donor algebraic identity, converts every coordinate to
an exact Fraction, then checks an exact residual using the original Fraction kernel.
That independent checker deliberately constructs a dense matrix and is required
candidate work. The current reference retains its behavior without an added residual.
No sparse runtime or active-k complexity claim follows from this implementation.
Transient RREF fill and bit growth remain unmeasured.

Callable relevance and supplied NavigationMatrix inputs immediately use the original
fixed_point function without extra evaluation or checking. Nonrational alpha also
uses that path. Candidate imports are lazy: a fresh reference-only process was
checked to complete without importing SymPy.
