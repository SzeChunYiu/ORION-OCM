# Adapter and operating contract
Base is exact main 1a6c99bd; later repository integration is not reexecution.
Two additive modules reuse existing clia_grammar forms/validate/dump, sexpdata,
clia_tasks' explicit grammar and the unchanged native Z3 verify boundary.

## APIs
- generation_clia.encode(candidate, signatures): host validation, simultaneous
  non-shadowing let elimination, fixed original formal order, de Bruijn lambdas.
- admit_macros(records): first-order, parameterized arity 1–2, Int/Bool sort
  inference, earlier admitted macro expansion, no free variables/recursion,
  and host validation of arbitrary-hole coefficient safety.
- decode(program, name, signatures, library): exact symbolic outer binders,
  capture-free expansion; final primitive host validation remains mandatory.
- equivalent(left, right, signatures): unchanged clia_process verify/Z3;
  counterexample is FAIL and unknown is CANNOT_CHECK.
- request(task, library): original fixed public constraints/signature and all
  primitive grammar alternatives plus a singleton GEN_fn_N nonterminal for
  each typed macro. The extra grammar structure may affect search size/order.
  Give identical donor grammar/check powers to the adaptive conventional parent.
- generation_stitch.induce(experiences): UNEXECUTED single fixed compress call,
  at least two distinct source-bound public tasks, native checks before input,
  preserved donor JSON and explicit admission/refusal. A proposed abstraction
  is not later use, protection, causal benefit or runtime authority.
- assess(result, prepared): keeps raw donor output and partial check receipts on
  refusal; returned data are JSON serializable. Rebuild Macro values through
  admit_macros with name/body/arity=len(sorts), never treat raw descriptors as
  authority. No persistence/controller framework was added.
- search_request(task, library, route): explicit submitted bytes/hash for
  implicit_primitive, explicit_primitive or explicit_macro. It does not synthesize.

```sh
env PYTHONPATH=src PYTHONDONTWRITEBYTECODE=1 PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest research/ocm-prototype/generation_tests -q
```

was modified. This command runs manual checks only, including fixed-Z3 checks.
