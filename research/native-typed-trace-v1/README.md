# Typed native trace seam

Read [CONTRACT.md](CONTRACT.md) first. This is a research-only structural interface,
separate from the installed OCM package and the class-only serving module.

The first tranche implements explicit three-parameter contexts, stack reconstruction,
all-proper-root extraction, exact recipe emission and ordinary one-step alias checks.
It does not implement support grouping, native admission, persistence or fresh-B
reconstruction. Those require a separately reviewed concrete fixture and lifecycle.

Pure fixtures are synthetic proof graphs. Their NATIVE_VERIFIED marker is input to
a structural checker, not a native acceptance receipt. No native verifier runs here.
The typed_alias.classify eligibility means only nonalias eligibility within its declared
ground domain; it never admits a method. UNKNOWN stays distinct from ALIAS.

The wff alias domain exposes the donor Boolean expression parser with its original
token/depth accounting; only the source-assertion root restriction is omitted.
the class domain uses the previous class syntax parser. Composite/repeated ordinary
substitutions are allowed. Learned recipe reconstruction uses explicit atomic bindings.
The current native context must also match the supplied floating contracts exactly.

Source ancestry is recorded in TRANSPLANT.json. Historical class/native receipts are
provenance only; this successor has no inherited native outcome authority.
