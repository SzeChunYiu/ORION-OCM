# V24 — falsifiers and exact boundaries

These are mathematical controls and registered test requirements. Actual execution
counts and pass/fail evidence belong to RESULT_V24.json and the independent reviews.

## Selected profiles and erased identity

A start with a self-loop has the empty selected record, while the full horizon-one
image also contains a one-step history. Terminal and capability agree; length,
history and possibly provenance do not. A horizon shorter than the shortest path
to a terminal need not preserve even terminal/capability images.

Two parallel edges bearing one action label can reach the same terminal. Their
stable edge histories differ while their old action words/profiles agree. The old
action-keyed provenance is shared. Attributing different tags to these edges under
one key, or claiming unique inversion, changes the source contract.

An absent outgoing slot followed by a present slot retains the latter original
ordinal. Reindexing present edges changes full-history identity. Reordering actual
adjacency can change selected histories at equal depth; it is not a semantic no-op
for the complete selected profile even when terminal reachability is unchanged.
Repeating an observation-tagged action gives presence1, not observation count2.

For terminal-factorization, coverage must use active histories. An inadmissible
or undefined selected representative cannot supply an attained value. Conversely,
equality after a coarse projection does not imply equality of complete images.

## Preferences, positivity and identity

Vectors(0,0) and(0,0) attached to different IDs both belong to every declared
positive-price argmin and the Pareto frontier. Keeping only one tie loses the
old correspondence. Vectors(0,1),(1,0) have coordinatewise infimum(0,0), which is
not an attained candidate. It cannot replace the frontier.

With weights(1,0), vectors(0,0),(0,1) tie although the latter is dominated.
With weights(1,-1), the dominated latter is strictly preferred. Strictly positive
weights are sufficient for every scalar winner to be Pareto efficient; this does
not make every Pareto point a positive-price winner. An unreachable cheap option
must disappear when reachable_only is true and remain eligible otherwise if viable.

A zero-dimensional abstract vector order is lawful, and negative coordinates can
be ordered. Neither is an allowed old resource declaration. The new parser rejects
bool/int aliases for Fraction, malformed unused weights, non-Boolean flags,
duplicate IDs and empty dimension even when no candidate is active. Old functions'
early empty-input returns do not establish the same validation contract.

## Plans and quantifiers

Three feasible sets{a,b},{b,c},{a,c} are pairwise compatible but not jointly so.
Two histories admitting only a and only b can each have loss image{0}, with no
common plan. Loss images erase a necessary witness identity in this example.

Empty history family means all declared plans, not an unguarded larger codomain.
Empty plan universe then makes compatibility false. Injective image transport
retains q(U); omitting it gives an erroneous empty-intersection equality.
Partial-loss and feasibility-in-admission presentations may give the same feasible
sets while disagreeing on illegal/undefined observations. Only set transport is
asserted between those presentations. Original total loss is a stated specialization.

## Evidence and source boundaries

Frozen primary strata are exhaustive only over their declared finite domains.
The separate64-case seeded AF review supplements them without enlarging those
counts. General image/intersection proofs do not certify the Python BFS queue,
its serialization, or every historical theorem sharing a symbol.

Adequate-output Gamma retains its task/adequacy/setup-cost contract elsewhere.
The executable conditional SEL opcode remains a three-argument conditional.
AI0 selection remains an interface supplied with data, uncertainty and preferences;
no unique tie rule, universal prior, objective or causal provenance is inferred.
