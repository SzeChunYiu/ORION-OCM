Externally originated; none generated by this package or by any agent. Every
number in every claim traces to these bytes.

  104,334 whitespace-separated tokens
  (`len(open(path).read().split())`, the exact arithmetic definition of `N`),
  in file order; sha256 digest of the file bytes
  `9e66281f7e51445eab6857488ff6e3d768afffadb7fb1adbef5e4617bee4a53b`.

Host of record: `billy-old`, Linux, CPython 3.14.4. Any digest mismatch fails
the run closed. A negative control asserts that a perturbed path or a perturbed
digest fails rather than passing vacuously.

Two degeneracy screens are registered here because they bound the evidence
channel before it is built:

- the source has **no duplicate lines** (`sort D | uniq -d` is empty; 104,334
  lines, 104,334 distinct tokens), so **raw token frequency is exactly 1 for
  every hypothesis and is a vacuous evidence channel**; it is excluded by
  registration and by the screen;
- the modal token length is **8** (the length histogram peaks at 16446 tokens of
  length 8, against 15459 of length 7 and 15020 of length 9), which fixes the
  registered threshold `T* = 8` below.

### The ecology, registered before it is built

`F17` (`SIGMA_H17R`). Tokenise `D` into its 104,334 whitespace-separated
tokens. The **presentation unit** is the descriptor closure: for every token
`w`, all prefixes of `w` of length ≥ 2, in source order. The exact total is

```
T = sum(len(w) - 1 for w in words) = 776,142 positions
```

A task is a closure position whose descriptor `q` is a **context**. The stored
table is **set-valued**: the hypotheses of `q` are the whole source words `w`
that have `q` as a **proper prefix** (`len(q) < len(w)`). Unlike the sibling
ecologies, the hypothesis set is **not a prefix tree** — each hypothesis is a
whole word, and the same word is a hypothesis of every one of its prefixes.

The **evidence weight** of a hypothesis `w` is its length, `len(w)`. This is
fan-out-independent by registration: the completion-length multiset of a
context is not a function of the number of completions of that context,
whereas the descriptor-count channel of the sibling ecologies is exactly such a
function. The registered degeneracy screens above exclude the vacuous
frequency channel and fix the threshold.

For a context `q` with completions `C(q) = {w : q proper prefix of w}`,

```
EXT(q) = |C(q)|                  the number of stored hypotheses
SUM(q) = sum of len(w) over C(q) the accumulated evidence
MAX(q) = max of len(w) over C(q) the largest single body of evidence
```

The protected interface is the **two-evidence posterior** of this row's
registered `PAIR_CONJUNCTION` contract — the posterior decision that turns on
two evidence coordinates at once, not on one accumulated quantity:

```
y(q) = 0                                        if |C(q)| < 2   (tie)
y(q) = 1  iff  2*MAX(q) > SUM(q)  AND  MAX(q) >= T*
y(q) = 0  otherwise
```

with `T* = 8` fixed **before any fit** as the modal source-token length of the
bound source — a property of the bytes, carrying no free parameter. The first
clause is the posterior clause (the top hypothesis holds more than half of
the accumulated evidence); the second is the pair clause (and that hypothesis
clears the registered evidence threshold). A context with fewer than two
hypotheses is a **tie** and takes `0`: a two-evidence posterior is undefined
there, and the label does not pretend otherwise.

Slices, fixed here before any fit: the closure positions are partitioned by the
registered deterministic 7:1 rule (see `FREEZE_V1_SLICE_ADDENDUM_H17_V1.md` for
the exact arithmetic form), giving

```
n_fit = (T * 7) // 8 = 679,124  >= 100k
n_held = T - n_fit = 97,018    >= 20k
```

which clears the R11 real-scale bar (n_fit ≥ 100k / n_held ≥ 20k on a
sha256-bound external REAL source, exact arithmetic, independent oracle).

## 5. Grammar

`G_BS`: a family-blind grammar derived ONLY from the sha-bound bytes of `D`.
Descriptor closure over the token vocabulary (prefixes of length ≥ 2), the
set-valued word-hypothesis table, the three evidence aggregates above, and a
charged-cost model over stored-table size and scan cost. No family-level macro,
no hand-encoded belief-update routine, no reference to any external
implementation. Section R03 asserts the grammar contains no
Bayesian/belief-update macro, and R04 attempts the family-blind recovery from
the grammar alone.

## 9. Falsifiers

The claim of this package is a boundary, so its falsifiers are the ways the
boundary could be shown NOT to hold, all of them registered with numerical
form so they cannot be read after the fact:

1. the winning arm's held error count **strictly exceeds** the fit-majority
   rule's held error count (the constant-arm comparison of the boundary);
2. the best weighted-evidence arm's held error count is **not worse** than the
   best raw stored-count arm's (which would make the boundary an artefact of the
   readout language rather than of the label);
3. the label's **full-source optimum** — the best achievable decision error
   over the label, with the store set equal to the whole source — **does not**
   exceed half the held majority count, which **refutes** the claim that F1 is
   structurally unsatisfiable at this label. This falsifier fired: the
   full-source optimum is `0` against a half-majority of `5,049`, so the
   F1-unsatisfiability claim of this package's first draft is refuted. The
   refuted claim, the measurement that refutes it and the corrected claim it is
   replaced by are recorded in `CORRECTED_CLAIM_V1.md`, which is committed with
   this package and whose digest is pinned in `MANIFEST_V1.json`. The boundary
   this package reports is the corrected one, stated here verbatim so no reader

## 10. Controls

Matched negative control (`R05`): the **weight reassignment design null**
redistributes each stored hypothesis's evidence weight across the whole stored
hypothesis set — a different query's completion multiset supplies the weight —
so the per-context evidence aggregates genuinely change. The raw count arms
(`CNT>=1`, `EXT>=2`) are required to be **bit-identical** under the reassignment;
if they move, the null is not matched. The **equal-weight control** runs the
same language on a store where every hypothesis contributes weight 1. A
shuffled-label null on the winning arm's unchanged predictions is reported for
completeness. The screen asserts `CLEAN` only when the no-alarm case also fires
(the checker's own controls are asserted to fire).

## 12. Why the amendment is not ecology iteration

The original sibling ecology `F15` — the prefix-tree descriptor closure with
evidence mass over the continuation closure — was measured first and is filed
in-package as the earned boundary `F15-B1`
(`F15_EARNED_BOUNDARY_V1.md`). Its obstruction is proven, not inferred: the
registered evidence weight is a deterministic function of the descriptor, so
the continuation count is a deterministic function of the structural weights
and the registered weight-shuffle null cannot destroy the label alignment (the
raw arms are bit-identical under the shuffle, and the weighted winner degrades
by 2.07×, short of the registered 3× bar).

The amended ecology `F17` is registered **in this freeze and its slice
addendum, committed before any measurement of it exists**, with the `F15`
result as its written justification — the K05 pattern already on `main`
(`FREEZE_V1_SLICE_ADDENDUM_K05_V1.md` plus a lower-bound proof committed alone
before its implementation, with the measured in-protocol boundary as the
registered justification). The amended ecology is therefore not a search over
ecologies until something passes: it is one registered amendment, whose
justification is a proven obstruction, measured once, and reported at whatever
strength it delivers — which is a boundary, and is reported as one.
