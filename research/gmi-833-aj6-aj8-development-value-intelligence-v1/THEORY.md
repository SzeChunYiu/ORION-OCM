# AJ6–AJ8 — development, value provenance, and first intelligence layer

This package consumes AJ1–AJ5 and #233/HSG. It does not create a peer theory. It locates HSG above the process-organization layer, keeps requirements/value on an independent provenance branch, and stress-tests the first layer at which an intelligence predicate can be stated.

## AJ6 — attach HSG to process organizations

#233 defines the developmental search-generating state

`Σ_t = (L_t, Q_t, H_t, E_t, R_t, V_t, C)`.

AJ6 supplies the lower attachment:

`Σ^S_t = (S, O_S, M_t ; L_t, Q_t, H_t, E_t, R_t, V_t, C)`

where `M_t` is an AJ4 process organization and `S/O_S` supply substrate-relative process admissibility.

The key repair is:

`A_t = Legal(L_t,Q_t,H_t,C) ∩ Adm_S(O_S)`.

A syntactically legal proposal is therefore not silently treated as physically/computationally realizable. The HSG theorems that quantify over legal strategy sets survive only after this admissibility intersection is made explicit.

Development is a higher-order transformation over the organization plus its search/development context:

`D_t : Σ^S_t -> Σ^S_{t+1}`.

Registered transformation roles map as follows:

- inherited capital / library formation: change `H_t`;
- operator invention / recursive grammar growth: change `L_t` and normally `H_t`;
- representation change: change `L_t` plus a semantics/resource translation record;
- proposal/search-law change: change `Q_t`;
- resource-policy change: change `R_t`;
- verifier/governance change: change `V_t/C` only under the separately governed authority contract;
- machine self-change: change `M_t` only after the registered proposal/verification/adoption path.

HSG anti-finality, NFL, Rice/halting, Gödel and Blum boundaries remain at their parent scopes. AJ6 does not re-prove or rename them. The lower process layer adds the explicit `S/Adm_S` premise and forbids treating grammar legality as realizability.

## AJ7 — objective/value is an independent provenance branch

Let world/process dynamics be `P(s'|s,a)`. Nothing in those dynamics alone chooses a unique requirement functional.

Register source-tagged requirement provenance:

`Π_Q = (Ω, r_internal, B_external, C_social, A_aggregate)`

where:

- `Ω`: distal viability/selection pressure;
- `r_internal`: internal reward/drive;
- `B_external`: external scientific/user behavioral specification;
- `C_social`: social/institutional constraints;
- `A_aggregate`: declared rule yielding the effective downstream requirement family `Q`.

The same dynamics can support incompatible `Q`. A one-state/two-action world has identical transitions for both actions; `Q0` rewards `a0`, while `Q1` rewards `a1`. Their optimal policies are opposite. Hence

`world dynamics != unique normative objective`.

The checker also preserves reward non-identifiability: one observed optimal policy is consistent with multiple distinct reward tables. This is parent territory of decision theory / IRL reward identifiability, not GMI novelty.

## AJ8 — where intelligence can first appear

AJ1–AJ5 need contain no intelligence at all. They provide processes, operational distinctions, organizations and presentations.

The registered candidate relational criterion is:

> An MI-control organization is a resource-bounded process organization that uses accessible distinctions so that collapsing those distinctions would reduce attainable verified capability for a registered requirement family.

A stronger developmental class additionally has a response law capable of changing organization/search/representation so as to alter future attainable capability or discovery burden.

This package therefore separates:

- `MI_CONTROL_AT_SCOPE`: fixed or adaptive control can exploit consequential distinctions;
- `MI_DEVELOPMENTAL_AT_SCOPE`: development additionally changes future capability/search response.

Development is **not required** for the weaker class: a frozen but broadly capable controller can satisfy demanding registered tasks. Development is required only for claims about developmental intelligence/evolvability.

### Same-substrate negative controls

All controls use the same binary lower process substrate.

- fixed lookup/identity controller: can be highly capable on its matching task but has no developmental response;
- universal-interpreter-like executor with externally supplied program but no selector: computational expressivity alone does not identify autonomous task competence;
- passive memory: stores distinctions but does not exploit them for the requirement;
- random dynamics: creates entropy/novelty without target alignment;
- constant reactive policy: acts but ignores a distinction whose collapse matters for the task.

These controls separate computation, storage, randomness, universality and capability from the stronger developmental notion.

### Current capability does not identify developmental potential

Two systems can have identical current capability and different future response laws; conversely different current capability can collapse to the same post-update developmental state. Therefore current capability is neither a sufficient nor a necessary identifier of developmental potential.

### Information acquisition != computational unfolding

If target-relevant information is already present in initial organization/state, extra computation can make it accessible without any new exogenous information. Conversely, an independent random bit can add one bit of entropy while adding zero mutual information about an independent target. AJ8 therefore keeps information acquisition, accessibility gain, novelty and target-aligned capability machine-distinct.

## Parent ownership

- #233/HSG owns developmental search geometry and its theorem/limit programme.
- decision theory / inverse reinforcement learning own objective/reward non-identifiability parents.
- bounded rationality, value of information and statistical decision theory own much of resource-relative decision competence.
- computational universality theory owns universality; universality is not promoted to intelligence.

AJ6–AJ8 contribute the attachment of those parents to the AJ operational derivation spine, the explicit substrate-admissibility repair, typed requirement provenance, same-substrate negatives, and the control/developmental intelligence-class separation.
