# AJ12 — foundation/formalization and physical-substrate relativity

## Assumption classes

Every lowest-layer claim must expose at least these distinct assumption sources when applicable:

- `MATHEMATICAL_FOUNDATION`: objects/equality/constructions used to state the finite mathematics;
- `LOGIC/METATHEORY`: reasoning rules and metalanguage used to prove statements about the object theory;
- `PHYSICAL_SUBSTRATE_LAW`: which mathematical processes are physically/computationally admissible;
- `RESOURCE_MODEL`: what time/space/energy/precision/etc. are charged;
- `VALUE/REQUIREMENT_INPUT`: what outcomes count as successful or preferred.

None is silently renamed an intelligence primitive.

## Invariance across two formalization styles

The executable microscope expresses the same finite process core twice:

1. finite sets and functional relations;
2. explicit typed objects and typed process records.

A semantics-preserving translation maps every registered function to its graph relation / typed table. All 16 ordered compositions agree. Identity laws agree. Three preparations evaluated by two registered tests produce the same response signatures and the same operational quotient `{{p0,p2},{p1}}`.

This is theorem invariance at the registered finite core, not merely typographic translation. It also does **not** prove metatheoretic equivalence of ZFC and type theory. Set theory and type theory are both established foundational programmes; the point here is that the GMI result does not rely on one presentation of the finite objects.

## Computational/physical substrate relativity

Standard effective computation is the registered baseline. If an alternative model is granted an oracle/advice stream, that access is recorded as `IMPORTED_ORACLE_OR_ADVICE_POWER`.

Likewise, an exact real parameter can encode advice. The finite witness encodes `1011` as ternary digits of `62/81`; exact ternary-digit access recovers those bits. At unbounded precision, the same construction can encode an arbitrary set in a real expansion. The extra information is therefore not credited to intelligence generated from nothing. Literature on real-weight recurrent networks explicitly relates some real-weight interactive models to Turing machines with advice/nonuniform power.

Whether any genuinely super-Turing mathematical idealization is physically usable is separate. Physical Church–Turing theses are physical claims, and proposed hypercomputation must satisfy input/output/reliability/precision constraints. AJ12 therefore records physical hypercomputation as empirical/open, not established.

## Metatheory boundary

Gödel incompleteness limits sufficiently expressive consistent effective formal systems; Tarski-style truth theory requires an object-language/metalanguage distinction for sufficiently expressive languages. These boundaries prevent promotion to a finite all-truth, self-justifying final foundation.

## Parent ownership

Set-theoretic, type-theoretic and categorical/structural foundations; computability/relative computability; advice/nonuniform computation; analog/real computation; Gödel and Tarski remain parent mathematics/philosophy of mathematics.

## Claim ceiling

`AJ12_FOUNDATION_STYLE_AND_COMPUTATIONAL_SUBSTRATE_RELATIVITY_AUDITED_AT_REGISTERED_CORE_SCOPE`

Forbidden: unique true foundation proved, physical hypercomputation proved, super-Turing power from nothing, or a self-justifying all-truth foundation.
