# Language as the first Machine Epistemics lifetime-learning experiment

Steering: #52  
Execution: #43 → #44 → #45  
Cross-domain thesis: #50  
Theory companion: `SzeChunYiu/ORION-V2#361`

## Scientific target

The language programme should test a stronger claim than “OCM can chat.” The target is:

```text
minimal linguistic substrate
→ learned listener/speaker
→ better language learner
```

The time-zero machine may contain language-general identity, evidence, warrant, dependency, operator, persistence and learning machinery, plus only the smallest representation/composition primitives required to make acquisition possible. English competence is presumptively learned state.

## Bootstrap accounting

Before protected language acquisition, freeze a manifest of every language-specific prior:

```text
lexemes/senses
morphology
constructions/templates
word-order assumptions
semantic-role mappings
parse/realization procedures
dialogue-act inventory
reference/pronoun policies
clarification procedures
explanation/discourse schemas
style/register rules
hand-authored teaching examples
```

Every retained item is charged as prior information. A reduced-bootstrap ablation and a conflicting artificial/non-English language hostile are required. If protected capability is largely encoded in the bootstrap, the correct terminal is `BOOTSTRAP_PRIOR_DOMINATES`.

## Lifetime curriculum

A prospective curriculum should cover:

```text
simple meanings
→ words/senses
→ morphology
→ simple constructions
→ modifiers/relations
→ questions
→ negation/modality
→ reference/pronouns
→ clarification/correction
→ multi-turn discourse
→ explanations
→ unfamiliar related families
→ unrelated/artificial-language family
→ harmful-transfer traps
```

Use multiple frozen order permutations. One favorable curriculum cannot define the result.

## Measurements

At every acquisition stage record:

```text
LanguageCapability(t)
CumulativeNewInformation(t)
CumulativeResourceVector(t)
PersistentState N(t)
ActiveTouchedState k(t), when instrumented
new linguistic object/operator identities
reused identities + execution witnesses
retention
negative transfer
revision cone
protected compositional outcome
```

A family’s acquisition cost ends at the first attainment of a frozen competence threshold. The threshold must include held-out combinations, not merely held-out strings.

## Compositionality requirement

Reusable linguistic competence is stronger than example memorization. Protected suites must include:

- unseen lexical fillers in known constructions;
- unseen combinations of separately learned constructions;
- held-out construction families taught only after system freeze;
- paraphrastic realization of meanings not seen as whole utterances;
- artificial/non-English structures that conflict with English defaults.

Whole-trace retrieval or fixed template substitution does not establish compositional language learning.

## Learning-to-learn hypothesis

For registered related families `F_j`, test prospectively whether:

```text
C_acquire(F_j | K_t) < C_acquire(F_j | K_0)
```

as reusable linguistic structure accumulates.

A descriptive sequence such as `100 → 30 → 10 → 3` examples is scientifically interesting only after controlling family difficulty, task order, supervision, prior information and strongest persistent parents.

The stronger **language meta-learning** claim requires evidence that an acquired strategy for learning language reduces later acquisition cost, not merely that a previously learned construction is reused.

## Strongest parents

At minimum subtract:

- reset-between-families OCM;
- persistent exemplar/retrieval memory;
- persistent grammar/construction/skill library;
- conventional grammar induction;
- continual neural adaptation where matched custody/compute permits;
- OCM with fixed parse/realization templates;
- open-weight LM as a non-matched reference unless true parity exists.

If these parents explain the curve under matched information/resources, use `PARENT_SUFFICIENT`.

## Local revision

Correct or revoke learned lexical senses, constructions, reference conventions and acquisition strategies. Require exact dependent reopening, unrelated retention and exact restoration after alternate support/relearning.

## Relationship to the cross-domain paper

Language becomes the first concrete Figure A/E domain for #50. The intended programme story is:

```text
learn how to communicate
→ learn reusable solving methods
→ learn reusable investigative methods
→ test whether marginal learning cost falls as governed competence accumulates
```

The strongest defensible language statement is therefore conditional:

> Starting from a minimal persistent cognitive substrate, the machine incrementally acquired executable linguistic competence, generalized it compositionally, revised it locally under correction, and—if the protected matched evidence supports it—reduced the cost of acquiring later related linguistic competence.
