# R10 — information, prediction, causality and control are distinct derived relations

Grand GMI does not use "structure" as a primitive scalar. Structure is always relative to a context, allowed observations/processes, future questions and resource budget.

Exact registered separations:
1. biased iid source: nonuniform marginals without temporal dependence;
2. dependent observations can remain irrelevant to an independent target;
3. a variable may perfectly predict an outcome while an action has no causal effect on that outcome;
4. a controllable variable can be irrelevant when utility ignores it;
5. compressible nuisance structure can be useless for the target;
6. information can exist in (observation,key) while observation alone is independent of the target, giving a finite accessibility separation;
7. if target Y is independent uniform binary under allowed history H, every deterministic predictor has accuracy 1/2;
8. a uniform bit has a two-point rate/distortion frontier: retain (resource 1, distortion 0) or forget (resource 0, distortion 1/2);
9. MDL preference depends on the registered coding language;
10. task-irrelevant Z should be forgotten under current-task memory cost, but can become worth retaining under future task uncertainty;
11. concept drift can reverse a perfect historical predictor;
12. observationally identical causal models can separate under intervention.

Sufficient statistics, predictive-state representations, causal states/computational mechanics, information bottleneck, rate-distortion, MDL, PAC-Bayes, causal inference and bounded-rational control remain parent mathematics.

True Kolmogorov complexity is not computable in general; GMI may use declared computable surrogates only.
