# R1-S1 — typed process paths, with category as a derived normal form

R1 V1 is retained as historical evidence. Its useful conclusion survives, but its primitive accounting was too presentation-dependent.

## Requirement-bearing process-side content

At the declared universal scope, the process branch needs:

1. **typed interfaces/configurations**, so boundary compatibility can be stated;
2. **substrate-admitted process steps/transformations**, so there is nontrivial transformation content;
3. **finite typed path formation**, so multi-step histories can be formed.

A path presentation includes the empty path at each interface and concatenates endpoint-compatible paths.

From these definitions:

- the empty path acts as a left/right unit;
- path concatenation is associative;
- multi-step reachability is derived.

These are mathematical laws of the path construction, not six independent ontological primitives.

## Identity boundary

The categorical identity represents the zero-length compositional unit. R1-S1 does **not** assert that every physical substrate admits a distinct positive-duration operation that literally leaves every relevant degree of freedom unchanged.

If a richer substrate has a physical waiting/stasis process, that is an ordinary admitted process and need not be identified with the categorical empty-history unit.

## Category boundary

An ordinary category remains a convenient canonical normal form when the substrate exposes composed extensional processes and equality/composition laws.

It is not proved to be the unique weakest encoding. A typed graph/free-path presentation, a partial-composition presentation, or a category presentation may encode the same registered reachability/history semantics with different primitive signatures.

Therefore the fixed-point claim concerns **typed composable process/history content**, not uniqueness of categorical syntax.

## Removal witnesses

- Remove typing: the finite hostile accepts the illegal sequence `f;f`.
- Remove the nontrivial step `f:A->B`: the registered A-to-B transformation disappears.
- Remove sequencing beyond one step: the registered A-to-D history `f;g;h` disappears.

By contrast, deleting identity/associativity as independent declarations does not destroy the path model because the empty path and list concatenation derive their laws.

## Optional richer process structures

Parallel/tensor composition, symmetry/braiding, stochastic kernels, nondeterministic branching, higher transformations and explicit ambient admissibility predicates remain optional enrichments or alternative presentations. Their mathematics is parent-owned.

A deterministic sequential path model is already a valid instance of the common GMI process branch; therefore those richer structures cannot be universally required by the current common-core requirements.
