# G2.5 utility-gated parent v2

**v1 frozen:** `research/g2-strong-parents-v1/` terminal `HARMFUL_TRANSFER_LIMIT`.
Frequency-ranked `inc → double` increased test attempts 9145 → 12410. That
capsule is not retuned.

**Root cause:** candidate admission used train-fragment *frequency*, which is
not search utility. A high-support infix can expand the token grammar and
lengthen BFS on held-out identities.

**v2 mechanism:** mine the same fragment class, then admit a macro only if a
**disjoint validation** aggregate is strictly below the primitive index.
Otherwise admit nothing. Frequency's winner is recorded and not deployed when
it fails the gate.

New salts; v1 populations untouched. Not a new G2.4 claim.

**v2 terminal:** `UTILITY_GATED_LIBRARY_BEATS_PRIMITIVE`.
On this population frequency `square → inc` already beat primitive (14969 vs
16407), but the validation gate admitted `double → square → inc` and cut test
attempts further to 13230. The frequency winner was not deployed. Gated
library is not worse than primitive.
